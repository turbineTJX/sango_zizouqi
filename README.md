# 三国 · 君临

《三国君主策略手游总体需求说明 V0.1》的可运行玩法原型。电脑浏览器可直接验证，界面适配手机窄屏；当前交付为 Web 原型，尚未打包成 Android / iOS 安装包。

## 在电脑上运行

需要 Node.js 20 或更高版本，不需要安装任何依赖。

Windows 双击 `start-game.cmd`，自动启动并打开浏览器。关闭终端窗口会停止本地服务；再次双击即可启动。

也可在项目目录执行：

```sh
npm start
```

然后打开 <http://127.0.0.1:4173>。服务仅监听本机。若端口被占用，可在 PowerShell 中先执行 `$env:PORT = '4174'`，再执行 `npm start`。

所有字体、地图、图标、代码和游戏规则均在本地，无 CDN、外部 API、登录或联网 AI。首次完整打开后，Service Worker 会缓存游戏资源，浏览器支持缓存且未清理站点数据时可离线重新打开。稳定使用建议保留本地服务；请勿通过 `file://` 直接打开 HTML。

## 五分钟验证流程

1. 初始驻地为许昌。打开「军团」，查看 8 名武将，调整首发、兵种、前中后排或两翼位置、主副将、军师和整体策略。
2. 在编制中点击武将名字查看部队属性，展开卡片可查看兵种基础、武将贡献与军团加成。点击地图「官渡」→「出征此地」→「结束回合」。军团行进一条道路后触发遭遇。
3. 可通过「战前战法配置」为每队混配 3 个武力 / 智力战法并调整优先级，也可再次进行战前编制，然后「进入战场」。在左侧绿色区域点击武将再点击格子，或直接拖拽；点击另一支己方部队可交换位置。完成后点击「确认布阵 · 开战」，双方自动寻路、攻击、释放战法。开战后暂停也不能改变位置。
4. 战斗中点击棋子或「部队属性 · 状态详情」自动暂停并查看双方属性、伤兵和各层护盾。暂停后在进攻、整军、扰敌分类中选择主将与军师解锁的军略，观察攻击 / 防御、战意、净化、冷却缩减、移动、断援和预备队护盾等效果。
5. 战斗结束查看战报，返回地图确认兵力、伤兵、士气和官渡归属。征兵休整后继续征战。

战斗支持暂停、0.5× / 1× / 2× / 4× 速度。同步参考武将属性后，默认官渡对局在 1× 下约 1～2.8 分钟，持续参战部队有时间完成多次战法；兵力差距、编制、策略和军略会改变时长。焦点未停留在输入控件或按钮上时，空格可切换暂停。刷新或读取存档后，战斗默认暂停。

战法满足战意门槛、冷却和目标条件后，在当前模拟步立即生效。自动战斗中，施放战法会短暂停住后续模拟步：压暗战场、突出施法者与战法名，再播放冲锋、火计、震波等命中特效，结束后自动继续。每次演出在 1× 下约 0.96 秒，4× 下仍保留 0.64 秒；同一战法的多目标、多段命中合并播放，同步发动的不同战法依次展示。演出期间移动、普攻、战意和冷却均不推进，不改变伤害数值或战斗结算顺序。手动暂停或切到后台会冻结演出，继续后接着播放；暂停单步与读取存档不补播历史演出。减少动态效果偏好下改为短暂静态高亮。默认「特效：清晰」收敛普通攻击的轨迹与伤害数字，两种模式均保留战法演出。右上角齿轮菜单可切换「特效：完整」，模式选择在浏览器中保存。点击底部「战法记录」展开记录，敌我各保留最近两条，显示步数、施法者、目标和战法；多段命中不重复刷屏。金色细条显示战意，战场态势显示共享战意，以及三个战法各自的门槛、冷却和施放状态。命中特效与伤害数字在单位离场后仍能完整播放，最后一击演出结束才进入战报。

战斗页以全屏战场为主，保留双方兵力、暂停、速度和底部军略条。「战况」「战法记录」及右上角工具菜单默认收起，点开查看。军略满条后按钮持续金色高亮并缓慢呼吸，直到施放；点击军略条会暂停并展开军略选项，施放后面板收起，进度归零。减少动态效果偏好会停用呼吸动画，保留金色提示。

战场使用尖顶六边形，奇数行右移半格；移动、射程、邻接被动、范围技能、冲锋、击退和布阵共用六边形坐标规则。当前规则版本存档保留原坐标，读取后按六边形继续战斗；相同种子在旧方格与新六边形下的战果可能不同。窄屏可横向滑动战场。

## 战役试炼

点击地图右上角「战役试炼」或侧栏「试炼」，直接进入布阵，无需行军。提供六个固定架空测试战役和一个自由选将试炼：正面野战、四队精兵对十二队敌军、敌军三批增援、攻城、守城、双方预备轮换。兵力、等级、批次数量、到达步数与目标显示在战役卡片中；用于机制测试，胜负取决于配置和操作。

试炼可配置随机种子；右上角齿轮菜单提供单步、推进 10 步、同种子重开和切换战役。试炼使用独立存档 `sango-battle-lab-v1`，刷新后暂停恢复；「返回天下」恢复原战略进度。切换或重开会重置当前试炼，战法和布阵也恢复预设。

敌军援军到达后进入预备序列，有空位才补入，仍受每方六队上限和「烽火断援」限制。尚未抵达的部队仍算可战兵力，不会提前判胜；战场显示到达倒计时、待命及在场数量。

攻守城按以下规则测试：

- 守方后场增加一个独立城门单位，占一格，不占六队出场名额，不移动或攻击，也不形成横贯战场的城墙。
- 城门耐久归零，守方立即败北，守军或预备队仍在也立即结算。守军全灭而城门尚存时，攻方继续攻击城门。
- 城门参与普通攻击索敌，可用「重兵合围」提高攻击倾向。普通攻击按攻击、兵力状态和普攻间隔削减耐久；部队战法、控制、治疗不作用于城门，城门不计入兵员伤亡。
- 仅守方开场在场的六队获得护盾，预备队不获开场护盾。默认厚度为该队初始兵力的 20%，战役选择中可改为 0～100%；护盾本场不随时间消失，消耗后不自动补发。其他战法和军略仍可提供自己的护盾。
- 普通撤退规则保留。日暮仍按双方剩余可战兵力比例判定，不额外给予守方超时胜利；试炼时限为 240～480 步，详见战场倒计时。

## 武将等级与被动技能

武将最高 10 级，2、3、5、8、10 级各解锁一个固定被动；10 级解锁专属或高级通用技能。技能不占三个战法槽。实际交战获得 100 经验，获胜额外 50；战后统一升级，需求为当前等级 × 100。未实际交战的预备队不获经验，双方遵守相同规则。等级不额外增加四维。

点击军团武将姓名或武将名录的“查看五技能成长路线”，查看经验、解锁节点、效果与条件；战报显示经验及新习得技能。41 位名将已有完整成长路线与专属战法，其余 794 人的成长路线暂空，仍可配置兵种通用战法。60 个被动技能与全部名将配装见 [名将技能与专属战法设计](docs/名将技能与专属战法设计.md)。原有 V2 存档缺少成长数据时补为 1 级、0 经验。

## 原型中的明确规则

- 一回合为一旬，每支军团每旬沿一条道路移动。按己方军团优先的顺序处理行军；触发战斗时暂停本旬后续行军，未执行军团的路线留到下一旬，避免两个军团相向穿过。
- 己方每座城每旬产出 160 金、600 粮。友城可补充随军粮草，断粮每旬降低 12 点士气。
- 敌军自第 5 旬起，每隔 4 旬有机会向最近己方城市发起行动；距离相同时优先许昌。
- 同一战场同阵营军团共享 6 个在场席位。首发优先进入战场，不足 6 队则从预备队补齐；零兵力武将不出场。
- 溃败自动补位。主动投入预备队消耗一条蓄满的军略进度；满员时只可轮换兵力低于或等于开战兵力 65% 的最弱部队；后军固阵期间门槛放宽到 85%。轮换离场者本场不再出阵，余兵保留。
- 军略进度开局为 0，每步累积在场总智力，累计 12000 蓄满一条。满条后可施放一次，清空后重新积累；不用就保持满条，不储存次数。暂停不增长。重兵合围与后军接阵也消耗满条进度，鸣金收兵免费。军略另有各自冷却 8 步。
- 军略分为进攻、整军、扰敌三组，仅解锁主将与军师拥有的军略；换人即时更新，战斗中锁定。除攻击、防御、战意与敌军削弱外，还可清除负面状态、缩短己方冷却、提高移动力、延迟敌方预备队、给予入场预备队护盾、治疗本场伤兵、提高弓弩射程和持续火攻。完整效果见 [战法规则](docs/战法规则.md)。
- 普攻使用攻击对抗防御；武力战法使用武技威力对抗防御；智力战法使用谋略威力对抗军纪。统率与兵种决定攻防，武力决定武技威力，智力决定谋略威力，政治与兵种决定军纪。主将加成攻防、副将加成武技、军师加成谋略。详细公式见 [部队属性规则](docs/部队属性规则.md)。
- 标准模拟步为 700 毫秒，普攻间隔：枪 / 骑 3 步、弓 2 步、弩 4 步。每队共用一条战意（0～100）：攻击命中 +12、存活受击 +10，无自然增长；施放战法不扣战意。一次多段 / 多目标战法最多为施法者增加一次攻击战意，灼烧不产生战意。
- 每个兵种有武力、智力各 3 个通用战法，每队选择 3 个不同战法混配；本人专用战法也占一个槽。修改即保存，下场沿用，开战后锁定。按槽位 1 → 3 依次检查门槛、冷却和合法目标，未满足则检查下一项。
- 战法即时施放，每队每步最多一个战法；施放后进入自身冷却，其他战法不受影响。无合法目标时不施放、不进入冷却。眩晕、混乱、封技会阻止施放；降低战意限制后续发动。当前版本存档保留战意、独立冷却和状态，不读取旧式待施放状态。
- 夺气攻心：消耗满条军略进度，立即降低敌军全部存活部队（含预备队）45 战意，最低为 0；不影响已有冷却，已结算的效果不受影响。郭嘉专用战法「十胜奇谋」对单体降低 45 战意。
- 激进：攻击 ×1.18、防御倍率 ×0.91；防守：攻击 ×0.92、防御倍率 ×1.15；稳健无倍率修正。
- 撤退部队自动走向己方边缘，途中仍可被攻击。预备队直接撤离。撤离完毕判负，进攻失败返回原出发友城或最近友城。
- 240 步仍未分胜负时，以仍在场及预备队的剩余兵力 / 初始总兵力判定；相差不足 5% 则平局，进攻军撤回。
- 累计实际战损的 35% 向下取整为伤兵，其余为阵亡；战中已救治数从伤兵池扣除，战后不重复结算。军团伤兵在友城每名武将每旬最多恢复 180 人；据点守军尚未实现独立伤兵管理。
- 征兵每次最多 4,000 人，每名兵员消耗 0.25 金、1 粮。按每将现役兵力加伤兵不超过 3,000 人补充。

## 完整武将库

点击「武将」打开 835 人名录，可按姓名、字、来源编号搜索、按五项原始能力排序、筛选自建人物。点「查看资料」阅读性格、义理、相性、性别、生卒年、人物关系、适性和生平；关系人物可以点击查看。上述人物资料已作为正式字段写入存档；关系值（0～100）已影响连携概率，其余资料暂不影响玩法。资料页可选择任意另一位武将，查看、变更当前关系、调整或恢复分值基准；普通最高59、亲爱最高79、父母子女最高90、夫妻最高95、义兄弟最高100，初始关系记录保留。开战后锁定。部队属性页也可展开查看。选中 1～6 人后点击「以此阵容开始试炼」；试炼独立保存，重开沿用所选阵容。

数据来源、字段映射和存档版本要求见 [全量武将接入说明](docs/全量武将接入说明.md)。41 位名将已接入成长技能与专属战法；名录并不表示全部人物已加入战略军团，战略招募尚未实现。

## 项目结构与验证

- `officer-catalog.mjs`、`data/officers.mjs`：完整武将数据、编号映射和搜索。
- `officer-roster.mjs`：分页名录及人物资料界面。
- `scripts/import-officers.mjs`：从参考项目重新生成武将数据。
- `passives.mjs`：60 个被动技能、41 条固定成长路线、条件和结算修正。
- `famous-officers.mjs`：名将定位、推荐兵种、专属战法参数与十级个人技能。
- `progression.mjs`：参战经验及战后升级。
- `unit-stats.mjs`：共享属性公式、兵种基础、加成来源与军纪控制减免。
- `engine.mjs`：纯模拟逻辑，不依赖页面、时间、网络或存储，可使用固定种子复现战斗。
- `tactics.mjs`：固定兵种战法、稀缺专用战法、目标条件和位移寻路。
- `hex-grid.mjs`：六边形坐标、邻接、距离与屏幕中心映射。
- `command-cue.mjs`：每次军略蓄满仅播报一次的提示状态。
- `app.js`：战略地图、编制与战斗界面，交互和本地存档。
- `battle-effects.mjs`：独立 Canvas 特效层，消费战斗事件，不参与伤害判定；支持暂停、视口缩放与减少动态效果偏好。
- `styles.css`：桌面与手机响应式布局。
- `server.mjs`：仅使用 Node.js 内置模块的本地静态服务器。
- `sw.js`：离线资源缓存。
- `tests/engine.test.mjs`：核心机制的自动化测试。
- `docs/需求基线-V0.1.md`：需求基线与首版边界。

npm test
