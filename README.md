# 三国 · 君临

离线运行的三国策略 Web 原型，包含普通模式与独立战役。当前规则版本由 `combat-rules.mjs` 定义；只支持当前版本存档。

## 规则与设计

- [当前规则总览](docs/README.md)：战斗、内政、地图、编制和人员规则。
- 普通模式支持侦察发现固定贼寨，随机生成低于全国平均能力、按全国平均等级的具名贼将。实际派军讨伐，胜后携钱粮返城，并可能获得人才或宝物；玩家与AI共用流程。见[固定贼寨与讨伐](docs/固定贼寨与讨伐.md)。
- 普通模式按战略回合评估战争节奏：第1–20回合以单目标扩张为主，第21–60回合扩大持续作战范围，第61回合起具备真实容量时支持多军团共同进攻和独立第二战线。每回合为10天；出征综合评估现有兵粮、后续补兵能力和武将素质，敌将只使用合法情报。新编军团携粮按每队至少900粮及实际30天口粮计算，从城市实际库存装载，玩家与AI共用。预计收入不提前变成库存或战场兵力，见[势力AI与跨旬作战计划](docs/势力AI与跨旬作战计划.md)。
- 普通模式支持持续派遣军团增援交战中的战场；独立战役可设置双方多批援军，选择按时间、指定部队被消灭或指定军团全灭后到达，后备不限四队、每军团最多十队。自定义战役可设置断粮、伏兵日期，以已有缺粮、混乱和失阵状态表达。己方援军抵达后可进入军议调整后备顺序与撤离设置，在场部队保持原位。见[援军与军议](docs/部队撤离与战前设置-规则65.md)。
- [能力设计指南](docs/能力设计指南.md)：特技、军略、专属战法的设计边界和验收流程。
- [设计表目录](docs/design-tables/README.md)：武将、能力、兵种、经济等当前数据；待接入底稿明确标注。
- 战意采用较低的攻击、受击获取量；友军真实溃败会降低在场部队战意，附近部队损失更大。受击不扣战意，无自然衰减，规则见[战斗规则](docs/战法规则.md)。
- [自然剧本验收](docs/当前版本验收与体验目标.md)：资源承载、受控压力及当前原始全AI运营检查。
- [历史战役兵力与援军验证](docs/玩家布阵与羁绊强度-下邳.md)：兵力和援军数量优势、强将阵容、双AI换边验证及下邳操作边界；五丈原保留均势。

内政办事可触发同岗连携、互相掣肘及跨领域的好坏纪事，商业负责人也能汇报农事或军营事件。具体同城人物故事会改变真实资源与双方友好度，结算凭据保存并进入奏报，规则见 [内政协作与随机纪事](docs/内政协作实现与验证.md)。

## 音乐与音效

已接入十三首原创采样管弦配乐，共约十九分钟，参考《三国志11》按四季与战势组织音乐的方式。四季分别写有独立旋律，号角、弦乐、笛箫与拨弦声部、战鼓和锣钹按段落展开；曲谱不使用参考游戏的旋律或录音。

| 情境 | 曲目 |
| --- | --- |
| 首页 | 汉末山河 |
| 春／夏／秋／冬内政 | 春水入江／夏野旌旗／秋原怀远／朔雪孤城 |
| 行军／军议／外交 | 万里征尘／帐前筹策／玉帛纵横 |
| 接敌／相持 | 烽火初起／阵云鏖兵 |
| 优势／劣势／决战 | 长驱破阵／危城不屈／逐鹿决胜 |

内政按实际360日历每90日换季，行军只读取本势力军团的行军标记，进入军议、外交或战场后使用对应配乐。战场最多每10秒检查一次公开的溃败队数，相差至少两队时播放优势或劣势曲；开战与决战曲只按现有交战时钟选择，不汇总兵力、不估算战力，也不进行视野检测。换日、切换场景或载入战局立即检查，其余重绘复用缓存，沿用现有页面更新而不新增轮询计时器。场景变化淡入淡出约1.5秒，返回曲目接续原播放位置。暂停与查看面板时降低音乐音量，切后台暂停；回到前台不追赶漏过的音符。

首页、地图和战场可一键静音。设置中可独立调整音乐、音效与武将语音，并分别试听。配乐默认随季节和形势自动切换，也可指定十三首中的任一曲试听，再切回自动。十九类操作与战斗音效保持按真实事件触发、去重与限流，声音不改变随机数、存档或结算。

武将语音用于确认布置任务、出征，以及真实开战、战法演出、军略、全军撤退和胜败。战略成果只在本轮新产生的重要完成报告或人才发现／签约报告实际呈现时播放，每批报告最多一句；侦察日常探报、后台自动安排、普通浏览、单队伤亡或自行撤离不触发喊话。切换页面停止当前语音，缺少对应战法演出或加载过迟的语音直接舍弃。当前提供97条本机中文合成短句，17名重点武将有专属台词，其余使用统帅、猛将、谋士和女声四种表现；这不是逐人录制的真人配音。播放时显示姓名、事件与字幕并降低配乐，单通道、间隔和同句冷却避免喊话堆叠。隐藏敌军不暴露身份，读档、刷新与返回页面不重播历史事件；后台、静音及语音音量归零立即停止。没有实际报事人的事项不虚构武将。语音文件通过独立素材清单的 `voices` 与 `voiceCredits` 登记，可按稳定台词ID替换；素材完整缓存后可离线播放。缺文件时仅尝试与既定声线性别匹配的设备中文语音，短暂等待设备完成声音枚举；缺少匹配声音则跳过该句，不使用默认女声替代男将。

管弦录音通过独立素材清单的 `music` 登记，使用稳定曲目ID与可校验的OGG文件；授权与制作资料在 `musicCredits` 登记的JSON中。源码和只含代码的发行包仍有合成演奏回退。曲谱为 `music-themes.mjs`、`audio-score.mjs`，自动选曲为 `music-director.mjs`，播放为 `game-audio.mjs`。素材包保留音频、循环区间、哈希与授权资料，不包含制作使用的SoundFont、合成器或临时音轨。

`npm run test:audio` 检查季节、情报边界、检查频率、确定性及素材契约；`npm run verify:audio-ui` 检查真实播放、试听、静音、切后台、手机及离线。`npm run audio:preview` 导出当前十三首录音和音效WAV到忽略的 `.local/audio-preview/`。重新制作使用 `npm run audio:compose`，需在 `.local/music-tools/` 准备FluidSynth与GeneralUser GS，在其 `python/` 下准备mido、soundfile，及本机numpy、scipy；制作工具只在作者机器运行，游戏只读取完成的音频。

`npm run verify:officer-voice` 检查真实战法与战略工程语音、字幕、独立音量、手机、离线及后台停止；`npm run audio:voices` 使用作者机器已安装的 Windows 中文男女声制作语音包，游戏运行只需完成的音频。台词为 `officer-voice-lines.mjs`，只读事件为 `officer-voice-events.mjs`，播放与限流为 `officer-voice-player.mjs`。

## 启动

EXE、APK 与二进制数据／资源封包的构建和交付见 [发行封包与试玩发布](docs/发行封包与试玩发布.md)。开发构建需要 Node.js 22 以上；独立代码发行包仍可用 Node.js 20 以上启动。

需要 Node.js 20 或更高版本。Windows 双击 `start-game.cmd`，或在项目目录执行 `npm start`，打开 http://127.0.0.1:4173。不要直接用 file 协议打开页面。

美术素材通过独立资源清单加载，可用 `SANGO_ASSET_ROOT` 指向独立美术工作目录。程序与美术可分别维护；发布生成独立 `code/` 和 `art/`，支持只打包其中一侧。配置、协作边界和校验命令见 [美术资源接入](docs/美术资源接入.md)。

普通模式默认全国地形已探索，灰雾隐藏实时敌情，城市保留带日期的最近情报。侦察先选派出城市，再选本城执行人和周边终点，随后预览路线并在大地图拖动中转点改线，不能穿城继续远行。从己方城市菜单进入时预选该城，不自动选人；换城清空执行人、终点与路线，换人清空终点与路线。负责人留城工作，由模拟斥候沿保存道路行动，遇到据点和军团立即取得情报并点亮地图。每回合十天，视野按回合尺度保留：智力31为20–40天（2–4回合），智力越高期限越长。停止工作后已点亮区域保留至到期。详见[战争迷雾与武将侦察](docs/战争迷雾与武将侦察.md)。

普通模式先选剧本和势力，在据点办理内政、编制独立部队、组织出征；选择终点后可在地图拖动中转点调整行军路线。独立战役使用相同的部队编制、军团任命、战前会议和战斗引擎。

界面以名称、数值、状态和操作为主，战法、特性、羁绊及军略的完整效果在对应详情查看。军略列表与选区仅显示简要实际效果、提供者、范围及状态；行军方式使用关键数值，名册、收获与行动记录删除重复规则说明，人物生平按需展开。城市面板先显示命令，钱粮预算、产出明细与科技树按需展开；费用、进度、资源缺口和必要风险保留。页面指引默认手动打开，点击“指引”或按 F1 即可查看真实界面框选与完整规则。设置可主动开启首次自动提示，已保存的开关保持；重置指引只清空已读，不改变开关，开局选择始终不自动弹窗。阅读期间暂停，关闭恢复原页面与暂停状态，保留草稿。见[游戏内页面指引](docs/游戏内页面指引.md)。

大地图以地图为主画面，名册与管理侧栏按需展开。鼠标悬停或键盘聚焦城市、军团可查看简略卡片（窄幅表格，短字段名与关键数值；城市兵粮与任职、军团兵力与行军补给）；移开、点击或缩放时收起。点选城市、军团图形或头像直接查看详情，可从详情进入调动、内政或编制；部队采用左侧卡片、右侧编辑与武将情报，选路旁持续显示出征名单与预计行程，核阅确认后才执行；支持局部到全国的缩放、拖动巡视及势力分布示意。

普通模式提供常驻“本势力”总览导航：自辖城市、军团、战场一键展开地图内快速选择，选中即定位实际位置，列表保持打开并提供查看／管理／进入战场操作，各分类搜索分别保存；人才、部队及详细总览使用独立列表，搜索与排序分别保存；选择据点或军团定位管理，选择人才或部队查看详情，选择战场进入该场操作。天下情报保留跨势力查询。地图左侧菜单为势力级操作：内政、侦察、外交、宝物、战役；城市出征、编制与调任从所选城市进入。按操作对象区分页面：据点面板只显示本据点，军团面板只显示所选军团；“内政”统一设置全城六方向内政优先顺序，按共用推荐规则补齐各城空缺方向，已有任职和正在办理的事务继续；同日开始事务时优先方向先使用本城可用金。城市、势力详情的“收支预算”分别提供本城明细和全势力汇总，实际结算与未来一旬预测分别展示；保留金粮在本城详情设置，人才接洽与报告归“人才”页面。外交提供交好、通商与交涉持续委任，武将后台拟案谈判，玩家批准完整最终版本后才实际签署与履约；AI共用人员、预算、路线和交付规则，由君主根据供需、战线及信用审核；钱粮兵使用双方君主驻城，城池、俘虏和援军按真实对象执行，详见[外交系统设计与实现](docs/外交系统设计.md)。“战役”以“XX之战”命名，以表格列出交战状态、交战双方、发生时间与战果，统一通过“进入”打开战役，可随时接管进行中的战场；已结束战场按每日记录播放、暂停、逐日跳转并显示最终战果。最近20场保留回放，更早战役仅保留战报摘要。地图与业务页的对象详情不附带全势力名册，关闭返回来源页面。天下情报入口采用名册、身份卡和分类详情布局；城市可查看驻军，军团可查看所属部队，部队可继续打开主将档案。部队基本页显示状态、归属、兵种及兵力，能力与战法另页查看；返回上一层保留原分类。

战法按适性及主将属性固定携带，所有等级可用并自动施放，不提供自由配装或顺序调整。战斗意图、初始位置、出阵顺序和各队撤离条件在战前会议安排，撤离支持逐队或批量填写具体兵力人数，并统一选择合法己方撤离据点。离场即按运输方式返城，后备正常补位；换目标或撤离需要离开近战牵制时先准备脱战。战斗特性采用兵科、战术及稀有共享羁绊，个人以1级为主、2级少见、3级逐项限一名代表，低级最高档至少六人在场；高级限定核心名单与个人点数，倾国2／3／5、勇武2／4／6、桃园1／2／3档。一人可持有多种，升级概率获得个人预设等级，10级全部获得；在场同名等级相加激活效果，军团任职等独立特性开局可用；军略统一15种，不区分基础与专属，只由明确名单内合资格的军团长和军师提供；通常每人1项，仅诸葛亮2项，强效果设独立长冷却；范围军略在战场选择圆形或矩形落点、预览并确认施放，全军号令明确标注全军效果。诸葛亮的八阵奇门可放置持续阵地，阵内敌军每回合按自身军纪判定随机异常。

基础军略按人物资格分配，并尽量跨势力分散；同势力的统帅与谋士优先分工。荀彧提供救疗，司马懿提供百邪不侵，各方完整分工见[军略池与任职](docs/军略池与任职-规则45.md)。转投势力不改变个人军略。

军略主要效果随施放者统智明显变化，强度类改变效果量，状态类改变时长；选择、选区及详情显示实际数值。例如百邪不侵由司马懿施放持续15回合，马良为4回合。公式、基准与逐人区别见[军略强度](docs/军略强度与持有者-规则46.md)。

## 本机存档与发行检查

完整自动档和手动档保存在 IndexedDB，localStorage 只保留小型偏好和编辑草稿。原有存档仅在事务提交成功后从浏览器小型存储移出，字节及游戏版本不改变；只支持当前游戏结构，不升级旧规则存档。保存成功提示以持久化提交为准，失败保留原档并暂停推进，可导出当前进度。武将仅保存当前动态，已完成内政历史在结算后清理，战场回放保留，导入与桌面导出共用256 MiB文件上限。

发行前运行 `npm run verify:delivery`：文档版本、实际规则来源、设计同步、全量回归、真实封包启动和自然大存档浏览器验证必须全部通过；Windows容器再运行 `npm run verify:delivery -- --desktop`。记录保存在新建的 `work/delivery-时间戳/`，包含逐文件指纹、版本及每步日志，途中源码变化不会报告发行通过。

## 修改与检查

正式设计源为 `data/design/*.mjs`，机制仍需引擎处理器；不可仅改效果文案。

```sh
npm run design:check
npm run design:export
npm run design:verify
npm run test:design
npm run docs:check
```

机制改动还须运行受影响测试。当前文档不保留过时报告、历史规则或已被替代提案；规则变更时同步清理文档。

深谋羁绊支持持有者首次入场获得限次挫志法球；具体次数、共存和保存规则见[羁绊特性与成长](docs/羁绊特性与成长-规则76.md)。

规则128强化名将与合作班底、辅助武将和美女武将的实际配合：保留张飞、司马懿、孙策、庞统、陆逊的接续机制，小乔、大乔、甄氏增加战歌启动支援，郭淮提供护卫。本轮核对26组历史与演义合作，新增真实支援接续和接应掩护连携；周仓增加摧锋，廖化、邓芝增加战歌，四对关系补入合适基准。战歌支援2格内一队友军，优先补足尚有次数的战法门槛，2／6／12点激活。六种高级羁绊与任职特性继续突出阵容组合；AI策略和评估忽略双方羁绊收益，实际战斗双方正常结算。旧档重新开始，详见[名将协作](docs/名将历史协作与战斗定位.md)与[羁绊规则](docs/羁绊特性与成长-规则76.md)。


## 大地图界面

地点目标直接在大地图点选，覆盖出征／调动、调任／运输、侦察派出城与终点、接力据点、撤离节点和外交重点势力。合法目标高亮，确认后返回原流程；取消保留原草稿，名称搜索只定位。


- 大地图铺满窗口；左上显示君主、日期与资源，左侧命令作用于当前选择的己方据点，右上提供情报和本势力分类入口。
- 点击城市只弹出名称与六个一级入口：内政、军事、人事、侦察、城内、详情。军事和人事再选具体命令，预算、资源与人员表在主动打开相应页面后显示。点击空白或按 Esc 收起；切换城市直接替换菜单，敌方及未侦察城市只提供合法查看入口。
- 据点、军团与战场快速选择在右侧展开，点击对象定位地图；管理面板按需打开。政务、待执行命令及各类纪事收纳在左下「政务与纪事」。
- 地图按「都市圈 → 圈内据点 → 城内建筑」逐层细化；缩远聚合都市圈，放大展开主城、小城、关卡和港口，继续放大查看当前地点建筑。工具栏可切换「都市圈」「据点」「城内」，缩小按相反顺序收拢。点击「城内」或城市菜单「查看城内」直接定位。城内使用有山川纵深的绘画全景与十二类细节建筑，体现木梁、瓦顶、石阶、庭院和生活器具；内政扩建改变设施规模，三级、五级增加附属建筑，施工保留脚手架和进度，存粮及城防损伤同步呈现。悬停或键盘聚焦显示建筑名称，点击查看等级、效果和当前事务。
- 主城和府的已建建筑、施工工地在平时大地图直接显示，停工仍保留工地，建成后原址显示成品；都市圈标签与实体分离，可直接点击建筑查看详情，放大只增加细节。
- 地图支持拖动巡视、滚轮缩放、方向键平移和 Home 返回操作中心；取消常驻小地图，通过“全国”、列表定位和“操作中心”导航。点选对象后查看详情或发起命令，调动沿用逐点选路与最终核阅。
- 城池标牌显示驻城部队兵力，军团标牌显示主将、实时兵力与状态；缩放保持标牌可读，密集处优先显示选中对象和城池名称，隐藏标牌的对象仍可点击。
- 全国地图的城市名单及分布也参考用户提供的古地图，现有 76 座城市，新增敦煌、张掖、西平、金城、平城、中山、彭城、豫章、番禺、龙编等 34 座城池，参与内政、调任、占领与统一条件。方框为大城、圆圈为小城、菱形为关卡；现有 42 座大城、34 座小城，井陉为小城，未高亮的保留城池按小城适配。规模用于模型、标记和情报，经济与设施按共用规则结算。同城只保留一座，采用三国古名，如建业、寿春、宛；原图晚期新城按三国区域旧治适配。海岸、山川水系、主图和势力选择图共用投影，12 处关卡和 41 处港口是道路节点，也可承接所属大城的都市圈建设。府、小城、关卡和港口按实际道路距离划归最近的大城；大城负责人自动选址，费用与成果计入建设城市，每级设施保存实际地点，敌方据点和封路工地暂停。区域路网同步扩展为 249 条路段；关隘与渡河通道落实地理禁连，水路仅在港口之间通行，已关闭山脊无法穿越。当前地图存档版本 65，使用新地图须重新开局。本地头像资源可用时显示人物头像，否则使用文字标记。

- 都市与府共同组成都市圈。现有24处府使用具名区域（如巨鹿、曲梁、尉氏、鄢陵），地图展示地域范围及道路连接；建筑可建在主城或府，保存实际地点，费用、人员和成果归建设城市。府没有独立的委任、占领或资源账本。

大地图军团标记支持悬停与键盘聚焦查看：主将头像、当前兵力、士气、行军速度、位置与目标，以及主将部队基础能力五维图。部队详情的基本页增加能力图和可点击的特性、战法入口，沿用基本、能力与战法、所属武将分页。

开局界面采用剧本卷轴列表与独立势力选择页，现有官渡风云、英雄集结、群雄讨董（190）、群雄割据（194）、赤壁风云（208）、汉中争雄（219）、群雄集结（251）共七个剧本。群雄集结按 `sango_infinity-main` 的完整英雄剧本保留37个有城势力及439名在职公共人物的驻地；其余人物进入共用人才系统。四个新增历史剧本沿用项目人物库，按年代调整领地与势力关系，过滤尚未登场或已去世的人物；领地是玩法改编，不声称来自原项目的历史存档。新增剧本保留实际人员驻城，不自动搬去填满各城。势力页展示君主头像、真实据点与武将数量，君主列表支持横向滚动；确认后开局。

剧本正式设计源为 `data/design/national-scenarios.mjs`，来源分布及文件校验摘要位于 `data/design/reference-scenario.mjs`；可以通过 `node scripts/import-reference-scenario.mjs <参考项目目录>` 更新来源快照，不覆盖现有人物能力或读取自建人物。参见[剧本与开局配置](docs/design-tables/剧本与开局配置一览表.md)。

己方城市在地图和据点列表显示内政已任命方向数（共六方向）及空闲武将人数，城市内政显示缺任方向、太守与空闲名单。空闲指实际在城、没有内政任职、太守职责、军团任务、在途任务或等待命令的武将；城内独立部队的编制不排除内政任职。战略重要奏报从每日记录的真实事项节点选取，包括建筑完工、技术突破、人才发现和签约、离职预警、灾情、工程中断或受阻、战果、城池得失和人员伤亡被俘；普通开工、日常收支与待命不弹奏报。结果先按发生顺序写入每日记录，奏报直接引用同一节点，不从状态消失猜测完工，也不依赖会截断的内政事件队列。推进时自动暂停，查看当日记录保持暂停并返回奏报；确认或关闭奏报后继续推进。确认只持久标记已读，已完成事项在本旬结算及引用结束后清理，读档不重报；无对应武将的灾情或城池事项保存在据点每日记录，不虚构汇报人。

右上「自辖城市」显示己方城市总数及有空闲武将的城市数。城市列表按真实可用人员状态区分：有空闲武将用金色高亮并优先排列，无空闲武将用灰色显示，灰色城市仍可选择。可筛选「有空闲」，按城市或空闲武将姓名查找；点击立即定位实际城市，列表继续保留，桌面与移动端均可逐城切换。所选城市显示完整空闲姓名，可直接进入「安排事务」，或查看详情与管理。内政委任、解除任职、调任、随军、外出、等待命令及城池归属变化后，从实际状态重新计算人数与颜色；浏览、定位和筛选不推进日期、不修改任职或军令。详细据点列表沿用同样的高亮与灰色。

地图城市、关卡和港口按实际建设地点绘制设施与工地；施工、停工、完工和读档同步更新当地外观与动画，内政面板可定位都市圈各地点。港口保留码头外观。城市标签仅显示城名、驻守兵力与粮草，己方任命方向及空闲人数用图标显示；港口不显示城市资源。城市和军团悬停卡片采用统一窄幅表格，顶部显示名称与势力，短字段名靠左、数值靠右，详细说明留在对象面板。

大地图军团以小队模型定位，上方使用紧凑主将头像牌：姓名、兵力、兵力比例条与士气条；势力色用于边框及脚下标记。目的地和完整任职通过悬停表格查看，头像资源不可用时显示姓名首字。

战斗日志使用紧凑逐行列表，势力色方标区分来源，人物、战法和数值分类突出；筛选保留。战略奏报按成果与告急分层：签约武将展示发生时的能力、特性与赴任状态，设施展示实际建设地点、等级变化与新增效果，技术展示解锁成果；无对应人物时显示纪事标识。原始文字和当日记录可回看，查看武将或实际设施后可返回奏报；保持暂停和已读存档规则。普通接洽进度、失败和恢复只写每日记录，人才发现不重复弹搜索完成事项。

每旬结束后，主界面显示城市产出与直接运营实际入库的金、粮和预备兵，以及本旬获得的人才、设施和技术。直接运营已在办理完成时入库，汇总不再发放；满仓未入库部分不计收获。展开可查看执行期间各城金合计与己方城仓净变化及各城入库，净变化包含真实支出、消耗和城池归属变化。查看成果与读档不重复奖励，汇总无需领取或额外确认。

玩家界面不显示日内计算步数、内部恢复公式或逐步倒计时。交战标题、日志、战报和存档摘要按天显示；技能仅显示冷却、调息、是否生效及剩余次数。自定义战役以天设置时限和援军时间，内部种子不展示。我方先遣及全部援军共用可设置的总预备兵，编制页面显示已用和剩余；新建部队默认使用当前地形允许的最高适性兵种，仍可手动修改。

战场现有21张内置模板（15张普通地图与6张历史地图），按野战、攻城、关卡、港口、水战用途分类，每格独立设置地形。自定义战役内的地图编辑器支持绘制、撤销重做、自建分类、通路校验、本机地图库及JSON导入导出；自建地图开战后保存完整快照，编辑或删除原图不影响续战。普通模式仍按据点或道路固定选图，港口使用湾岸港口、关卡使用狭口雄关。山壁不能通行；树林、坡地、水面和桥梁的展示与实际地形一致。运行 `npm run test:map-editor`、`npm run verify:map-editor` 验证编辑器；内置地图回归使用 `npm run test:battle-maps`、`npm run verify:battle-maps`。详见[战场自定义编辑器](docs/战场自定义编辑器.md)与[地形战斗规则](docs/地形战斗规则.md)。

所有真实设施保存当前／最大耐久。新建、扩建与修复共用耐久进度；实际攻城和驻点战的建筑损坏、修缮按原址回写。暂停与读档保留已付工程和耐久，修复保持建筑等级；瞭望塔毁损后停止额外视野，修复后恢复。详见[内政与建筑耐久](docs/内政六方向-规则56.md)。

城市科技树共23项、最多两层，每城固定开放10～13项。委任技术负责人后按实际工作日推进研究并保存百分比、已工作天数和已付费用；完成直接生效，中断接续不重复收费。军务与特色兵种不要求兵营等级。科技提高本城收入、降低费用、提供持续瞭望塔视野，解锁箭塔、军乐台和救护营等原址战场设施建设，并解锁枪、戟、骑、弓的升级兵种及升级装备。每队分别携带一种兵器与一种船，入水、登岸和攻城时自动切换形态；普通与战役模式共用兵种、战法和次数规则，详见[兵科、技术与装备](docs/兵科与据点编制-规则59.md)。


城市金、粮和预备兵各自保存，收入入本城、建设和编制等费用从本城扣除；顶部金粮为各城合计。城市预算显示未来一旬收入、用度、预留和缺口，同时检查旬末收入到账前是否够用。各城可设置保留金粮，预留目标未满仅在预算中提示，实际用度不足通过奏报与地图提示提醒；普通城际金粮调拨须真实运输。地图城市上方为“现役士兵／（现役士兵＋预备兵）”。详细规则见[城市钱粮与预算](docs/城市钱粮与预算.md)。

新局势力大城配置10000金、18000粮、18000预备兵，小城5000金、10000粮、9000预备兵，玩家与AI共用，初始驻军携粮按库容归并。中立大城只保留1000金、3000粮、1000预备兵，小城减半，中立期间没有周期产出；武力占领只接收50%金、50%粮、20%预备兵，向下取整，中立接收还按小额库存封顶，和平移交仍按外交契约办理。在仕官员按武将等级1至10级每旬依次发5、10、15、22、30、40、52、66、82、100金，待命、出征及外派照付，欠俸保存并补发。预算单列俸禄并保留应付款，钱粮不足不提出对应付费内政提案，免费有用事务仍可办理。优秀人才在合适岗位和真实需求下的额外贡献应覆盖俸禄；太守与经营按政治增强，选事核对净收益，人才不按人数自动产钱。战争费用与压力验证见[单城资源与经济平衡](docs/单城资源与经济调整-2026-09-22.md)。当前战略存档版本64、内政版本23，旧档重新开局。


内政付费事务先由负责人呈案，玩家准奏或暂缓，可开启全势力自动准奏。成事把握以奏报文字表示，成败按各方向主属性与适用特性判定；施工和研发受阻保留真实进度及已付费用。详见[内政规则](docs/内政系统最终设计.md)。
