# 三国 · 君临

离线运行的三国策略 Web 原型，包含普通模式与独立战役。当前规则版本由 `combat-rules.mjs` 定义；只支持当前版本存档。

## 规则与设计

- [当前规则总览](docs/README.md)：战斗、内政、地图、编制和人员规则。
- [能力设计指南](docs/能力设计指南.md)：特技、军略、专属战法的设计边界和验收流程。
- [设计表目录](docs/design-tables/README.md)：武将、能力、兵种、经济等当前数据；待接入底稿明确标注。

## 启动

需要 Node.js 20 或更高版本。Windows 双击 `start-game.cmd`，或在项目目录执行 `npm start`，打开 http://127.0.0.1:4173。不要直接用 file 协议打开页面。

普通模式先选剧本和势力，在据点办理内政、编制独立部队、组织出征并逐点选路。独立战役使用相同的部队编制、军团任命、战前会议和战斗引擎。

大地图以地图为主画面，名册与管理侧栏按需展开。点选城市或军团显示操作菜单，可进入情报、内政或编制；部队采用左侧卡片、右侧编辑与武将情报，选路旁持续显示出征名单与预计行程，核阅确认后才执行；支持局部到全国的缩放、拖动巡视及势力分布示意。

普通模式提供常驻“本势力”总览导航：据点、军团、战场一键展开地图内快速选择，选中即定位实际位置，列表保持打开并提供查看／管理／进入战场操作，各分类搜索分别保存；人才、部队及详细总览使用独立列表，搜索与排序分别保存；选择据点或军团定位管理，选择人才或部队查看详情，选择战场进入该场操作。天下情报保留跨势力查询。按操作对象区分页面：据点面板只显示本据点，军团面板只显示所选军团；全势力军费和人才报告从“势力事务”打开，战役与快照从“战役记录”打开。地图与业务页的对象详情不附带全势力名册，关闭返回来源页面。天下情报入口采用名册、身份卡和分类详情布局；城市可查看驻军，军团可查看所属部队，部队可继续打开主将档案。部队基本页显示状态、归属、兵种及兵力，能力与战法另页查看；返回上一层保留原分类。

战法按适性及主将属性固定携带，所有等级可用并自动施放，不提供自由配装或顺序调整。战斗意图、初始位置、出阵顺序和各队撤离条件在战前会议安排，撤离支持逐队或批量填写具体兵力人数，并统一选择合法己方撤离据点。离场即按运输方式返城，后备正常补位；换目标或撤离需要离开近战牵制时先准备脱战。战斗特性采用兵科、战术及稀有共享羁绊，个人以1级为主、2级少见、3级逐项限一名代表，普通最高档至少四人在场；桃园限定刘关张各1点，设2／3档。一人可持有多种，升级概率获得个人预设等级，10级全部获得；在场同名等级相加激活效果，军团任职等独立特性开局可用；军略由合资格的军团长和军师提供；范围军略在战场选择圆形或矩形落点、预览并确认施放，全军号令明确标注全军效果。诸葛亮的八阵困敌可放置持续阵地，阵内敌军每回合按自身军纪判定随机异常。

## 修改与检查

正式设计源为 `data/design/*.mjs`，机制仍需引擎处理器；不可仅改效果文案。

```sh
npm run design:check
npm run design:export
npm run design:verify
npm run test:design
npm run docs:check
```

机制改动还须运行受影响测试。当前文档不保留过时报告、历史规则或已被替代提案；规则变更时同步清理文档。

羁绊支持首次入场法球与重击：弓将给弓弩、深谋给持有者、先登给持有者的枪戟骑；具体次数、共存和保存规则见[羁绊特性与成长](docs/羁绊特性与成长-规则76.md)。

蓄锐在开战时锁定后续预备队强化名额；桃园改为共同分担伤害与成员溃败后的奋战，三人结义后仅存一人可短暂无敌。当前战斗规则85，旧档重新开始，详见[羁绊规则](docs/羁绊特性与成长-规则76.md)。
