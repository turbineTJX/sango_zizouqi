# 美术生产参考与云端同步

用户授权通过 Git 同步现有参考头像。`face-references/index.json` 按稳定武将 ID 记录参考文件、SHA-256 和共用头像名单，文件名以内容哈希去重。当前可用映射 713 人，另有 119 人没有对应参考；缺失时独立设计，不能借用别人。

`node scripts/officer-art-face-references.mjs --all` 优先使用本机现有资源映射；云端没有本机资源时，读取此处便携参考清单并核对文件哈希。源头像用于原创身份设计，其余场景只使用本人已审阅原创身份图。

本目录仅供生产参考，不是原创成品，不加入游戏运行时清单或发行包。已审阅原创素材、身份图、活动候选与批次进度在 `assets/officers/`。旧本地续跑保持暂停，云端是当前唯一生产者。

云端每次续跑先拉取 `codex/cloud-officer-art-20261008`；工作区干净且只有远端新增提交时使用快进同步。发现分支分歧时先保留本地成果再解决，不强推。每批完成后检查图片哈希、批次状态、目视 QA 和相关测试，再提交并推送同一分支。
