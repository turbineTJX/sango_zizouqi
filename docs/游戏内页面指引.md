# 游戏内页面指引

接入状态：已实现。页面指引默认手动查阅，点击“指引”或按 F1 打开。设置可主动开启玩法页面首次自动提示；明确保存的开关保持，游戏模式、剧本和势力选择始终不自动弹窗。玩家可用“收起”、关闭按钮或 Esc 关闭；已读按页面类型保存，跨新局共用。

## 展示与查阅

参谋人物在操作位置旁以对话提示下一步，优先框出实际需要点击的按钮或候选行。人物复用已有肖像；未安装素材包时显示内置参谋插画。页面保持原来亮度，没有指引遮罩；框内按钮、其他操作和滚动均可直接使用。高亮按实际可见元素的位置计算，跟随窗口缩放、滚动与界面布局变化；对话避开高亮区域。指引不另画地图、不复制界面，也不读取隐藏游戏状态。

点击框中控件后，提示跟随实际操作进入下一步；进入新的玩法页面时切换为该页面提示，回到开局选择时收起。已经选好委任方向的页面直接提示选人。点击“进行”或开始战斗时收起指引，再由原游戏按钮执行。步骤按钮、左右箭头或对话内的键盘左右方向键也可切换步骤，不要求读完才能关闭。完整操作与规则收在“详细说明”中，按需展开。尚未出现、被折叠或完全离开可视区的控件不虚构框选，也不代替玩家选择、展开、滚动或下令。从目录查阅其他页面时保留当前界面，只显示说明并提示到对应页面打开指引。

页面或弹窗标题处保留“指引”，F1 可重看当前页；“全部指引”按开始游戏、经营与人事、出征与补给、战斗分类查阅。切换步骤和展开说明不标记已读，不推进模拟。

当前共46项说明。预算指引随城市、势力详情的“收支预算”分页打开；内政指引只覆盖优先顺序、委任和提案，人才接洽从本势力“人才”页面查看。普通模式覆盖大地图、城市、内政委任、提案、内政、预算、人事、太守、侦察、报告、部队编制、出征、任命、选路、调任运输、执行时机、外交、宝物、当前动态与情报，贼寨讨伐另有手动说明。战斗覆盖军议、布阵、战场、军略、援军、部队、固定战法、能力、建筑、战果与回放。整局回顾提供手动战绩、最终存档及新局说明。开始游戏覆盖模式、剧本、势力、战役编辑、战场地图编辑和存档；地图编辑始终只手动查阅。

编制、任命与选路按当前向导页面分别提示；列表不按每个对象重复提示。进入战场的布阵阶段与正式交战阶段分别提示。已读仅在玩家主动关闭或切换所读指引时记录，不以渲染次数代替已读。

## 状态与暂停

参谋提示不替换业务弹窗，不主动提交或清空选人、配兵与军令草稿，不确认奏报或批准提案。阅读期间冻结世界与战斗推进，但不禁用页面、不锁住键盘焦点；玩家仍可直接点击、选人和填写表单，操作沿用原有校验与提交。关闭保留原页面 DOM、表单与滚动位置，并恢复原来的暂停状态，继续推进时重置播放计时，避免补跑阅读期间的时间。只有“全部指引”目录使用独立模态窗口与焦点隔离，退出目录即解除隔离。

偏好保存在浏览器独立键 `sango-page-guides-v1`，包含自动提示开关与已读页面集合。该偏好不写入游戏存档、不随读档重抽。设置中可关闭或开启自动提示，也可“重置指引”；重置只清空已读集合，保留当前开关，不重新开启提示。模式、剧本和势力选择始终只手动查阅。访问选择页面不自动标记已读。自动提示关闭时手动查阅始终可用。浏览器存储不可用时本次会话仍记住关闭状态。

## 实现与验收

- `page-guides.mjs`：说明内容、可见页面识别与独立偏好。
- `page-guide-view.mjs`、`page-guides.css`：参谋对话、真实按钮框选、跟随操作、详细说明与目录；目录单独管理焦点与背景隔离。
- `page-guide-targets.mjs`：各步骤对应的真实控件、可见范围检查与提示位置计算。
- `app.js`：统一渲染与时钟接入，设置入口；离线资源登记于 `sw.js`。
- `npm run test:page-guides`：默认手动、开局选择不自动提示、已读持久化、开关及重置保持偏好、异常存储、页面与战斗阶段识别、独立存储边界。
- `npm run verify:page-guides-ui`：开局选择及关闭自动提示后的重置无弹窗、指引开启时直接选择势力与完成内政委任、参谋对话跟随选人和确认、真实控件框选与窗口缩放跟随、提示避让、步骤切换与详细说明、手动关闭与重看、读档刷新、草稿与提案保护、暂停、键盘与桌面／手机布局。

内容只解释共同游戏规则，不添加教学战役、自动演示命令或额外资源。修改玩法时同步维护对应指引。
