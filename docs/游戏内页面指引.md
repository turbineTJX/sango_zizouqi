# 游戏内页面指引

接入状态：已实现。首次打开一个页面时显示操作说明，玩家可用“知道了”、关闭按钮或 Esc 关闭。每类页面独立记住已读状态，更换城市、人物或新开一局不重复提示同类页面。

## 展示与查阅

指引按“页面用途、如何操作、注意事项”展示详细说明，使用游戏当前按钮名称与真实规则。页面或弹窗标题处保留“指引”，F1 可重看当前页；“全部指引”按开始游戏、经营与人事、出征与补给、战斗分类查阅。

当前共43项说明。普通模式覆盖大地图、城市、内政委任、提案、统一内政、预算、人事、太守、侦察、报告、部队编制、出征、任命、选路、调任运输、执行时机、外交、宝物、每日记录与情报。战斗覆盖军议、布阵、战场、军略、援军、部队、固定战法、能力、建筑、战果与回放。开始游戏覆盖模式、剧本、势力、战役编辑和存档。

编制、任命与选路按当前向导页面分别提示；列表不按每个对象重复提示。进入战场的布阵阶段与正式交战阶段分别提示。已读仅在玩家主动关闭或切换所读指引时记录，不以渲染次数代替已读。

## 状态与暂停

指引独立覆盖当前页面，不替换业务弹窗，不提交或清空选人、配兵与军令草稿，不确认奏报或批准提案。阅读期间冻结世界与战斗推进，屏蔽背景快捷键与点击，Tab 焦点保持在指引中。关闭保留原页面 DOM、表单与滚动位置，并恢复原来的暂停状态，继续推进时重置播放计时，避免补跑阅读期间的时间。

偏好保存在浏览器独立键 `sango-page-guides-v1`，包含自动提示开关与已读页面集合。该偏好不写入游戏存档、不随读档重抽。设置中可关闭或开启自动提示，也可“重置指引”；自动提示关闭时手动查阅始终可用。浏览器存储不可用时本次会话仍记住关闭状态。

## 实现与验收

- `page-guides.mjs`：说明内容、可见页面识别与独立偏好。
- `page-guide-view.mjs`、`page-guides.css`：说明窗、目录、焦点与背景隔离。
- `app.js`：统一渲染与时钟接入，设置入口；离线资源登记于 `sw.js`。
- `npm run test:page-guides`：已读持久化、开关与重置、异常存储、页面与战斗阶段识别、独立存储边界。
- `npm run verify:page-guides-ui`：真实页面首次提示、手动关闭与重看、读档刷新、草稿与提案保护、暂停、键盘与桌面／手机布局。

内容只解释共同游戏规则，不添加教学战役、自动演示命令或额外资源。修改玩法时同步维护对应指引。
