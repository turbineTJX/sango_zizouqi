## 维护约定

美术资源入口：[资源接入](美术资源接入.md)、[武将多场景批量流程](武将多场景美术流程.md)、[人物素材生产skill](../.agents/skills/sango-officer-art/SKILL.md)。

- 数值、名称与分配以 `data/design/*.mjs` 为正式源；`docs/design-tables/` 一览表由 `npm run design:export` 生成，不手改。
- 说明文档描述机制，不能代替引擎处理器。表格标记“待接入”的内容尚不构成运行效果。
- 改规则时同步修订受影响专题、生成器文字与入口；已替代条文直接删除，不再靠“历史保留”维持两套规范。
- Markdown只保留现行说明与当前设计底稿；审计生成器输出的旧版报告不得重新放回文档入口。
- 仅维护当前结构与确定性续战，不添加旧档兼容或迁移。

- [羁绊特性与成长](羁绊特性与成长-规则76.md)：共享池、个人上限、概率成长及在场统计。

城市空闲人才定位、建筑头像、每日行动记录及从记录中选取战略奏报的规则，见[内政规则](内政系统最终设计.md)。外交的实际出使、审批、签署、交付与AI流程沿用同一每日记录和奏报。
