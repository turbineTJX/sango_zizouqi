# 当前版本验收与体验目标

维护日期：2026-10-27。游戏规则129、AI结构17、战略结构13、战略存档65、内政结构25。当前版本行及 docs/current-docs.json 的 runtimeVersions 由 docs:check 对照实际运行时定义校验。

## 当前实现与规则来源

- [战场自定义编辑器](战场自定义编辑器.md)使用野战、攻城、关卡、港口、水战用途分类，每格地形独立绘制；21张内置模板可派生自建地图，支持自建分类、本机地图库和JSON地图包。独立战役保存地图快照，全国仍按真实地点与道路固定选图。

- 全国地理通道已按实际河岸与山口重接：水路只连接两个港口；途中改令不能直接靠岸，关口与渡河通道封锁后须绕远或不可达。当前76城、12关、41港、24府，共249条道路；陆路接岸不跨越四条主河道。机制、图论及自然全AI观察分别验收，详见[府区域与都市圈连接](野外路口与横向小路-2026-09-22.md)。

- 普通模式已接入[固定贼寨与讨伐](固定贼寨与讨伐.md)：独立保存全国平均能力与等级快照、随机具名贼将、实际侦察报告及清寨状态；真实出征、战斗、伤亡与AI讨伐共用流程。钱粮随军返城入库，人才与宝物沿现有真实人物和唯一物品处理。当前观察覆盖原始全AI前六回合的两次自然讨伐；刷新节奏和具体奖励仍为可继续调整的初值，不以讨贼代替诸侯战争节奏验收。
- 战略、内政、战斗继续使用共同人员、资源、情报和结算规则。各城六方向内政分别限制人数：初始3人，随建设和科技逐步扩容至10人；扩容及待执行改任预留随当前内政结构保存。具体门槛见[内政规则](内政系统最终设计.md)。
- 发行启动先校验二进制数据，再导入同步游戏模块；数据错误或启动超时保留已有存档并提示重试。
- 自动档及命名手动档均进入 IndexedDB。保存成功只在事务提交后显示；失败保留原档并暂停推进，可导出当前进度。既有小型存储中的保存内容按原字节转存，成功后才清除原项；旧游戏结构仍按现行校验拒绝，不补字段。
- 存储层为每个槽位维护与正文同事务提交的变更标记，列表只复用标记未变化的已校验摘要，不缓存完整手动档。另一窗口覆盖后重新校验；失败写入同时回滚正文与标记。既有 IndexedDB 只新增存储元数据，游戏正文不改写。
- 普通存档保存当前人员、任职、任务和资源；本旬结算、未读奏报及上一旬收获保留必要凭据，已完成内政与人员历史清理，战场快照及战报继续保留。导入及桌面导出共同上限为256 MiB。
- [规则来源一览表](design-tables/规则来源一览表.md)登记实际配置与处理器。11类未定稿底稿继续明确隔离；修改底稿不代表游戏已变更，运行时误导入底稿使设计检查失败。

## 本轮验收方法

发布前执行：

```powershell
npm run verify:delivery
npm run verify:delivery -- --desktop
```

后一命令在Windows上额外构建只含代码的实际EXE，并验证桌面容器、导入导出、进程重启及免安装启动器。Android运行验收仍须实际设备。

结果保存在新建的 work/delivery-时间戳/，包括 manifest.json、result.json 及逐步日志。manifest记录程序、设计、脚本、测试、文档与打包输入的SHA-256；每步前后复核，版本变化或源码变化不能拼接成同一轮通过。全量或任一步未完成时 passed 保持false，不把旧版本数字抄作当前结果。

门槛覆盖：

1. 当前文档清单、链接、运行时版本行和正式来源契约。
2. 设计字段校验、生成一览表同步及全量行为回归。
3. 重新构建发行包后的真实启动、数据损坏拒绝、导入导出、重载、离线重载及手机宽度。
4. 原始官渡剧本、正常迷雾及内政事件、全部势力AI正常推进至第41天，保留全部行动历史，使用真实超过localStorage容量的当前存档。
5. 浏览器实际存储对照、自动档与多个完整手动档并存、连接重开、当前界面导入和页面重载、命名保存、中断覆盖保留原档、删除仅作用于选中档。
6. 当前自然存档经过校验后，复制两份沿共同流程继续并比较完整结果，存储测试不修改人物、资源、道路、战争或战果。

## 证据范围与体验缺口

[AI互战行为与决策审计](AI互战行为与决策审计.md)中的战术及战略观察仅支持其各自冻结输入，不自动代表本轮源码。近均势战损估算仍需独立校准；当前轻量评估、AI不规划羁绊和军略固定触发边界继续保留。

第41天的大存档检查证明真实容量、历史保留及续行，不证明中后期战争节奏或最终统一。阶段仍为第1–20回合前期、第21–60回合中期、第61回合起后期，每回合10天。当前版本的多剧本、多种子长局、真实多军团同侧参战与统一收尾需分别记录，空城占领与真实战斗分开统计。

全国胜利、战败及全AI统一后自动显示独立整局回顾。疆域得失、实际交战、各战伤亡和武将净功绩取自战果记录与累计功绩计数，不依赖有数量上限的详细战报归档。空城接收与实际交战分列；伤兵、参战兵力按各战累加，不冒充独立人数。战败玩家仅汇总本方记录；观战结局明确显示实际统一势力。页面提供最终存档导出、返回地图、分页回顾和新局选择入口。`verify:campaign-ending` 使用明确标记的终局机制夹具，不能算自然统一证据。

长局审计同时记录逐日耗时、并行战场数、当前结算凭据与待处理节点数、保存与验证耗时、完整存档体积。性能门槛预先定义于 `scripts/performance-budgets.mjs`，慢样本保留为失败，人物状态仅保留当前快照，战场回放继续验收。`verify:campaign-performance -- --save=<自然当前存档>` 检查独立副本；Android实测门槛由 `verify:android-device` 检查，包含实际安装包与当前重新编译代码的版本一致性、启动、导入导出、命名存档、前后台、横竖屏及断网重启。测试包允许WebView调试，最终发行包关闭调试后另做覆盖安装与启动确认。浏览器窄屏验证不代替设备运行。

Android大文件可用 `verify:android-device -- --apk=<验收APK> --save=<自然存档> --install=true --native-file=true`，通过手机本地下载目录和系统文件选择器导入；计时从实际选中文件到持久化成功，不包含测试工具传输文件和寻找文件的时间。验收结束删除本次临时下载文件。完整保存、推进及导出仍按实际界面和完整字节核对。

Android 使用原生 SystemBars 安全边距和 `viewport-fit=contain`，避免新版 WebView 在全面屏模式下把操作栏绘到状态栏、手势栏和摄像头区域。横竖屏验收同时核对原生 WebView 边界并保留包含系统栏的设备整屏截图，不能只检查 WebView 内部截图。

横屏矮视口取消地图页固定最小高度，命令列表可独立滚动，收获摘要按需展开；顶部菜单、推进与势力命令须在实际视口内可见且可命中，底部工具不依赖页面外滚动。

地图持续拖动时保持已解码的地形预览，短暂停住手指不提前切回矢量图；装饰性道路、城市阴影及施工闪光在移动期间暂停，松手后恢复。建筑、标记、迷雾和交互使用原有节点。`verify-map-performance-ui.mjs` 验证持续按住、松手恢复、静止地形像素及完整存档不变。

道路优化替换最短路队列，在单次同步查询内复用公开几何及不变补给连接，并用终点距离排除不可能属于最短路径的仓库搜索分支。各仓库仍按原正向顺序选路，保留代价、同代价节点与道路顺序、外交通行及实时封锁；逐日库存和多军团共享吞吐重新计算。`scripts/verify-route-equivalence.mjs` 对冻结优化前引擎与当前引擎逐日比较完整存档，不能只比较城市数或胜负。

`planning-queries.mjs` 将人员、内政候选、预算、补给及路径的索引限制在同步只读候选比较中，实际任命、支付、条约变化或移动前全部释放。不同迷雾视角分别索引；候选部队人数、条约限制、虚拟城市和显式补给预测不得共用不相符的结果。历史关系来源可预先索引，存档中的动态关系类型与分值仍实时读取。性能计时须独立运行，不与全量回归或其他长局争用计算资源；并发运行的观察耗时保留为诊断，不据此宣称独立性能达标。

侦察计功及旬报按已验证的日期顺序定位近期纪事，不遍历全部永久历史。情报投影按需生成本方纪事，并保留投影创建时的序列边界。外交只读查询仅在同一同步比较作用域内复用有效条款，契约对象、顺序、通行条件及兵力上限不变；作用域结束后重新核对实际日期和条款状态。

自然统一必须从原始剧本新局开始。`scripts/audit-ai-unification.mjs --require-unification=true` 在观察天数耗尽时返回失败；`verify:natural-completion -- <运行目录1> <运行目录2>` 要求至少两个剧本、两个种子，核对当前运行时全部输入、实际统一胜利、完整存档及长局性能。发行检查可用 `--completion=<目录1>,<目录2>` 加入该门槛；未传入时发行结果只覆盖已列步骤，不宣称自然长局已通过。中断、天数上限、终局夹具及旧版本记录均不算统一。

源码网页版的 `source-offline-files.js` 由真实HTML、JS动态导入及CSS依赖图生成，包含存档、任命、宝物等实际模块。源码服务启动自动更新；手动部署先执行 `offline:generate`。Service Worker仅在全部必需文件缓存成功后激活，以同一版本缓存提供代码；美术按访问单独缓存。`verify:source-offline` 在全新浏览器中禁用HTTP缓存，完成首次缓存后立即断网刷新，再测试离线开局、保存、重载与动态加载。发行包离线验收使用其自身完整文件清单。独立美术生产进度按美术工作区核对，本机缺图不作为全库缺图结论。
