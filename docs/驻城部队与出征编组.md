# 驻城部队与出征编组

城市保存独立的预编部队，不保存常驻“大军团”。城内预编没有十队总数限制，不取消太守或内政任职；军团只在实际出征后成为大地图实体。

## 出征流程

先在单支部队表单选择一名在城主将、兵种及兵力，可逐支编制；再从已编部队中选择一至十队组成军团，任命军团长和军师，大地图逐点选路，最终核阅确认。策略、首发、位置与出阵顺序在战前会议安排。取消不改变状态。

若所选武将正在办理内政，沿用立即执行或完成当前事务后执行的选择。等待命令持久保存所选部队及任职，等待期间仍是驻城部队；实际执行时重新校验资格、扣取携粮并创建军团。

军团抵达己方城市后，部队归入该城独立部队，剩余携粮入库，军团实体解除。守城战开始时从驻城部队临时组织防守军团，战后解除临时编组；败退部队按真实战斗结果撤退。地图不显示临时守城军团。

守城遭遇待处理时，可通过「临时编制守城部队」选择尚未编队的在城武将、配置兵种并整补，确认后加入当前守方真实战斗名单。开战后关闭此入口；取消草稿不改变存档。仍使用本城兵源、金粮与本旬征募额度，不额外赠送兵员。

守城临时编制为可选操作，仅有尚未编队且符合资格的驻城武将时显示入口；已有守军直接进入战前军议。取消临时编制返回军议并保留原草稿，关闭遭遇提示不会反复弹出同一场遭遇；待处理战线仍保持全局暂停，可从舆图战线入口继续处理。
