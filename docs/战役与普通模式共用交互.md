# 战役与普通模式共用交互

战役使用普通模式的选将、安排编制、任命指挥和核阅确认界面。查看武将、部队属性、战法效果时使用同一组详情弹窗，返回保留选择与草稿。取消不提交，确认才更新编制。

- `strategic-roster.mjs` 的 `taskPickerMarkup` 接收候选数据及事件适配参数；普通模式提供实际驻城人员与可任用原因，自定义战役提供武将库与双方去重限制。两者共用推荐算法与特性说明；连携放到军团编组阶段。
- `army-setup-view.mjs` 提供共用部队配置和指挥任命视图，由 `strategic-command.mjs`、`military-flow.mjs` 和 `scenario-setup.mjs` 使用。
- `combat-comparison.mjs` 共用部队、战法、特性、军略与连携分页；指挥任命同样使用列表选择。
- `scenario-setup.mjs` 仅负责独立战役数据与提交。自定义战役保持每方一至十队，编制时配置等级、兵力、兵种；军团编组任命军团长和军师；战前会议配置布阵与出阵顺序；两方不能重复选同一武将。
- 历史及演义战役仅能在开战前调整既定己方军团的兵种、顺序、首发、位置、任职与策略，不增减剧本武将，不改等级、兵力、战法学习记录或敌军。实际开战后仅查看。
- 独立战役不调用城池征募、人员调任、内政打断、返程和战后去向规则。普通模式继续使用原有规则，最终确认前的预览仍不消耗资源。

自定义战役确认后保存配置；战前进一步调整也写入本局自定义阵容，可随当前存档继续或按同种子重开。战法预览按本局种子和等级生成，换兵种不重抽。


## 两阶段编制向导

按“编制部队（页内选择武将和兵种） → 部队面板 → 选择已编部队 → 编组军团 → 核阅结果”推进。编制部队时选择兵种并展示该兵种适性、适用武将特性；部队面板展示现役兵力、带兵上限、属性及当前兵种已学战法。此阶段不混入军团任职、连携和军略。

确认部队后安排军团指挥任职，并分页查看连携与军略。普通模式仅城内预编时，在部队核阅后结束，不建立军团；出征继续编组军团及选择目标。战役的既定阵容固定武将。军团选队页只列已编部队；普通模式也列出本城现有独立部队。普通模式调整、拆分军团也采用部队配置、部队面板、军团编组、核阅顺序。

所有中间步骤仅编辑草稿；返回可修改，最终确认才提交。切换信息页签、查看详情后返回保留滚动位置。

军团核阅预览与现有军团详情共用 `army-details.mjs` 的任职、兵力与行军、军略区块。大地图移动力调用实际 `movementPoints` 规则；独立自定义战役按开局士气80、无缺粮展示，既定军团保留实际士气与缺粮状态。

## 单支部队表单

编制部队主页面只显示一支部队的表单。点击“选择主将”进入单选武将列表，选定即返回，再选择兵种并核对适性与适用特性。列表仍支持查询、表头排序与分页签，但不允许多选。点击“确认编制这支部队”后展示该部队面板；自定义战役和出征流程可“再编一支”，军团选队阶段才多选已经确认编制的部队。


战前会议共用 `battle-council.mjs`，在开战前选择调整出阵顺序，并在战场布阵；首发最多六队，其余依序候补，援军到达时间不变。自定义战役支持野战、我军守城、我军攻城和城门耐久设置，城门与场景随存档保存并校验。

兵力采用滑动条和最小／最大按钮，最小1000。普通模式最大值扣除其它草稿占用，受带兵上限（含伤兵）、据点未预留兵员、征募额度、金粮约束；减少现役人数归还据点预备兵，不退还征募费用。战役编制预备兵无限，仍受带兵上限约束。最终提交重新校验，草稿及取消不花资源。

选择已编部队时动态显示所选部队的连携。编组步骤只指定军团长和军师，不提供副将、位置和出阵顺序设置；完整军团详情仍在核阅步骤查看。战前会议队列支持拖动排序，战场支持拖动部队布阵，开战后锁定。

## 部队管理入口

编制入口先展示部队列表。玩家可选择任意已有部队进入单支编制表单，也可点击“新增部队”。确认后返回列表，可继续修改其它部队或新增；表单提供“返回部队列表”。部队管理不作为只能顺序前进的向导，军团选队、任命与最终核阅仍在后续完成。历史战役保留指定人员不可增减的限制。

部队列表支持解散。普通模式解散实际驻城部队时，现役兵员与伤兵返还本城预备兵，编制金和粮草不返还；武将留城，保留内政任职与事务、学习记录。解散与新增/改编共用草稿和最终核阅，取消不改变资源。待出征命令内的部队须先取消命令。未提交的新部队移除不产生返还。自定义战役可移除部队，指定历史人员不允许增减。编制表单和部队列表显示据点现有预备兵，自定义战役显示 inf。
