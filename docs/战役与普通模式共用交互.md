# 战役与普通模式共用交互

战役使用普通模式的选将、安排编制、任命指挥和核阅确认界面。查看武将、部队属性、战法效果时使用同一组详情弹窗，返回保留选择与草稿。取消不提交，确认才更新编制。

- `strategic-roster.mjs` 的 `taskPickerMarkup` 接收候选数据及事件适配参数；普通模式提供实际驻城人员与可任用原因，自定义战役提供武将库与双方去重限制。两者共用推荐算法与特性说明；连携放到军团编组阶段。
- `army-setup-view.mjs` 提供共用部队配置和指挥任命视图，由 `strategic-command.mjs`、`military-flow.mjs` 和 `scenario-setup.mjs` 使用。
- `combat-comparison.mjs` 共用部队、战法、特性、军略与连携分页；指挥任命同样使用列表选择。
- `scenario-setup.mjs` 仅负责独立战役数据与提交。自定义战役每军团一至十队，可给双方分别新增多支援军军团；编辑一军只提交该军，所有先遣及援军人员去重。编制时配置等级、兵力、兵种；军团编组任命军团长和军师；战前会议配置布阵与出阵顺序。
- 历史地图载入自定义编辑器后，双方先遣、援军和到达时间均可编辑。实际开战后布阵、编制和战斗意图锁定；己方援军抵达时可重开军议调整后备顺序与撤离条件，在场部队保持实际状态和位置。
- 独立战役不调用城池征募、人员调任、内政打断、返程和战后去向规则。普通模式继续使用原有规则，最终确认前的预览仍不消耗资源。

自定义战役确认后保存配置；战前进一步调整也写入本局自定义阵容，可随当前存档继续或按同种子重开。战法预览按本局种子和等级生成，换兵种不重抽。


## 两阶段编制向导

按“编制部队（页内选择武将和兵种） → 部队面板 → 选择已编部队 → 编组军团 → 核阅结果”推进。编制部队时选择兵种并展示该兵种适性、适用武将特性；部队面板展示现役兵力、带兵上限、属性及当前兵种已学战法。此阶段不混入军团任职、连携和军略。

确认部队后安排军团指挥任职，并分页查看连携与军略。普通模式仅城内预编时，在部队核阅后结束，不建立军团；出征继续编组军团及选择目标。战役的既定阵容固定武将。军团选队页只列已编部队；普通模式也列出本城现有独立部队。普通模式调整、拆分军团也采用部队配置、部队面板、军团编组、核阅顺序。

所有中间步骤仅编辑草稿；返回可修改，最终确认才提交。切换信息页签、查看详情后返回保留滚动位置。

军团核阅预览与现有军团详情共用 `army-details.mjs` 的任职、兵力与行军、军略区块。大地图移动力调用实际 `movementPoints` 规则；独立自定义战役按开局士气80、无缺粮展示，既定军团保留实际士气与缺粮状态。

## 单支部队表单

编制部队主页面采用军团整备名单，一队一行直接调整兵种、适性和兵数；点击头像或姓名进入共用部队详情，返回保留草稿与列表位置。属性、羁绊和战法在详情内查看。新增部队保留单支表单，点击“选择主将”进入支持查询、排序和分页的单选武将列表，选定即返回，再配置兵种和兵数。确认后回到整备名单，可继续调整其它部队；军团选队阶段多选已编制的部队。


战前会议共用 `battle-council.mjs`，在开战前选择调整出阵顺序，并在战场布阵；首发通常最多六队，已抵达的奸雄所属军团可用第七名额，其余依序候补，援军到达时间不变。援军军议只重排后备及设置撤离，不移动或替换在场部队。自定义战役支持野战、我军守城、我军攻城和城门耐久设置，城门与场景随存档保存并校验。

兵数支持手动输入整数、滑动条和最小／最大按钮，最小1000。输入后按回车或离开输入框更新草稿，超额或低于下限保留输入并提示，阻止下一步，不静默截断。普通模式最大值扣除其它草稿占用，受带兵上限（扣除伤兵）、据点未预留兵员、征募额度、金约束；减少现役人数归还据点预备兵，不退还征募费用。自定义战役设置我方总预备兵，先遣及全部我方援军共用；最大值扣除其他草稿部队及其他我方军团占用，同时受带兵上限约束。减少兵力、解散或移除我方军团后可重分配；剩余不足1000时不能新增。敌军不占用我方额度。新建部队默认最高合法适性，并列优先武将常用兵种；已有及手动选择保留。预设战役的开战前整备保留固定兵数，只允许调整兵种。最终提交重新校验，草稿及取消不花资源。

选择已编部队时动态显示所选部队的连携。编组步骤只指定军团长和军师，不提供副将、位置和出阵顺序设置；完整军团详情仍在核阅步骤查看。战前会议队列支持拖动排序，战场支持拖动部队布阵，开战后锁定。

## 部队管理入口

编制入口先展示部队列表。玩家可选择任意已有部队进入单支编制表单，也可点击“新增部队”。确认后返回列表，可继续修改其它部队或新增；表单提供“返回部队列表”。部队管理不作为只能顺序前进的向导，军团选队、任命与最终核阅仍在后续完成。独立战役只保留自定义编辑器，双方人员均可编辑。

部队列表支持解散。普通模式解散实际驻城部队时，现役兵员与伤兵返还本城预备兵，编制金和粮草不返还；武将留城，保留内政任职与事务、学习记录。解散与新增/改编共用草稿和最终核阅，取消不改变资源。待出征命令内的部队须先取消命令。未提交的新部队移除不产生返还。自定义战役可移除部队，指定历史人员不允许增减。编制表单和部队列表显示据点现有预备兵，自定义战役显示我方预备兵总额、已编制和可用人数。
