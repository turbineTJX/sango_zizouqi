# 单城资源与经济平衡

## 资源与实际消耗

储备兵是尚未编制的兵源资源，和部队现役士兵分开保存。玩家编制、调整兵力或补兵时，按实际兵种花费金并消耗储备兵，将兵源转为现役；编制本身不扣粮，玩家在零粮库存时也能编制。现役部队驻扎、行军和作战消耗粮草，真实战斗减少现役兵力并产生真实伤兵；战损不会直接扣城内储备兵，后续补兵操作才扣钱和兵源。

未编制储备兵不收金或粮维持费，不轮换归乡，不自行减少。当前无定期部队军费，金用于编制、补兵、改编、建设、科研、人才与外交等实际操作。军务在兵源不足时征集库存，兵源充足且部队有缺额时按真实费用整补；征集库存不生成现役部队。医疗只恢复真实伤兵，测试按重新编制同等兵力所需的装备金与兵源提供参考价值，不代表实际新增库存或保证节省同额资源；医疗本身仍支付命令的药粮和金费用。

自动整补可以因未来口粮不足而减少计划人数，但粮是随后现役部队需要的补给，不是编制时的一次性费用。玩家与AI使用相同编制扣费，AI的补给预留不会给AI免费粮兵或禁止玩家手动编制。出征携粮从城仓转入军团，在途粮与库粮不得重复计算；实际食用、损失后才算消耗。

正式数值源为 `data/design/economy-rules.mjs`、`data/design/domestic-actions.mjs`、`data/design/troops.mjs`。查看[经济规则表](design-tables/经济规则一览表.md)、[内政动作表](design-tables/内政动作一览表.md)。当前战略存档版本53、内政版本19，旧档重新开局。

## 城市先决定收入空间

按照用户最新方向，先由当地富庶程度、都市圈实际地点和建设上限决定持续收入，再安排内政和校准资源价值。人才决定建设速度、成果概率与当地生产能力的利用，不能让贫城依靠堆武将获得无限产出。富庶名单是游戏配置，不声称来自历史经济统计。

市场、农田、兵营：小城本地最多2级，普通大城本地3级，富庶大城本地6级。大城可扩建到圈内小城、关卡和港口，但自己记录的单类设施总等级最多12。小城外部建设额度各2级，与小城自己的设施共用地点容量；关卡市场1、农田0、兵营2；港口市场3、农田1、兵营1。其它设施本地5、外部3，城墙只在本城。地点有其产业倾向，并非每圈三类设施总上限都能达到12。

新增商业收入、督耕粮和未编制兵源，每类每城每旬共享价值额度 `100＋有效对应设施等级×50`，分别除以基准价值并向下取整。实际成功成果、合作与特性都在额度内结算，多人可以更快兑现额度；没有成功任务不会自动领取。旬内已用额度存档，读档或查看不会恢复。买卖和运输是资源转移，费用退回及真实伤兵救治不作为新增本地资源截断。

主城只领取自己实际拥有的设施成果；小城自己的设施不会向主城重复结算。敌方小城、围城和敌军封路令外部设施失去生产能力及相应办事额度。失守时已建设施移交实际小城，保留物理等级，不重复记账。

以下是充分建设、道路畅通、无太守及临时加成，并充分兑现直接办事额度时的每旬本地直接生产上限；不代表开局或日常自动收入。买卖、外援、运输收入及战利品另计，不能把直接生产上限当作府库全部现金流的上限。

## 先测消耗，再校准产出

`npm run audit:economy-valuation` 先测消耗，不读内政产量来决定比例。45组对照包括和平守备、常规作战、高永久减员、昂贵兵种、粮运损耗，覆盖30／60／120天与5000／10000／15000名周转储备兵。初次编制、部队口粮、补兵金、实际投入的储备兵及粮运损耗分别记录，并提供初次编制按时长摊销的结果。

固定负载为2500人守备与3队各2500人的前线，普通前线兵种为枪兵、弓兵、骑兵。常规每旬5%永久减员，高损兵18%；昂贵兵种为投石、骑兵、冲车，每旬8%永久减员；粮运压力每旬另损失1500粮。口粮、编制费用、兵源转换和本旬额度使用真实共用函数。减员与粮运损耗是明确的压力输入，不冒充真实战斗或运输袭击抽样；部队驻城以隔离纯消耗。测量每旬补回已使用的兵源，维持相同负载，补入量完整记录，不计为免费内政产出。

120天常规负载下，每旬约消耗127金、962.5粮、375储备兵。127金为真实整数装备费用，375储备兵为实际补入现役人数；初次组建10000现役士兵另花3125金、10000储备兵，不扣粮。和平无战损时储备兵消耗为零，不能从和平场景硬推一个兵源汇率；储备库存大小不改变未编制阶段的口粮或金消耗。

按覆盖同样需求时长折算，常规粮价值为127÷962.5≈0.132，兵源价值为127÷375≈0.339。当前采用圆整基准金1、粮0.13、兵源0.34。它是常规供养需求的共同尺度，不是唯一客观市场汇率；兵种、战损频率、运输损失与初次编制摊销会改变结果。交易与外交仍需根据真实库存、缺口、预留、运输和履约能力定价，不能把消耗比例当成无条件成交价。

然后采集16个开发种子、32个独立验证种子，30／60／90三档能力、8类资源相关事务的原始净资源变化，共1152次实际结算。17738组候选比例只用于敏感性诊断，不反过来决定消耗基准。编制对照覆盖当前9兵种：缺粮不影响一次性编制，增加粮不会替代缺钱或缺储备兵；现役部队产生后才需要持续口粮。

## 建设基础与额外运营

城市经济分成两部分：城市底值和有效已完工设施提供基础收入，武将驻城任职及实际事务提供额外运营成果。基础收入不含太守政治、任职效果或阶段经营加成，撤走武将不会扣掉已建成设施的基础产出；外部设施仍须满足真实归属与通路条件。太守离城停止其任职加成，已完成的阶段经营成果保留到实际有效期结束，直接成果已经入库，不因负责人离开而倒扣。

内政和城市详情分别显示“城市建设基础／旬”“太守与阶段运营加成／旬”“本旬直接运营已入库”。旬末结算只发放基础和有效周期加成；直接运营在事务完成时已支付，不能再按收入汇总重复领取。这里的已入库成果是生产数量；评估运营收益仍须从实际资源变化扣除费用，而不是拿界面生产总量当净收益。

建设与运营采用两个独立验收口径：

1. **建设效率**：同相关能力、同设施起点、无特性及协作，比较名义工程量／实际占用人员天数。各类建筑保留各自正常工程量；20天工程正常需要10天工程的两倍时间。三种经济设施另比较新增永久旬产值／实际人员天数、新增旬产值／实际净建设费用，计算真实延期及成功退费。普通受阻延期为原工期的50%，向上取整；命令特性可缩短延期，接续不重复收费。
2. **运营收益**：同设施条件、同相关能力、同实际需求，比较额外成果扣除实际费用后的日历净资源价值，排除城市基础和无关太守收益。武将可兑现当地额外产能，不能因所在城市原本富裕而被算成个人效率更高。建设提高的潜在办事额度单列，不当作已经获得的运营收入。

市场、农田、兵营每级永久增加100金、770粮、294储备兵，折合100、100.10、99.96基准金／旬；基础费用同为500金、名义工期同为10天。工坊、城墙等功能型建筑按工程量比较施工效率，其科研、防御与人才作用按实际目标评估，不附会现金产出。

`npm run audit:economy-income-parts` 使用16个开发种子与32个独立验证种子、30／60／90三档能力，完成九类建筑各一级共1296次实际工程，另测三类直接运营共432次。修复前固定延期5天会让20天工程在开发样本中最多快约16.9%；改为工期比例后，配对同随机结果的九类工程效率一致。三种经济设施的新增基础价值／人员天数及净费用偏差约0.141%；独立验证的直接运营日历净收益最大偏差约0.141%，均低于10%目标。开发样本运营最大偏差约0.154%，同样通过。

诊断在七个现行剧本、开局／任职加成／合法成熟设施／外部阻断四类明确输入下检查2128个城市状态。收入拆分前后的实际周期收入、农业需求及自动整补预测均一致。这是函数对照，不代表重新跑了旧年度战争；20天工程受阻后的工期已变化，当前剧本另做逐日复测。原始结果为 `outputs/economy-income-parts/results.json`。

## 内政运营和用人

集市、督耕、常规兵源征集均只使用对应方向的主属性、真实概率与成果倍率。同能力、同等级、无特性时，按常规基准折算的日历净收益应在10%以内；本地产能约束在三方向使用等值额度。常规事务成果为200金、1538粮、588储备兵；三者近似等值，属于武将额外运营而不是城市建设基础。库存满或没有实际需求时不会保证同额有效收益。单人原始价值复测使用6级许昌，避免把产业限额误作主属性或医疗能力差异；另测贫城限额下的多人收益。

日常三类生产不需垫金，可在钱粮见底时恢复经济；未建设市场或农田也能办理。建设、科研、医疗、人才、贸易、加急与真实部队装备仍支付各自费用。安全城市优先常规征兵，不随机反复支付加急费用；遇到实际威胁再提高加急选择权重。

一人每旬正常重新选令一次，5天事务通常完成后等下一旬；同时报告办理天数与日历收益，不假设每旬自动办理两次5天任务。医疗共用一次总救治额度，不能因部队增加将额度重复发给每队。武备、科研、人才、救灾与守城准备按真实目标和长期成果验证，不虚构现金产出以凑齐六方向。

AI填补六方向空缺时，先按现役、真实待编人员、在城军团和武将真实兵力上限预测口粮；战略整补的4500人初步目标不代替军务内政可补齐的完整上限。若农田的持续产出不足，优先安排农业，再按能力与需求填其它空缺。已有任职和事务不自动替换；之后商业、农业、军务各可安排最多3名实际人员。AI外交在持续产粮不足时不抽走最后一名实际在城可办事的农业负责人，玩家可自行调整。共用玩家推荐和费用，不给予免费资源。正常施工和内政继续使用真实队列、地点、费用和人员时间。

农业在库存低于本城20天口粮及已承诺粮食时优先直接产粮；不产粮的农业事务须留足实际工期及正常延期的口粮。售粮保留本城20天口粮和已承诺运输／出征粮。完全处理过的灾情不再反复抢收或整理，未处理灾情按剩余可避免损失评估。

## 承载与压力验收

战争承载由城市收入空间与人才共同决定。金、粮、储备兵、后续补兵、运输与留守都计入，不把开局库存当成持续产出，也不靠停止战争或停止补兵通过验证。

`npm run audit:metropolitan-economy` 测四种城市的合法成熟设施上限，保留小城原有设施的地点占用，分开记录固定收入和办事额度。32个独立种子、三档能力、每方向1／3／8名同步同能力办事人员，按单人真实成果逐样本截断，校验限额后的三方向价值偏差。多人同结果是明确的受控输入，不冒充实际独立任务或AI安排。

成熟承载对照按每线3支3000人部队、2500人留守，测试一至三线、每旬5%／18%永久损失，持续120天。每日口粮与旬末补兵使用真实共用函数；永久损失是明确压力输入，补回测量用兵源有单独记录，不能当成实际收入。初次成军单列，不在日常需求中重复收费。表中持续承载是毛收入上限比较，实际用人、施工、运输和道路受阻会降低能力。

高损耗一线每旬实耗540金、988粮、1620储备兵；成熟襄平直接生产最多1276储备兵，仍差344人，直接资金产出也有缺口，依靠本地生产不能长期维持。出售余粮可改善现金流，交易、运输或盟友补给可以补足实际缺口，仍须执行真实交换与交付。成熟许昌可承担一线，未加太守时两线已略缺兵源；成熟完整江陵圈可承担三线高损耗，其兵源上限5686高于每旬4860的补兵需求。低强度战争更易承载，不能把高损耗结论解释为贫城无法出兵。

`npm run audit:economy-campaign` 使用当前官渡剧本、完整真实道路、实际编组和敌城守军，跑120天出征、运输、真实战斗与存读档，不缩短道路或指定胜者。真实玩家军团为3队各2500人；小规模实战只验证机制，不替代三线大军团持续消耗测试。
