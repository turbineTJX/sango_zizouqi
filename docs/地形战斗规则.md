# 地形战斗规则（规则 17 引入）

当前版本存档保留地形与确定性续战，旧档不迁移。具体地形数值以正式设计表和共享处理器为准。

地形作为场景配置保存，开战后锁定。地图与属性面板展示实际地形及修正；合法场景、水陆限制由共同引擎校验。

## 战场与通行

14 × 8 六角网格使用15张普通地图和6张历史地图，由 `data/design/battle-maps.mjs` 定义。地图以 `mapId` 保存，不消耗战斗随机数；未指定地图的自定义战役使用该地形的默认地图。普通模式按交战据点或道路固定选图，道路反向、阵营和随机种子不改变地图；港口使用湾岸港口，关卡使用狭口雄关。编辑器可预览和选择全部地图，开战后锁定；重试、读档及每日回放保留原图。

| 战场 | 布局 |
|---|---|
| 平原 | 阡陌旷野、双丘夹道、古道交汇：开阔展开、丘陵侧翼、交叉进路 |
| 林地 | 林间大道、曲折山谷、溪桥密林：宽路、弯折谷道、双桥渡溪 |
| 丘陵 | 双台对垒、狭口雄关、三岭争道：台地射击、狭窄关道、分叉坡口 |
| 湿地 | 芦荡浅滩、水网堤道、双泽夹岸：绕行、干堤、水泽夹道 |
| 河流 | 两岸水道、南北双桥、湾岸港口：横向水战、双桥突破、岸路与港湾 |

历史地图分别使用下邳城前积水与干堤、官渡北坡南林、赤壁宽江与沙洲、合肥纵河与窄桥、夷陵曲折林谷、五丈原台地与北侧渭水。地形与兵力仍属游戏尺度的战术改编。

山壁不可通行，携船和无视ZOC也不能穿越。桥梁可供陆军通过，积水需要携船或绕行。图中小路标示可选通路，不额外提高速度；树林、坡纹、芦苇、波纹和山壁按实际格子绘制，不参与随机或结算。设计校验检查每个陆上部署格能接敌并返回己方边缘，避免孤立的部署区。

携船部队进入水面自动成为船形态，登岸或进入桥面恢复原兵种；没有船的部队只能走岸地和桥面。水陆切换不刷新兵力、状态、战法次数和冷却。地形不移除部队占位、城门和有效 ZOC 的限制，穿阵也不能跨越水陆通行限制。

常规移动按本步起点地形修正：林地骑兵 ×0.65、兵器 ×0.75、其他陆军 ×0.9；高地 ×0.85；湿地 ×0.6；桥面骑兵 ×0.8。其余 ×1。修正参与属性面板和小数移动进度，不修改战法位移的最大格数。

## 战法与地形

战法地形修正由 `terrain-rules.mjs` 的共享处理器判定，战法详情展示当前实际规则。按火攻、远程、冲锋、伏击、防御、机动、架设和水战效果分别处理；一个战法不会因多个文案标签重复乘算。

施放位置、目标位置、真实冲锋路径与水陆类型决定修正。持续灼烧按每次结算时的目标地形处理，不把进出地形造成的倍率反复叠乘。地形不绕过目标、射程、占位、ZOC或真实伤兵预算。

战场模板和通行定义见[战场地形表](design-tables/战场地形与地图模板一览表.md)。当前版本保存场景与随机状态，续战不重新生成地形。
