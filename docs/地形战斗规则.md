# 地形战斗规则（规则 17 引入）

当前版本存档保留地形与确定性续战，旧档不迁移。具体地形数值以正式设计表和共享处理器为准。

地形作为场景配置保存，开战后锁定。地图与属性面板展示实际地形及修正；合法场景、水陆限制由共同引擎校验。

## 战场与通行

14 × 8 六角网格采用固定、对称布局，由存档中的地形类型确定，不消耗随机数。

| 战场 | 布局 |
|---|---|
| 平原 | 全部平地 |
| 林地 | 两翼为林地，中路保留平地 |
| 丘陵 | 两侧为高地，中央为平地 |
| 湿地 | 中央为湿地，两翼为平地 |
| 河流 | 中间两行水道，中央两列桥梁，其余为岸地 |

舰船只能走水面和桥下，陆军只能走岸地和桥面。桥上陆军按桥面，桥下舰船按水面结算。地形不移除部队占位、城门和有效 ZOC 的限制，奇门也不能跨越水陆通行限制。

常规移动按本步起点地形修正：林地骑兵 ×0.65、兵器 ×0.75、其他陆军 ×0.9；高地 ×0.85；湿地 ×0.6；桥面骑兵 ×0.8。其余 ×1。修正参与属性面板和小数移动进度，不修改战法位移的最大格数。

## 战法与地形

战法地形修正由 `terrain-rules.mjs` 的共享处理器判定，战法详情展示当前实际规则。按火攻、远程、冲锋、伏击、防御、机动、架设和水战效果分别处理；一个战法不会因多个文案标签重复乘算。

施放位置、目标位置、真实冲锋路径与水陆类型决定修正。持续灼烧按每次结算时的目标地形处理，不把进出地形造成的倍率反复叠乘。地形不绕过目标、射程、占位、ZOC或真实伤兵预算。

战场模板和通行定义见[战场地形表](design-tables/战场地形与地图模板一览表.md)。当前版本保存场景与随机状态，续战不重新生成地形。
