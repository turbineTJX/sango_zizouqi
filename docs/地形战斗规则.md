# 地形战斗规则（规则 17 引入）

当前存档规则为 19，包含后续战意、敌军 AI 与状态界面更新；以下地形数值继续适用。

## 使用入口

在「战役试炼 → 演武 · 因地制宜」体验；所有战斗的布阵阶段都可选择平原、林地、丘陵、湿地、河流。切换会重置双方在场部队的阵位，保留战意、兵力、配装和随机种子。开战后锁定地形，有舰船（含预备队）时仅能使用河流。

地图用颜色与文字标识各格地形，部队属性显示所在格及移速修正。战法配置显示每招的地形规则，战法记录显示本次实际增强或减弱。普通战役默认平原，有舰船时默认河流；地形试炼默认林地。

## 战场与通行

14 × 8 六角网格采用固定、对称布局，由存档中的地形类型确定，不消耗随机数。

| 战场 | 布局 |
|---|---|
| 平原 | 全部平地 |
| 林地 | 两翼为林地，中路保留平地 |
| 丘陵 | 两侧为高地，中央为平地 |
| 湿地 | 中央为湿地，两翼为平地 |
| 河流 | 中间两行水道，中央两列桥梁，其余为岸地 |

舰船只能走水面和桥下，陆军只能走岸地和桥面。桥上陆军按桥面，桥下舰船按水面结算。地形不移除部队占位、城门和有效 ZOC 的限制，奇门也不能跨越水陆通行限制。

常规移动按本步起点地形修正：林地骑兵 ×0.65、兵器 ×0.75、其他陆军 ×0.9；高地 ×0.85；湿地 ×0.6；桥面骑兵 ×0.8。其余 ×1。修正参与属性面板和小数移动进度，不修改战法位移的最大格数。

## 战法增强与减弱

| 战法 | 判定位置 | 修正 |
|---|---|---|
| 火矢、火计、带灼烧的专属战法 | 每个目标格 | 林地伤害 +30%，湿地 −20%，水面 −40% |
| 箭雨、连珠、退射、破甲、阻射、投石、舷射；非火攻的远程武力专属战法 | 施放格及每个目标格 | 高地施放伤害 +20%；林地目标伤害 −20%；两项相乘 |
| 冲阵、八百破阵 | 起点、实际路线、目标格 | 取最不利修正：林地伤害 −30%，高地 −15%，湿地 −40%，桥面 −20% |
| 伏弩 | 施放格 | 林地伤害及迟滞、疲弱时长 +30%，高地 +15%，湿地 −20% |
| 枪阵、铁壁、营垒 | 施放格 | 高地、桥面状态时长 +25%，湿地 −25% |
| 疾驰 | 施放格 | 林地、桥面减伤与疾行时长 −25%，湿地 −50%；减伤百分比不变 |
| 架设 | 施放格 | 高地时长 +20%，湿地 −40% |
| 涡流 | 每个目标格 | 水面伤害及迟滞、衰咒时长 +25%，岸地（含桥面）−30%；不改变衰咒层数 |
| 其他战法 | — | 无额外地形修正，仍遵守原有射程、目标、位移限制 |

火攻专属战法优先采用火攻规则，不叠加远程射击规则。地形不改变战意门槛、冷却、目标数、射程和装备资格，也不降低治疗的伤兵限制。

直接伤害在最终取整前乘地形倍率，范围攻击逐个目标计算；退射按撤步前的施放格，冲锋按移动前记录的实际路线。状态基础时长乘地形倍率并四舍五入，至少 1 步，然后叠加关系连携的时长奖励。未列出的状态时长不变。

灼烧、燃击续叠和军略火攻的基础伤害不预先乘地形倍率；每步持续伤害按目标当前地形修正。进出林地或水面会改变下一步伤害，避免叠层反复放大。疫伤不受火攻地形修正。普通攻击、治疗、护盾、城门伤害保持原结算；地形通过移动和相关战法影响战局。
