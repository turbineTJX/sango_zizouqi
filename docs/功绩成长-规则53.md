# 功绩成长（规则53）

- 武将升级资源统一为功绩，存储字段为 `merit`，不再使用经验字段。1～9级升级依次消耗100、300、600、1000、1500、2100、2800、3600、4500功绩，溢出继续用于升级，10级封顶。升级不增加或更换固定战法，不重抽特性、适性或军略。
- 内政执行人按实际成果获取功绩：通常60、部分达成按结果比例减少、出色完成最多90。建设必须完工；研究、训练、治疗、贸易、探索、招揽等必须产生实际进展或成果。失败、取消、目标失效、无成果均不奖励；工程延期不重复奖励。太守每旬治政100功绩，围城仍按原规则暂停。
- 战斗双方共用贡献算法，取消固定参战奖励。普通模式和独立战役采用同一算法，战役成长只影响本场独立状态。

## 战斗贡献

贡献分＝实际杀伤＋实际承伤×0.35＋实际救治×1.2＋攻城／修缮×0.5＋支援次数×100＋控制次数×150。

功绩＝贡献分÷60，胜方额外乘1.25，最后四舍五入；有贡献至少1功绩，无贡献为0。不是按击杀尾刀分配，也不由全军均分固定奖励池。

- 杀伤包括普攻、战法和持续伤害，仅计实际扣除的敌军兵力；溢出伤害、自损不计杀伤或承伤贡献。
- 救治按实际恢复的本场伤兵计入施救者；军略救治归实际军略提供者，持续恢复沿用其来源。
- 攻城按实际扣除城门耐久，修缮按实际恢复耐久计数。
- 战法支援计入新施加给其他部队的有效状态及实际恢复战意的次数；未成功的控制和被免疫的控制不计。相同有效状态未结束时重复施加不另计状态贡献。
- 全军军略的号令支援／控制按施放时在场作用队数记入提供者；救治和火攻改按实际恢复／杀伤记账。此处是贡献估分，不反推增益最终带来的额外伤害。
- 所有计数随当前版本存档和每日战斗快照保存；结算仅执行一次。未行动的预备队不领取固定参战功绩，但担任指挥并实际施放军略者可获得相应贡献。

战果显示功绩和贡献明细，内政事件显示功绩与升级。参数以 `data/design/progression.mjs` 为准；当前版本保存贡献与结算标记，旧档不迁移。
