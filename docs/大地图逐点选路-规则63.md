# 大地图逐点选路与单一道路（规则63）

## 道路

- 删除同一连接自动生成的平行主路、支路，每条连接只有一条真实道路。
- 保留野外路口及横向小路；绕行通过真实路网完成。双方行军、运输、粮道与遭遇均使用同一条道路。
- 道路加粗、增加对比度，并保持缩放时的屏幕线宽；已选行军路线高亮。

## 操作

- 军团出征完成编组后进入大地图选路；点击军团图形或头像直接打开军团详情，点击“调动军团”再进入这一流程。
- 点击据点、野外路口或与当前选路起点相连的道路，预览到该点的路线。
- 选点后显示四个选项：继续行进（选下一点）、设为终点、返回（到上一点选择）、取消。
- 继续行进保存已选路段，再选择下一点；返回恢复上一选点及其之前的路线；取消丢弃草稿。
- 设为终点进入原有命令核阅，最终下令前不扣资源、不建立出征军团、不改变现有军团路线。
- 明确选定的道路逐段保存，不在提交或等待内政完成后重算成另一条最短路径；非法、断开的路径和重复经过同一点的路径被拒绝。
- 战略移动仍遵守原有筹划阶段、实际行军速度及内政打断规则。
- 大地图点击“进行”后每3秒推进一天，独立于战斗观看倍速；暂停、查看弹窗及页面隐藏期间不累计补跑时间。每日行军距离、粮耗和内政进度仍按共同战略规则结算。

## 地图选目标

- 出征、军团调动、人员调任与运输目的地均在完整大地图点选，不使用目的地下拉框；行军保留逐段选路与最终核阅。
- 侦察派出城与周边终点、运输接力城、普通模式军议撤离节点、外交重点势力共用地图点选界面。外交通过点选该势力已知城市指定势力，不读取隐藏城市归属。
- 金色标记表示当前合法目标，选中目标高亮；无资格地点不能选入。候选分别复用侦察范围、己方城市、道路安全撤离及合法势力规则，最终执行继续使用原处理器复核。
- 点选只修改选取草稿，确认后返回原表单；侦察、运输与外交仍须在原流程下令。撤离节点确认时通过原设置处理器保存。
- 取消或 Esc 返回来源页面，保留原目标、负责人员、物资、外交表单和军议草稿，不推进日期或扣资源。
- 名称搜索只定位地图，仍须点选标记并确认；缩放、拖动、全国视图和定位始终只改变视野。支持地图缩放、拖动与键盘选点，手机使用同一界面。
- 界面验证：`node scripts/verify-map-targets-ui.mjs`、`npm run verify:war-fog-ui`、`node scripts/verify-diplomacy-ui.mjs`。

## 地图查看

- 地图为主操作区域，城市名册与对象管理侧栏按需展开；点选城市、军团图形或头像直接打开对象详情；详情保留调动、内政、编制和管理入口，明确选择操作后才进入命令流程。
- 城市内政在独立工作页显示六方向委任、设施与办理进度；查看武将后返回原页，取消委任返回内政页。
- 部队管理左侧列出编制卡片，右侧查看部队／武将情报或编辑主将、兵种和兵力；普通模式与独立战役共用布局。
- 地图选路旁持续显示待出征部队、总兵力、道路消耗与预计行程；预计行程以当前行动力计算，实际受补给和交战影响。
- 初始显示当前操作区域；支持左键拖动空白、右键拖动巡视、滚轮缩放、全国概览和定位复位。取消常驻小地图，地图导航只改变视野。
- 缩远时淡化道路与次级地名；势力示意按最近据点归属着色，仅用于辨认分布，不代表逐格占领，也不改变道路、补给与战斗规则。
