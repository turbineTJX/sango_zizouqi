# 内政中断与后续命令

每名内政武将的当前事务保存在委任记录中，包括事务、目标、起始日期、剩余天数、已支付费用和暂停状态。武将详情显示当前事务、待执行命令及最近十二项完成、失败或中止记录；详细记录默认折叠。

## 玩家操作

- 改任其它内政方向、解除委任、调任或军团出征涉及当前事务时，先弹出选择，列明受影响武将、事务和剩余时间。
- 立即执行：中止原事务并执行新命令，记录中止结果；原事务已支付费用沿用现有不退还规则。
- 完成当前事务后执行：保存后续命令，原事务继续办理，结束后自动执行。等待期间不再为相关武将开始新事务。
- 批量改任按每个人分别处理：无在办事务者立即改任，其余人各自做完后改任。军团出征则等待全军涉及的当前事务结束，再整体出发。
- 等待出征的军团继续驻城并能守城，不预先生成行军路线；等待期间禁止拆分或合并，以保留确认时的人员范围。
- 可以取消等待；取消只撤销后续命令，不中止原事务。新命令覆盖已有等待安排时也会提示。
- 原事务的普通失败算本次办理结束。工程失败导致延期时仍属于同一项事务，继续等待实际完工。
- 实际参战守城者中断原事务，取消相关后续命令并保留任职；非参战者在围城期间暂停，解围后继续。若原事务被中止或武将、据点、道路等条件失效，取消后续命令并记录原因。
- 太守任命和城内部队预编仍遵循内政兼任规则，不因编制而打断内政。

## 存档与执行

当前事务、个人历史和待执行命令一起保存。读取后按同一任务标识继续等待，不重开事务或重复支付费用。每日内政结算后检查后续命令，行军从后续实际推进日开始，不额外获得行动。
