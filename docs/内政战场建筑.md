# 内政战场建筑

普通模式的箭塔、军乐台和救护营由内政负责人自动建设，建设城市支付费用、保存总等级和实际地点。大城可在主城、圈内小城、关卡或港口建设；各地点共用物理额度，每类最多3级。地点限额、道路通行、围城暂停、协作、受阻延期、中断接续和修复沿用共同施工规则。不增加逐项建造向导。

| 建筑 | 负责方向 | 解锁技术 | 技术开始条件 | 每级建设费／工期 | 原址战场效果 |
|---|---|---|---|---|---|
| 箭塔 | 军务 | 守备箭术 | 烽堠法、工坊1级、治安60 | 800金／20天 | 4格射程，每4回合射击一支可见敌军，优先近敌；基础威力180，每增加一级提高60，经目标防御和减伤结算 |
| 军乐台 | 武备 | 军乐鼓吹 | 烽堠法、校场1级、治安60 | 600金／10天 | 每6回合使3格内在场友军获得每级2战意，仍受100战意上限约束 |
| 救护营 | 技术 | 战地救护 | 烽堠法、医馆1级、治安60 | 700金／10天 | 每8回合救治3格内在场友军的本场真实伤兵，每级每队上限为初始兵力的0.4%；疫伤照常降低救治 |

三项技术是所有城市共有的守备进阶节点，不改变地方资质与特色兵种。科技树共23项，四条分支、最多两层，每城开放10～13项。完成研究只解锁建设资格，随后实际付费施工；不会直接赠送设施。技术和设施随城市易主保存，圈内小城已完工设施按共用规则移交当地。修复已取得的实体设施无需重新获得建设技术；扩建仍需本城技术。

每级1000耐久。未完成的新建没有战场效果，扩建期间仅已有等级生效；耐久归零停止效果，实际修复后恢复。城市攻防和军团在关卡、港口驻点交战，只带入当前交战地点真实设施，不把都市圈总等级投射到别处。没有真实守军的城市仍立即占领，建筑不作为守军或出场部队。

箭塔使用共同护盾、无敌、伤兵与溃败冲击处理；不读取隐身目标，不射击城门、建筑、后备或离场部队。设施不能移动、提供羁绊、军略或武将功绩。军乐台和救护营的重叠支援取附近同类较强设施，不叠加；后备、撤离中、脱战中及避战部队不接受支援，所属方全军撤退时设施停止工作。箭塔附近必须仍有可工作的真实守军。

战场保存每座设施的原址来源、已建等级、实际耐久和最近行动记录；读档、查看、暂停和修复不刷新间隔。战后损坏及战斗修缮回写同一地点，下一场沿用。双方和独立战役共用设施战斗处理器；独立战役不增加城市研究或战略资源。当前战略存档44、内政14，旧结构要求重新开始。

## 自动选敌与转火（规则112）

自动战斗双方共用 `pickTarget`、真实寻路和近战拦截规则，不给AI额外动作或数值。这里没有按累计伤害或治疗量增长的仇恨表；每次行动按当前合法目标、作用与位置重新判断，上一实际普攻目标有小幅连续攻击偏好。

- 嘲讽先检查来源存活、可见及实际可达；有效焦点状态沿用共用规则，不能穿过占位、近战牵制或不可通行地形。当前操作界面仍只提供已开放的军略及全军撤退，不新增集火按钮。邻接被前排遮挡的目标不能导致无意义脱战；非邻接目标必须有实际脱战后的接近路线。路线因新占位而失效时解除接续，重新选择合法目标。
- 普通近战先处理当前拦截者，邻接部队仍共用一次普攻伤害预算；设施自身不产生ZOC。近处10%以下兵力的合法军事目标优先处理；普通后排偏好与有实际作用的可攻击战斗建筑随后竞争。疾驰、穿阵、伏兵和追击继续按各自现有规则行动，不为了拆建筑取消其职责。
- 箭塔须已启用、仍有可工作的真实守军且射程内存在可见敌军，才提高攻击优先级；军乐台只计算附近可见在场部队的战意缺口，救护营只计算这些部队的本场可救伤兵。未建成、损毁、无受益者、已全军撤退或当前没有作用的设施不给军事价值加分。冷却中的有效设施仍保留作用评价，不因一次发射后进入间隔而来回转火。
- 无威胁建筑不进入首选目标池；此资格在焦点状态、伏兵、追击和评分前统一过滤，部队被定身、军事目标暂不可攻击或先前正在攻击该设施也不能绕过。攻城城门仍是进攻方的合法胜利目标。只有军事目标无真实路线可达，且解除某些敌方无威胁设施的占位后存在合法接敌路线时，才取该路线上的首个可达障碍作为清障目标；友方占位、前排牵制、守备边界与水陆通行仍受约束。部队实际移动绝不穿过尚未摧毁的建筑，旁边无关的设施不参与清障。
- 同层目标按距离、实际绕行长度、剩余比例、兵种克制、战斗意图及守城威胁评分。距离每格9分，剩余比例最多7分，普通设施增加32分；当前普攻目标仅减4分，弱于一格距离。战斗建筑按实际作用抵减设施惩罚，携带攻城器械的部队额外考虑拆除职责。目标毁坏、离场、隐身不可见或失去作用时重评，嘲讽、近战牵制及明确优先目标可立即改变攻击方向。参数在 `combat-rules.mjs` 的 `TARGETING`，作用计算在 `building-rules.mjs` 的 `buildingTargetValue`。
- 无城门的关卡、港口驻点战也能针对敌方真实建筑展开已携带的攻城器械，仍需合法距离及展开时间；移动接续不会把刚展开的兵器立即收回。后备择序在有实际建筑威胁时考虑已携带器械，继续保留前排、支援、实际到达和共同名额约束。

器械展开、攻击及收起时，战场模型、兵种图标、标签和详情均按当前形态更新，原兵种仍保存在编制中。冲车使用带顶撞木模型，投石车显示抛射臂，井栏显示高层楼架；每种优先加载自身匹配的素材，缺少对应素材时使用内置几何模型，不用同一投石车替代所有器械。WebGL不可用时使用对应矢量外形；收起后移除器械模型并恢复原兵种。查看和美术切换不改变真实战斗状态。运行 `npm run verify:equipment-models-ui` 检查桌面／手机、展开、实际攻击、收起及显示故障后的外形。

箭塔自身按范围内最近的可见敌军射击，距离相同优先兵力较少者，再按稳定ID排序。原目标超出范围、隐身、避战、离场或溃败后，下一次合法射击重新选择；不是谁累计伤害最高就必然吸引箭塔。军乐台和救护营按范围内合法友军工作，不追逐部队。

`node --test tests/building-targeting.test.mjs` 检查双方换边、有效与无效支援、民用建筑干扰、嘲讽、近战阻拦、不可达焦点、目标连续性、毁坏转火、攻城展开及确定性接续；`node scripts/audit-building-targeting.mjs` 使用合法多队阵容和固定战法运行双方自主战斗，检查反复脱战、兵器展开及完整续战。上述是机制验收，不能据此宣称建筑平衡或历史战役胜率已经达标。

本轮46项建筑选敌专项、5项器械外观专项及共168项相关回归通过。救护营价值使用实际救治预算，包含疫伤削减和人数取整，预算为零时不取得军事目标资格。16场完整自主战斗使用两个种子、平原／高地、野战／攻城及建筑所属方换边，全部通过当前存档校验及确定性续战。记录到227次有效箭塔射击、5761名真实伤兵救治及1次实际建筑攻击，未出现连续脱战准备；兵器展开最长连续4回合。多数接战先处理阻拦部队，歼灭或攻破城门即结束，不要求无必要地拆光建筑。原始阵容、兵力、目标、战果与行为计数保存在 `outputs/building-targeting/audit.json`。三种器械双方换边的桌面／手机、实际展开攻击、收起、内置模型和WebGL失效后的对应外形检查见 `outputs/equipment-models/ui/summary.json`。

正式参数为 [建筑设计](../data/design/buildings.mjs)、[科技设计](../data/design/technologies.mjs) 和 [都市圈选址](../data/design/metropolitan-areas.mjs)。共享战斗处理在 [building-rules.mjs](../building-rules.mjs) 与 [engine.mjs](../engine.mjs)，原址耐久及回写在 [building-durability.mjs](../building-durability.mjs)。运行 `npm run test:battle-buildings`、`npm run test:building-durability`、`npm run test:city-technology` 和 `npm run verify:battle-buildings-ui`。

新增建筑的透明素材用内置 ImageGen 生成并保存于 `assets/town/han-arrowTower-v2.png`、`han-musicStage-v1.png` 和 `han-aidCamp-v1.png`；完整提示词、返修来源与目视检查见 [素材记录](../assets/town/military-generation-prompts.json)。42项建筑、施工、技术和城内专项回归通过；另有68项共享引擎、战意、功绩和战争迷雾回归及16项建筑／经济对照通过。桌面与手机验证包含实际素材加载、技术节点、设施详情切换和只读检查，结果在 `outputs/battle-buildings/ui/summary.json`。全量战略回归未完成，单独诊断的76城正常开局已完成第一日推进，但AI筹划和情报投影耗时较长；工作区既有城镇背景及原建筑贴图缺失，新增三类素材完整。
