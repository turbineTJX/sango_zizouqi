# 大地图信息面板

大地图右上角「情报」提供据点、军团、部队、武将、势力五类名册，支持按名称或势力搜索。左键点选城市、府、港口、关卡或军团后，在地图上显示同一套紧凑信息卡片；点另一对象替换卡片，点空白、关闭或按 Esc 收起。悬停不打开信息卡片，点选也不自动展开侧栏或完整详情。城市卡保留简要兵粮与一级命令，府显示所属主城和可见驻军，军团显示兵力、粮草与操作；完整资料从“详情”进入，管理和命令须明确选择。所有信息仍按当前视野或带日期的旧情报显示。

详情中的势力、据点、军团、部队、武将名称可关联跳转。「返回上一层」恢复原名册搜索或原详情；「返回名册」回到当前类别。关闭面板返回地图。查看不下达命令、不修改存档，打开期间世界时钟遵循现有弹窗暂停规则。

点选卡片的电脑与手机横屏实操入口为 `node scripts/verify-map-selection-ui.mjs`，覆盖左键、悬停不弹卡、换选、空白／Esc 关闭、管理入口、情报限制及查看前后存档一致。

城市点选卡片直接显示现役兵、预备兵、伤兵、金、粮草和城防耐久，耐久按“当前值 / 上限”显示。完整详情的基本页使用相同的兵员统计；驻城军团计入本城，已出发部队不计入，伤兵为0也保留。兵员种类分别列出，不合并成一个含义不明的“兵力”。

军团卡片直接显示现役兵、伤兵、部队数、士气、每日耗粮、携粮／容量；完整详情、管理页及逐队明细使用同一组当前兵员数据，交战时读取战场余兵与伤兵。每日耗粮显示整数，零伤兵保留。军团长、军师和军略在指挥页查看，管理页保留供粮城市、实际运入量、缺粮程度和断供续航。

点选己方军团后，地图高亮它当前接通的粮道，卡片和完整详情注明供粮城市。路线共用当前补给连接及实际道路、军团位置；未来行军目标不改变当前粮道，也不使用已失效的旧粮道。换选军团切换路线，点选其他地点、关闭卡片、点空白或 Esc 清除高亮；粮道断开时不画连线，并显示“未连接”。其他势力的隐蔽粮道不显示。实拍入口为 `node scripts/capture-action-guide.mjs armyStats`。

## 内容结构

城市卡片提供“委任、军事、人事、详情”。“委任”打开本城六个方向及负责人岗位；内政提案、统一委任、外交和侦察从主界面的势力入口办理，城市卡片不重复提供侦察。

- 据点：概况、城防资源、驻城独立部队、驻扎军团、驻城武将、内政事务。
- 军团：位置与目的地、指挥任职、现役兵力与补给、所属部队。
- 部队：归属与主将、能力成长、兵种兵力、计算属性、携带战法、持有军略、事务与等待命令。
- 人才名册以“任职”页展示所在、任职、事务，不另设重复状态列。任职列显示太守、内政、侦察、外交、随军等实际职责及任务；城内无职无事者显示“空闲”，预编部队不占用工作。事务与剩余时间单列，等待命令照常提示，查看不打断进度。君主开局驻城时默认兼任太守，任职和城市收入共用同一任命。
- 武将：身份与所领部队、五维成长、本方当前忠诚、四系兵种适性、特性、羁绊、战法、军略、内政任职及事务。人才名册和人物详情的兵种适性、特性、羁绊、战法、军略各自独立，点击姓名进入对应页。未编制人物不显示虚构部队数值，已编制部队的计算属性从所领部队查看。
- 势力：据点、军团、部队、武将、兵力与据点存粮汇总及关联名册。

仅列出当前世界中已经实例化的人员，不将未发现人才库当作在职名册。城内部队不会生成虚拟出征军团。军团、部队与势力的现役兵力共用战场余兵，伤兵共用战场伤兵池；查看不触发结算。

未知、当前可见和旧情报分别表示。未观察到城市归属时显示“未知”，不能用中立代替；失去视野的城市卡片、名册与详情共用最后观察日期和旧数值，不读取随后变化。敌方内政、军令及具体等待原因未掌握时不显示零或无。敌方势力页按“已知据点、可见军团、可见部队、可见武将、可见现役兵、已知存粮”标注范围；城仓可能包含带日期的旧情报，不当作全势力实时总量。没有发现军团或战事不能断言不存在。

兵种适性统一使用当前规则中的枪、戟、骑、弓四系与 C／B／A／S 等级；名册按实际等级排序。武将库、人物详情、编制选择与战场所属武将使用相同口径，进阶兵种继承所属系适性，兵器和船不另外展示旧资料等级。本势力部队列表及战场部队详情同时标出当前兵种与适性。

## 后续任务引导复用

`campaign-info.mjs` 将索引、详情内容和呈现分离：

- `campaignInfoIndex(state)`：五类当前世界实体。
- `campaignInfoDetail(state, type, id)`：标题及带稳定 ID 的详情区块。
- `campaignInfoSections(detail, {sections: ['overview', 'troops']})`：按任务需要只呈现指定区块；省略参数显示完整详情。
- `campaignInfoMarkup(state, view)`：完整名册或详情内容。

未来选择面板可复用这些区块，选择资格、勾选、确认和命令执行仍由任务流程负责，不写入只读详情模块。

## 当前状态

五类详情顶部固定显示 `status` 区块，，不重复标注当前日期。状态通过 `campaign-info-status.mjs` 从当前游戏状态派生，不存储额外副本。

- 武将 / 部队：位置、当前行动、行军路段进度、调任目的地与剩余天数、内政事务及剩余时间、等待命令及执行时机。任职但尚未开工时显示实际等待原因。已编制武将仍正常展示内政事务。
- 交战部队：读取当前战场的在场 / 预备 / 溃败 / 撤离、战斗行动、实时兵力和战意。
- 军团：驻扎、待出发、行军、战后休整、等待事务或交战，以及目的地、战役进度。
- 据点：所在地域、是否被围攻、当前内政事务与待执行命令数。
- 势力：辖境、当前战事、各军团动向、办理中的内政和调任人数。

任务引导可用 `campaignInfoSections(detail, {sections: ['status', 'overview']})` 单独复用当前状态。弹窗打开期间世界按现有规则暂停，状态对应打开时的当前世界日。

## 地图军情表现

左上角以剧本起始年份和当前日期显示“208年1月上旬”形式的时间，每月分上、中、下旬；原型中原战区采用官渡风云的起始年份展示日期，不再重复显示累计第几旬。地图移除底部例行命令播报，以及右下角景色选择和加减缩放按钮；拖动、滚轮和地点定位继续使用原有地图交互。

大地图只常驻必要的名称、数值和操作。进行按钮只显示“进行”或“暂停”，没有“执行本旬”等副标题；左上角保留年月旬和势力名称，不重复显示当前操作状态。势力列表只用“势力”作为入口，日志合并至顶部“日志”，不加“几路诸侯”等修辞和计数。地图工具只保留“定位”“全国”“领地”，三级细节仍随滚轮和地点操作连续展开。

都市圈标记只显示城名，不在名称下面显示成员类型和数量。城市详情的“都市圈”页显示成员统计和名单：小城与府合并显示为“府”，与港口、关卡并列；各成员使用同一张平级表格。内政页中的都市圈名单默认收起，点击后查看。

府、港口和关卡的地点卡只显示地名、所属主城与驻军，不堆叠“府 · 野外战场”等分类或“许昌都市圈”字样；所属主城显示为可查看详情的“隶属许昌”。没有驻军时仅显示“无驻军”，有驻军时列出军团、势力和兵力。底部“查看建筑”定位本地点，己方主城另有“内政”入口。卡片按内容收缩，不另设单项分类页签；手机横屏保留完整常用内容，驻军较多时在卡片内滚动。

军团名牌保留主将、势力简称、实时兵力及兵力、士气条，不再附加常驻状态文字。行军队列显示甲胄、兵器和旗帜，方向箭头沿当前真实路段指向；同地名牌向周边避让，并与实际位置保持连接。缩放时军团与战场标记保持可读尺寸。

推进一天时，军团沿实际道路曲线播放约2.2秒的移动与逐兵迈步，抵达、遇敌和旬末暂停同样保留本日移动。查看、筛选及地图刷新不会重播已完成移动；读档、跨日跳转和敌军重新进入视野不补演未观察到的路程。系统启用减少动态效果时直接显示当前位置。

交战点只显示交叉兵器和双方余兵，状态与交战天数在悬停及详情中查看。持续交战的局部火星随世界暂停冻结，尚未开战保持静态；点击或键盘确认仍进入原有战场流程。表现只读当前视野中的实体，不改变道路、行军速度、遇敌、战斗结算或存档。

## 入口与记录

大地图与所有实时战场使用同一个绝对日期和战斗步骤；切换场景只交接指挥权，进入目标战场时仍是世界的当前时刻。暂停统一作用于全部实时战场，不能独自暂停一场并让它停留在过去。

已结束战场可进入独立只读回放，顶部同时标出“当前世界”和“回放”时间。时间条支持连续拖动、播放／暂停、逐段前后查看及0.5／1／2／4倍回放；这些操作不触碰真实日期、随机数、伤亡、军令或战果，也不能从历史时刻续战。新战斗按实际每个战斗步骤保存紧凑的位置、兵力、战意和城防变化，不重新推演 AI；既有战斗只有每日快照时按原记录展示。返回当前局后仍停留在进入回放时的世界时刻，继续按钮推进真实时间。

暂停采用统一世界时钟：大地图和战斗界面的主动暂停、查看部队详情都会同步暂停所有战场；恢复后同步推进。切换视图的确认会告知战斗将继续进行，加载完成后自动恢复，玩家同时只指挥当前战场。

普通模式战斗顶部提供“切换视图”下拉选择，可直接选其他可见的进行中战场或大地图；地图交战标记也共用切换确认。确认框明确告知玩家只能同时指挥一场、离开的战场交 AI 继续作战。确认后加载画面，结束即自动继续所有战场的统一时间推进，返回大地图也继续后台战斗，无需再次播放；取消、关闭和 Esc 保留原场、草稿与原播放状态。实际可计量项目按完成数显示，其余阶段为等待状态；素材失败保留简化画面，不重新读档或重置战斗。待开战部署、援军军议、筹划和其他必办事项仍须确认；全 AI 接管限制保持，读档不自动开播。

地图的查找与势力默认收起，查找只列地名，选中后定位并收起查找。现有城市、军团和战场分类承担快速定位，不另设“快速选择”或“所选对象”按钮。详情的名称只在标题显示，势力与类型保留在对应字段；移除重复的“对象详情”“当前情报”说明。

大地图上方日期固定显示“XXX年X月X日”，取当前世界日并随实际日结刷新。

“日志”统一分全部、内政、人员、战事和命令，保留各类原有事项及待执行命令。日期共用剧本日历：事件显示年月日，只有旬编号的记录显示年月旬；原型战区以200年为起始年份。内政审批使用“提案”“同意”“暂缓”“自动同意”，成功程度标为“成功率”，实际资格、费用、进度和失败原因保留。
