# 大地图信息面板

大地图右上角「情报」提供据点、军团、部队、武将、势力五类名册，支持按名称或势力搜索。地图选中城市、军团后，从菜单进入详情；详情底部保留“管理”，具体操作在对应菜单或管理页办理。

详情中的势力、据点、军团、部队、武将名称可关联跳转。「返回上一层」恢复原名册搜索或原详情；「返回名册」回到当前类别。关闭面板返回地图。查看不下达命令、不修改存档，打开期间世界时钟遵循现有弹窗暂停规则。

## 内容结构

- 据点：概况、城防资源、驻城独立部队、驻扎军团、驻城武将、内政事务。
- 军团：位置与目的地、指挥任职、现役兵力与补给、所属部队。
- 部队：归属与主将、能力成长、兵种兵力、计算属性、携带战法、持有军略、事务与等待命令。
- 武将：身份与所领部队、五维成长、兵种与能力、战法军略、内政任职及事务。编制与内政分开呈现。
- 势力：据点、军团、部队、武将、兵力与据点存粮汇总及关联名册。

仅列出当前世界中已经实例化的人员，不将未发现人才库当作在职名册。城内部队不会生成虚拟出征军团。军团现役兵力沿用战役实时汇总；部队和势力的战略编制兵力明确标注，战斗结算前不冒充即时战况。

## 后续任务引导复用

`campaign-info.mjs` 将索引、详情内容和呈现分离：

- `campaignInfoIndex(state)`：五类当前世界实体。
- `campaignInfoDetail(state, type, id)`：标题及带稳定 ID 的详情区块。
- `campaignInfoSections(detail, {sections: ['overview', 'troops']})`：按任务需要只呈现指定区块；省略参数显示完整详情。
- `campaignInfoMarkup(state, view)`：完整名册或详情内容。

未来选择面板可复用这些区块，选择资格、勾选、确认和命令执行仍由任务流程负责，不写入只读详情模块。

## 当前状态

五类详情顶部固定显示 `status` 区块，，不重复标注当前日期。状态通过 `campaign-info-status.mjs` 从当前游戏状态派生，不存储额外副本。

- 武将 / 部队：位置、当前行动、行军路段进度、调任目的地与剩余天数、内政事务及剩余时间、等待命令及执行时机。任职但尚未开工时显示实际等待原因。已编制武将仍正常展示内政事务。
- 交战部队：读取当前战场的在场 / 预备 / 溃败 / 撤离、战斗行动、实时兵力和战意。
- 军团：驻扎、待出发、行军、战后休整、等待事务或交战，以及目的地、战役进度。
- 据点：所在地域、是否被围攻、当前内政事务与待执行命令数。
- 势力：辖境、当前战事、各军团动向、办理中的内政和调任人数。

任务引导可用 `campaignInfoSections(detail, {sections: ['status', 'overview']})` 单独复用当前状态。弹窗打开期间世界按现有规则暂停，状态对应打开时的当前世界日。

## 地图军情表现

左上角以剧本起始年份和当前日期显示“208年1月上旬”形式的时间，每月分上、中、下旬；原型中原战区采用官渡风云的起始年份展示日期，不再重复显示累计第几旬。地图移除底部例行命令播报，以及右下角景色选择和加减缩放按钮；拖动、滚轮和地点定位继续使用原有地图交互。

大地图只常驻必要的名称、数值和操作。进行按钮只显示“进行”或“暂停”，没有“执行本旬”等副标题；左上角保留年月旬和势力名称，不重复显示当前操作状态。势力列表只用“势力”作为入口，日志合并至顶部“日志”，不加“几路诸侯”等修辞和计数。地图工具只保留“定位”“全国”“领地”，三级细节仍随滚轮和地点操作连续展开。

都市圈标记只显示城名，不在名称下面显示成员类型和数量。城市详情的“都市圈”页显示成员统计和名单：小城与府合并显示为“府”，与港口、关卡并列；各成员使用同一张平级表格。内政页中的都市圈名单默认收起，点击后查看。

军团名牌保留主将、势力简称、实时兵力及兵力、士气条，不再附加常驻状态文字。行军队列显示甲胄、兵器和旗帜，方向箭头沿当前真实路段指向；同地名牌向周边避让，并与实际位置保持连接。缩放时军团与战场标记保持可读尺寸。

推进一天时，军团沿实际道路曲线播放约2.2秒的移动与逐兵迈步，抵达、遇敌和旬末暂停同样保留本日移动。查看、筛选及地图刷新不会重播已完成移动；读档、跨日跳转和敌军重新进入视野不补演未观察到的路程。系统启用减少动态效果时直接显示当前位置。

交战点只显示交叉兵器和双方余兵，状态与交战天数在悬停及详情中查看。持续交战的局部火星随世界暂停冻结，尚未开战保持静态；点击或键盘确认仍进入原有战场流程。表现只读当前视野中的实体，不改变道路、行军速度、遇敌、战斗结算或存档。

## 入口与记录

地图的查找与势力默认收起，查找只列地名，选中后定位并收起查找。现有城市、军团和战场分类承担快速定位，不另设“快速选择”或“所选对象”按钮。详情的名称只在标题显示，势力与类型保留在对应字段；移除重复的“对象详情”“当前情报”说明。

“日志”统一分全部、内政、人员、战事和命令，保留各类原有事项及待执行命令。日期共用剧本日历：事件显示年月日，只有旬编号的记录显示年月旬；原型战区以200年为起始年份。内政审批使用“提案”“同意”“暂缓”“自动同意”，成功程度标为“成功率”，实际资格、费用、进度和失败原因保留。
