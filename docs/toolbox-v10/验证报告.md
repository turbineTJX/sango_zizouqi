# 六选三组合实战抽样

规则 10；4 个种子、交换双方先后手，共 3912 场。每个兵种、每种固定属性都遍历 20 组；同一组合按门槛从高到低排列，不穷举六种优先级。所有战斗从零战意开始，不人工触发战法，不使用军略。

固定三人阵容、一级武将、3000 兵；敌人分别为密集枪阵、近距离骑兵、分散弩阵。比较战后双方剩余兵力差；这是定位取舍的抽样，不能证明全局平衡或实战最优。
