# 攻城属性（规则42）

攻城基础威力 = 当前攻击 × 兵种攻城系数；再应用机巧等攻城专属加成。

各兵种系数只维护于[兵种一览表](design-tables/兵种一览表.md)，包括投石、冲车和井栏的独立参数。普通模式空城抵达即占领，不要求拆门；实际守军存在时才作战。

当前攻击已含现役兵力、统率、被动、策略及临时状态；攻城不重复乘兵力。面板与结算共用 unitAttributes。普通攻击城门只使用攻城威力，再应用全局伤害系数与随机浮动、取整，实际损失不超过城门剩余耐久。

冲车继续遵循战法说明：对城门使用（武技威力 + 攻城威力）× 3，并保留暴击、连携；不额外加普通攻击。

旧规则存档提示重新开始，不迁移。当前版本的保存、读取及确定性续战继续保留。

回归覆盖当前兵种、非均分兵力、攻击增益、真实普攻城门及冲车连携。冲车连携测试使用足够高的目标耐久，避免致死截断掩盖倍率。
