# 战法与战斗规则

当前规则入口见[规则总览](README.md)。本页整合已确认的有效规则；具体战法数值只维护于[战法一览表](design-tables/战法一览表.md)对应的正式设计源。

## 能力与配置

- 特技是身份固定、开局可用的正面能力，不占战法名额；战法由兵种、适性与主将属性决定；军略由合资格的军团长、军师提供。
- 每兵种固定两个小战法和一个大战法；S三项、A一个小战法加大战法、B/C一个小战法，按武智、统政、魅力依次选择。专属限确认的16人，额外携带，所有等级可用。详见[固定战法规则](固定战法与稀缺专属-规则64.md)。
- 战法自动携带、自动施放。玩家界面只查看效果与携带条件，不提供换装或施放顺序调整；AI也不能换技能、重抽或优化技能顺序。

## 行动与施放

- 每步按已有顺序检查战法的行动资格、战意、独立冷却、调息、剩余次数和合法目标；无合法目标跳过，每步最多施放一项。
- 战意上限100，无自然增长；各兵种普攻、存活受击收入以 `combat-rules.mjs` 的 `TROOP_INTENT` 为准。伤害战法不提供施法者普攻战意，反击和持续伤害不产生战意。
- 当前普攻／受击战意：枪3／2、戟3／2、骑5／1、弓3／1、弩5／1、投石与冲车及井栏6／1、舰船4／2。同次多段战法对每个存活受击者只提供一次收入；完全被护盾吸收不提供受击收入。受击不扣战意，也没有随时间自动增加或衰减。
- 一队真实溃败后，同方其他实际在场部队失去20战意，距溃败部队2格以内额外失去10；最低为0。后备、未到援军及已离场不受影响。主动撤离、疑兵消失和城门被破不触发。同一伤害批次全部结算后再逐队处理溃败冲击，不在同次攻击中途改变勇武判定；记录随存档保存，不重复触发。
- 大多数战法不扣战意，少数爆发例外以各项 `intentCost` 为准。战法类别由 `learningTier` 决定，不能按战意门槛推测高级或低级。
- 每队每项战法独立限次，补次、增加上限和缩短冷却是不同效果，详见[战法次数与整备](战法次数与整备-规则48.md)。
- 属性、威力、抗性和概率分别见[部队属性](部队属性规则.md)、[威力与概率](战法威力与概率规则.md)。控制、免疫、护卫、疑兵与伏兵使用[公共状态机制](部队状态与特殊机制-规则62.md)。

## 目标、战场与结算

- 双方使用共同的走位、普攻、目标与施放引擎。近战遵守ZOC，远程遵守射程和最小射程；合法目标中的残血优先级见[目标选择](目标选择与避战及功绩-规则61.md)。
- 多面接敌按一次攻击预算分摊，详见[邻接分摊](邻接分摊与部队名牌-规则30.md)。突破见[ZOC规则](ZOC突破与远程优先-规则57.md)，地形见[地形规则](地形战斗规则.md)。
- 每军团至多十队、通常同时上场至多六队，奸雄任军团长时本军团可用第七名额；首发与补位遵守到达时间和合法空位。战斗意图、站位、出阵顺序和[逐队撤离条件](部队撤离与战前设置-规则65.md)在战前会议安排；撤离支持批量设置，实际离场才腾出补位名额。
- 普通模式无实际守军的据点到达即占领，不因城门或城墙创建战斗；有现役守军、驻守军团或守备兵才进行战斗。
- 战略一旬10天；战斗日和模拟步的换算及最大时限读取 `combat-rules.mjs` 的 `CAMPAIGN_TIME`，避免把效果的步数与战略天数混算。
- 功绩按实际贡献结算一次，详见[功绩成长](功绩成长-规则53.md)。当前版本保留确定性续战，旧档不迁移。

共享羁绊按当前规则101叠加：强攻、铁壁、迅击直接提高持有者攻击、防御、攻速。昂扬只提高实际在场持有者普攻与受击收入（50%／100%／150%），最终四舍五入；分击仍只发一份攻击收入，多段战法仍对每个受击目标只发一份收入。截气普攻有30%／60%／100%概率阻止该次受击收入，不阻止自身攻击及友军战歌、鼓舞，不削减已有战意。需要真实兵力伤害且目标存活，不能从全额护盾、疑兵、城门、反击或持续伤害触发。实际参数与个人名单见共享羁绊专题及设计表。
