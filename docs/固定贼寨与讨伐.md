# 固定贼寨与讨伐

用户确认：普通模式提供侦察发现的固定贼寨，使用实际武将和部队出征、进入现有战场。每寨随机若干名有姓名等资料的贼将，兵力较少；能力以全国当前平均值偏下生成，等级取全国当前平均等级。

全国基准包含本局已登场、存活的正式武将，包括在野与被俘人员；排除未登场、死亡、排除人物及随机贼将。五项能力分别取平均，按75%至90%向下取整；等级按平均等级四舍五入。各寨在开局生成并保存基准、人物种子、姓名、字、性别、年龄资料、能力、兵种和实际兵力。侦察、浏览、战斗和读档不重新生成，不修改832名正式人物库。

目前为初始调参：各省域分散选取道路节点附近的固定贼寨，全国最多24处，每寨1至3将、每将400至800兵。贼寨依附陆路府或关卡节点，地图用独立寨旗表示；不增加城市、经济岗位、统一目标或城内设施。途经道路不强制讨伐；军团以该节点为终点、实际抵达后才接战。独立战役不加入贼寨。清除后不刷新，刷新节奏留待讨论。

行政领地的完整视野不自动发现隐藏贼寨；实际斥候与真实军团接近可获得情报。各势力独立保存观察日期和当时的部队资料；视野消失后只显示旧情报。敌方清寨、损兵等情况须再次观察后更新，AI同样只能使用本方报告。点击地图寨旗查看贼将并选择派出城，后续使用共同编制、任命、路线编辑、出征确认和战前军议。

战斗使用现有地图、固定战法、AI布阵、军略、伤亡和补给处理。贼寨不加载附近都市圈的设施。败退后幸存守军和剩余粮草保留，原址原人，不刷新兵力。实际攻破后清除一次；真实幸存者收取剩余库存，无幸存接收人时按散失记录。贼将为本局敌方人物，暂不作为可招降的新武将；正式人才奖励来自真实在野人物。

寨库初始300至650金、900至1800粮，战中实际消耗粮草后再结算剩余。战利品随真实幸存部队携带，独立记录为缴获物资，不作为军团补给或出征预算。获胜后默认沿可达道路返城，玩家可以另行调动。返城后实收入库；粮仓满时余粮仍随原持有者保存，腾出空间后再入库，分兵合兵不复制。库存、缴获、散失、随军物资及入库均为整数，凭据保存且不重复发奖。

人才初始15%机会：胜利后在贼寨相邻城市中选择当前实际在野、未旅行、未受冷却限制、没有在谈项目的正式人物，因平贼投效。无人符合时不造人；沿既有人才入仕与实际赴任流程办理，人物不瞬移、不重复出现。宝物继续使用现有战场旧藏判定、唯一原物、眼力和30日间隔，不新增重复宝物或另设掉落倍率。

AI每旬正常评审可安排一项讨伐：只用本方已知贼寨、实际空闲或尚未开办的可选岗位部队；保留经济负责人、太守、在办事务、外交、待执行军令与主攻计划人员。复核共同城市预算、守备、往返携粮、真实兵力与战力，使用同一出征入口，不赠兵粮、不强制获胜。战斗及战利品与玩家共用。
