# 战前意图与基础军令

当前 AI 优化范围见[固定阵容 AI 决策边界（规则40）](固定阵容AI决策边界-规则40.md)，仅包括出阵顺序、初始站位与军略施放。[规则39完整流程](固定阵容战斗AI决策全流程-规则39.md)保留为历史记录，其中自由三槽与 AI 角色配装已取消。

- 战前布阵时选择歼灭、固守或攻城。攻城仅对攻城方开放。
- 歼灭侧重敌方部队；固守优先处理靠近己方阵地的敌军；攻城提高城门目标优先级。仍遵守接战、射程、挑衅等规则。
- 确认开战时锁定双方意图，暂停和存档续战均不能修改。意图不改变战役既定胜负条件。
- 战中基础军令仅保留免费「全军撤退」，移除重兵合围与后军接阵；预备队仍自动补位。
- 军略保留，仍按主将、军师解锁和智力蓄力规则使用；敌军仍自动使用军略。

验证：72 项相关测试及浏览器测试通过，覆盖意图选择、开战锁定、刷新恢复、军略入口和撤退入口。
