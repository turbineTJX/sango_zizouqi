# 全国地图与战略AI

普通模式选择剧本和可用势力；剧本定义见[剧本表](design-tables/剧本与开局配置一览表.md)，据点见[城市表](design-tables/城市一览表.md)。

全国包含76座城市、12处关隘、41处港口和24处府，共153处实际地点。道路使用真实野外路口与横向小路，同一连接仅一条道路，不再生成平行主路与支路。军团、运输队和补给共享路网与拦截条件。见[路网](野外路口与横向小路-2026-09-22.md)及[逐点选路](大地图逐点选路-规则63.md)。

主城与府的逐城取舍见[分层设计候选](主城与府分层设计候选.md)：48座主城、28座城邑府，另保留24处乡邑府；七剧本开局检查通过。五处府的归属仍需随道路和行程落实，运行版本继续使用54大城、22小城，未因设计稿改动势力存续或经济规模。

主图显示当前操作对象附近的局部地图，可连续缩放或点击“全国”查看全国态势；取消常驻小地图。拖动巡视和缩放只改变视野，手动巡视保留视野，列表选中对象或点击定位重新定位。府只使用已登记地名，不按城市加方位编造地点；没有府承接的位置不自动生成岔路，撤去的接路由正式道路关闭清单约束。

全国地图的地形、道路和城镇建筑改用 PixiJS WebGL 绘制。美术通过 `npm run art:map` 离线生成多级地形和建筑图集，公开素材清单的 `mapGPU` 指向完整版本；内容哈希使未变贴图继续复用，地形支持增量构建。项目窗口启动前检查并构建，素材检查与打包拒绝过期产物。替换原画后无需更改建筑 ID、命中位置、规则或存档。

运行时使用后台解码、校验和按帧上传；低精度父图保留到细节就绪，快速改变视野会取消过时请求。城镇和地形分别限制为 64 MiB，图集预算包含 mipmap；固定的领地、都市圈和迷雾效果另占 36 MiB。标签在独立屏幕层更新，SVG 保留点击与改线等交互，不在滚轮期间生成 SVG 截图或 PNG。WebGL 不可用时回退原绘制方式。`npm run verify:map-performance` 分开记录首次输入、完整地图就绪和三个缩放层级的连续帧耗时，同时检查实际建筑点击、改线吸附、显存预算和存档不变；60 FPS 是目标，实测结论绑定源码和具体硬件。

陆路按公开河岸、山麓和聚落位置形成连续弯折，避开新跨河和越出海岸的曲线；路面保留不规则路肩及细车辙，山路与横向小路较窄，水路使用航线标识。道路、行军、运输、侦察和路线预览共用曲线及路程比例，双向沿同一道路；不使用模拟随机数生成景观。近景保留沿路田块、林丛、缓坡、关隘岩坡和河岸植被。城市、府、港口和关卡共同按相邻据点间距限制模型占地，留出城外道路与郊野。模型位置、比例不随缩放、易主或建设变化。

港口逐个绑定实际河岸、湖岸或海岸，建筑位于陆侧，码头朝向对应水面；关卡按沿路隘口定位，可以只有前后两条接路，不要求多路交汇。黄河、长江及主要支流使用较宽的连续水面，汉水、湘水、赣水和湖口接入主河道形成分岔。航线沿真实河道、湖面与近海弯行，船队、预览、运输和实际水战位置共用曲线；水路行程仍使用既定道路长度，上下船仍只能经过港口。水面汇流本身不新增陆路府或上下船地点，遭遇仍按实际所在水路路段结算。

地图以汉末三国的地理关系为目标。用户提供的底图属于西晋时期，只沿用构图与投影，不照搬西晋疆域与地名。依据与可执行的校核关系维护于[历史地理设计表](../data/design/historical-geography.mjs)；[CHGIS](https://gis.harvard.edu/china-historical-gis)用于按年代核对地名，[《三国志11》地图介绍](https://www.gamecity.ne.jp/sangokushi/11/chi/)用于城、关、港及水陆空间的游戏参考。当前岸线和坐标属于有资料约束的游戏适配，不声称历史 GIS 精度。

`npm run audit:historical-geography` 检查全部153处地点的陆侧位置、41个港口岸线、已登记相对方位及真实陆路是否穿湖；地图重建在写入之前执行地点校核。`npm run test:historical-geography` 同时验证水路连续性、港口接路、关隘封锁及错误输入拒绝。`npm run verify:historical-geography` 实拍洞庭、鄱阳、襄阳、巢湖、南太行、阳平与函谷，并核对桌面、横屏、读档及只读浏览的存档不变。查找、缩放、地点卡及下令步骤不变；HTML 手册其它流程已有待核对项，不将本次地图验证作为全手册验收。

战略AI按势力计划、城市用途和实际军团状态决策，使用玩家共用的费用、资格、推荐评分、内政和调度流程。详情见[跨旬计划](势力AI与跨旬作战计划.md)。

无实际守军的据点抵达即占领；有守军按真实攻城输出、携粮和补给估算。保存当前道路位置、人员动向、等待命令、战场及随机状态，读档确定性继续。
