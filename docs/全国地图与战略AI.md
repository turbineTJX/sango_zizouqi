# 全国地图与四势力试玩

普通模式从「模式首页 → 普通模式」选择剧本。当前玩家执掌曹操；另外三方由战略 AI 控制。

## 地图与剧本

- 参考 `sango_infinity-main/Build/Content/Scenario/Scenario.json`，接入全部 **42 城、10 关、35 港**，共 87 个可选择、行军、补给和占领的据点。
- 42 城邻接关系来自参考项目。原项目的关港依赖自由地形移动，本项目为其补充道路、水路，并将主要关隘插入对应通道，形成 151 条双向通路。坐标按参考格点投影；山河底图为当前项目的 SVG 示意图。
- 「官渡风云」：200 年，曹操、袁绍、刘表、孙策四方试玩，其他区域为地方据点。历史背景下的玩法改编，未复原全部历史势力和事件。
- 「英雄集结」：251 年架空四方对抗，曹操据中原、袁绍据河北、刘备据巴蜀荆襄、孙策据江东。参考库人物按势力和地区归并，不限制生卒年。
- 全国视图突出城池，缩放后显示关隘和港口名称；可用据点选择框直接定位。支持拖动、滚轮、方向键、季节外观、军团路线和粮道显示。
- 目标为占领全部 87 处据点；全部据点丢失则失败。日历采用每月 30 天、每年 360 天，一旬 10 天。

## 战略 AI

每旬筹划征募与建设，每天评估军情。决定与世界日历一起保存；同一天重复调用不会重复征兵、消费或重新下令。

1. **择敌进攻**：比较实际兵员、能力、士气、缺粮、驻军及城门耐久。优先有价值且可达的目标，出征需有兵力优势和足够携粮；路线只穿过友方中间据点。
2. **守备与增援**：识别进逼己城的敌军，先守城或增援。出征时拆出真实留守部队，兵力和携粮守恒；同一目标已有充足友军时，避免继续堆兵。
3. **后方调度**：腹地军团向前线集结。大军团合并后可再次拆出不超过 10 队的出征部队，战场同时上阵仍为 6 队。
4. **补给与回撤**：粮草不足或失去驻地时寻找可达粮仓，沿当前道路回撤；不会瞬移。严重战损或断粮时使用真实战斗撤退指令。足粮驻城休整恢复士气，双方使用相同恢复规则。
5. **征募与发展**：AI 使用独立、有限的府库；开局额度与玩家相同。按实际城市收入进账，征募实际扣除本城预备兵、粮食、每人 0.25 金，并共享本城每旬整补额度。将本地待命武将编入军团时从待命名单移除；建设支付费用并走现有建设队列。

「诸侯动向」展示最近军令及原因；选择敌方军团也可查看其当前方略。AI 不使用额外伤害、瞬移、凭空补兵或额外兵粮收入。判断属于规则启发式，后续可继续增加外交、跨旬作战计划与更精细的联合进攻。

## 存档与验证

战略存档版本为 6；按项目约定，旧战略档需要重新开局。战役模式和演武试炼仍独立保存。

为控制全国多战线的存档体积，所有进行中的战役保留完整日快照，已结束战役保留最近 20 场完整日快照，更早的最近 100 场保留战报摘要。

```sh
npm run check
npm test
npm run test:national
npm run verify:national-ui
npm run audit:strategy
```

行为回归覆盖城防评估、避免劣势进攻、留守分兵守恒、救援优先、沿路回撤、征募费用及额度、大军团再出征、四方实战与确定性读档。长程推演脚本逐旬校验存档并输出城池归属、战线、军令和存档体积。界面检查覆盖两个剧本、87 个据点、搜索缩放、手机布局、模式切换与独立存档。

数据重建：`node scripts/import-national-map.mjs <参考项目目录>`。导入文件保留源文件 SHA-256 和道路适配说明。游戏运行不依赖参考项目目录或网络。

## 本次验证结果

- 全套自动测试：504 项通过；最后的回撤方向保持修复另通过 10 项战略 AI 行为回归。
- 两个四势力剧本从第 1 天推演至第 61 天，逐旬存档校验通过；第 61 天的英雄集结存档在真实浏览器中读取、继续执行和刷新恢复通过。
- 界面检查：两剧本、87 个交互据点、定位缩放、季节、视觉操作不改写进度、手机无横向溢出、战役模式独立存档均通过。
- 长程推演以玩家不下达新军令、遭遇统一委托为条件，用于检查行为和状态完整性，不作为胜率平衡结论。
