# 全国地图与战略AI

普通模式选择剧本和可用势力；剧本定义见[剧本表](design-tables/剧本与开局配置一览表.md)，据点见[城市表](design-tables/城市一览表.md)。

全国包含87处城市、关隘和港口。道路使用真实野外路口与横向小路，同一连接仅一条道路，不再生成平行主路与支路。军团、运输队和补给共享路网与拦截条件。见[路网](野外路口与横向小路-2026-09-22.md)及[逐点选路](大地图逐点选路-规则63.md)。

主图显示当前操作对象附近的局部地图，可连续缩放或点击“全国”查看全国态势；取消常驻小地图。拖动巡视和缩放只改变视野，手动巡视保留视野，列表选中对象或点击定位重新定位。

战略AI按势力计划、城市用途和实际军团状态决策，使用玩家共用的费用、资格、推荐评分、内政和调度流程。详情见[跨旬计划](势力AI与跨旬作战计划.md)。

无实际守军的据点抵达即占领；有守军按真实攻城输出、携粮和补给估算。保存当前道路位置、人员动向、等待命令、战场及随机状态，读档确定性继续。
