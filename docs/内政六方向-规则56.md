# 内政六方向（规则56）

玩家只选择方向、委任武将，之后查看办理进度与实际成果。城市需求、资源条件、事务优先级和随机选择全部在后台处理，不要求玩家先识别城市问题或逐项安排事务。

| 独立委任方向 | 唯一主属性 | 自动办理内容 |
| --- | --- | --- |
| 商业 | 政治 | 市场、集市、税务、商旅、招商、售粮 |
| 农业 | 政治 | 农田粮仓、督耕灌溉、购粮、抢收与仓储 |
| 军务 | 统率 | 兵营城防、征兵、修缮、动员与布置守备 |
| 武备 | 武力 | 校场、守城操演、城防巡查 |
| 技术 | 智力 | 工坊医馆、研究试制、伤兵救治、人才搜索 |
| 人才 | 魅力 | 招贤馆、登用、劝说、安抚 |

商业与农业始终是不同的委任、进度和成果记录，不因共用政治而合并。同方向内所有事务（含建设）都使用表中唯一属性＋适用特技。五种属性全部有实际用途，但不为凑五个按钮合并重要事务方向。

六方向沿用持续委任、多人同岗、自动协作、围城暂停、事务打断与等待执行。军务征兵也采用统率，不再因隐藏任务变化转用魅力；武备不会自动转做统率任务。技术中的医疗不再要求军事负责人的智力。

玩家与敌方AI选人共用推荐评分，默认按任务推荐，仍允许手动按属性排序。独立特性不提供成功率、产出或节费加成；青囊只改变无医馆时的救治资格。无合法事务时按对应主属性评价候补，有事务时按实际需求、成功率、成果和工期评分。AI从六方向空缺岗位选人，不打断现有任职。后台先排除无合法目标、资源不足、已有有效准备等不能执行的事项，再按需求、适用特技与现有权重自动选择。玩家界面不显示后台需求分析清单。

正式源为 `data/design/domestic-actions.mjs` 中的方向、主属性及动作表，建筑所属方向由 `data/design/buildings.mjs` 定义。设计校验拒绝同一方向混入其它主属性。内政动作与建筑一览表由设计导出脚本生成。

当前版本存档不迁移旧结构。功绩仍按实际完成成果结算，战斗和军略规则不变。
