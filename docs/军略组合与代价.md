# 军略组合与代价

规则142已接入六项组合军略。玩家通过军团任命、初始布阵、已有保护与军略施放时机减轻副作用；部队移动、普攻和战法继续自动执行。当前共21种军略、91名持有者，新增20人，仍为个人固定分配，通常每人一项、诸葛亮两项。不改剧本登场时间、人事、归属或开局资源。

## 属性、代价与保存

全部持续效果分别按实际提供者统率、智力折算，包括护盾期限、坚定和副作用。沿用系数K＝2^((综合属性−80)÷20)，限制0.5～2；舍守强攻、专力运筹、乘隙猛攻使用统率30%＋智力70%，其余使用统率70%＋智力30%。每项持续时间为四舍五入后的基准时间×K，至少1回合、最多独立冷却−1回合。固守待援最高为31回合，短于32回合冷却。

护盾额度也按K缩放，实际发放仍遵守兵力上限和共同剩余护盾容量，数量取整数。其他增益、减益幅度及20点战意费用不随K重复放大。冷却与范围固定。

增益与异常分别执行公共状态规则。魔免阻止适用的战斗异常；坚定阻止封技等对应控制，不阻止破甲、疲弱或迟滞。整军等解除能力按各自列表工作，解除副作用后保留已经获得的增益。异常只在施放时施加一次，保护先到期也不补加已被阻止的异常。

励军固阵逐队核对实际战意、保护缺口和资格；不合格者不扣费、不获得此次效果，整个选区无合法目标则不消耗蓄势或开始冷却。魔免、坚定与驱散不能免除实际20战意消耗。舍己护军要求实际提供者在场、存活且未撤离；后备提供者不能使用此项，亦不能借另一部队承担疲弱。

状态保留来源、幅度、施放回合与逐项期限；施放记录保存选区、提供者位置、实际受益部队及扣费前后战意。存档复核来源任职、人物固定资格、范围、金额与时长。换任、离场、浏览和读档不重算已施放效果，不返还已支付战意，不重抽提供者。旧规则存档重新开局。

## 实际配合

- 舍守强攻可以利用开场阵法盾、自动支援护盾、减伤或敌军已经受控的窗口。保护承担新增伤害，保护耗尽后破甲风险仍在。
- 固守待援适合已经接敌的前排和已有射击目标的远程阵地；追击、行军接敌时迟滞的代价更大。
- 专力运筹适合谋略战法尚有次数、接近启动门槛的部队。缓攻也影响谋略普攻及普攻战意收入，战歌、鼓舞可提供真实支援。
- 乘隙猛攻适合关键战法刚施放、正在冷却时发动，让封技与既有冷却重叠；不改变固定战法顺序。
- 励军固阵可在战意充足、急需保兵时使用，由附近实际战歌、鼓舞补回后续战意。仍须承担延迟下一次战法的可能性。
- 舍己护军让辅助型军团长或军师承担本队攻击下降，通过任命和初始布阵保护周围主力。

军略共用一份蓄势，不能假定连续施放两项军略。上述配合优先使用场上已有状态和自动战法，不新增逐队接应、停走、拉扯或施法操作。

## AI与验证范围

AI保留固定条件、固定优先序和仅数有效目标的落点规则，不等待保护、冷却或支援组合。新增项相对顺序为励军固阵、舍己护军、固守待援、专力运筹、舍守强攻、乘隙猛攻，排在既有魔免之后；原15项相对顺序不变。

强攻两项要求当前存在合法普攻目标；专力运筹要求当前有合法目标且仍有次数的谋略战法；护盾类检查保护缺口，励军固阵额外检查真实20战意，舍己护军额外检查实际在场来源和周围其他友军。实际施放仍调用与玩家完全相同的资格、范围和结算入口。

机制回归：`npm run test:stratagem-combinations`；完整相关回归：`npm run test:stratagems`；逐项自然充能AI检查：`npm run audit:stratagem-ai`；桌面、横屏、取消、实际施放与读档：`node scripts/verify-stratagem-combinations-ui.mjs`。原始全国自然全AI另外观察；机制和局部检查不代替全局平衡、趣味或完整可玩性验收。

验证分别记录机制回归、21种军略的真实自动施放与条件不足保留、六项组合军略的桌面／横屏操作、实际扣费及读档。原始全国全AI短窗另保存真实出兵、战果、缺粮和确定性续行；未实际触发的军略和长期平衡仍须独立验证。旧通过数量和短窗统计不直接覆盖后续源码修改。
