# 特技、军略与专属战法设计指南

当前内容数值从[设计表目录](design-tables/README.md)查询；机制从[战斗规则](战法规则.md)和[内政规则](内政系统最终设计.md)查询。以下用于逐项讨论和实现新能力。

## 三类能力边界

| 项目 | 特技 | 专属战法 | 军略 |
| --- | --- | --- | --- |
| 名称 | 固定两个字 | 两个字或四个字 | 固定四个字 |
| 获取 | 身份固定、开局可用，全部正面 | 16名确认武将固定持有，所有等级可用 | 身份固定；基础智力至少70，通常两项，诸葛亮三项，专属占名额 |
| 生效 | 本队、军团、本人事务、太守职责或行旅，必须明确范围 | 固定携带和施放，所有兵种可用；遵守目标、门槛、冷却、次数和调息 | 合资格军团长或军师提供；按实际统智计算；零兵不提供 |
| 操作 | 自动触发或持续生效 | 不提供配装及施放顺序操作 | 玩家从完整可用列表选取；AI固定条件与优先序 |
| 主要约束 | 同名不叠加，内政按实际职责生效 | 普通补次不影响专属；补次能力不能恢复自身或相互恢复 | 同名合并取较强来源；补次每场有上限 |

战斗特性使用兵科、战术与稀有共享羁绊池，种类与个人上限逐人配置，各羁绊可使用不同档位；个人上限以1级为主，2级少见，每种低级羁绊最多一名3级代表；低级最高档至少六人在场，稀有强机制须由指定多人合作到达最高档，内政及任职特性独立保留。

人物战斗特色通过羁绊组合、个人成长上限及专属战法体现。独立特性只分普通、专属，须改变规则或具有明确事件触发，不允许纯常驻属性、收益、成功率、速度或恢复倍率加减项；规则80允许实际投入兵员的屯田、卸下辎重的轻装和消耗士气的急行等有成本机制；不强制人物拥有独立特性。当前名单见[独立特性规则](武将正面特性-规则49.md)。

## 每项能力填写

| 字段 | 需要回答的问题 |
| --- | --- |
| 持有者与定位 | 谁持有？体现哪种实际贡献？史实还是演义依据？ |
| 范围与资格 | 本队、友军、敌军、预备队还是本人内政？要求何种任职、兵种、驻城或状态？ |
| 触发与目标 | 何时触发？合法目标怎样选择？无目标、免疫、失败时如何处理？ |
| 效果与属性 | 基础值多少？用哪种属性或威力？是否受兵力、抗性或概率影响？ |
| 时间与资源 | 持续多少模拟步？门槛、消耗、冷却、调息、每场次数分别是什么？不要混用战略天数。 |
| 叠加与边界 | 同名、同类、跨来源如何合并？净化、保护、退场、预备、死亡、避战如何处理？ |
| 真实预算 | 治疗来自哪些伤兵？征募与增产受哪些资源、容量、目标或额度限制？ |
| 存档与结算 | 保存哪些来源、强度、次数与标记？怎样避免重抽或重复奖励？ |
| 验收 | 如何证明触发正确、有实际贡献，并与同预算替代能力比较？ |

内政必须沿用六方向单属性：商业／农业政治、军务统率、武备武力、技术智力、人才魅力。军略只用统率与智力；部队战法的威力分类见[部队属性](部队属性规则.md)。不要把这些属性口径相互套用。

## 设计与验证流程

1. 先查[状态表](design-tables/战斗状态与效果一览表.md)与已有能力，优先复用公共处理器；新机制明确记录需要新增的处理器。
2. 修改 `traits.mjs`、`tactics.mjs` 或 `stratagems.mjs`；持有人和固定配置修改 `assignments.mjs`。稀有度、定位及史实理由写入 `notes.mjs`，不放进玩家效果文案。
3. 实现引擎并验证行为：双方共用规则，使用固定配置、战意、目标及限次流程；覆盖非均分兵力、控制／免疫边界与确定性续战。
4. 执行 `npm run design:check`、`npm run design:export`、`npm run design:verify`、`npm run test:design` 和受影响机制测试。
5. 行为通过后做同预算、开发种子与独立验证种子对照，保留失败局及换边结果。先修引擎异常，再评估强度；不为保住旧胜率回改机制，也不把全部武将胜率拉平。


## 触发频率与效果预算（规则69）

同类效果须按实际触发频率、覆盖率、人数、触发成本及每场次数分配强度，不共用一套幅度与时长。高频普攻附着采用较低幅度、短持续；有兵力门槛或明确间隔的被动可适当提高单次效果；每场一次的效果应提供更强爆发或更长有效窗口。常驻机制不机械套用持续时长，硬控制不因一次性而无限延长。持续刷新的减益只刷新、不叠层，弱效果不能覆盖或延长已有强效果。


## 状态名称与描述（规则75）

战法、军略、特性的状态名称统一取 `data/design/battle-statuses.mjs`。施加、解除、免疫或利用状态时写出正式名称，再注明效果、范围和时长；不以“破防”“奇门”“免控”等词代替破甲、穿阵、坚定。减伤状态覆盖直接伤害，统一名为“减伤”。固定属性加成和军略阵营效果不冒充单队状态。战斗时间统一写“回合”，等于一个模拟步，不是战略天数；频率、次数、免疫与真实伤兵预算仍按各自规则。

军阵按阵位首次入场快照生效，破军按真实击溃累积并限时乘胜；与桃园伤害分担与溃败强化、勇武按双方当前战意判定增伤与免疫、护卫残血邻军护盾与破盾免伤保持不同触发条件。完整规则见[羁绊特性与成长](羁绊特性与成长-规则76.md)。

入场装备同时标明来源羁绊、受益者是否必须持有、允许兵种及次数；不能将“贡献羁绊点数”混为“获得入场装备资格”。弓将、深谋、先登分别示范兵种限制、持有者限制、两者同时限制。法球单槽与限次重击规则见[羁绊特性与成长](羁绊特性与成长-规则76.md)。

桃园的伤害分配必须守恒：原目标抗性只算一次，各份额分别消耗护盾和兵力，残血容量不足的份额继续分配。无敌与奋战在整个伤害批次结束后授予幸存者，不能回滚致命伤害。蓄锐采用开战锁定的后备名额，不通过等待时间积累，不追加个人成长额度。
