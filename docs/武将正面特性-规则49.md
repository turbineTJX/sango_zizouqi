# 武将正面特性（规则83）

独立特性分普通、专属，按人物固定，开局可用，不占羁绊或战法名额。当前已接入52项普通、15项专属，共67项；其中50项绑定既有内政命令，7项同时影响既有外交办理，详见[内政命令特性一览](design-tables/内政命令特性一览表.md)。

纯常驻属性、收益、成功率、费用、移速和恢复倍率加减项不恢复。轻装、急行、屯田等机制具备真实资源取舍或人员投入，参数是机制结果。战斗特色主要通过[共享羁绊](羁绊特性与成长-规则76.md)、战法和军略实现。

独立特性采用[至少相当于50点对应主属性的收益下限](能力设计指南.md#独立特性收益下限)。下表描述当前已接入效果；已按该下限调整；对应命令以50对100主属性的成果、费用或工期对照验收，资源和目标耗尽时仍按真实上限截断。

## 内政与人物分配

荀彧王佐能发现更多真实关系人才，张昭辅政允许跨方向协办，邓艾军屯调用实际空闲驻军，马钧巧思衔接研究。普通续研交给诸葛亮，避免马钧同时携带同机制的普通与专属版本。国渊获得漕运；公共832人库没有任峻、枣祗、蒲元，本轮不新增或伪造人物。完整分配以设计表为准。

玩家只任命方向与负责人，后台从该方向的合法事务中自动选择。随机收益、施工受阻、救灾、名匠机会和被动荐才可保留，不要求所有特性稳定生效或首次任命必定兑现。勤政、研习和说客直接强化正常办理，不要求更换执行人或留下前任事务；筹械强化所有合法研究，不限定科技与研究方式；统筹在同城另任技术负责人后，自动组织一名实际空闲人员协助研究，协助期间不另开事务，无需玩家指定待命，已开办事务与提案不会被打断。特性不提供专属交接资格，建设已投入进度与城市研究进度按公共规则保存。安众重新支付后续事务费用；续研和巧思接续同一研究项目不重复收费，开始新科技则支付项目费用，全部按实际工作日办理，等待出征、调任或免职命令时不续办。

军屯与屯田按实际办理农业期间的在城兵力逐日累计，出征、围城或忙碌人员不提供额外贡献；收益有上限。抚伤提高治疗额度，并把未用部分分给其他真实伤兵或办理期间新增伤兵，不额外造兵。举荐和王佐从真实人物关系发现仍在野的人才，不直接招募或移动人才。

## 行军与运输

轻装和急行通过军团的“行军方式”选择并确认，取消不修改状态。轻装在己方据点交接辎重，降低携粮容量，卸下粮草真实返还本城；急行按实际移动日消耗士气，缺粮或士气不足停止，结束后需休整。只有有现役兵力的军团长提供相应资格。

转漕在调任运输中选择己方中转据点，两段均沿真实路网行进；中转不卸货或瞬移。漕运允许纯粮运输执行2～5趟，每次返回出发城后才重新扣粮装载，并保留本城口粮及事务预留；路线、归属或库存不满足时停止续运。空车返程仍在地图显示并可被拦截。

接粮由抵达同一节点的己方运输队向具备资格的停驻军团实际交付粮草，受携粮容量限制。留粮在到达己方据点时从可用库存补给，保护本城口粮及已预留粮草。运输遇敌沿用实际损失规则，不增加运输队战斗。

## 存档与验证

仅接受当前规则及当前结构存档，旧档重新开始。等待命令、正常事务、公共工程与研究进度、屯田贡献、行军模式、中转与循环运输均随存档保存。双方共用处理器与真实资格、费用、路网及伤兵预算。人物分配见[独立特性表](design-tables/特技一览表.md)和[能力分配表](design-tables/能力分配一览表.md)。

本轮验证覆盖实际办理、费用不重复、真实兵员和伤兵、行军代价、接力及往返运输、倾国实际命中、当前存档与确定性续行；机制通过不代表已完成经济及战斗平衡验收。

## 内政命令特性（已接入）

设计与实际效果来自 `data/design/traits.mjs` 的 work 字段，正式持有者来自 `assignments.mjs`。50项特性已绑定原命令结算；部分原战略特性同时强化办理效果。新增专属为刘备仁望、诸葛亮统筹、周瑜督练、曹仁坚壁、刘晔筹械、贾诩审势。

- 玩家选择内政方向和负责人，裁示付费提案，后台仍从现有命令库选择合法命令。特性仅修改所绑定命令的产出、成功机会、部分达成比例、已有临时效果幅度／期限、受益目标或建设受阻结果；不新增命令、子系统和操作流程。
- 商业、农业用政治；军务统率、武备武力、技术智力、人才魅力。特性须按原命令所属方向生效，不混入其它属性；探索未知人才按当前库属于技术，不能另写成人才方向。
- 每项用 actionIds 引用 `domestic-actions.mjs` 已有记录；建设命令方向取原建筑表。校验拒绝不存在的命令、方向错配或未完成的正式分配。
- 加强只在实际办理对应命令时生效，不变成持有者在城即常驻增产、免工期、免费用或战斗属性加成。实际费用、办理时间、返款和有界产能按特性与命令共同结算；真实资源、目标资格、仓容与兵员缺额继续按公共规则。
- 救灾只处理本城真实有效事件；备荒可同时保护另一类既存灾情；救治只恢复原部队真实伤兵；征兵不得超过预留、人口、粮草及编制缺额；建设仍逐级完成；研究达到100%直接掌握科技，不生成额外研究机会。
- 仁望仅在既有安抚命令成功结算时扩展本城合法受益对象，不创建额外安抚任务或关系召集。统筹通过正常技术方向任命自动安排同城实际空闲协助者，在主办提案等待裁示期间保留协助资格；获准后才实际推进研究，协助期间不另开事务，有既存行动、提案、使命、侦察或等待军令的人员不能兼任。筹械覆盖五种合法研究方式和后台选择的任一科技。督练与坚壁仅修改原守城准备，不创建水上运输或临时工事。
- 相同效果修正取强不叠加；不同修正按共用顺序结算，最后统一应用资源／容量上限。不得重复抽签、复制成果、重复奖励功绩；失效目标、围城暂停、等待军令及中断沿用共用规则。
- 玩家推荐与AI使用同一套按具体命令计算的收益、费用和资格评分。同类效果取较强项；效果、命令绑定与正式分配均受设计校验，行动快照必须匹配执行人与具体命令。当前规则版本不读取旧档。

眼力（钟繇、王朗、张华、虞翻）与夺宝（胡车儿、潘璋、韩当、周仓）为两项普通独立特技：仅修正合法宝物发现与缴获，不改变内政原事务、战斗数值或选敌。实际主办／贡献、存活与目标归属须复核，不叠加。规则见[宝物系统](宝物系统设计稿.md)。


## 外交特性与收益验收

通商、善贾接入经贸，好贤、王佐接入亲善，游说接入交涉，说客接入亲善与交涉，辅政接入经贸与交涉。本人实际到达办事地点后，进度按对应主属性和特性倍率计算；最高同类倍率生效，接洽费折扣取强。路程、每日行资、条款费用、真实库存、最终版本批准及签署条件照常，不能自动令对方同意。

市集、精耕和征募等直接成果使用有界提高的城市额度，仍扣同一份当旬产出计数；同名特性或多名负责人不重复增加额度。屯田与军屯只按实际工作日投入的合格现役兵员贡献提高成果和额度，全城上限基础五倍；满仓、满编、目标失效或道路中断仍截断。高成功率持有者通过研究进度、工期、治疗量或实际节费保留收益，避免仅增加已封顶的概率。

验收：`tests/trait-benefit-floor.test.mjs` 对50项命令特性逐个绑定命令，比较主属性50与100，并覆盖0／1／2／3／6／12级生产设施、正式高属性持有者、真实结算、产能不按人数叠加、安众接续及协助人员资格。`tests/domestic-trait-appointments.test.mjs` 仅委任方向，在有多个合法候选、没有前任事务且未限定命令的条件下验证勤政、研习和说客正常办理、筹械无需指定科技与研究方式、统筹在两种任命顺序下自动组织协助；另验提案准奏或暂缓、既有事务不被打断、实际费用及确定性保存。随机事件型特性仍按真实事件发生及合法目标结算，不以每次委任必定触发为验收条件。剩余伤兵、出使、行军、费用、存档和自然AI剧本继续由专项回归验证。数值达到基准不代表已经完成长期经济与战斗胜率校准。
