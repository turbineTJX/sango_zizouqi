# 武将正面特性（规则49）

固定特性规则；配合要求见[规则50](武将能力配合-规则50.md)，光环见[规则60](武将光环与删除辅兵-规则60.md)。

## 固定人物能力

- 全部832名武将按身份固定持有不同数量的正面特性。开局即可使用，不再在2／3／5／8／10级逐项解锁。
- 不加入负面特性。性格仍是独立人物资料，沿用已有的内政选事倾向，不占特性名额，不额外处罚。
- 换兵种、布阵、升级、任免、存读档不改变特性配置，不使用随机数生成特性。
- 成长继续提高带兵上限并按规则64固定携带战法。战法限次沿用规则48；军略资格沿用规则51，强度沿用规则47。特性不占战法槽，不改变双方合法出阵、自动目标或施放优先序。
- 共享特性根据人物基础能力与默认兵种分配，固定人物另有明确配置；人物特性名与数值是游戏化设计，不作为史实断言。

## 范围与数据

战斗特技须明确本队、相邻友军或所属军团范围及任职条件。事务特技按本人真实执行动作生效；太守效果按实际驻城与职责生效，同名不叠加。预编部队不取消内政，外出期间不提供在城加成。

事务开始记录实际特技、费用及适用快照，结算受真实资源、容量、伤兵和目标限制。协作者不把其他事务专长重复叠给执行者。

具体数值和持有人统一查[特技一览表](design-tables/特技一览表.md)和[武将一览表](design-tables/武将一览表.md)，不在机制文档复制第二份人物分配。

特技、学习、任职、事务进度及来源随当前版本保存。旧档不迁移；验证真实成果、同名合并、来源与确定性续战。
