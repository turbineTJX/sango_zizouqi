# 军略 AI 固定条件触发

军略与战法分别处理。军略不比较现场收益，不评估兵力、状态严重程度、距离、路线或未来接敌；战法保留共同引擎的周围目标、射程、战意、次数及冷却判断。

军略在自然进度蓄满后的步末检查一次；如果没有符合条件的军略，保留进度，下一步继续检查。只使用任职武将实际提供的军略，仍遵守冷却、已有效果和每场补次上限。不因玩家是否施放军略而改变检查时机。

固定顺序如下，找到第一项就施放。同效果的普通与专属军略沿用可用列表顺序，不比较持有者强度；实际效果结算仍按正式持有者规则执行。

| 顺序 | 效果 | 基本触发条件 |
| --- | --- | --- |
| 1 | 猛攻 | 存在敌军或敌方城门 |
| 2 | 虚实及同效果专属 | 存在敌军 |
| 3 | 火攻及同效果专属 | 存在尚未受到军略火攻的敌军 |
| 4 | 远射 | 在场有弓兵或弩兵 |
| 5 | 疾行及同效果专属 | 通用条件满足即可 |
| 6 | 守备及同效果专属 | 存在敌军 |
| 7 | 鼓舞 | 在场部队有战意未满者 |
| 8 | 轮替 | 在场部队有战意未满者，或有剩余次数的战法正在冷却 |
| 9 | 夺气 | 有敌军战意大于零 |
| 10 | 断援及同效果专属 | 有敌方预备队 |
| 11 | 后军固阵 | 有己方预备队 |
| 12 | 救疗 | 在场部队有可救伤兵且兵力未满 |
| 13 | 休养 | 在场部队有可救伤兵且兵力未满 |
| 14 | 镇静 | 在场部队有可清除状态 |

通用条件：战斗未结束、己方未撤退、有在场存活部队和敌军或敌方城门；军略未冷却、同字段持续效果未生效。补次军略另检查每场次数和可补充的普通战法。

实现：`battle-ai.mjs`。回归：`tests/proactive-command-ai.test.mjs`、`tests/cleanse-ai.test.mjs` 及现有军略、战法、步末施放与确定性续战测试。
