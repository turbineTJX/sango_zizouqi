# 军略AI固定条件触发

双方AI按固定顺序、固定条件选择首个满足充能、冷却、限次与实际来源资格的军略，不比较现场收益、兵力权重、伤害预期或未来接敌。范围只数满足本项条件的合法有效目标，相同覆盖保持稳定顺序，不读取未来随机数。

## 共同边界

整军肃阵只有实际异常才触发，落点须覆盖至少一名异常友军，再按全部有效受益友军数选择；玩家可以提前保护。额外后备使用共同后备排序与真实到达、合法空位，不为羁绊挑选队列。雷火不估算敌我损失；八阵AI仍按实际可影响敌军落点，玩家可提前布置空地。

新增组合军略不等待护盾、战歌、魔免或战法冷却配合，不规划羁绊。舍己护军固定以实际在场提供者为中心，不能用后备来源施放。励军固阵逐队检查并实际扣除20战意，无合格目标不耗蓄势。实际执行均调用玩家相同入口。

逐项回归通过正式 createScenario → lockDeployment → stepBattle 自动充能与施放，不注入蓄势或战意。机制样本固定无关行动；励军固阵的战意来自真实普攻。每项四种子分开发和独立验证、双方交换，检查8次自动施放、2次条件不足保留进度，以及施放前后确定性读档。一次性军略另验再充能仍不突破限次。

回归 `npm run test:stratagem-ai`；逐项记录 `npm run audit:stratagem-ai` 写入本机 outputs/stratagem-ai-every/。这是机制检查，不代表全国自然触发或战役平衡。普通全国自然全AI另行记录。正式范围与来源见[施放规则](军略资格与施放-规则51.md)，新军略见[军略组合与代价](军略组合与代价.md)。
