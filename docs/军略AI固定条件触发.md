# 军略 AI 固定条件触发

军略与战法分别处理。军略之间不比较现场收益，不评估兵力、状态严重程度、路线或未来接敌；范围军略单独优化落点和矩形方向；战法保留共同引擎的周围目标、射程、战意、次数及冷却判断。

军略在自然进度蓄满后的步末检查一次；如果没有符合条件的军略，保留进度，下一步继续检查。只使用任职武将实际提供的军略，仍遵守冷却、已有效果和每场施放上限。不因玩家是否施放军略而改变检查时机。

固定顺序如下，找到第一项就施放。同效果的普通与专属军略沿用可用列表顺序，不比较持有者强度；实际效果结算仍按正式持有者规则执行。

| 顺序 | 效果 | 基本触发条件 |
| --- | --- | --- |
| 1 | 魏武挥鞭 | 存在尚未受魔免保护的在场友军 |
| 2 | 猛攻 | 存在敌军或敌方城门 |
| 3 | 虚实 | 存在敌军 |
| 4 | 八阵 | 存在可受八阵异常影响的合法在场敌军，且本场未使用 |
| 5 | 火攻及同效果专属 | 存在未灼烧且无魔免的合法敌军 |
| 6 | 远射 | 在场有弓兵或弩兵 |
| 7 | 兵贵神速 | 存在尚未受神速影响的合法在场友军，按固定部队顺序取首队 |
| 8 | 疾行 | 通用条件满足即可 |
| 9 | 守备 | 存在敌军 |
| 10 | 鼓舞 | 在场部队有战意未满者 |
| 11 | 轮替 | 在场部队有战意未满者，或有剩余次数的战法正在冷却 |
| 12 | 夺气 | 存在有战意且无魔免的合法敌军 |
| 13 | 断援及同效果专属 | 有敌方预备队 |
| 14 | 后军固阵 | 有己方预备队 |
| 15 | 救疗 | 在场部队有可救伤兵且兵力未满 |
| 16 | 休养 | 在场部队有可救伤兵且兵力未满 |
| 17 | 镇静 | 在场部队有可清除状态 |

通用条件：战斗未结束、己方未撤退、有在场存活部队和敌军或敌方城门；军略未冷却、同字段持续效果未生效。限次军略另检查本场剩余次数。

实现：`battle-ai.mjs`。回归：`tests/proactive-command-ai.test.mjs`、`tests/cleanse-ai.test.mjs` 及现有军略、战法、步末施放与确定性续战测试。

范围军略在固定优先序中先检查是否有有效落点，没有则继续检查下一军略。落点优化遍历合法格中心；矩形同时比较0°和90°。以有效目标队数最多为准，不按兵力、伤害或伤兵数量加权，也不改变军略优先序。火攻计入未受灼烧的合法在场敌军，救疗计入仍有可救伤兵且兵力未满的友军，夺气计入战意大于零的敌军；八阵计入仍有至少一种可施加异常的敌军，不按军纪或异常严重程度加权。隐身、避战、预备队等非法目标不参与计数。

同覆盖数时保持确定顺序：先按目标方部队顺序检查其所在格，再按行、列检查全场；同落点先0°后90°。不使用随机数，不改部队数组。实际范围结算与玩家共用，存读档后选择一致。回归见 tests/stratagem-placement-ai.test.mjs。

魏武挥鞭的固定位置在普通猛攻之前，避免曹操专属始终被猛攻优先序排除；这不是现场收益评分。神速的单队目标沿用部队稳定顺序，跳过已有神速者，不按兵力或输出重排。
