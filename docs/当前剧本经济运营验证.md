# 当前剧本经济运营验证

金、粮、预备兵已经统一按城市库存结算。经济验证须逐城记录库存、直接运营、周期收入、费用、驻城耗粮、粮道供给及实际运输；势力合计仅作汇总，不可掩盖某城的资金或口粮缺口。

当前验证入口为 tests/city-budget.test.mjs、经济专项测试、外交与运输回归。机制验证覆盖城市独立收支、富城不能替穷城直接扣款、真实金运输、旬末入库前缺粮、预警去重与升级、预算持久化及只读查看。

七剧本共用城市资源与预算规则。初始势力金总量按各城规模分配；不补资源掩盖缺口，不将势力总库存视为每城可用库存。年度自然运营与持续战争的承载结论须由这一城市库存结构重新取得，当前机制回归不能替代年度战争承载验证。

当前回归记录在 outputs/city-budget-final-regression.txt、outputs/city-budget-final-ai.txt、outputs/city-budget-diplomacy-mechanisms.txt、outputs/city-budget-reservations.txt；界面验证在 outputs/city-budget-ui。
