# 战法次数与整备（规则48）

## 基础规则

- 每队每项已学战法独立计数：低级2次、高级1次、专属通常1次；持续专属2次。提供增加或恢复次数的专属固定1次。常驻光环不主动施放、不计次数。
- 保留原有战意门槛、独立冷却、合法目标、槽位顺序和4步调息；用尽后跳过，继续检查后续战法。无目标不消耗次数。
- 普通战法和绝大多数专属不消耗战意；目前仅吕布「人中吕布」保留70战意爆发消耗。
- 次数、额外上限及恢复记录随当前版本存档保存。入场、轮换和读档不重置；新战斗从基础次数开始。非当前版本存档提示重新开始，不迁移。
- 修缮同样使用低级战法的2次基础次数，不再另设3组物资额度。

## 补次与整备边界

增加次数上限、恢复次数、缩短冷却相互独立；补次不清除冷却或调息，不受威力、连携放大。普通补次不恢复专属或常驻光环，补次能力不恢复自身或互相恢复。

只有存在合法友军和实际缺口时才提供相应补次；军略补次遵守每场上限。具体能力目标、数值与每场次数见[战法表](design-tables/战法一览表.md)和[军略表](design-tables/军略一览表.md)。

详情显示剩余次数、本场上限、冷却和用尽状态；实际使用记录随当前存档保存，新战斗重置。验证使用真实学习、交战、战意积累与合法目标。
