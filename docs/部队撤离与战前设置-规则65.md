# 部队脱战、撤离与战前设置

已接入双方共用战斗引擎、普通模式和独立战役。规则68引入，版本以 `combat-rules.mjs` 为准，不迁移旧档。

## 战前会议

后备队列使用与上场部队相同的头像卡片，显示姓名、兵种、兵力与战意。左键点击整张卡片打开该部队属性；拖动卡片可调整后备顺序、交换场上部队或放入合法阵位，未到援军仍须实际抵达后才能入场。

每队填写具体非负整数：现役兵力不超过该人数时自动撤离。伤兵不计入判断；留空表示不自动撤离，仍可执行全军撤退。默认留空。人数不小于开局兵力时，该队上场即开始撤离。

支持勾选多队或全选，输入统一人数后点击“应用”；批量留空取消所选部队的自动撤离。未勾选部队不受影响。后备和待援部队同样可设置；查看详情、调整军团、存读档保留设置。开战后仅在援军军议期间允许重新调整；正在撤离或已经离场的部队不能取消撤离。

普通模式默认撤向最近的安全节点，按实际道路剩余距离计算，考虑当前路段的两个方向。候选包括己方城市、路口、港口和关卡，排除敌军驻守、正在交战或不可安全到达的节点。战前及援军军议期间可统一指定其它合法节点；目的地失效时就近改道。双方共用 `canRallyAt` 规则。独立战役使用本方战场出口。

## 战场援军与军议（规则104）

普通模式允许继续向正在交战的地点派军团。军团必须沿实际道路抵达节点或道路中的交战位置，才将本军实际部队加入同方后备，不创建第二场战斗。战场后备不设四队上限，可由多批军团累积；每个出征军团仍最多十队。双方共用通常六个上场名额，奸雄所属军团可使用第七名额，额外名额不能转给其它军团。

独立战役可在自定义编辑器中给双方新增多支援军军团，分别命名、编制、任命，选择按时间到达、指定部队被消灭或指定军团全灭，每军团最多十队，全场人员去重。目标可来自双方先遣及其它援军，军团全灭包含后备，主动撤离不触发；不能指定本军团或循环等待。条件满足时整团到达，仅确认一次。最后一支先遣队被消灭后先检查援军条件，再判定胜负；条件尚未满足的援军不延续已全军覆灭的战斗。历史模板也使用这一配置。到达前不能布置上场，不提供军略或奸雄第七名额；到达后并入本方后备，保留独立军团身份与指挥来源。交换双方同时交换全部援军归属及先遣军团目标。

己方援军抵达已开战的战场后，全局暂停，并提供“军议”或“继续作战”。军议复用战前会议界面，可以拖动调整全部后备的补入顺序、逐队或批量调整撤离人数及选择合法撤离节点。在场部队不能换位、换下、重新布阵，也不能把后备直接拖上场；战斗意图、地形、兵种及固定战法继续锁定。后备尚未实际补入时不贡献在场羁绊，也不领取入场奖励。

军议期间不推进日期、战斗或随机数，不清除战意、伤兵、冷却、次数、已生效效果和开场锁定记录。后备排序只交换原后备数组位置，保持在场部队的行动顺序。确认军议后，后备在后续战斗步中按空位、入口和合法名额补入；敌军援军沿原 AI 补位规则处理。再次抵达的己方援军可再次触发军议。委托交战也可接管进入援军军议，交还委托后按调整后的队列继续。待军议及军议中的状态随当前存档保存，读档后继续处理。

## 定时状态与援军军议（规则105）

独立战役可在编辑器设置断粮、伏兵的日期、目标方与持续时间。事件复用缺粮、混乱和失阵，不直接扣兵。到期只触发一次；断粮期限内抵达的援军进入军议时已带缺粮状态，伏兵只影响事件当时在场的部队。军议不刷新或清除事件，读档保持触发记录和状态余期。详见[生成器规则](战役生成器与验证-规则58.md)。

## 脱战

- 原地即可合法攻击新目标时直接换目标；未受近战牵制时正常移动。
- 受近战牵制而需要移动换目标或撤离时，先消耗一个行动周期准备。准备中停止普攻、反击与战法，不产生ZOC，仍可被攻击和控制。
- 准备完成后，按实际移速走一步脱离原牵制，方向须远离原牵制部队，遵守地形、占位与移动限制。不能穿过敌我部队或借此贯穿敌阵；接触新的牵制后重新准备。
- 普通伤害不重置准备；不能行动的控制阻止移动。无可通行位置则等待，不瞬移、不额外扣兵。换目标的脱战过程保持目标，目标失效后重新判断，撤离优先。

## 撤离与补位

- 有兵部队达到人数条件后立即进入撤离状态；恢复兵力不取消撤离。零兵按溃败处理。
- 开始撤离即取消待结算战法；包括治疗、护盾、位移、专属在内的全部战法均不可再次施放。不普攻、反击，不产生ZOC、军略资格或蓄力；已结算的持续效果沿用原期限。
- 向本方出口实际移动，途中仍可被追击、攻击、控制或歼灭。未离场前仍占上场名额。
- 到达出口当步标为已撤离，释放名额，后备按通常六队、奸雄七队上限、援军到达时间、入口占位及既定择序正常补位。单队撤离不等同全军撤退；全军撤退则不再派后备上场。
- 离场后本场不能再次参战，包括战略返城后再次出征进入同一战场的情况。

## 大地图撤退、整编与结算

离场当步将真实剩余兵力、伤兵及分配携粮移交撤离队，从原军团移除人员；战场保留战报快照和已交接标记。随当步世界时间开始移动，不等待整场战斗结束。空军团移除，不能保留重复人员或再次回写兵力。

撤离队复用运输队速度、道路位置、拦截与卸载流程。每个战斗步按一天的1/24推进，避免离场时额外获得整天移动。沿路遇敌直接损失部队与物资，不创建新战斗；人员按现有脱身、被俘和战死规则处理。战场出口已完成的脱离不在大地图原点重复判定原交战军团拦截，但实际路线上的后续敌军仍会拦截。

目的地失守或被围城时，从当前道路位置重新选择合法可达据点；没有候选则保留实际位置，暂停移动并提示，仍可能遭到敌军拦截。抵达己方城市后转为城内独立部队；抵达非城市节点后，同一原军团的幸存部队重新集结为真实军团，保留现役、伤兵、携粮及运输容量，不瞬间回血补兵。筹划阶段可调整任职、拆分或合并，每军团最多十支现役部队。节点仍无独立资源与内政委任，关卡和港口可承接大城都市圈建设；驻军不可在节点征兵或改换兵种；待到达部队超过军团上限时保留为撤离队等候整编。功绩在原战斗结束后按实际贡献及战果一次结算，兵力和伤兵不再次覆盖已返城的部队。

全部状态随当前存档保存并确定性续战。独立战役只结算战场结果，不生成大地图运输。
