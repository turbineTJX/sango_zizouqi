# 战法观看与结算

观看节奏调整保留如下；当前战法已加入威力成长、成功判定和暴击，详见 [战法威力与概率规则](战法威力与概率规则.md)。

- 每次战法在 1× 下展示 1.9 秒，2×、4× 下至少展示 1.4 秒；0.5× 为 2.3 秒。演出期间模拟时间暂停，结束后按当前速度继续，不补跑积压步骤。
- 同步触发的战法逐个演出，多段与多目标只演出一次。连携标签并入对应战法，不再另播一次全屏演出。减少动态效果模式同样保留阅读时间。
- 修正“休养生息”每步、每队回血误触发全屏战法演出的问题：它和回春一样属于持续治疗，不新增施法记录或重复暂停战场，实际治疗与伤兵预算保持原样。
- 战场下方常驻最近一次战法摘要，按当前演出切换，演出结束后仍保留。点击摘要或“战法记录”暂停战斗，查看双方最近各 20 条记录，最新在前。
- 每条记录显示施法者、目标、实际损兵、实际治疗、护盾吸收，以及新增、刷新或解除的状态和实际剩余步数。伤害不再被“混乱”等状态文字替代。护盾显示实际新增或刷新层数值与期限。
- 多段伤害按目标累加；治疗以实际伤兵预算为准；未成功施加的控制不记作成功。后续灼烧和回春描述为持续状态，不提前累计为已经造成的伤害或恢复量。
- 结果记录来自该次施法的结算快照和事件，不修改部队状态。存档保留当前步结算记录，读取后按原随机数状态确定性续战；界面的历史记录仅保留本次打开战场以来的条目。

验证覆盖真实多段命中、护盾吸收、治疗预算、控制抵抗、存档校验与确定性续战，以及暂停、后台、倍速、同步施法顺序、连携合并和摘要保留。现有控制突入和持续战意压制回归继续通过。
