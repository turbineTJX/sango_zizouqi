# 战场发动提示与实际结算

战场采用“发动者—能力—目标—实际结果”的展示顺序。战斗演出参考《三国志12》的武将亮相、招式题字与战场效果层次，参考入口为官方[战法](https://www.gamecity.ne.jp/sangokushi/12cn/sentou/sentou_03.htm)与[秘策](https://www.gamecity.ne.jp/sangokushi/12cn/sentou/sentou_05.htm)介绍。本项目使用已有原创武将素材与独立绘制的演出，不复制原作素材或战斗规则。

## 演出风格

- 首次使用默认完整特效，已保存的清晰／完整偏好继续生效。完整模式采用战场压暗、较窄的武将横幅与题字；标题桌面不超过30px、手机不超过22px，命中前退出切入。战场表现以部队本身动作为主，不给整队反复套发光圆环。
- 战法切入使用本人的战斗用途裁剪，军略使用实际施放记录中的提供者；无图显示姓名标识，隐藏敌方提供者不显示身份。手机按当前可见战场宽度排版，横向查看战场后题字仍在可见区域。
- 清晰模式保留局部动作、军令旗和数值反馈，减少动态效果时关闭大幅人物切入与战场闪光。暂停或后台冻结演出时钟，切换倍速不重播已经开始的演出。
- 普攻和小战法共用480毫秒的常规动作节拍，按记录顺序错开16毫秒，均随倍速缩放；常规步等待本批动作结束，大战法、真实连携和军略保留独立窗口。前冲在0.52的真实命中点到达峰值并保持至0.6，连携起手错峰但共用命中点。命中力度按真实损兵比例、暴击与实际击溃分级，以士兵身体后仰、护甲接触亮点及有方向的局部火星和扬尘表现；全额吸收不后仰，持续伤害保持较轻反应。真实溃败先倒伏、落旗再淡出，主动离场不倒伏；减少动态效果关闭动态受力与倒伏。取消战场下方新增文字摘要，不增加全场停顿、虚构击退格子或改变结算。

## 部队动作与状态

- 枪戟、骑兵和弓弩各变体默认使用可动原生模型，补足分片甲、头盔、盾牌、弓弩、箭囊和骑乘马匹；双方使用各自衣甲配色、柔和光照和贴地阴影，不把阴影画成状态光圈。每名代表士兵的手臂、兵器、身体与腿部按真实动作阶段挥击、突进和齐射，各排准备错开、实际命中时点一致，阵亡在实际致命命中后倒下并淡出。手机减少代表士兵数量，保留兵种轮廓和动作，不改变真实兵力。
- 原生陆战动作由 `troop-animation.mjs` 按表现时间采样：步兵分开大腿、小腿与脚掌，支撑时脚掌回正、抬脚时屈膝；起步和停步渐入渐出。枪兵压枪前刺，戟兵转腰挥斩，弓兵左手持弓、右手拉弦，弩兵架持后复位；弓弦与搭箭随准备、放箭和重新搭箭变化。骑兵采用对角马步，马膝、马颈、马尾与骑乘身体协调，旗布轻微随动。持械方向随手臂补偿，避免枪尖朝后或弓身横倒。
- 转身沿最短方向在0.16秒表现时间内过渡，不因跨过角度边界整圈旋转；同一时间重绘不推进动作。攻击起手和收势平滑，发弹仍在动作进度0.24、实际命中仍在0.52，近战命中后短暂保持伸展再收回，不额外暂停模拟。实际损兵才增加身体后仰与头颈反应；全额护盾吸收只抬盾格挡。定身保留原地攻击，眩晕停止攻击和步态，减少动态效果不播放这些动态过渡。
- 已配置的独立兵种模型优先使用；不支持三维显示时回退到平滑采样的精灵帧。船只与器械保持现有模型，冲车槌体前撞、投石机抛臂转动，已有GLB动画片段按演出时钟播放，骨骼实例相互独立。没有骨骼的静态资源不虚称有骨骼动作。
- 全部53项当前状态映射到身体表现通道：眩晕停步摇晃，混乱打乱朝向和队形，疲弱及疫伤下沉姿态，防御收紧阵形，疾行调整步频，伏兵和疑兵降低不透明度；封技在身体挂小符，定身在脚部束缚，灼烧贴着士兵燃烧，护盾在实际护甲位置亮起及破碎。增益、减益的细微武器／身体标记跟随实际逐兵位置，不绘制部队外光罩、转圈状态字或重复地面光环。
- 状态附加、刷新、解除仍在真实结算点更新，不提前显示排队结果；免疫与失败不增加状态。动画不更改实际格子、行动资格、攻速数值或随机数。减少动态效果保留静态状态标记和小图标，关闭摇晃和方向变化。
- 跳字同时最多显示6项实际收据，常规数值约11～13px、暴击不超过16px；普通强化和状态刷新不弹名称，破盾及首次关键控制用9～10px短提示，完整来源和状态通过聚焦或详情查看。上方发动卡只保留小头像、提供者和名称，完整结算保留在卡片提示及日志。

## 发动提示

形状战法蓄势时用短时虚线格标明真实锁定范围；只显示己方或实际可见敌军的蓄势，不由隐藏来源泄露位置。范围保持原地点，目标移出不会拖动标记。实际命中才显示损兵、吸收与状态；落空和蓄势中断记录对应结果，不表现为命中或伪造伤害。读档直接恢复当前锁定范围，继续原期限。

- 战场上方分别保留我军、敌军一张提示卡，显示发动武将头像（素材缺失时显示姓名标识）、阵营、战斗日、特性／战法名称、目标和实际结算。点击卡片、摘要或“战斗日志”暂停查看。两方不会互相覆盖，卡片不遮挡地图。
- 仅专属特性、专属战法和大战法进入醒目提示，普通特性与小战法只保留正常命中特效、数值和发动记录，不弹卡片、不标出发动名称、不覆盖重要结果摘要。大战法依据正式表的高阶战法分类，不以100战意门槛代替；全屏演出仍按下文分级。醒目提示保留3秒表现时间，不随倍速缩短，不暂停模拟。暂停与后台冻结表现时钟。同来源同能力的高频发动合并计数，展示最近一次结果；具体每次结果仍分别保留在战斗日志中。
- 每方队列最多4项，超过6秒的等待提示不再补播，避免提示严重落后战况。记录不受提示队列丢弃影响；双方共保留最近300条日志，按战斗日倒序显示，可筛选特性、战法、普攻、军略、战况与持续效果。迟到提示不在地图补画旧命中位置。
- 即时发动时短暂标记来源部队与受影响部队，减少动态效果模式保留静态标识和文字、关闭连线及入场动画。敌方仍处伏兵隐藏状态的特性不显示来源卡片或记录，避免泄露位置。
- 未触发或未产生新效果只记入记录，不播放成功提示。高频状态刷新只记录实际变化；持续灼烧、回春、反击不冒充新一次战法施放。老健首次取得远射时提示，后续每步续期不重复提示。常驻数值、免疫及任职倍率仍通过部队特性详情查看，不虚构触发战果。

## 大战法与连携

部队溃灭、撤退与后备／援军实际入场共用真实状态观察器。溃灭在致命命中点倒下、倒旗并扬起散尘，配低鼓与下行号角；撤退先转向出口并鸣金，实际抵达出口后行进淡出，保留撤离声；实际入场的部队从本方一侧短距离行进入阵，配进军鼓与上行号角。未抵达援军与仍在后备的部队不提前演出，整批同类音效合并。提示保持局部小字与旗帜，不加常驻光圈，不增加单队伤亡或撤离语音。

动作与音效沿表现时钟暂停，减少动态效果保留静态旗帜和短提示；读档、切回战场、浏览与刷新不补播旧事件。死亡和撤离始终区分，隐藏敌军与疑兵不产生此类提示。局部过场不额外暂停整场模拟，战斗结束时保留最后一次倒下／离场的收尾。实现为 `battle-transition-events.mjs`、`battle-transitions.mjs`，共享原生模型与精灵位置和朝向；不改变规则、随机数或存档。回归包含于 `npm run test:battle-readability`、`npm run test:audio`，`node scripts/verify-battle-transitions-ui.mjs` 使用合法的受控双方阵容验证实际撤退、离场、补位、溃灭及音效，输出桌面、手机、减少动态效果和动图；该画面夹具不作为自然AI或平衡证据。

- 100战意大战法和真实连携保留人物切入；其他战法暴击不升级成切屏。所有切入使用发动者本人头像，暴击通过文字和颜色强调，避免通用插画掩盖发动者身份。
- 大演出在1×下1.9秒，2×、4×下至少1.4秒，0.5×下2.3秒；期间模拟暂停，结束后不补跑积压步骤。同步触发依次播放，多段、多目标与同次连携合并演出。
- 特性提示不增加全屏演出或模拟暂停。军略采用独立军令通道：完整模式先显示实际提供者与军略题字，随后按实际范围绘制火焰、治疗、阵纹或已保存的雷击落点；清晰模式使用简洁军令旗。护盾、控制是否实际生效仍由真实状态反馈决定，不用题字冒充成功。军略不进入大战法队列，双方同时施放依次展示；其已记录的伤害、治疗与状态变化在同一军令演出的命中点呈现。

## 归因与记录

羁绊使用31种独立矢量图标，羁绊栏、个人羁绊与战场短时徽记共用符号。真实开战时，实际在场持有者短暂亮出已激活羁绊，徽记下方的一至三格表示档位；约1～1.6秒后进入交锋。战中战歌、摧锋、火谋、连环、倾国、勇武免疫等按实际事件在触发部队上显示图标，局部身体闪光按进攻、防护、突进与支援区分，真实受益部队同步反馈，羁绊栏对应项短暂亮起。背水依据实际残血转变，蓄锐依据真实入场领奖记录；常驻加成只显示激活，不伪造逐次触发。后备、疑兵、已离场和隐藏敌军不提前提示。读档只建立当前基线，刷新不补播，暂停冻结时钟，减少动态效果只保留静态徽记，不增加文字摘要或常驻光圈。

实现为 `bond-icons.mjs`、`battle-bond-effects.mjs`，局部核对运行 `node --test tests/battle-bond-effects.test.mjs tests/bond-display.test.mjs tests/battle-effects.test.mjs` 与 `node scripts/verify-bond-activation-ui.mjs`。这轮核对用于表现试调，不作为全游戏或发行验收门槛。

- 触发特性从该次被动事件的前后快照生成结算，保留持有人、固定特性ID及实际结果。战法触发的特性护盾等变化归入特性记录，不重复计入战法战果。
- 记录包括实际损兵、伤兵救治、护盾吸收、新增／刷新／解除状态、实际幅度与持续时间、位移、战意和冷却变化。控制失败不写成成功，未发生的后续灼烧与治疗不累计为即时战果。
- 最近一次摘要在提示消失后继续保留。存档保存最近300条战斗日志及当前步结算，读档后继续追加，不重复写入已记录事件；按原随机数状态确定性续战。普通能力仍记日志，是否弹卡片不影响日志。此项为规则72，旧档重新开始。
- 展示层不消费随机数、不修改战斗数值、不重新施放能力。发动记录的来源须与武将固定特性及名称对应，导入时校验。

验证：`npm run test:ability-cues` 覆盖真实特性归因、战法与特性分离、双方提示、合并与队列上限、失败与伏兵隐藏、倍速／暂停、确定性续战；`npm run verify:ability-cues-ui` 通过真实合法战斗快照验证桌面、390px手机、查看记录及减少动态效果。

演出验证：`npm run test:battle-readability` 覆盖支撑脚与屈膝、最短转身、弓弦释放、动作首尾衔接、53项状态身体通道、切入退出时点、双方军略顺序、提供者隐藏与真实命中反馈；`npm run verify:battle-body` 使用明确的合法状态画面夹具检查逐兵位置、无通用圆环、小字、桌面、手机、暂停与原生器械部件／GLB动画，夹具不作为平衡或自然AI行为证据。`npm run verify:battle-models` 检查原生陆战模型的独立关节、命中动作时点、全部关节暂停冻结、手机减量与渲染预算，并输出真实战场和同镜头精灵回退对照。`npm run verify:troop-animation` 用战场共用模型生成受控动作近景，检查持械方向、弓身与弓弦、马膝及同时间像素一致；近景用于观察动作，不作为自然战斗或平衡证据。`npm run verify:battle-cinematic` 继续验证自然充能军略与真实大战法。
