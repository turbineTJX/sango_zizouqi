# 战场发动提示与实际结算

战场采用“发动者—能力—目标—实际结果”的展示顺序。参考[《三国志8 REMAKE》官方战斗介绍](https://www.gamecity.ne.jp/sangokushi8-re/system.html)中突出武将、奇才与连携的方向，使用本项目已有美术；不复制原作素材或战斗规则。

## 发动提示

- 战场上方分别保留我军、敌军一张提示卡，显示发动武将头像（素材缺失时显示姓名标识）、阵营、战斗日、特性／战法名称、目标和实际结算。点击卡片、摘要或“战斗日志”暂停查看。两方不会互相覆盖，卡片不遮挡地图。
- 仅专属特性、专属战法和大战法进入醒目提示，普通特性与小战法只保留正常命中特效、数值和发动记录，不弹卡片、不标出发动名称、不覆盖重要结果摘要。大战法依据正式表的高阶战法分类，不以100战意门槛代替；全屏演出仍按下文分级。醒目提示保留3秒表现时间，不随倍速缩短，不暂停模拟。暂停与后台冻结表现时钟。同来源同能力的高频发动合并计数，展示最近一次结果；具体每次结果仍分别保留在战斗日志中。
- 每方队列最多4项，超过6秒的等待提示不再补播，避免提示严重落后战况。记录不受提示队列丢弃影响；双方共保留最近300条日志，按战斗日倒序显示，可筛选特性、战法、普攻、军略、战况与持续效果。迟到提示不在地图补画旧命中位置。
- 即时发动时短暂标记来源部队与受影响部队，减少动态效果模式保留静态标识和文字、关闭连线及入场动画。敌方仍处伏兵隐藏状态的特性不显示来源卡片或记录，避免泄露位置。
- 未触发或未产生新效果只记入记录，不播放成功提示。高频状态刷新只记录实际变化；持续灼烧、回春、反击不冒充新一次战法施放。老健首次取得远射时提示，后续每步续期不重复提示。常驻数值、免疫及任职倍率仍通过部队特性详情查看，不虚构触发战果。

## 大战法与连携

- 100战意大战法和真实连携保留人物切入；其他战法暴击不升级成切屏。所有切入使用发动者本人头像，暴击通过文字和颜色强调，避免通用插画掩盖发动者身份。
- 大演出在1×下1.9秒，2×、4×下至少1.4秒，0.5×下2.3秒；期间模拟暂停，结束后不补跑积压步骤。同步触发依次播放，多段、多目标与同次连携合并演出。
- 特性提示与军略提示不增加全屏演出或模拟暂停。军略继续采用独立军令表现。

## 归因与记录

- 触发特性从该次被动事件的前后快照生成结算，保留持有人、固定特性ID及实际结果。战法触发的特性护盾等变化归入特性记录，不重复计入战法战果。
- 记录包括实际损兵、伤兵救治、护盾吸收、新增／刷新／解除状态、实际幅度与持续时间、位移、战意和冷却变化。控制失败不写成成功，未发生的后续灼烧与治疗不累计为即时战果。
- 最近一次摘要在提示消失后继续保留。存档保存最近300条战斗日志及当前步结算，读档后继续追加，不重复写入已记录事件；按原随机数状态确定性续战。普通能力仍记日志，是否弹卡片不影响日志。此项为规则72，旧档重新开始。
- 展示层不消费随机数、不修改战斗数值、不重新施放能力。发动记录的来源须与武将固定特性及名称对应，导入时校验。

验证：`npm run test:ability-cues` 覆盖真实特性归因、战法与特性分离、双方提示、合并与队列上限、失败与伏兵隐藏、倍速／暂停、确定性续战；`npm run verify:ability-cues-ui` 通过真实合法战斗快照验证桌面、390px手机、查看记录及减少动态效果。
