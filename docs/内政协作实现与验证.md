# 同城同方向内政协作

日期：2026-09-19。已接入普通模式的天下战略，对应内政设计V1.5。此次实现多人委任与自动协作，人物草案中的完整战斗性格、义理与人才公式仍是独立后续工作。

## 操作

在城池内政的商业、农业、技术、军事、人才卡片中，使用“添加负责人”连续加入本城武将。每人显示自己的行动、剩余时间、已付费用与成功把握。每人仍只能负责一个方向；添加到另一方向时，只改派这个人。行内“解除”只解除对应武将，不清空同僚。

同城、同势力、同方向的武将自动成为协作候选，不要求同一具体动作。例如市场建设与集市经营、征兵与救治都可协作。同方向待命者可帮助执行者，协助者也可继续自己的原事务；全部待命、离城、调任、出征、暂停或被围时不凭空协作。

## 当前数值

每城每方向每旬最多判定一次，失败也消费本旬次数。按人物ID稳定排序，从符合条件的主执行人—协助者组合均匀抽取，再判定是否触发。多人不会按所有两两组合反复掷骰。

```text
相性距离 = min(abs(A-B), 150-abs(A-B))
相性修正C = 距离0～10: +8；11～25: +4；26～45: 0；46～60: -4；61～75: -8
协作概率 = clamp(20 + 0.4 × (关系值-50) + 2 × C, 5, 65)%
成果增幅G = 10% + 协助者有效能力 / 100 × 15%
成功把握增幅S = 3 + 协助者有效能力 / 100 × 5 个百分点
```

相性0有效；未载相性按中性修正处理。能力沿用原动作的政治、智力、统率与魅力权重，限制在0～100。关系和相性只影响协作概率；协助者能力决定幅度，主执行人原有能力不重复乘算。

| 事务 | 效果 |
| --- | --- |
| 建筑施工 | 一次额外完成 `min(剩余工期,10天)×G` 的工作量，受剩余工作量限制；支持小数工期，费用不变 |
| 研究、修缮 | 本次研究进度或修复耐久增加G，分别受100研究进度与城门耐久上限限制 |
| 集市、督耕 | 本次正向成果增加G；亏损集市不因协作被改成盈利，粮食受库容限制 |
| 临时产出、建设优惠 | 本次临时效果提高G，仍有原来的期限或一次性消费，不永久提高建筑基础产出 |
| 征兵 | 在已批准人数、分配到具体部队的预留、钱粮与本旬额度内增加有效人数；满额征兵不突破批准人数，部分达成可获得更多士兵 |
| 救治 | 从原接收部队的真实伤兵中提高恢复人数，不治疗离城、交战或缺粮部队 |
| 守城准备 | 提高准备效果，单项最多15战意或12.5%护盾；含建筑的最终上限仍为30战意、35%护盾 |
| 贸易、救灾、试制、人才 | 本次主要成功把握增加S，沿用现有94%概率上限与有效目标条件；其余结果按剩余概率同比缩放，只结算一个原动作 |

数量类只在真实增加成果后奖励关系成长。成功率类只在本次结果获得改善并产生有效成果时奖励；失败、结果未改善和已经达到上限不刷关系。成长按合拍程度为1～3点，每对每旬最多一次；厌恶关系不会因偶发协作自动和解。当前战斗连携仍按原关系值，不叠加相性倍率。

## 资源和存档

- 每人一个委任，同方向可多人；每城仍只有一个建设队列与一个研究执行槽。
- 同一人才的登用、劝说或安抚不能同时被多人占用。同类临时效果、同一守城准备与机会来源也不会重复占用。
- 多人征兵扣除其他行动已经分配的部队缺额，再批准人数和费用；协作新增实际征兵继续扣对应预备兵、粮食与人头费用，未转化部分释放或退款。
- 保存每城每方向的协作旬、参与人、承接行动、独立随机状态、判定、前后值、已应用标记与关系成长额度。同一天重复结算不推进动作，不重抽协作。
- 关系成长更新战略世界；已有战役和历史快照保留开战关系，新战役读取成长后的关系。
- 战略存档版本4，内政数据版本2；按项目策略拒绝旧档并提示重新开始，不迁移旧结构。当前版本支持自动保存、刷新恢复、导入导出和确定性续算。
- 离线缓存同步更新并包含新增协作规则模块。
