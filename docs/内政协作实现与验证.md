# 内政协作与随机纪事

协作遵守当前六方向单属性规则，与玩家和战略AI共用内政处理器。

## 操作

在城池内政的商业、农业、军务、武备、技术、人才卡片中，使用“添加负责人”连续加入本城武将。每人显示自己的行动、剩余时间、已付费用与成功把握。每人仍只能负责一个方向；添加到另一方向时，只改派这个人。行内“解除”只解除对应武将，不清空同僚。

同城、同势力、同方向的武将自动成为协作候选，不要求同一具体动作。例如市场建设与集市经营、征兵与修缮都可协作。同方向待命者可帮助执行者，协助者也可继续自己的原事务；全部待命、离城、调任、出征、暂停或被围时不凭空协作。

## 同岗连携与掣肘

同城实际在岗、办理同一具体事务的两人，关系达到亲爱及以上时可触发「同心协力」；同一工地、研究槽的同方向待命人员也可协助该项目。总判定通过后，关系判定沿用战场连携的关系值。两人的当前事务成事把握提高45个百分点，最高仍为94%，实际成果和每日工程／研究进展乘2；共用库存、库容、目标、工程量与本城旬办理额度。该轮没能办成或已达当地上限时，不凭空发放额外成果。

触发同心协力时友好度提高6，触发相互掣肘时降低6，按当前关系类型的边界和转变规则结算。与日常协作的实际成果成长分别记录；已达关系上限时只报告实际变化，不重复宣称获得交情。

厌恶关系可触发「相互掣肘」，当前事务成事把握降低45个百分点，最低12%，实际成果乘0.35，工程／研究进展乘0.4。不同工作或不同地点不触发这类关系事件。离城、外出、围城、等待军令或改办其他事务后，关系事件不继续提供效果。单项目仍只保留一个真实执行槽，协助者分享实际额外进度的功绩，合计不超过该项目预算。

## 跨领域意外

意外纪事以具体人物故事呈现。报事人的委任方向不限定事件领域；当事人从实际在同一城市的同势力武将中抽取，可以负责另一方向、任太守、在城预编部队或待命。实际外出、在途、侦察或参战者不作为故事当事人，外部工地人员也不虚构在主城发生故事。人物能力和性格只影响部分故事的当事人抽取权重，不固定位某人的专属事件，也不新增负面特性。

例如荀彧办理商业时，可能巡市发现夏侯惇强夺摊贩货物，出言制止后引发争执；乡民离心，预备兵离营，二人友好度降低。实际例子按两人当前所在城市及当事人抽取产生，不能从外地拉入人物。

| 故事 | 基准实际资源变化 | 友好度变化 |
| --- | --- | --- |
| 强夺市货 | 本城可用预备兵减少800 | -12 |
| 市肆解纷 | 客商献资2000金 | +12 |
| 合力护田 | 乡绅献粮6000 | +12 |
| 私宴耗粮 | 本城存粮减少2400 | -10 |
| 乡勇归附 | 整批乡勇投效，预备兵增加2000 | +10 |
| 欺压乡勇 | 本城可用预备兵减少600 | -10 |
| 匠心互启 | 对另一名实际研制人的本轮成事把握和进展生效 | +12 |
| 借力助工 | 对另一名实际施工／修缮人的本轮成事把握和进展生效 | +10 |

资源和关系在发生时结算一次，双方每日记录及奏报使用同一结算凭据，显示真实当事人、经过、资源变化和交情变化。正面资源故事改为客商、乡绅从私资私仓献赠或外来整批乡勇投效，作为罕见外来所得，不占用本城日常直接运营额度；仍受仓储及兵源上限限制，只入库一次。只有至少可接收基准奖励的75%时才抽取对应正面故事，避免满仓时触发后只得到零星奖励。旬末收获凭据包含已入库的纪事所得，回看不再次发放。日常内政、连携和命令特性仍共享原产能额度。罕见外来所得不计为稳定城市生产能力，不用于宣称经济持续承载达标。已有实际有效市场、农田或兵营才可产生对应正面收益。负面损失按实际存量封顶，预备兵只扣未预留部分，保留已付费整补的兵源和人数；没有可损失兵源时不抽取离营故事。未编制兵源仍不收维持费、不轮换或定期自行损耗，人物事件是有明确原因和奏报的损失。研究／施工协助需要实际已开办项目，费用不重复支付，既有进度保留。

友好度使用既有关系统一处理器，可跨越友好／亲爱等档位，特殊关系下降至边界以下按共同规则转变。变化只更新战略世界，已开战的关系快照保持。关系达到上下界或资源只够部分损失时，奏报只写实际变化，不将基准变化当成已得到的成果。故事发现本身不额外发功绩，真实事务继续按原实际贡献计功。

每势力每旬仅一次总判定，门槛3%；失败也保存并消费本旬机会。通过后才在该势力真实已开办的城市方向中抽取一组，最多发生一项纪事，城市和委任数量不增加判定次数。所选工作组先判同岗关系事件，亲密者按当前关系值判定连携，厌恶者按30%判定掣肘；未触发再抽取符合条件的跨领域故事，不再按方向额外判概率。每人和每城仍最多参与本旬一次。独立随机流不改变原事务的随机顺序。源事务、实际同城当事人、随机判定、资源和关系前后凭据保存；查看、确认奏报、读档均不重抽、不重复奖扣。

纪事先写入双方每日记录，再进入重要战略奏报；核阅暂停世界，确认只标记已读。内政页展示本轮事务效果和本旬已发生的故事。文案使用成事把握及交情渐笃／转疏等描述，不展示明确概率。正式数据见 `data/design/domestic-incidents.mjs`，回归 `npm run test:domestic-incidents`，桌面和手机界面 `npm run verify:domestic-incidents-ui`。

## 日常协作数值

每城每方向每旬最多判定一次，失败也消费本旬次数。按人物ID稳定排序，从符合条件的主执行人—协助者组合均匀抽取，再判定是否触发。多人不会按所有两两组合反复掷骰。

```text
相性距离 = min(abs(A-B), 150-abs(A-B))
相性修正C = 距离0～10: +8；11～25: +4；26～45: 0；46～60: -4；61～75: -8
协作概率 = clamp(20 + 0.4 × (关系值-50) + 2 × C, 5, 65)%
成果增幅G = 10% + 协助者有效能力 / 100 × 15%
成功把握增幅S = 3 + 协助者有效能力 / 100 × 5 个百分点
```

相性0有效；未载相性按中性修正处理。能力统一使用该方向的唯一主属性与适用特技，按规则56计算，限制在0～100。关系和相性只影响协作概率；协助者能力决定幅度，主执行人原有能力不重复乘算。

| 事务 | 效果 |
| --- | --- |
| 建筑施工 | 一次额外完成 `min(剩余工期,10天)×G` 的工作量，受剩余工作量限制；支持小数工期，费用不变 |
| 研究、修缮 | 研究协作在本旬一次实际工作日增加G比例的当日进度，修缮增加本次修复耐久；分别受100研究进度与城门耐久上限限制 |
| 集市、督耕 | 本次正向成果增加G；零成果不因协作创造收益，粮食受库容限制 |
| 临时产出、建设优惠 | 本次临时效果提高G，仍有原来的期限或一次性消费，不永久提高建筑基础产出 |
| 征集兵源 | 本次实际入库的储备兵增加G，受剩余库容约束；不消耗粮、不直接免费补满现役部队 |
| 整补部队 | 在已批准人数、分配到具体部队的预留、钱粮与本旬额度内增加有效人数；满额整补不突破批准人数，部分达成可获得更多士兵 |
| 救治 | 全体接收部队共用本次救治额度，协作提高该总额度；从真实伤兵中恢复，不治疗离城、交战或缺粮部队 |
| 守城准备 | 提高准备效果，单项最多15战意或12.5%护盾；含建筑的最终上限仍为30战意、35%护盾 |
| 贸易、救灾、人才 | 本次主要成功把握增加S，沿用现有94%概率上限与有效目标条件；其余结果按剩余概率同比缩放，只结算一个原动作 |

数量类只在真实增加成果后奖励关系成长。成功率类只在本次结果获得改善并产生有效成果时奖励；失败、结果未改善和已经达到上限不刷关系。成长按合拍程度为1～3点，每对每旬最多一次；厌恶关系不会因偶发协作自动和解。当前战斗连携仍按原关系值，不叠加相性倍率。

## 资源和存档

- 每人一个委任，同方向可多人；每城仍只有一个建设队列与一个研究执行槽。
- 同一人才的登用、劝说或安抚不能同时被多人占用。同类临时效果、同一守城准备与机会来源也不会重复占用。
- 多人整补扣除其他行动已经分配的部队缺额，再批准人数和费用；协作新增实际整补继续扣对应储备兵与装备金，不扣编制粮费，未转化部分释放或退款。自动整补仍考虑新兵未来口粮。多人征集兵源不占用已有兵源，共用实际库容，每次完成重新检查剩余容量。
- 保存每城每方向的协作旬、参与人、承接行动、独立随机状态、判定、前后值、已应用标记与关系成长额度。同一天重复结算不推进动作，不重抽协作。
- 关系成长更新战略世界；已有战役和历史快照保留开战关系，新战役读取成长后的关系。
- 存档按当前版本校验；按项目策略拒绝旧档并提示重新开始，不迁移旧结构。当前版本支持自动保存、刷新恢复、导入导出和确定性续算。
- 离线缓存同步更新并包含新增协作规则模块。
