# 武将能力配合

特技、兵种适性、战法和军略围绕武将职责形成配合。已确认16人的专属战法不限兵种；兵种强化特技应对应武将擅长的兵种。普通战法按兵种适性和主将属性固定配置，不替换或重抽。

连弩与长弓使用弓兵适性，青州、白毦、藤甲、大戟、虎豹与白马继承各自枪、戟、骑适性；兵器、船为携带装备，普通名额按原兵科适性决定。辅兵已删除。默认兵种与独立特性从正式设计表读取；战斗羁绊升级概率获得，换兵种和读档不重抽，10级达到个人预设上限。缺少高适性的武将可依自身最佳适性形成职责，不统一提高能力。

专属能够携带不等于所有场景都能发动，仍须满足射程、目标、路径、战意、冷却、次数与调息。军略另遵守基础智力70门槛及统智缩放，不能以兵种适性绕过资格。

当前人物配置见[武将表](design-tables/武将一览表.md)，效果见[特技表](design-tables/特技一览表.md)、[战法表](design-tables/战法一览表.md)和[军略表](design-tables/军略一览表.md)。验证覆盖适性配合、合法跨兵种携带、学习记录稳定及真实作用，不引用旧人物配置或旧胜率。
