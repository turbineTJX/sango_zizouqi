# 战略旬回合、连续战役与内政

这是当前可运行战略模式的规则。入口：模式首页「普通模式」，进入天下战略。历史战役、演义推演和演武试炼继续使用各自存档和单场流程。

## 时间与操作循环

- 战略回合为一旬，即十天；战役日回合为一天。一天配置为 24 个真实战斗结算步，常规势均力敌的战斗以 5～10 天为目标；优势战斗可更早结束，胶着战斗上限为 30 天，即 720 步。满 30 天仍未分胜负，按剩余可战兵力比例收兵。日步数与最大天数集中在 `combat-rules.mjs` 的 `CAMPAIGN_TIME`，由战略模块的 `CAMPAIGN` 使用。
- 第 1、11、21……天进入战略筹划。全局暂停，可处理内政、武将调任、编军、征募及行军命令。
- 点击「进行」开始执行。本旬逐日结算供粮、行军、遭遇和所有战场。暂停、布阵、面板操作与战法演出不增加日期。
- 进入前台战场后，每推进一个真实结算步，其他战场也推进一个结算步；地图行军、补给在日首处理。每 24 步结束一天。援军抵达不重置战役开战日期或 30 天上限。
- 第十天完成后，结算城市产出与建设，返回战略页面。正在指挥的战役保留全部状态，再次点击「进行」返回原战场。
- 「推进一天／推进本日」是可控的日回合操作，会停在新遭遇、待确认布阵或下一旬筹划点。

## 遭遇、委托和接管

军团沿道路逐日移动，图标显示真实道路中段位置。道路上的相向交会、追及和城池抵达均可触发战役。相向交会采用路径区间检测，避免高速军团互相穿过。

首次发生涉及己方的遭遇时，玩家可选择「亲自指挥」或「委托作战」。亲自指挥可以布阵、配置合法三槽战法；委托使用既有配置及规则 AI，立即锁定战前操作。

后台战斗不预先计算未来日期。军略、移动、攻击、战法、预备队与战损使用现有真实战斗流程。玩家可从「战役与快照」接管当前战场；已经推进的状态、随机数、兵力与冷却不回退。接管后可下军略、轮换、合围或撤退，不能再次布阵、换兵种或换战法。

后台按完整日快速计算，接管使用最新已完成日的状态。前台允许日内暂停；切换或读档保留已完成的日内结算步，不重复扣粮或移动。不同战场共享同一天，而不是轮流加总耗时。

同一天出现其他遭遇时，暂停全部战场并提示指挥方式。援军必须在大地图沿路实际到达战场，才加入预备序列；同阵营始终共享六个在场席位。

## 武将与军团

- 初始主力包含己方许昌主力与陈留援军、敌方河北前后军，各城原固有守军也改为真实部队。同城部队默认归并为城内大军团。另有可参与内政、调任或编军的在城武将。
- 武将记录归属城池，出征不自动变更归属。在城待命武将可以调任友城，经过实际天数后到达。
- 城内大军团不限队数；每支出征军团仍最多十队，每队一名武将。超过十队需先拆分才能出征，败退也按最多十队分组。主、副将与军师从其中任命。拆分与合并要求筹划阶段、同城驻守并且未被围城。战场同阵营同时上阵六队的规则不变。
- 新军团从在城武将组建，然后使用当地兵源征募整补。太守须先解除任命才能出征或调任。
- 军团有携粮、携粮上限、每日耗粮、缺粮程度、每日移动公里数、粮道来源及运入量。
- 混编军团采用最慢兵种速度。骑兵 42 公里／日、兵器 16、戟兵和舰船 24，其他兵种 28；道路距离按地图坐标统一换算。数值为原型调试参数。
- 获胜军团就地整队；败军从当前道路位置反向撤回友城，需要真实行程，并有短暂整队期。战役结束不把野战胜利直接当作占城。

## 存粮与粮道

粮食存放在各城粮仓。军团的日耗粮为 `现役兵力 / 100 + 伤兵 / 200`，使用三位小数保留余量，包含预备队；新产生的真实战斗伤兵也计入。

粮道通过受控城池及道路连接存粮据点与军团。敌军占据运输道路会切断连接；军团所在末端道路也检查敌军是否处于补给来源与军团之间。最大补给距离为 180 公里。

每座粮仓的每日发送额度为 `240 + 粮仓等级 × 120`；距离增加会降低末端运量，同一条道路每天共享 360 运量。多个军团按携粮可维持天数优先，共享真实库存及道路额度，不复制粮食。运输和耗粮都只执行一次日结算。

当前补给是抽象运输网络，没有实体运粮车和运输在途库存；己方据点都是存粮节点。地图虚线显示所选军团当前粮道。

## 缺粮与解散

库存较少但当天足额供粮时不施加惩罚。缺粮程度按实际未满足口粮比例累积：一天只供应一半口粮，增加半天缺粮；足额供应一天消除一天缺粮程度。

| 缺粮程度 | 战斗属性 | 大地图移动 | 其他后果 |
| --- | --- | --- | --- |
| 大于 0、不足 1 天 | 攻击、武技与谋略威力 −10% | −10% | 状态栏显示缺粮 |
| 1～3 天 | 上述三项 −20% | −20% | 继续积累缺粮 |
| 3～5 天 | 上述三项 −35% | −30% | 每天约 10% 现役兵员逃散 |
| 达到 5 天 | 部队解散 | 军团撤销 | 武将按返程时间回到友城 |

惩罚按所属军团作用于所有部队，包含预备队和参战部队；不能用战场净化解除。逃散单独记录，不产生伤兵，也不能被治疗。解散保留武将等级和成长，现役与伤兵退出可用兵力，武将返城后须重新编制与征募。

## 持续委任内政

玩家在本城给商业、农业、技术、军事、人才选择负责人。委任一直有效，直到解除、改派、调任、编入部队或城池失守。每人只负责一个方向，每城每方向一人；太守可以兼任一个方向。旬首执行时自主选行动，按世界日推进，本旬完成后下一旬重新决策。

五方向共40项行动定义、9类设施；同一设施根据等级执行新建或扩建，最高五级。各方向共享每城一个建设队列。负责人在资源、道路、部队缺额、伤兵、敌情、机会和已有效果之间评分，从合理候选中带权抽选；能力影响成功把握，性格影响选择。结果可正常、超额、部分达成或失败，工程受阻延长五天而不重复收费。开始、结束、暂停、中止和实际损益进入事件记录。

| 方向 | 建筑 | 事务示例 |
| --- | --- | --- |
| 商业 | 市场 | 集市、商旅、合作、售粮、税务 |
| 农业 | 农田、粮仓 | 督耕、灌溉、购粮、抢收、整理仓储 |
| 技术 | 工坊 | 研制、攻关、工匠、名匠、仿制、试制 |
| 军事 | 兵营、医馆、校场、城防工事 | 征兵、救治、修缮、操演、动员、守备 |
| 人才 | 招贤馆 | 探索未知、登用在野、劝说周边、安抚本城 |

府库全势力共用，城市独立持有粮食、预备兵和对应旬收入。默认保留500金军费，可在界面调整，自动事务不得动用；直接建设与征募属于玩家主动支出。首版不启用民心，也不保留民心产出倍率。产出使用太守政治倍率 `1 + 政治 / 500`，再叠加已有内政技能及有期限的治理效果。

本城每旬征募与整补共用 `2000 + 兵营等级 × 1000` 人额度。征募必须扣除真实预备兵、费用和粮食，直接补入已编制的具体部队；没有独立的已征待编库存。自动征兵开工预留人力，防止玩家直接整补重复使用；失败或取消释放预留并退还未使用的人头费用。城内士兵、伤兵从真实部队汇总，现役与伤兵合计受每将带兵上限约束。

技术按城市持有。研究达到100后仍需试制成功才能解锁；编制、改编、征募检查所在城市的技术。已有部队可以正常战斗、行军和恢复伤兵。舰船还检查本城水域条件。

友城驻守、没有行军命令、未交战且足额供粮的部队，每日恢复最多 `18 + 兵营等级 × 6 + 医馆等级 × 6` 名已有伤兵。主动救治只恢复真实存在且仍在本城的伤兵。城防工事提高耐久与开场护盾，校场提高开场战意；操演和守备取得有期限的一次加成，只在本城守城战锁定布阵时发给首发六队，接管、读档及后续援军不重复领取。

围城暂停本城内政进度及产出。负责人离开后保留工程已付进度，后继负责人无需重复付费。失守解除原委任、清理准备与建设。详细数值及首版边界见[内政实现与验证](内政实现与验证.md)。

## 存档与快照

战略存档包含 `campaign.version = 3` 和独立内政随机数状态，继续核验当前战斗规则和武将数据版本。旧战略存档提示重新开始，不做迁移；当前支持自动保存、读取与 JSON 导入导出。刷新后统一暂停。

每日快照记录可续战的完整动态状态。人物静态数据按每场战役去重，读取时完整重建。历史快照仅供查看阵位、兵力、战意、预备序列和战况记录；接管只能使用当前时间的权威状态。日内进度、是否已完成日首结算及随机数也进入存档，防止重复结算。

## 验证

`npm run test:strategy` 验证旬日换算、多战场同步、真实行军遭遇、援军到达、后台接管、日内与每日快照续战、内政、调任、编军、征募、粮道封锁、断粮和存档拒绝。

`npm run verify:strategy-ui` 使用 Playwright 完成真实页面操作，验证内政开工、委托、接管、刷新、跨旬返回、继续原战场、历史快照、手机布局及历史战役入口。可用 `PLAYWRIGHT_MODULE` 指向已安装的 Playwright 包。

完整单元测试使用 `npm test`，语法检查使用 `npm run check`。本次验收图片和结果位于 `outputs/strategic-ui/`。

`npm run verify:domestic-ui` 验证五方向委任、军费保留、旬末事件、改派、刷新读档和手机布局，结果位于 `outputs/domestic-ui/`。
