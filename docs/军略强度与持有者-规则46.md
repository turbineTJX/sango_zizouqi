# 军略强度与持有者

统一15种军略，资格以明确人物名单为准，取消统一智力门槛。通常1项，诸葛亮2项；资格、名单及冷却见[施放规则](军略资格与施放-规则51.md)。

护盾、无敌与魔免按统率70%＋智力30%；其余按统率30%＋智力70%。综合属性80为基准，系数 K＝2^((综合属性−80)÷20)，限制0.5～2.0。每提高10点主要效果约提高41%，20点约翻倍；时长与投入队数四舍五入取整。武力、政治和魅力不提高军略效果。正式参数在[属性表](../data/design/stratagem-attributes.mjs)，权重与主要缩放轴在[军略设计](../data/design/stratagems.mjs)。

同名军略取当前合资格来源较强者；施放后保存实际统智及效果，后续离场、更强军师加入、军纪改变或读档不改写原效果。时长与队数有取整，相近属性可能对应相同整数，不额外按人物ID伪造区别。详情、选择、范围预览与日志共用计算；完整逐人效果见[军略表](design-tables/军略一览表.md)。

双方与两模式共用真实部队、次数、伤兵和伤害规则。机制正确性与战役平衡分开验收，不能仅据机制测试宣称历史胜率或以弱胜强目标已经达标。
