# 军略强度与持有者

当前21种军略、91名持有者，通常1项，诸葛亮2项。资格、范围见[施放规则](军略资格与施放-规则51.md)，分配见[名单覆盖](军略池与任职-规则45.md)。

## 防御优先与冷却（2026-11-02，已接入）

基准护盾45%、救治上限40%，高于同系数雷火单次25%×最高浮动125%＝31.25%；坚定8回合、无敌6回合、范围魔免12回合，长于进攻眩晕4回合。比较同属性、相同单次目标与资源条件；八道雷火的重复命中、实际覆盖与本场伤兵量仍影响结果。这些是实现初值，机制通过不等于完整战役平衡通过。

可重复军略的独立冷却为20～56回合，仍须满蓄势且冷却结束；最强属性的持续时间短于冷却。奇阵、奇兵、重整和雷火每场一次，冷却分别96、96、112、128回合。旧规则存档拒绝读取，不在读档时改写效果。

整军肃阵向选区内所有合法友军发放坚定，包括尚无异常者；驱散全部战斗异常但保留缺粮，不缩短已有更长坚定。AI仍要求存在可驱散异常，自动落点覆盖至少一名异常友军后按有效目标数选择；玩家可提前施放。

## 属性折算

护盾、无敌与魔免按统率70%＋智力30%；其余按统率30%＋智力70%。综合属性80为基准，K＝2^((综合属性−80)÷20)，限定0.5～2.0。主要效果按K缩放，时长与投入队数四舍五入；武力、政治、魅力不提高效果。范围、冷却、限次及神速移动与攻速幅度不重复放大。

号令如山按受益者施放时军纪计算基准6＋⌊军纪÷25⌋、最多16回合，再乘施放者K。奇阵的单次异常仍持续3回合，概率仍按目标当前军纪。正式参数在 data/design/stratagems.mjs 与 stratagem-attributes.mjs。

## 组合军略的逐项时长

六项新军略全部持续时间（包含护盾、坚定及副作用）按同一施放者K快照计算：max(1，min(冷却−1，round(基准时间×K)))；护盾量也按K折算并遵守共同上限，其余幅度与20战意费用固定。原15项按各自既有缩放轴处理。玩法与固定名单见[军略组合与代价](军略组合与代价.md)。
