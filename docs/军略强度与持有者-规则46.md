# 军略强度与持有者（规则47修订）

设计依据是人物实际统军、谋划、组织与保障能力，用来决定效果类型和强度；名称仅负责清晰表达功能。个人勇武不等同于全军指挥能力。

## 属性计算

综合值按效果类型加权：攻防、机动等为统率70%＋智力30%；谋略压制为统率30%＋智力70%；鼓舞为统率70%＋智力30%；治疗为统率30%＋智力70%。

效果系数 = (综合值 / 80)²，限定0.35至1.30。百分比、治疗量、战意变化按系数折算；普通射程和移动力保持整数，改为缩放持续时间。持有者武力、政治、魅力均不参与普通军略倍率。战法适配不同类型武将；军略突出统帅和军师的作用，不按职业标签额外禁止施放。

同名军略由符合任职条件者中效果最强的一人提供，不叠加人数。施放时记录提供者、系数和持续时间，供结算、界面和确定性存读档共同使用。双方遵守相同规则。八阵困敌为持续区域机制：半径、寿命和状态时长固定取设计表，异常概率只取目标当前军纪，不按持有者属性缩放。魏武挥鞭按每支受益部队施放时当前军纪确定时长；兵贵神速的单队加速与时长固定取设计表，二者不套用普通军略倍率。

## 资格与显示

仅基础智力≥70者合资格，通常两项，仅诸葛亮三项，专属占总名额。军团长与军师统一遵守，低智者无保底军略。详见[军略资格](军略资格与施放-规则51.md)。

武将、军团和战斗详情显示实际持有者效果。基础倍率、持续时间与分配见[军略表](design-tables/军略一览表.md)，不以旧人物示例替代当前计算。

督军羁绊按实际在场等级合计1／2／3点，使指定普通军略的数值效果额外提高10%／20%／30%；不增强专属、火势、范围、时长、次数或冷却缩短。施放时记录增强快照，双方共用。具体效果范围见[羁绊规则](羁绊特性与成长-规则76.md)。
