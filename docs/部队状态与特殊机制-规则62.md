# 部队状态与特殊机制（规则62）

状态定义来自 `data/design/battle-statuses.mjs`，通过公共状态处理器生效，详情见[状态一览表](design-tables/战斗状态与效果一览表.md)。

## 状态归并

- 删除眩晕，原战法统一使用混乱：不能普攻、施放战法，随机合法移动，不产生ZOC。
- 震军不再作为复合状态，原对应效果使用缓攻；取消其附带的谋略威力削弱。
- 火攻与灼烧共用灼烧状态，最多三层，不因来自战法或军略而形成两套状态。
- 减疗并入疫伤：持续损兵并降低救治，不削弱护盾。原衰咒战法改为挫志，施加丧志，不再叠加三属性削弱。
- 原幻卫次数减伤改为实体疑兵目标；疑兵战法保留低于10%兵力时附加2回合避战，雾隐保留1回合避战，共用12回合保护间隔。疑兵本身不免伤、不赋予无敌。
- 失去拦截统一名为失阵。定身只限制移动；缴械只限制普攻；封技只限制主动战法。
- 坚定阻止新增混乱、定身、缴械、封技、嘲讽、失阵，不自动清除已有状态。受控保护继续使用共同处理器。

## 新的基础状态

| 状态 | 基础效果 |
| --- | --- |
| 丧志 | 每回合失去5战意，最低为零 |
| 抑气 | 攻击、受击获取战意减少30%，实际入账取整，不影响直接给予的战意 |
| 速攻／缓攻 | 普攻间隔缩短20%／延长25%，面板和实际行动共用属性结算，不改变战法冷却 |
| 远射／短射 | 远程普攻最大射程增加／减少1；同类增程取最高，不改变最小射程，不改变战法范围 |
| 洞察 | 识别2格内伏兵与疑兵，供己方共享；不直接解除伏兵的绕行能力 |
| 护卫 | 指定相邻友军分担25%直接伤害，不能递归分担；护卫者离开距离、退场或避战后不分担 |
| 连环 | 同组其他部队分摊合计20%传导伤害；衍生伤害不再触发护卫、连环或反击，不产战意 |

状态默认不叠加数值，同名重复施加保留较强效果；灼烧按明确三层规则，护盾保留独立来源和到期。参数由状态表提供。现有阵形类状态保留各自的组合效果；状态库定义不代表已分配，合法获取以固定战法与人物特性分配为准。

## 伏兵

当前共享羁绊不提供伏兵状态；伏兵、伏弩保留在战法效果库，但未进入当前固定兵种配置，不通过升级获得。

- 潜行最长12回合，敌军不能直接选中，暂时不产生ZOC；进入敌军ZOC时停止潜行，直接攻击拦截部队并显形，保留破隐混乱。移动途中在首次接触格停下，不穿越防线；攻击仍遵守冷却、缴械和最小射程，无法攻击时仅显形。
- 实体部队、不可通行地形、守城移动边界仍有效，不瞬移或额外行动。
- 双方用同一可达后排择敌逻辑；潜行中暂缓主动战法与支援绕行，优先弓弩、兵器后排，无可达后排则选择其他合法敌军。
- 首次普攻发动时显形，命中且目标存活则附加1回合混乱，无额外增伤；坚定可阻止混乱。
- 实际兵力受损，包括持续伤害，会提前破隐并失去首击混乱。护盾完全吸收的伤害不破隐。
- 洞察范围内可被选中，仍保留绕行；被识破时发动的普攻不附加混乱。
- 敌方伏兵不显示在战场位置和单位动画中，己方伏兵淡显；日志显示入场、显形原因和破隐一击。

## 疑兵

疑兵已作为弩兵固定谋略小战法接入；雾隐保留为未分配效果库。每队同时最多一个幻象，生成在邻近可通行空位，无空位则不能生成。

- 幻象初始耐久为本队本场初始兵力30%，承受200%伤害，持续6回合。
- 幻象没有攻击、战法、光环和ZOC，不占出阵名额，不阻挡移动，不计入胜负兵力。
- 正在攻击本体的敌军，在幻象满足射程和ZOC限制时转火；嘲讽仍优先。洞察识破后不再选中幻象。
- 范围攻击可以同时波及本体、幻象；本体不因此免疫持续伤害。
- 攻击幻象消耗正常攻击机会，但不获得战意、击破奖励、伤亡或功绩，也不靠幻象触发连携。
- 幻象状态保存耐久、位置、来源、到期步数，不伪造武将或增援。
- `prepareDecoy` 提供残血预置入口，一次非致命伤害后低于阈值才触发；致命伤害不回滚、不复活。该预置入口未分配给武将或军略；诸葛亮可按弩兵固定配置获得主动疑兵战法。

## 解除动作

| 动作 | 解除范围 |
| --- | --- |
| 镇静 | 混乱、嘲讽、丧志、抑气 |
| 整军 | 挫锐、定身、缴械、封技、失阵、迟滞、破甲、疲弱、缓攻、短射 |
| 救护 | 疫伤；救治依旧受实际伤兵预算限制 |
| 扑火 | 灼烧 |
| 破阵 | 状态表明确列出的护盾、护卫、坚定与阵形等增益 |

玩家界面不使用“净化”“驱散”。普通镇静、镇静全军及名将原镇静效果均使用相同解除范围；不会扑灭灼烧或解除封技。整军、救护、扑火、破阵分别调用独立处理器。军略AI仍按固定条件和固定优先序触发，镇静仅检查存在对应可解除状态。
