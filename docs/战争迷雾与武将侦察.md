# 战争迷雾与武将侦察

普通模式全国地形默认已探索。城名、山川、道路、港口、关卡和路口可见；开局势力归属是公开初始情报，驻军、资源和外地易主须有视野确认。无视野处覆盖灰雾，不设置未探索黑幕。

## 在城负责人和模拟斥候

在势力命令的“侦察”入口按顺序选择派出城市、本城合法武将、周边侦察终点；城市入口可预选当前城市，但仍须主动选择武将和终点。更换城市清空武将与终点，更换武将清空终点。未完成前一步时后续选择禁用，不自动选人。负责人必须实际在本城、未任职且没有其它工作、待执行命令或计划承诺。在城已编制部队的武将也能负责。负责人留在城内并计为工作状态，占用一个实际人员岗位；侦察期间不能同时委任、调任或出征。

周边终点包括路口、港口、关卡和相邻城市。地图节点按实际道路行程归入最近城市，本城及道路边界相邻城市的附近构成侦察范围；斥候不能穿过另一座城市继续前进，也不能沿连续水路或小路进入更远城市的周边。范围不依赖敌军、隐蔽军令或实时归属。终点列表、路线、派遣、AI和存档校验共用此规则。

独立模拟斥候按独立每日行程沿真实道路前往终点，目前每天105行程点，比原来的70提高50%；玩家与AI共用此速度，普通武将调任与运输按各自参数处理。地图上以“斥候”标记显示，不把武将头像或位置移到外地。抵达后持续驻察，沿路遇到的据点、军团立即保存报告并可查看详情，不设置情报获取等待时间，不编制实际军团，不产生额外军队或兵粮。速度参数位于 `data/design/movement-rules.mjs` 的 `scouting.speed`，点亮时限仍单独由智力决定。

停止侦察立即释放负责人，模拟斥候结束；已点亮的地图仍保留到各自期限。负责侦察属于实际任职，即使未编制部队也计入连续工作天数，不积累闲置惩罚；自动太守和内政委任避开正在侦察的负责人。围城暂停工作和斥候行动；负责人离岗或原城失守结束工作，负责人实际去向按共用人员规则处理。模拟斥候不参加军团战斗、不单独判定武将伤亡。

## 智力与点亮持续时间

随机时间指地图点亮视野的持续时间。斥候经过时立即获取情报，附近地图立即点亮；离开后按已抽取的期限保持视野，期限到达恢复灰雾。负责人智力越高，随机持续时间越长。实际当前位置提供视野；持续驻察每日更新经过区域的期限，同一天同一区域不重复抽取。重叠区域保留较晚到期时间。

正式参数在 `data/design/movement-rules.mjs` 的 `scouting`。上限为 `ceil(基础上限 + 智力 / 100 × 智力延长天数)`；下限为 `max(最低天数, 上限 − 随机跨度)`；在上下限间均匀随机取整数天。当前智力0为1–2天、智力100为4–6天。种子、观察日期、到期日期随存档保存，查询、查看详情和读档不会重新随机，也不会延长期限。

己方城市、实际军团持续提供各自视野。视野半径和未侦察军事估计位于同表 `vision`，双方共用。军事估计不改变实际兵员、资金、粮草或城防。

实际军团以当前大地图位置为中心持续提供视野，行军中使用道路上的实际进度，驻扎及交战时仍提供视野；军团解散或没有现役兵力后不再提供。半径为 `army + max(军团长智力, 军师智力) × armyIntellectPerPoint`，只读取本军团内实际任职人员，不叠加两人的智力，不计未任这两职的其他武将。当前基础半径20、每点智力增加0.12，智力0／50／100对应20／26／32地图坐标单位。更改任命后按当前任职重新计算；半径随已有任命、人员智力与军团位置确定，保存读取不重抽、不新增随机期限。

军团视野范围内接触的敌方据点和军团立即可见，并在范围内持续更新当前情报，无需另派侦察。敌军不会成为我方的额外视野来源。双方军团移动、离开范围或我方视野来源消失后，失去视野的敌军从当前地图和名册隐藏，据点及军团只保留最后所见的带日期情报；其它仍有效的城市或侦察视野照常生效。军团悬停、所选军团面板及详情／编组预览显示当前半径，主图与雷达共用实际范围；玩家和AI共用该计算与情报投影，独立战役不增加大地图视野机制。

## 情报边界

有效视野内的据点、军团显示当前情报；到期后敌军从主图、小地图和当前名册消失，城市保留最后观察的归属、设施、兵粮与日期。沿路报告保留当次观察日期，可在侦察工作中查看据点和军团报告。未侦察城市兵粮显示未确认。己方城池得失可直接获知。

地图、悬停、详情、天下情报、管理面板和战役列表共用只读情报投影，敌方后续路线、目的地和内部命令不公开。己方参与的战役保留完整记录；其他势力的战役只显示当前所见状态，不能回看侦察前的过程，也不能自动获取视野外最终战果。

电脑每天优先安排侦察，根据自己的当前或最后情报评估，每势力最多同时两项，并占用实际在城负责人。派出城至少留一名实际可办事人员，不把小势力仅有的人手全部用于侦察；不足时释放低优先级侦察。优先主攻目标，其次未知或已满3天的旧边境情报。已有任务取得目标情报至少2天且抵达终点后，可改派到优先级明显更高的未知或旧情报边境；主攻目标可在完成当前侦察后立即优先改派。保留有效驻察，不每日反复改令，不中途轮换尚未抵达的斥候，不重复目标。

负责人优先使用空闲人手；没有合资格空闲人手时，可通过共同解除委任入口释放尚未开始的可选事务。已开始的事务、农业和商业负责人、太守、外交、运输、等待军令及计划人员继续保留。进攻、救援、反攻及路线判断与玩家共用情报投影；有可行侦察时先了解未知或过旧的目标，再决定出兵，没有可用负责人时使用保守估计。所有资格、资金、兵源和真实遭遇照常校验。详细决策见[势力AI与跨旬作战计划](势力AI与跨旬作战计划.md)，回归运行 `npm run test:war-fog`。

## 存档与验证

当前战略存档保存负责人岗位、模拟斥候路线与进度、沿路报告、随机种子、点亮区域与到期日期；旧档不迁移，重新开局。独立战役保持既有规则。

`npm run test:war-fog` 检查依次选择、本城人员、周边范围、跨城路线拦截、留城工作、道路移动、即时据点与军团情报、智力随机视野时间、到期灰雾、释放岗位、只读浏览和确定性读档；另覆盖军团长／军师取最高智力、任命变化、行军实际位置、双方持续接触、出范围后的最后情报、军团解散及空编制、范围显示与确定性读档。`node scripts/verify-war-fog-ui.mjs` 检查主图、小地图、三步指派、选择重置、周边列表、负责人位置、视野时间提示、桌面和手机、保存读取及停止工作。

斥候到达道路终点时，视野代理先将已用行程换算为0至1的比例，再乘实际路长，保证保存进度不会因小数乘除误差越过终点；存档校验仍严格检查合法路段与实际进度。回归包括群雄集结的小数路长终点及确定性保存、续跑。自然行为验证运行 `npm run audit:war-fog`，按源码快照逐日记录各AI的侦察、生产入库与真实军团离城，详细口径见[势力AI与跨旬作战计划](势力AI与跨旬作战计划.md)。
