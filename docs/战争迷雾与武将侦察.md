# 战争迷雾与武将侦察

普通模式全国地形默认已探索。城名、山川、道路、港口、关卡和路口可见；开局势力归属是公开初始情报，驻军、资源和外地易主须有视野确认。无视野处覆盖灰雾，不设置未探索黑幕。

全国地图中，己方城镇所在区域及大城所辖府完整提供视野，相邻己方区域连接为一片。府按实际道路归属最近大城，小城按本城归属；敌方或中立区域不会因两侧城镇同属己方而被填亮。区域边界与地图共用公开地理，城镇易主后即时变化，不保存另一套领地；玩家与AI使用同一规则。城市近旁仍提供原有半径的视野，区域瞭望塔从实际位置向外警戒，军团与侦察也继续叠加。

未侦察城市只显示按公开位置与城镇大小绘制的朦胧外观和名称，城市下方不另标“未侦察”；灰雾表达当前没有视野。该外观不读取实际设施、损毁、施工和资源。有过观察的城市仍保留带日期的实际旧情报，失去视野后详细信息停留在最后观察时，不随隐藏状态更新。

## 区域瞭望塔

烽堠法沿用城市技术负责人的研究与建设流程，支付400金，正常工期10个工作日；开工时在本城区域或大城所辖府中随机确定陆地位置，避开城镇、河湖与海面。地图按保存位置显示工地，完工后显示实际瞭望塔，以塔为中心持续提供半径32的视野，不能把范围继续算在城中心。每城一座，连烽法在原址扩建并把半径提高到38；真实耐久归零停用，修缮和易主不重新选址。区域塔不带入城内战场。

己方塔和施工进展可见，敌方塔必须先进入视野，离开后仅保留第几天所见的外观与状态；隐藏升级、损坏或建造不会被直接读取。玩家与AI共用资格、费用、工期、随机选址和视野来源。内政结构27保存实际位置，第3版迷雾情报保存独立的塔观察记录，旧档重新开局。

## 在城负责人和模拟斥候

“侦察”按派出城市、执行人、终点、路线预览与调整的顺序操作。城市、执行人及终点均以可查找、排序的表格弹窗选择，也可在同页大地图选城市与终点；终点旁的“地图选点”可进入独立地图，点选合法节点后确认，取消保留原终点与路线，同一终点重选也保留中转点。人员表展示本城武将、智力、视野持续时间、所在、任职及事务；不可用者标明原因。从主界面“侦察”统一安排本势力任务，先选城市，不自动选人。更换城市清空执行人、终点与路线，更换执行人清空终点与路线。地图显示默认道路，拖动路线上的圆点到其它道路节点即可增改中转点，终点不变；派遣前只保留草稿，重置可恢复默认路线。行军和出征使用同样的选终点、拖动改线方式，不再逐点点击“继续选路”。负责人必须实际在本城；已有内政任职或事务的人也可选择，玩家下令时提示受影响的任职和事务，确认后立即解除可中止的内政、太守、原侦察或尚未开办的外交委任，执行新命令。取消提示或新令校验失败不会改变原工作。实际随军、外出和不可中止事务仍按原资格限制。在城已编制部队的武将也能负责。负责人留在城内并计为工作状态，占用一个实际人员岗位；侦察期间不能兼任其它工作；玩家改派出征时可经提示立即停止侦察。

周边终点包括路口、港口、关卡和相邻城市。地图节点按实际道路行程归入最近城市，本城及道路边界相邻城市的附近构成侦察范围；斥候不能穿过另一座城市继续前进，也不能沿连续水路或小路进入更远城市的周边。手动中转点也受同一范围、道路连通和不得重复经过节点的校验，派遣后保存实际道路序列，读档不改线。AI保持按合法最短道路安排侦察。范围不依赖敌军、隐蔽军令或实时归属。终点列表、路线、派遣、AI和存档校验共用此规则。

独立模拟斥候按独立每日行程沿真实道路前往终点，目前每天10行程点，约为统率80、士气80且无缺粮的常行枪兵军团（约1.45点／天）的6.9倍；这是本轮试玩初值，器械、骑兵及水路军团速度仍按各自规则计算。玩家与AI共用此速度，普通武将调任与运输按各自参数处理。地图上以“斥候”标记显示，不把武将头像或位置移到外地。沿路遇到的据点、军团立即保存报告并可查看详情；抵达后完成最后观察，斥候立即从地图与任务列表移除，负责人恢复在城待命，不设置情报获取等待时间，不编制实际军团，不产生额外军队或兵粮。速度参数位于 `data/design/movement-rules.mjs` 的 `scouting.speed`，点亮时限仍单独由智力决定。派遣先保存待出发命令并占用负责人；首次日结实际执行前不扫描周边、不建立临时视野、不发现贼寨，也不抽取视野期限，浏览、取消与读档均不会提前执行。实际执行中经过即观察，抵达即结束，不继续驻察或自动续期。

派遣预览、终点表、地图确认和常驻底部摘要显示预计用时与费用；当前费用为预计天数×10金，属于试玩初值。改线同步重算；确认时从派出城一次扣款，余额不足先拒绝，不解除原任职或事务。派遣前取消不付费，派出后停止不退已付费用；途中暂停、浏览、完成与读档都不追加费用。AI沿同一付费入口办理，并保留原城俸禄、运输与外交等必要预算。

停止侦察立即释放负责人，模拟斥候结束；已点亮的地图仍保留到各自期限。负责侦察属于实际任职，即使未编制部队也计入连续工作天数，不积累闲置惩罚；自动太守和内政委任避开正在侦察的负责人。围城暂停工作和斥候行动；负责人离岗或原城失守结束工作，负责人实际去向按共用人员规则处理。模拟斥候不参加军团战斗、不单独判定武将伤亡。

## 智力与点亮持续时间

随机时间指地图点亮视野的持续时间。斥候经过时立即获取情报，附近地图立即点亮；离开后按已抽取的期限保持视野，期限到达恢复灰雾。负责人智力越高，随机持续时间越长。在途当前位置提供视野，同一天同一区域不重复抽取；抵达后只保留已经建立的固定视野，不每日续期。重叠区域保留较晚到期时间。

世界按日结算，每战略回合推进十天，行程天数仍为真实天数。视野保留按回合尺度设置，避免刚侦察的区域在本次十天结算内就消失。正式参数在 `data/design/movement-rules.mjs` 的 `scouting`：最低30天、基础上限50天、智力延长50天、随机跨度20天；上限为 `ceil((基础上限 + 智力 / 100 × 智力延长天数) / 每回合天数) × 每回合天数`，下限为 `max(最低天数, 上限 − 随机跨度)`；在上下限间均匀随机取整数天。当前智力0为30–50天（3–5回合）、智力31为50–70天（5–7回合）、智力100为80–100天（8–10回合）。页面优先显示回合并附天数，预计到达按实际选定路线的道路代价之和除以每天10行程点、向上取整；每日剩余行程可结转到下一路段，预览与实际到达一致。种子、观察日期、到期日期随存档保存，查询、查看详情和读档不会重新随机，也不会延长期限。

己方城镇区域、城市近旁和实际军团持续提供各自视野。近旁视野半径和未侦察军事估计位于同表 `vision`，双方共用。军事估计不改变实际兵员、资金、粮草或城防。

实际军团以当前大地图位置为中心持续提供视野，行军中使用道路上的实际进度，驻扎及交战时仍提供视野；军团解散或没有现役兵力后不再提供。半径为 `army + max(军团长智力, 军师智力) × armyIntellectPerPoint`，只读取本军团内实际任职人员，不叠加两人的智力，不计未任这两职的其他武将。当前基础半径20、每点智力增加0.12，智力0／50／100对应20／26／32地图坐标单位。更改任命后按当前任职重新计算；半径随已有任命、人员智力与军团位置确定，保存读取不重抽、不新增随机期限。

军团视野范围内接触的敌方据点和军团立即可见，并在范围内持续更新当前情报，无需另派侦察。敌军不会成为我方的额外视野来源。双方军团移动、离开范围或我方视野来源消失后，失去视野的敌军从当前地图和名册隐藏，据点及军团只保留最后所见的带日期情报；其它仍有效的城市或侦察视野照常生效。军团悬停、所选军团面板及详情／编组预览显示当前半径，主图按实际范围显示视野；玩家和AI共用该计算与情报投影，独立战役不增加大地图视野机制。

## 情报边界

侦察沿途相当于在实际位置留下有期限的侦察守卫，覆盖区域在到期前持续提供实时视野；斥候离开或停止工作不清除已留下的守卫，也不把守卫坐标跟着斥候挪动。另一次真实侦察经过原地可续期，浏览和读档不会续期。任一有效守卫、军团或其它己方视野覆盖仍存在，就继续显示当前信息。

当前视野内的城内武将可查看五项能力、等级、功绩、适性、特性、羁绊、战法、军略和实际忠诚。它们只随当前视野实时显示，所有视野覆盖消失后立即从当前名册与详情隐藏，不加入人物侦察报告，不保留可供查看的旧人物详情。已有据点兵粮与设施报告仍按原规则保存。玩家与AI只使用各自视野；我方实际关押或押送的俘虏可实时查看详细资料，关押权不改变其原势力归属。

有效视野内的据点、军团显示当前情报；到期后敌军从主图和当前名册消失，城市保留最后观察的归属、设施、兵粮与日期。沿路报告保留当次观察日期，可在侦察工作中查看据点和军团报告。未侦察城市兵粮显示未确认。己方城池得失可直接获知。

地图、悬停、详情、天下情报、管理面板和战役列表共用只读情报投影，敌方后续路线、目的地和内部命令不公开。己方参与的战役保留完整记录；其他势力的战役只显示当前所见状态，不能回看侦察前的过程，也不能自动获取视野外最终战果。

AI每旬初按当前主攻、报告不确定性、道路与人手比较侦察价值，无固定30天刷新或两天驻察门槛。所有侦察抵达即结束并释放负责人，下一旬才可按实际需要探索未知目标；在途不轮换，保留必要内政人手。已有报告用于风险评估，只有未知且有可行斥候时先等实际观察；双方真实视野期限不变。

负责人优先使用空闲人手；没有合资格空闲人手时，可通过共同解除委任入口释放尚未开始的可选事务。已开始的事务、农业和商业负责人、太守、外交、运输、等待军令及计划人员继续保留。进攻、救援、反攻及路线判断与玩家共用情报投影；有可行侦察时先了解未知目标，再决定出兵，没有可用负责人时使用保守估计。所有资格、资金、兵源和真实遭遇照常校验。详细决策见[势力AI与跨旬作战计划](势力AI与跨旬作战计划.md)，回归运行 `npm run test:war-fog`。

## 存档与验证

大地图用骑马斥候模型显示独立斥候，标签列出所属军队与待出发、侦察中或暂停状态；实际移动时沿共同道路播放骑行，负责人仍在原城。点击或键盘打开该模型进入侦察任务。缩放与浏览不重播已经结束的移动；减少动态效果设置关闭骑行动画。

人才劝说与离间只使用当前可见邻城的人员；失去视野后，旧报告不能提供人物详情、忠诚或后续军令。双方预览使用当前可见的实际忠诚；忠诚不低于70时可离间，低于70后按既有意愿等条件劝说。离间由人才负责人自动选择，初始费用240金、当地办理10天、普通成果降低12点忠诚，实际效果按共用成败结算；原城同类事务结算后冷却30天。执行人须沿真实道路抵达，目标离开、改仕或失去资格不远程扣忠诚、不退已付费用。离间不直接招入，邀请的真实赴访和签约仍复核接受资格。回归为 `tests/talent-subversion.test.mjs` 与 `tests/talent-intelligence.test.mjs`。

侦察结构2保存负责人岗位、模拟斥候路线与进度、原预计天数与实际已付费用、沿路报告、随机种子、点亮区域与到期日期；旧档不迁移，重新开局。独立战役保持既有规则。

`npm run test:war-fog` 包含按实际路线展示用时与费用、原城一次扣费、余额不足与冲突确认取消无副作用、抵达移除并释放人员、当天真实工作计入就业、留存视野及旧报告等回归，并检查先选城市再选本城执行人、禁止跨城选人、周边范围、手动中转点、跨城路线拦截、留城工作、道路移动、即时据点与军团情报、智力随机视野时间、跨十天回合保留、到期灰雾、释放岗位、只读浏览和确定性读档；另覆盖军团长／军师取最高智力、任命变化、行军实际位置、双方持续接触、出范围后的最后情报、军团解散及空编制、范围显示与确定性读档。`node scripts/verify-war-fog-ui.mjs` 检查主图迷雾、城市与本城执行人及终点的选择顺序、换城和换人重置、周边列表、真实拖动、实际路线保存、负责人位置、回合时间提示、桌面和手机、保存读取及停止工作；`node scripts/verify-city-command-menu-ui.mjs` 检查城市委任六方向与主界面势力命令入口。`node scripts/verify-scouting-dispatch-ui.mjs` 用桌面及手机实际进行按钮验证费用、扣款、读档、抵达消失和余额不足；`npm run verify:war-fog-ui` 连续执行两项侦察界面检查。行军对应 `node scripts/verify-map-route-ui.mjs`。

斥候到达道路终点时，视野代理先将已用行程换算为0至1的比例，再乘实际路长，保证保存进度不会因小数乘除误差越过终点；存档校验仍严格检查合法路段与实际进度。回归包括群雄集结的小数路长终点及确定性保存、续跑。自然行为验证运行 `npm run audit:war-fog`，按源码快照逐日记录各AI的侦察、生产入库与真实军团离城，详细口径见[势力AI与跨旬作战计划](势力AI与跨旬作战计划.md)。

所有侦察均为一次性任务：抵达终点完成最后观察后立即移除斥候并释放在城负责人，已留下的限时视野与据点情报继续保留；已有报告不因年龄自动重派。
