# 人物性格、相性、义理与忠诚

日期：2026-09-19  
状态：人物机制设计草案。第4.3节的同城同方向多人委任、自动协作和协作关系成长已接入，当前数值见[内政协作实现与验证](内政协作实现与验证.md)；其余完整人物公式仍待实现。草案数值均为首轮调参建议。

## 1. 分工与现有基础

目标是让“派谁做什么、让谁与谁合作、由谁招揽谁”成为实际决策。

| 人物信息 | 回答的问题 | 主要作用 |
| --- | --- | --- |
| 统率、武力、智力、政治、魅力 | 能做好什么 | 沿用战斗面板、技能和内政行动的能力判定 |
| 性格 | 面对同一局面优先怎么做 | 战斗目标与走位取舍、委托军略、内政选事 |
| 相性 | 两个人是否容易合得来 | 内政协作机会、接洽难度、合作后的关系成长 |
| 当前关系 | 已经建立了多少信任 | 战法连携、内政协作机会、人才接洽效果 |
| 义理 | 对已有归属与承诺有多坚定 | 抵抗劝说与忠诚动摇 |
| 当前忠诚 | 现在有多愿意效力于本势力 | 是否有转投机会、安抚需求 |

现有代码核对：

- `officer-catalog.mjs` 已保存性格、义理、相性；性格与义理使用来源剧本覆盖后的资料。
- 性格编号：1胆小、2冷静、3刚胆、4莽撞；义理编号：1容易背叛、2无情义、3普通、4情理坚定、5不会背叛。
- 全库相性值范围为0～149。相性0是合法值；性格、义理0为未设置，不能统一按假值处理。
- `relationships.mjs` 已有关系值和关系变化接口；普通关系基准50，亲爱70，夫妻与义兄弟80，厌恶20。
- 符合条件的战法连携已经按关系值百分比判定；本文保留这一出口。
- `engine.mjs` 已有目标评分、寻路和玩家军令；`battle-ai.mjs` 已有自动军略评分。
- 内政首版已有持续委任、人才与忠诚，现已追加同方向多人委任与自动协作；范围见《内政实现与验证》和《内政协作实现与验证》。其余人物公式仍为待接入设计。

性格不额外乘攻击、防御或产出；相性不另加一份战斗连携概率，但与当前关系共同影响内政协作机会；义理不提高战法伤害或免除缺粮。人物技能仍负责专长和强度。

## 2. 性格如何影响战斗

### 2.1 四种取舍

| 性格 | 战场目标与移动倾向 | 优点 | 代价 |
| --- | --- | --- | --- |
| 胆小 | 优先有友军接应、接敌数量少的位置；兵力低时偏好已有合法安全位置；降低孤军追击倾向 | 保全部队，适合后排与持续支援 | 容易放过短暂的追击窗口 |
| 冷静 | 优先克制目标、有效射程和合适地形，偏好稳定收益 | 行动稳定、善用兵种条件 | 对有风险的抢攻与追击较保守 |
| 刚胆 | 优先正面接战和解围，在代价相近时接替受压友军 | 能维持接触、保护阵线 | 可能为支援友军承担更多战损 |
| 莽撞 | 优先接近可攻击目标、追击残兵，在合法路线中较少回避额外接敌 | 更快争取接战和歼敌机会 | 更容易暴露于多队夹击 |

这些倾向必须服从兵种职责：莽撞的弓兵仍争取射程位置，胆小的枪兵仍需要承担前排任务。不能让性格制造明显无效行为。

### 2.2 决策优先级与数值入口

决策顺序：

1. 处理撤退、强制状态、合法目标、地形、拦截和兵种限制。
2. 执行现有玩家军令与守城任务逻辑；性格不能削弱合围指令、解除守城区域限制或取消撤退。
3. 在可选目标和路径之间按战况评分。
4. 性格对合理候选增加有限偏好，同分按固定ID或坐标排序。

目标选择沿用现有“分数越低越优先”的方向。先运行未加入性格的基础评分，仅保留距基础最优不超过12分的候选，再加入下列修正；当前距离一格约值9分，这使个性通常只改变邻近机会的选择。

| 可见条件 | 胆小 | 冷静 | 刚胆 | 莽撞 |
| --- | ---: | ---: | ---: | ---: |
| 预计行动落点会额外接触至少一支敌军 | +8 | +4 | +2 | 0 |
| 可攻击敌军的剩余兵力不高于本场初始兵力35% | 0 | -2 | -2 | -7 |
| 目标正在威胁两格内兵力低于40%的友军 | 0 | -2 | -7 | 0 |
| 当前兵种克制目标 | 0 | -4 | 0 | 0 |
| 合法落点两格内没有其他在场友军 | +6 | +2 | +1 | 0 |

- 多项修正合计限制在-10～+10；所有比例使用明确的本场初始兵力口径。
- “预计落点”取当前可达路线实际能走到的位置，不允许穿过敌阵评估一个无法到达的位置。
- 支援判定只用当前已知位置和敌方有效攻击范围，不读取敌人未来随机结果。
- 合法路径长度相同或相差不超过一格时，使用相同风险与支援因素选路；不改变移动速度。
- 有合法攻击机会时不因胆小自动空过回合；没有安全位置时继续执行基础战斗逻辑。
- 既有追击、侧击若在进入评分前固定了唯一候选，需要先调整候选生成接口，避免性格评分实际上不起作用。
- 普攻邻接分摊规则保留；选择偏好不能把同时接敌的普攻重新变成只打一个目标。

### 2.3 委托作战的军略选择

主将性格只修正AI委托军略的偏好；军师仍按既有规则提供军略与能力。个人性格负责自己的部队，不把主将性格复制到全军。

可用且达到基础施放门槛的军略中，保留距基础最高分不超过15分的选项，再增加偏好：胆小对治疗、固守加6；冷静对当前有效的净化、压制加6；刚胆对整军、接应加6；莽撞对突击、火攻加6。只在技能确实有收益时生效，不为无伤兵的治疗加分。

玩家亲自施放的军略直接按现有规则执行。性格不引入拒令、不擅自撤出战场、不改写玩家三槽战法顺序；战意、冷却和施放条件保持现有规则。

## 3. 性格如何影响内政

### 3.1 先保证任务有效，再体现偏好

每旬选事按以下顺序执行：

1. 过滤方向不符、无法支付、缺少前置条件、对象失效和冷却中的动作。
2. 扣除已批准承诺支出，保护既有军费与供粮底线。预算限制对所有性格相同。
3. 处理紧急事项：有供粮缺口时优先保粮，临近攻城时优先有效守备，不能被性格加分挤走。
4. 将净收益、长期价值、工期、战略用途和风险折成0～100的基础分。
5. 保留距基础最高分不超过15分的候选，再施加性格修正，从最终价值接近的动作中按内政设计进行带权选择。

| 性格 | 动作评分修正 | 可观察结果 |
| --- | --- | --- |
| 胆小 | 常规低风险事务+8；抢修、加急、试制等高风险事务-8 | 愿意常规征兵、保粮、疗养；对高风险机会更谨慎 |
| 冷静 | 已有条件支持的长期建设、分段研究+8；缺乏铺垫的尝试-4 | 更常扩建市场、粮仓、工坊，累积后续能力 |
| 刚胆 | 符合实际战备需求的限时事务+8；其他事务不额外修正 | 更愿承担迫近的军事准备与有时间压力的任务 |
| 莽撞 | 合法且有实际时效收益的加急、试制、短期机会+8；非紧急长工期事务-4 | 更常抓商机、抢技术或加急征募，承担对应成本与风险 |

一个动作可有多个标签，但性格总修正限制在-10～+10。低风险、紧急、长期、高风险标签必须来自行动规则和当前世界状态。

### 3.2 在五个方向里的表现

| 委任方向 | 胆小倾向 | 冷静倾向 | 刚胆倾向 | 莽撞倾向 |
| --- | --- | --- | --- | --- |
| 商业 | 稳定税务与低风险经营 | 市场建设、有效合作 | 为明确的近期军费需求筹资 | 有净收益机会的限时集市 |
| 农业 | 保粮与稳定督耕 | 农田、粮仓、灌溉 | 对紧迫供军需求及时采购、调节 | 有时间价值的抢修或紧急筹粮 |
| 技术 | 已有基础、成功把握高的项目 | 分段研究与工坊建设 | 优先满足已确定的出征技术缺口 | 高风险但能提前解锁的试制 |
| 军事 | 常规征兵、精心疗养 | 兵营、医馆与持续整备 | 接敌前的守备、抢修、动员 | 有真实缺额与时限的加急征兵 |
| 人才 | 安抚、有把握的登用 | 探索线索、合理铺垫 | 及时争取能填补关键空缺的人才 | 接洽条件合法但较难的劝说 |

此表表示偏好，不能强行创造商机、灾害或人才。不同性格在只有一个合理动作时应做相同选择。

同一个执行人若执行相同动作，性格不直接改变成功率。风险和收益来自所选动作：常规征兵与加急征兵的费用、时间和结果分布不同。这样冷静不是所有事务永久加成，莽撞也不是所有事务永久减成。

## 4. 相性、当前关系与合作

### 4.1 相性距离

建议使用150点环形距离，与现有0～149的数据范围对应；这是本项目拟采用的算法，不宣称是来源游戏的原公式。

```text
d = min(abs(相性A - 相性B), 150 - abs(相性A - 相性B))
```

| 相性距离d | 显示 | 接洽修正C（百分点） | 有效共同经历后的关系增长 |
| --- | --- | ---: | ---: |
| 0～10 | 很合拍 | +8 | +3 |
| 11～25 | 合拍 | +4 | +2 |
| 26～45 | 一般 | 0 | +2 |
| 46～60 | 不太合拍 | -4 | +1 |
| 61～75 | 难合拍 | -8 | +1 |

例如5与145的距离是10。缺少相性时接洽修正为0，关系增长按中性值+2；相性0参与正常距离计算。

### 4.2 战斗：通过关系影响连携

保留当前公式：符合连携时序、目标等条件后，成功率等于当前关系值百分比。关系80时仍是80%，不再叠加相性+8个百分点。

相性通过有效共同经历影响后续关系：

- 首轮只接入共同参战获胜事件：双方真实参战且至少完成一次对敌有效攻击、战法或对真实伤兵的治疗；仅在预备队或空放增益不算。
- 每对武将每旬最多获得一次共同作战增长，按上表增加；事件ID去重。首轮不因普通败仗自动减关系。
- 没有前置和解事件时，当前“厌恶”关系不靠共同出战自动解除。相性接近也不覆盖夫妻、义兄弟、亲爱或厌恶等明确关系。
- 普通社交关系按现有规则最高增长至79；夫妻、义兄弟等特殊关系仍需明确事件产生。
- 当前关系成长不直接提高攻防、军略进度或城市固定产出；内政通过提高自动协作机会，改善实际行动成效。

战斗使用开战关系快照，关系成长只影响新开战役。战略模式可能同时存在多场战斗，因此实现时必须调整“活动战场关系始终等于全局关系”的校验假设，分别验证快照合法性；不能在一场战后将其他进行中战役的关系重写。

### 4.3 内政：同城同方向自动协作

确定规则：同属本方、实际位于同城、负责同一大方向的武将，就有机会自动协作提高效果。五个方向均适用，无需指定搭档或专门协作动作，不要求执行同一具体事务或针对同一对象。

每城同方向可委任多人，每人仍只有一项委任和一个具体行动。例如一人扩建市场、另一人举办集市，同属商业即可协作；征兵与救治同属军事，也可协作。

参与与频次的首轮建议：

- 每城每方向每旬最多判定一次。在首次出现可承接实际进度或结果的机会时，从合法的“主执行人—协助者”有序组合中均匀抽取一组，再进行协作概率判定，均使用内政随机流。
- 主执行人须有本次实际推进或结算的合法行动；协助者可执行本方向其他事务或待命。这属于事务中的轻量相互帮助，协助者原行动继续，不额外创建行动或重复收取整份行动费用。
- 离城、出征、改任其他方向或暂停执行者不参与，城市被围时不触发；全部待命时没有实际效果可承接，不抽取、不奖励。
- 判定失败也消耗本旬次数；增加人数、重新委任、调整顺序与读档不重抽。多人提供更多正常事务处理能力与搭配选择，协作额外收益不按全部两两组合无限叠加。

首轮概率建议（百分点）：

```text
P协作 = clamp(20 + 0.4 × (双方当前关系值 - 50) + 2 × C双方相性, 5, 65)
```

C使用第4.1节的相性修正。关系50、相性一般时为20%；关系70、很合拍时为44%。关系差或相性差仍有最低5%的机会，不是资格门槛。

增益幅度由协助者在该行动现有能力公式中的有效能力E决定。E限制在0～100，沿用动作对政治、魅力、智力或统率的权重，主执行人能力不再重复加入协作幅度：

```text
成果或进度增幅G = 10% + 15% × E / 100
成功把握增幅S = 3 + 5 × E / 100（百分点）
```

每个动作在目录中指定一种协作出口，不同时加速、增产和提高成功率：

| 动作类型 | 协作效果 | 边界 |
| --- | --- | --- |
| 建设、研究、修缮 | 施工一次额外完成`min(剩余工期,10天)×G`的工作量；研究或修缮的本次成果增加G | 不乘历史累计进度，不额外增加建筑等级 |
| 集市、督耕等产出事务 | 本次正向行动收益增加G | 不放大费用、不把亏损变收入，不永久提高建筑常规产出 |
| 征兵、救治 | 本次有效人数增加G | 受预留预备兵、批准钱粮、共享额度、部队缺额和真实伤兵限制；新增征兵仍消耗对应资源 |
| 守城操演、动员、守备 | 本次准备效果增加G | 保留原有总上限、期限与一次性消费规则 |
| 人才事务、试制、贸易及救灾 | 本次主要成功概率增加S | 只判定一次原动作，不复制人才、不额外恢复一次忠诚；当前接入沿用现有94%概率上限 |

成功率加成在原公式后计算，仍受原动作上限、资格与义理硬规则限制；原成功率为0时不靠协作恢复机会。多结果动作增加主要成功概率后，其余结果按剩余概率同比缩放，合计100%。人才公式中的关系与相性对应“执行人—目标”，协作对应“执行人—同方向同僚”，不重复计算同一组关系。

协作在实际应用本次进度或结果时判定并结算，不保存可携往他城的加成。跨旬行动只增强本旬选定的一次结算；整数数量四舍五入并按真实上限截断。实际增益为0时，不声称提高了效果，也不奖励关系成长。

有效协作后，双方按第4.1节增长关系。内政协作与共同作战共用每对每旬最多一次的正向合作成长额度；厌恶关系仍需和解事件，不靠偶发协作自动解除。保存城市、方向、旬、参与人、行动ID、判定结果、加成前后值与已结算标记。

### 4.4 人才接洽的关系作用

- 登用：考虑执行人与目标的当前关系、相性，以及目标与拟加入势力君主的相性。
- 劝说：考虑执行人与目标的接洽关系，以及目标与新旧君主的相性差异。
- 安抚：考虑执行人与目标的当前关系和相性。
- 同城同方向的人才负责人还可按第4.3节自动协作，但只帮助一个原行动与原目标，不额外进行一次人才加入判定。

## 5. 义理与忠诚

### 5.1 义理是稳定倾向，忠诚是当前状态

义理不等于勇敢。胆小而高义理的武将会重视保全部队，但不因此容易投敌；莽撞而高义理的武将可以敢打敢冲，同时坚定效力。

| 义理 | 外部劝说转投倍率q | 敌方劝说造成的忠诚动摇倍率 | 规则含义 |
| --- | ---: | ---: | --- |
| 1 容易背叛 | 1.50 | 1.50 | 忠诚低时较容易被争取 |
| 2 无情义 | 1.25 | 1.25 | 对现有归属约束较弱 |
| 3 普通 | 1.00 | 1.00 | 基准 |
| 4 情理坚定 | 0.50 | 0.50 | 难以通过劝说改变归属 |
| 5 不会背叛 | 0 | 0 | 现所属势力存在时，外部劝说不能使其转投或动摇忠诚 |

义理未设置时计算采用中性倍率1，资料仍显示未设置，不回写成“普通”。

“不会背叛”按当前名称兑现为硬规则，不能在概率下限中又恢复1%或5%的转投机会。原势力灭亡后成为在野，再走登用流程，不属于背叛。首版不设计主动叛乱、战中倒戈或俘虏招降。

### 5.2 忠诚的变化闭环

忠诚L范围0～100，绑定人物对当前势力的效力状态。开局按本项目剧本配置，不读取参考库的忠诚0或100作为当前状态；普通登用后的首轮建议值为70。

| 实际事件 | 忠诚变化建议 | 限制 |
| --- | ---: | --- |
| 安抚成功 | +6～+12 | 有费用、工期与执行人，按下式结算 |
| 真实参战获胜 | +2 | 每人每旬最多一次 |
| 真实参战战败 | -3 | 每人每旬最多一次；未参战预备队不受影响 |
| 本人所在部队当旬发生持续缺粮，缺粮程度达到至少1天 | -2 | 每人每旬最多一次，不按每步扣除 |
| 敌方劝说部分成功 | 基础-4，乘义理倍率后四舍五入 | 每人每旬最多一次；进入接洽冷却 |

首轮将每旬全部负向忠诚变化合计封顶为-6，正向变化不重置已使用的负向额度。义理5仍可能因战敗或缺粮降低忠诚，但外部劝说的两种结果都被硬规则排除。

不设置无事件的每旬忠诚衰减；撤换职位、正常调任与闲置首版不扣忠诚。低忠诚不降低攻击、产出、命令服从，也不每旬自动掷骰离开，其风险在有敌方真实接洽时兑现。

## 6. 人才事务的首轮公式

所有概率均使用百分点口径，最终再除以100供随机判定。它们是调参起点，必须与人才动作费用、工期一同验证。

共同定义：

```text
E = 0.7 × 执行人魅力 + 0.3 × 执行人政治
A = clamp(0.4 × (E - 70), -12, 12)
H = clamp(0.3 × (执行人与目标关系值 - 50), -15, 15)
C = 相性距离表中的接洽修正
B = 建筑、有效线索、接洽准备等明确条件的合计修正，上限+10
```

### 6.1 登用在野人才

```text
P登用 = clamp(45 + A + H + C执行人目标 + C目标新君主 + B, 5, 90)
```

先核验目标身份、发现状态、可接洽性、冷却和硬性拒绝条件，再进入概率公式；不允许把非法对象夹到5%。没有君主资料时对应相性项为0。执行人就是君主时，只计算一次相性C。

义理不对在野人才设置“难招募”通用惩罚，因为他此时没有需要背弃的现所属势力。

### 6.2 劝说其他势力人才

先排除君主、义理5、无合法接触条件和冷却中的人物。建议L≥80时不开放转投与动摇动作，等待真实事件形成接洽机会；玩家只看见“当前难以动摇”等情报，不泄露敌方隐藏忠诚数值。

```text
D = clamp(C目标新君主 - C目标旧君主, -10, 10)
P转投 = clamp((35 + A + H + C执行人目标 + D + B - 0.5 × L) × q, 0, 60)
```

执行人与拟加入势力君主是同一人时，去掉C执行人目标，避免与D中的新君主相性重复计分。义理5在计算前排除，不能走概率兜底。

一次完成只抽一个结果：先分配P转投，其次为部分成功概率`min(15, 100-P转投)`，其余为拒绝。部分成功按上一节扣忠诚；拒绝不额外扣忠诚。接洽完成后目标统一冷却两旬，不论哪个势力派谁接洽；本轮不再叠加另一套可无限累积的“劝说进度”。

接洽对象在执行过程中忠诚升至80或归属改变时，原转投机会失效，完成时必须重新校验。战中、不能安全交接的人物不能即时转投，按内政总设计延迟到合法交接点并重新核验。

示例：其他修正均为0、忠诚40时，普通义理的转投概率为15%，义理1为22.5%，义理4为7.5%，义理5不可劝说。忠诚降低只改变风险，不保证转投。

### 6.3 安抚本方人才

```text
P安抚 = clamp(65 + A + H + C执行人目标, 20, 95)
成功恢复量 = clamp(round(8 + (E - 70) / 10 + C执行人目标 / 4), 6, 12)
```

一次完成：P安抚对应正常成功，剩余概率一半小幅恢复+3、一半无效果；恢复不得超过100。忠诚满值不执行安抚。不以义理低为由让安抚天然失效，玩家仍能通过投入维护人才。

## 8. 界面反馈

人物页：展示“性格倾向”“义理含义”“当前忠诚”，相性保留数值并支持查看两人的合拍程度。当前未实现的效果不能提前显示成已生效。

编组页：显示两人的当前关系、条件满足后的连携概率与相性评价，不显示一个混合的“综合默契分”。城市内政页按方向显示多名负责人及各自事务，协作记录显示参与人和实际增益。

行动开始：展示执行人、预计时间、成本、成功把握和关键选择原因，如“选择常规征兵：偏好低风险，当前没有紧迫出征需求”。

战斗：只在实际选择发生变化时记录原因，如“追击残兵，预计接敌增加”；普通逐步评分不刷屏。不得为没有发生的救援、争执或拒令生成故事。

旬末：汇总人物关系和忠诚变化及真实原因。敌方只显示已掌握的情报和成功把握区间，隐藏字段不能从公式明细泄漏。

## 9. 实现顺序与验证

第一批：战斗目标与路径性格偏好、委托军略偏好、人物倾向说明。复用现有AI接口，不增加随机战斗决策。

第二批：在持续委任上接入同方向多人任职、人物性格评分与自动协作；在人才系统接入本文相性、义理、忠诚和接洽公式。

第三批：共同参战与内政协作的关系成长、共享成长额度、跨战役关系快照与界面报告。

建议集中增加人物规则模块，统一处理环形相性、义理倍率、内政性格标签和解释文本；不要把常数散落在UI和多个结算函数中。

验收重点：

- 相同人物能力、装备、兵力与种子，仅改变性格，在设计好的临界选择局面中出现预期差异；不存在合理替代选择时应保持相同行动。
- 四种性格都遵守玩家军令、兵种职责、守城范围、接敌拦截和三槽战法顺序。
- 胆小不会原地停摆，冷静不总是最优，刚胆不为了“救援”无效绕路，莽撞不越过预算和合法性限制。
- 相性149与0的距离为1；相性75与0距离75；缺失值与合法0分开处理。
- 关系80的合法连携概率保持80%，不因相性重复提高。
- 同城同方向执行不同动作也可协作；同城不同方向、同方向不同城市不触发。待命同僚可以帮助执行者，全部待命不能空发奖励。
- 关系差或相性差的组合仍有协作机会；增加人数不扩大每城每方向每旬的判定次数，也不绕过建设、研究、预算及目标占用。
- 协作只改善指定的一项进度、数量或成功率；没有实际增益不刷关系，作战与协作共用每对每旬成长额度。
- 当前义理5、势力君主、在野人物、效力人物走各自正确的资格规则。
- 转投只移动人物归属，原兵力与城池按已有军事交接规则保留，不复制或删除。
- 预备队挂机、同一事件重复结算、反复开面板与读档不会刷关系、忠诚或结果。
- 同期多战役分别保留开战快照，关系成长只进入新战役；战斗与内政随机流独立保存。
- 接洽费用、冷却、同旬扣忠诚上限和完成时再校验对双方势力一致。
- 使用同种子成对样本观察战损、接敌时间、选事频率、长期净收益和人才流动，不先假定任一性格必须有固定胜率优势。
