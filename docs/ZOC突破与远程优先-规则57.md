# ZOC 突破与远程优先（规则57）

- 疾驰战法：保留减伤与接敌加速，增加自身无视 ZOC 4 日。沿用穿阵状态与共用寻路；不能穿过占位部队、城门或不可通行地形，效果到期恢复正常拦截。
- 疾驰羁绊（当前规则101）：首次可行动前及每12回合冷却结束后短暂突进。2／6／12点分别加速30%／40%／50%、持续4／5／6回合，无视ZOC；普攻追击优先实际可达的后排，进攻战法在自身合法范围内优先后排，嘲讽与有效集火优先。封闭占位或不可通行地形仍阻挡，不可达则攻击合法目标；定身仍禁止移动。窗口结束、失去资格或不能行动时恢复正常拦截，冷却与窗口继续计时。友军支援沿用原规则，邻接普攻仍共用一次伤害预算。
- 挫锐：优先选择射程内仍能拦截且无坚定保护的敌军，保留降战意与疲弱，增加失去拦截 4 日。目标仍可移动、普攻与施法；坚定阻止施加失去拦截，净化可以解除。其它敌军的重叠 ZOC 继续生效。
- 普通攻击：双方共用规则，在合法目标池和当前实际射程（含最小射程）内优先弓兵、弩兵、攻城器械；有实际作用的箭塔、军乐台和救护营按当前威胁与路线参与同层比较，见[战场建筑选敌](内政战场建筑.md)。嘲讽与有效焦点状态优先；未获得穿阵、疾驰突进等无视ZOC效果的近战仍受前排拦截。普通远程偏好不会因范围外后排放弃范围内的可攻击目标；疾驰突进窗口可优先合法接近后排。民用设施不产生拦截，不因贴身便阻止部队接敌。
- 战法继续使用各自的作用目标和已学顺序；冲阵沿用优先可达后排规则，不改变伤害倍率或兵种属性。
- 战法仍按当前固定配置、战意、冷却与次数施放。状态保存、读取与续战沿用当前版本；非当前版本存档提示重新开始。
