# ZOC 突破与远程优先（规则57）

- 奔袭战法：3格内有合法可见敌军时启动减伤与接敌加速，穿阵4回合可无视普通ZOC；枪兵及升级枪兵对骑兵的强拦截仍生效。疾行增加0.25格／回合，各项修正后最多1格／回合。不能穿过占位部队、城门或不可通行地形。
- 疾驰羁绊：可行动且3格内有合法可见敌军时短暂突进，之后仍遵守12回合冷却。2／6／12点分别加速30%／40%／50%、持续4／5／6回合，无视普通ZOC，枪对骑强拦截仍生效；普攻追击优先实际可达后排，进攻战法在自身合法范围内优先后排，嘲讽与有效集火优先。实体占位和地形仍阻挡，定身仍禁止移动，窗口及冷却不因暂停或换阵重置。
- 挫锐：优先选择射程内仍能拦截且无坚定保护的敌军，保留降战意与疲弱，增加失去拦截 4 日。目标仍可移动、普攻与施法；坚定阻止施加失去拦截，净化可以解除。其它敌军的重叠 ZOC 继续生效。
- 普通攻击：双方共同使用近敌接战与合法目标持续，不再对所有部队统一设置后排硬优先。专门突破能力与侧翼骑兵保留合法绕击倾向；普通远程有目标可打时持续输出。有实际作用的建筑继续按威胁与路线参与比较，民用设施不产生拦截。完整目标顺序、留守与后排跟进见[布阵与自动战斗](布阵与自动战斗重设计.md)。
- 战法继续使用各自的作用目标和固定顺序；冲阵、八百破阵和艨冲按实际移速逐格沿锁定路线推进，受控可中断，支付及伤害仅结算一次，不追加逐格伤害。
- 战法仍按当前固定配置、战意、冷却与次数施放。状态保存、读取与续战沿用当前版本；非当前版本存档提示重新开始。
