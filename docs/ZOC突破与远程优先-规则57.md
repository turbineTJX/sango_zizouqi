# ZOC 突破与远程优先（规则57）

- 疾驰：保留减伤与接敌加速，增加自身无视 ZOC 4 日。沿用穿阵状态与共用寻路；不能穿过占位部队、城门或不可通行地形，效果到期恢复正常拦截。
- 挫锐：优先选择射程内仍能拦截且无坚定保护的敌军，保留降战意与疲弱，增加失去拦截 4 日。目标仍可移动、普攻与施法；坚定阻止施加失去拦截，净化可以解除。其它敌军的重叠 ZOC 继续生效。
- 普通攻击：双方共用规则，在合法目标池和当前实际射程（含最小射程）内优先弓兵、弩兵、攻城器械。嘲讽与有效集火指令优先；未获得穿阵的近战仍受前排拦截。范围外远程不会挤掉范围内的可攻击目标。
- 战法继续使用各自的作用目标和已学顺序；冲阵沿用优先可达后排规则，不改变伤害倍率或兵种属性。
- 战法仍按当前固定配置、战意、冷却与次数施放。状态保存、读取与续战沿用当前版本；非当前版本存档提示重新开始。
