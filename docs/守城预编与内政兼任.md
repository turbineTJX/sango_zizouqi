# 守城预编与内政兼任

城内部队是提前准备的守城编制。是否已有部队，与是否可以管理内政无关；太守、负责人都能编制部队，驻城部队的武将也能正常任职。

## 行为

- 编制、征募、拆分、合并城内部队，保留太守和内政负责人身份；费用、进度与人才任职天数继续使用同一名武将的数据。
- 无兵员的预编部队也可从事内政，不因暂未征兵而被判为无职闲置。
- 离城行军涉及未完成内政时，先选择立即出发或等待当前事务结束。实际执行行军令时，结束该军团武将在原城的内政与太守委任；等待期间保留岗位和守城资格，留守人员不受影响。单纯拆分待用部队不算出征。
- 已编制且有兵力的驻城武将沿用真实守城战流程参战；守城开始时中断参战武将的当前事务并取消相关等待军令，保留任职。非参战人员的事务按围城规则暂停。守住后继续任职，工程按既有规则保留进度，失城或离岗则终止。
- 编制中的武将不再因“已编入军团”被排除在内政或太守选择之外。重复编制仍禁止；已编部队的异地调动使用军团行军，未编部队武将继续使用原来的调任流程。
- 太守收益、折扣和治政经验直接读写所属部队的武将实例；不会往待命列表复制同一个人。当前结构的自动保存、导入导出和确定性续战继续有效，无迁移分支。
- AI在城编制和人才负责人选用遵循同一资格规则；出征也按同一在城资格清理委任。
