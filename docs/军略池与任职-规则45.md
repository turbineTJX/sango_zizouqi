# 军略池与任职

资格以[规则51](军略资格与施放-规则51.md)为准：仅基础智力≥70者拥有军略，通常两项，仅诸葛亮三项。军团长和军师遵守同一门槛，副将不提供军略；零兵随军人员不提供军略。

普通与专属分池，专属占总名额；同名军略合并，取合资格来源的较强效果，不按人数叠加。分配按身份固定，升级、换兵种、任免和读档不重抽。

名称、实际效果和持有者只维护于[军略一览表](design-tables/军略一览表.md)和[能力分配表](design-tables/能力分配一览表.md)，不在本文重复旧名单和旧倍率。

设计以人物统军、谋划和保障事迹决定效果与强度，明确区分史实和演义；名称表达功能，不把典故直接当作机制。强度见[统智缩放](军略强度与持有者-规则46.md)，施放见[固定条件AI](军略AI固定条件触发.md)。
