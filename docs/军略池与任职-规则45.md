# 军略名单与任职

当前统一21种军略，91名持有者通常各1项，诸葛亮2项，共92项固定分配。取消基础／专属分池与统一智力门槛；按统军、谋划、军队组织或宗教领袖表现逐人分配。升级、换兵种、转投和读档不重抽。张飞、甘宁、王平当前仍未分配。

军团长与军师提供本人军略，部队须存活、实际抵达、在场或后备且未撤离。同名取较强来源，不叠加人数。覆盖统计只计本势力实际在职人物，不把在野、未登场、已去世或别势力人物算入开局。

## 名称与覆盖（2026-11-02，已接入）

名称、效果和人物相互对应，多人共用采用通用统军、谋划名称。整军肃阵、抚军安众、临敌不乱、众志成城、攻心乱敌、奇兵突入、奇阵困敌与断援阻敌已接入。李儒改持火烧连营，取演义焚都谋议的火攻意象；天雷地火仅张角持有。军略仍为玩法抽象，不声称人物有超自然能力。

尽量让中等势力有1～2名持有者、小势力有0～1名，不给大势力设两名上限。规模按实际领地、人才与军力逐项审查，不仅按城数划档。个人固定分配不随势力变化重抽；历史剧本不改年代、人事或在野身份凑覆盖。雍闿等缺少合适参谋的小势力保留零持有者；覆盖目标不是两人上限。本轮补齐马腾、刘焉／刘璋、袁术、公孙瓒、毌丘俭、韩遂等缺口。
