# 军略名单与任职

当前统一15种军略，取消基础／专属分池与统一智力门槛。资格完全以明确人物名单为准，49名持有者通常各1项，诸葛亮2项。限定有统军、谋划或宗教领袖表现者；张飞、甘宁、王平不分配。孙策、陆逊、吕蒙、钟会保留统帅价值，补入蒯良、蒯越、许攸、逢纪、张昭、张纮等谋士与组织者，宗教势力张角、张宝、张梁、张鲁和阎圃也有可用军略。

分配先考虑人物资格，再分散能力类型；同势力核心优先分工。荀彧负责救治，司马懿负责范围魔免，荀攸负责战法整备，郭嘉负责额外后备。不同势力保留特色，不要求全部获得同一套能力。个人军略随本人保持，转投不重抽；历史剧本沿用真实开局年代和人员，不能提前加入未来人物。
