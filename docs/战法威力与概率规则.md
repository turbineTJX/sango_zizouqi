# 战法威力与概率规则（当前规则 64）

本表由 `node scripts/tactic-power-doc.mjs` 从运行数据生成，覆盖全部基础与专属战法。施法时读取部队当前对应的武技威力、谋略威力或营务威力，包含现役兵力及状态修正。

## 威力成长

- 武技战法使用武技威力，谋略战法使用谋略威力；伤害继续分别由防御、军纪抵御。
- 增效系数 S = clamp(0.6 + 威力 / 700, 0.7, 1.6)。威力 280 对应基础效果；70 对应 0.7 倍，560 对应 1.4 倍。
- 固定治疗、护盾、战意增减、冷却缩减及状态幅度乘 S。原公式已经含威力的治疗、护盾、灼烧、疫伤等不再重复乘 S。治疗仍受真实伤兵预算限制，护盾仍受容量限制。
- 混乱、封技、挑衅、坚定、疾行、反击、奇门、追击和限时谋攻／燃击的基础时长乘 S 后取整，至少一步。谋略控制再受军纪缩短。
- 次数型强化普攻固定 3 次，不乘 S；削弱幅度按装填时威力记录，普攻基数与火矢每次新灼烧按命中时威力计算。装填与附着命中不触发连携，按普攻结算一次战意。
- 持续状态在施放时记录强度，施法者之后受伤不会追溯改变已经施加的状态；续叠灼烧按现有较强快照规则处理。
- 射程、目标数量、位移格数、层数上限、净化是否解除负面、自损和自身破防代价固定；净化战法通过附带治疗、护盾或坚定时长关联威力。

## 成功率与暴击

- 混乱、封技、挑衅、诱敌位移及援护击退逐目标判定。概率 = clamp(0.65 + (威力 − 抗性) / 1000, 0.25, 0.95)。武技使用目标防御作为抗性，谋略使用目标军纪。
- 例如威力 280、抗性 100 时，成功率为 83%；威力 80 时为 63%。坚定阻止新增混乱、定身、缴械、封技、嘲讽、失阵。AI 仍优先寻找合法、有价值的目标。
- 判定失败仍算一次施法并进入独立冷却，战意按该战法 intentCost 结算。混合战法的伤害和其他效果单独结算；纯控制失败不建立连携。
- 下表标注可暴击的直接攻击，暴击率 = min(0.05 + 威力 / 2000, 0.30)，暴击伤害 ×1.5。威力 280 时为 19%，威力 500 时达到 30%。
- 同次多段攻击对同一目标共用一次暴击判定，不同目标分别判定。持续伤害、反击、治疗与护盾不暴击。
- 使用战斗原有种子随机数，当前版本存档读取后继续得到相同判定；旧规则存档提示重新开始。
