# 府区域与都市圈连接

全国地图含76座城市、24处府、12处关卡、41处港口及3条横向小路，共223条实际路段；全国剧本共用。府采用有地名、有范围的城外地区设计，都市与周边府共同形成都市圈。[三国志14官方说明](https://www.gamecity.com.tw/manual/sangokushi14/wpk/sc/3100.html)作为区域组织参考；本项目当前只接入地区、道路与圈内建设，不引入独立府占领、委任或资源账本。

## 府、都市与连接

- 现有府使用巨鹿、曲梁、尉氏、临颍、鄢陵等具名地区。主城及府各有固定范围，都市圈轮廓由成员地域共同构成；范围是地图适配，通行仍依真实道路连接，不声称复刻原作地块或历史GIS边界。
- 许昌都市圈包含主城及鄢陵、尉氏、临颍。许昌经鄢陵通向谯，鄢陵向北接尉氏，可在城外转向；临颍南路经过许昌，不再保留完整的三角绕城网络。鄢陵名称参考[复旦历史地名资料](https://tgaz.fudan.edu.cn/tgaz/placename/hvd_44354)，位置与行程为游戏适配。
- 府可作为逐点选路的终点，军团抵达后实际驻守。府间连接允许绕过城市，为绕后和截断粮道提供空间。府不创建城内部队、城门或城市胜利资格。
- 府、小城、关卡、港口按道路行程距离归入最近大城，等距按城市ID固定排序；既有小城保留独立人员、资源和内政。范围、都市圈成员、选路与建设使用同一组真实地点。

## 历史通道与道路取舍

当前采用主干优先的疏路网：24处具名府、223条实际路段，横向小路从原15条缩减为3条（巨鹿—曲梁、尉氏—鄢陵、博望—棘阳）。城外道路有交点就汇入具名府；不在交点处按方位编造地名，也不让未设府的两条路在画面上相交却无法转向。过密斜线通过改接或撤去处理，全部城市、港口、关隘和府保持连通。

## 村落与显示密度

府在固定地点绘制民居、院落、田畦和巷道，远近共用同一布局；民居不冒充可产出资源的设施。全国视角优先主城，府不常驻旗形图标。放大后按屏幕空间逐步显示村落，不限定某个最低层级；名称按当前屏幕面积和相邻文字间距独立收起，选中及悬停时可查看地名。府的已建建筑与工地仍按真实地点、等级、进度和耐久显示。桌面与手机横屏验收：`node scripts/verify-prefecture-villages-ui.mjs`；路口几何与存读档回归：`node --test tests/prefecture-villages.test.mjs`。

## 主城与府内建设

大城负责人使用共同选址流程，可在主城或圈内府建设；城墙留在主城。费用、人员、设施总等级和成果由建设城市记录，每次扩建保存实际地点。府内经济设施每类最多2级，其他设施按既有类别上限、最多3级；仍受都市圈单类总等级12及同址设施共用限额约束。选址权重见`data/design/metropolitan-areas.mjs`，地点等级限制见`data/design/economy-rules.mjs`。

平时大地图在实际府内持续显示已建建筑和施工工地，可直接点击设施查看真实耐久及办理人员；放大府增加细节，默认都市圈层不会隐藏实体或用一个主城模型代替所有建筑；没有建设的府不绘制已建城墙或虚构设施。敌军封路、驻守或当地交战时暂停施工及当地设施生产贡献；恢复后原址接续，不重新收费。建成后不移动回主城，设施成果不重复结算。存档保存建设地点、进度和耐久，读档按原状态重建。

## 山脊、河岸与港口

全国水路只连接两个港口；军团从陆路进入出发港，再经水路到靠岸港，最后沿同岸道路前往城市或府。途中改令不产生河中登陆点，船只也不能打开被关闭的山路。金城／金城东港、淮水／淮南港和江州／南津港是三对新增渡口；位置为地理游戏适配，不声称历史GIS精度。相邻城市的基础船只资格覆盖其实际港口接路，编制仍扣真实费用。

路段上相遇按实际道路地形选战场：港口间水路为河战，港口接岸陆路为陆战，真实山道为高地战；南中和巴蜀陆路保留林地场景。到达节点才按港口水陆战场或关卡高地战场处理。携船、附近河流或一端为港口均不能将陆路遭遇变为河战。保存实际地形与 mapId，反向、双方及读档一致；机制回归包含 tests/road-encounter-terrain.test.mjs 的真实对向行军接敌和确定性续战。

虎牢、潼关、函谷、武关、壶关、雁门、军都及蜀道关卡控制对应主通道；汉中入蜀改为阳平—葭萌—剑阁—梓潼。关闭长安—汉中、梓潼—江州、武陵—永安、武陵—涪陵等穿山近路，并删除黄河、长江、淮河及汉水两岸的城际直连。府的剧、夏丘、三水随合法同岸道路重接，东光及岸边港口按对应河岸校定，横向小路不跨河。

12处关卡及7组渡河／峡江通道逐项核对：封锁后替代路径至少两倍道路行动代价或不可达；这不是行军天数倍率，水路仍按真实船速计算。检查同时确认全部153处地点连通、陆路及港口接路不穿过四条主河道。运行 `npm run test:geographic-roads`、`npm run audit:geographic-roads`、`npm run verify:geographic-roads`；自然全AI剧本另行报告。

## 行军、驻守与粮道

府单独保存在道路节点列表，不加入经济城市列表。军团、运输队、侦察和补给共用实际路网：府驻军可拦截敌军、运输队及粮道；运输队遇敌沿用损失规则，军团触发真实野战。府内已建设施按原址载入战斗，战后回写耐久。补给允许寻找其他可通道路，封锁一府不等于封锁整圈。

每处府保留实际道路接路。只在已登记的具名府交汇和转向，不按城市加方位编造府名；没有府承接的交叉接路按正式关闭清单撤去，保留全部地点连通及关隘、渡河通道。横向小路必须提供避开对应城市的实际路线。城市级AI邻接折叠官道上的府，真实执行和预览展开完整路线；双方使用相同规则和自动建设资格。选路、停驻及核阅只显示地名，不在府标记上叠加用途说明。[逐点选路](大地图逐点选路-规则63.md)沿用先拟定、再核阅下令的流程。

## 全国地形表现

全国图以用户提供的古地图为城市名单、分布及地形参考，原图尺寸 1378 × 1477，使用等比缩放及水平居中投影至 1024 × 1024。海岸、山脉及主要水系重新绘制，76 座城市、12 处关卡、41 处港口和 24 处府共用投影。参考像素点位于 `data/design/ancient-atlas.mjs`，增补城池、旧名对应、剧本归属及连接位于 `data/design/atlas-cities.mjs`；`scripts/reconstruct-ancient-atlas.mjs` 将其同步到城市、路口、道路及行程长度设计表，来源地图导入脚本也调用同一布局生成器。重建可重复执行，不重复增加城池或道路。原图印制的时代标题、边界和红白标记不进入游戏归属。

地形定义位于 `national-geography.mjs`，绘制层位于 `ancient-atlas-terrain.mjs`。主图和开局势力选择图共用海岸及黄河、长江、淮河、汉水、渭水、湘水、赣水、岷江、嘉陵江、辽水、汾水；同时表现洞庭湖、鄱阳湖、太湖和具名连续山脉。河道和湖面从势力覆盖层中扣除，水系名称显示在道路层上方。四季外观共用同一地理，地形、城市建筑和资源显示保持分层。

区域路网随增补城市扩展为 223 条路段，北方加入军都、雁门关及井陉小城的实际通道；关卡仍是无资源的道路节点。保留同岸道路，删除直接跨河、穿山或架空关隘的近路；绕行与渡河段按实际通道校定独立设计长度；基础道路长度维护于 `data/design/road-distances.mjs`，具名府的接路分段维护于 `data/design/road-crossings.mjs`，无府位置撤去的接路维护于 `data/design/road-link-policy.mjs`，本轮历史主干、府方位与重新接路维护于 `data/design/historical-road-plan.mjs`，分段按原路长度分配，同一对地点的合流道路仅保留代价较低的一条，行军、补给、人才移动、预览和 AI 共用该表。地图、开局界面及胜利条件采用实际城市数量，不固定为旧城市数。山脊禁行与港口渡河直接落实到路网；陆路及港口接岸不得穿过黄河、长江、淮河与汉水主河道。路网校验拒绝旧地图存档并提示重新开始，不迁移旧数据。

## 城池规模与图例

用户确认方框是大城、圆圈是小城、菱形是关卡。现有 42 座大城、34 座小城，均保留独立经济、内政与统一资格；规模用于城市模型、标记、查找和情报显示，未增加规模资源倍率。城镇保留古地图中心位置，模型按地图尺度缩小，并根据相邻城市间距固定限制占地，留出城外郊野和道路；近景与远景建筑位置及占地一致，城内镜头进一步放大以便查看。大城采用较大城镇模型和方框，小城采用较小模型和圆圈；主图与势力选择图共用规模。井陉在原图中是圆圈，作为小城，不再列为关卡。原有城池中没有高亮标记的条目按小城适配，不声称原图中存在对应圆圈。

## 城池名单与古名称

新增 34 座真实城市，包括河西的敦煌、张掖、西平、金城、陇西，北方的成乐、平城、中山、平阳、肥如、平郭，徐淮的彭城、谯、钟离、合肥、广陵、京口，以及涪陵、武昌、豫章、寻阳、巴陵、临川、侯官、番禺、龙编等。每城拥有独立资源、设施、人员和内政；可以调任武将、占领、编制与补兵，并计入统一条件。开局人员使用已有真实名册，新增城市缺少人员时保持空缺；空城占领沿用无守军即占领的共用规则，不虚构守军或随机补造武将。

用户最终选择同城沿用三国古名：图中建康使用建业，寿阳使用寿春，南阳使用宛；同城不增加第二个城市。建业／建康参考[南京地方沿革](https://www.xwzf.gov.cn/zjxw/xwgk/lsyg/)，寿春／寿阳参考[寿县地名沿革](https://www.shouxian.gov.cn/ztbd/ztzl/cctwsx/fyfc/8112346.html)，侯官参考[福州建制沿革](https://www.fzja.gov.cn/xjwz/qzfc/jagk/jzyg/202107/t20210706_4134658.htm)。

广固、和龙属于晚期城名，采用临淄、柳城作为三国区域旧治的游戏适配，位置近似；这两项是区域替换，不作为同城改名或精确历史地理结论。广固与临淄的迁治参考[青州地方志](https://shandong-chorography.org/database/c7/section/9/article/12/)，柳城区域沿革参考[朝阳县介绍](https://www.cyx.gov.cn/cyxzf/mlcyx/index.html)。
