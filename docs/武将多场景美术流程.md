# 武将多场景美术流程

当前采用“一套固定人设、三张动作母图、按界面裁剪和共享背景组合”。十一种界面用途由同一组人物图服务，生产队列只包含三张母图。按当前832人名册计算共2496个母图目标；实际完成、复用与剩余数量以 `npm run art:batch -- status` 为准，不能把多个裁剪视图算成多张原画。

## 人物与原头像

先按稳定ID读取名册身份和传记，在 `art-direction.json` 的 `profiles[id].role` 记录主类型、次类型、依据与仪态。武勇将领、战场统帅、谋士军师、文臣学士、君主领袖和特殊职能按实际身份区分，不从兵种、能力排名、性别或阵营推断。未分类任务标为 `blocked-role`。

使用 `node scripts/officer-art-face-references.mjs --officers <人物ID>` 解析该人物准确对应的本地《三国志11》原头像，先目视提取脸型、眉眼、眼距、鼻形、颧骨、下颌和胡须。原头像用于脸部辨识，既有已审阅项目身份图可作为服饰与画风的辅助参考；不得借用另一人物的脸。缺失参考时单独设计并检查差异，不能只换帽子或衣色区分人物。

新站立母图审阅接入后，办事、指挥任务直接引用该站立母图的路径和实际SHA。人设身份哈希与动作母图参考哈希分别记录：改脸影响所有依赖素材，更换站立母图使引用旧母图的动作候选失效。来源路径、哈希和实际提示词必须真实保存。

中性神态不等于书生气质。阿会喃等武人办理事务仍保持军职仪态；文臣在军务界面保持本职。关羽读春秋等个人道具例外须有依据。审阅先看人物职责，再看脸部、手脚、头饰和服装结构。

## 三张母图

| 生产键 | 规格 | 用途 |
| --- | --- | --- |
| `neutral` 站立母图 | 目标1536×2560，真实透明，全身 | 固定人设基准；头像、详情、行旅及缺动作时的通用图 |
| `work` 办事母图 | 同上 | 内政、巡视、外交、报喜、告急；按本人职能选择小幅动作和道具 |
| `command` 指挥母图 | 同上 | 整军、指挥和战斗切入；文武人物保持各自职责 |

目标比例约3:5，导入记录生成器的实际高分辨率尺寸，不拉伸图像。三张均只有一名人物，不画环境或大桌案；头脸清晰、完整头饰和双脚留在画内。表情克制自然，嘴唇闭合，手势舒适；避免吼叫、怪相、伸掌、挥击、扭身和夸张透视。个人动作可写入 `sourceActing[id]`，不再要求十一套动作。

## 界面复用

`officer-art-scenes.mjs` 将生产母图与展示场景分开。头像取头肩，事件取半身，详情保留全身；背景按府衙、军营、田野和道路共享。裁剪只改变取景，动作仍由对应母图提供。裁剪在浏览器和战斗Canvas中完成，不另存十一份PNG。

每张母图可通过结果JSON的 `crops` 或导入的 `--crop-file` 指定 `face`、`half`、`full`。每个框为归一化 `[x,y,width,height]`，必须完整落在原图内。高冠人物调整框后检查冠顶、脸和肩部；不要为不同界面重复生成同一动作。切换用途或窗口大小时重新计算取景。

旧已审阅图经身份、风格和文件SHA校验后按URL复用：全身立绘作为站立母图，内政或外交图作为办事母图，指挥、战斗或训练图作为指挥母图。其原始尺寸、背景、提示词和规范记录保留，不冒充新透明图。已有优质头像可继续作为小图。旧PNG和生成记录保留在本地，运行时清单只发布三母图及必要的已有头像；发行不携带其余未引用图。

## 批次与接入

以后可直接说“继续按三母图工作流生成下一批武将”，或调用 `$sango-officer-art`。项目技能源在 `.agents/skills/sango-officer-art/`，通过 `npm run skill:officer-art` 安装到本机技能目录。进度从素材工作区的 `officers/batches/index.json`、活动批次、凭据与公开清单恢复，不依赖聊天记忆；自动跳过已完成或已复用目标，下一批仍须逐人读取身份、传记与本人原头像。

```powershell
node scripts/officer-art-batch.mjs status
node scripts/officer-art-batch.mjs plan --limit 3
node scripts/officer-art-face-references.mjs --officers <人物ID>
```

旧十一图批次首次读取时按三母图任务刷新，旧候选和原始任务保留在批次的 `previousFormat`，不改写其来源、不自动当作新母图接入。合格已接入图优先复用。只生成缺失母图，先完成站立母图，再刷新任务获取动作所需的实际参考路径。

使用内置 `imagegen`，一张母图一次调用并请求真实透明背景。新站立母图以本人的原头像为脸部参考，已有身份图只辅助衣装与画风；办事和指挥以已审阅站立母图为参考。实际结果JSON记录 `officerId`、`scene`、`file`、完整 `prompt`、任务的 `referenceSha256` 和真实 `referenceInputs`（路径、SHA、用途），可附裁剪框。

```powershell
node scripts/officer-art-batch.mjs record <批次ID> <结果JSON>
node scripts/render-officer-art-batch.mjs <批次ID> --portraits
node scripts/officer-art-batch.mjs accept <批次ID> --reviewed --scenes neutral
node scripts/officer-art-batch.mjs plan --limit 3
node scripts/officer-art-batch.mjs accept <批次ID> --reviewed
node scripts/officer-art-batch.mjs finish <批次ID>
```

`--portraits` 现在筛选站立母图审阅。操作者完成目视QA即可接入，无额外逐图审批。程序校验PNG比例、透明通道、人物ID与参考哈希，不能替代面部、解剖和角色气质检查。旧参考候选为 `stale-identity`；保留记录并重做，不能重标SHA冒充一致。真正更换已接入母图须 `--replace`，来源记录必须保留。

```powershell
node scripts/officer-art.mjs import <人物ID> neutral <PNG> --approve --prompt-file <实际提示词>
node scripts/officer-art.mjs gallery
node scripts/officer-art.mjs plan --all
```

新母图在 `assets/officers/generated/v4/<人物ID>/<母图键>.png`；公开映射在 `assets/officers/manifest.json`。身份、凭据、候选、批次与原头像参考不进入发行。可通过 `SANGO_ASSET_ROOT` 或 `.local/assets.json` 挂载独立素材目录，详见 [美术资源接入](美术资源接入.md)。

## 验证与续跑

```powershell
npm run test:officer-art
npm run test:asset-pack
npm run art:check
npm run art:verify-officers
npm run docs:check
```

检查桌面和手机中的脸部取景、完整立绘、事件半身、战斗切入、共享背景、动作缺失回退和显示开关。浏览和加载图像不得修改规则、日期或存档。发布更新程序缓存，素材包只包含公开清单引用文件。

全库续跑按文件记录恢复，跳过已完成或已复用的三母图目标。实际PNG数量与已满足的母图目标分别报告；三个裁剪用途仍只是一张图。保留真实剩余任务，工具故障或额度限制时保存已有成果并说明，不能静默改用API。只有全部目标及明确返修完成后才结束生产。
