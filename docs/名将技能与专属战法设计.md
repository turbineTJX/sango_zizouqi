# 武将特性与专属战法（规则 85）

由 `npm run docs:famous` 从运行数据生成。独立特性开局可用；战斗羁绊升级概率获得，10级达到个人预设上限，详见羁绊成长一览表。技能名和效果属于游戏化设计，不作为史实叙述。

详细规则见[武将正面特性](武将正面特性-规则49.md)。固定战法、每场次数和军略任职分别沿用规则64、48和51；军略强度沿用规则47。旧胜率报告不能直接用作当前平衡结论。
