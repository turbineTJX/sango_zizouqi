# 战意门槛分层（规则 27）

本轮只调整战意门槛，保留上一轮直接伤害系数 1.05。战意上限 100、普攻／存活受击收入、冷却、技能效果与每步最多一次施法保持原规则。战意达到门槛即可施放，不消耗战意。

## 分层原则

- 10～30：小型增益、战意支援与压制，例如输粮 10，振旅／挫锐 15，奋战／铁壁／架设／抛锚 20，枪阵／营垒／阵枢 25。
- 30～55：轻伤害减益、复合支援与控制。例如阻射／破甲／伏弩 35，衰咒 40，惑阵 55；硬控与复合效果不会全部降到最低档。
- 45～65：普通直接伤害，例如贯阵 45，火矢／横扫／舷射 50，连珠 55，投石／艨冲 60，冲阵／疑阵 65。
- 75～85：强力群攻与爆发，例如箭雨／撞城 75，奋击 80，火计 85。
- 100：无双乱舞、赤壁业火、火烧连营、苍天雷殛；原有八百破阵、虎卫折冲、十胜奇谋继续为 100。其他专属战法保留各自门槛。
