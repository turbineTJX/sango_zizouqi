# 美术资源与游戏规则分离

当前项目是 Web 原型。新表现层接入本地图片、逐帧动画、OBJ 模型及 GLB 模型，游戏启动不需要 Unity、Godot、Blender 或 npm install。

当前优先使用本项目原创武将素材，参考三国志系列的沉稳人物表现，神态尽量中性、手势自然克制。首批曹操、关羽、诸葛亮各有十一张独立素材，包含头像、透明全身立绘、半身像与横幅场景，详情、内政、巡视、整军、外交、指挥、行旅、奏报与战斗按实际用途选图；场景差异通过坐立、道具、视线和构图体现。全人物批量队列、身份一致性与导入方式见 [武将多场景美术流程](武将多场景美术流程.md)。尚未生成的武将沿用下述本地试玩包；原创素材和本地包分别加载。

## 启动与切换

双击 `start-game.cmd`，或在项目目录执行 `npm start`。如果之前启动过旧服务，关闭该服务再启动。当前机器已生成 `art.local.json` 与 `.local/art/manifest.json`，默认启用本地资源。

首页和战斗右上角齿轮菜单提供人物美术开关。切换只保存浏览器显示偏好，不修改战斗存档。缺场景图先使用该人物独立头像，再使用原创详情、本地头像或姓名标识；缺模型使用兵种图集，图集也不可用时回到原有图标；WebGL 不可用时自动使用二维表现。

资源目录移动后重新执行：

```powershell
npm run art:import -- "C:\你的目录\sango_infinity-main" "C:\你的目录\三国策略"
```

随后重启服务。不带参数的 `npm run art:import` 复用本机配置。也可用环境变量 `SANGO_ART=off` 禁止服务提供本地资源。

## 分层与替换接口

### 协作目录与资源契约

素材的公开入口为 `assets/manifest.json`（`version: 1`），其中 `town.art`、`town.terrains`、`town.foundations` 按稳定 ID 映射文件，`officers` 指向武将运行时清单。素材版本使用清单的 `revision`；换文件名或版本时只修改素材包，不修改 `town-art.mjs`、Service Worker 或游戏规则。城镇图集保持现有三列裁切规格；改变裁切结构属于接口变更，需要程序与美术共同调整。

默认使用项目内 `assets/`，也可把完整素材工作目录放在独立仓库或共享目录，根目录直接包含 `manifest.json`、`town/` 和 `officers/`：

```powershell
$env:SANGO_ASSET_ROOT = 'D:\sango-art'
npm start
```

也可在程序项目的 `.local/assets.json` 写入 `{"root":"../sango-art"}`；相对路径以程序项目为基准，环境变量优先。两种配置都不进入代码仓库。该配置同时用于服务、美术生产、校验和打包工具，浏览器地址仍为 `/assets/`。服务逐次读取文件，素材接入后刷新页面即可，不需重启服务；改变挂载目录后需重启。缺少素材包时程序仍可启动，以姓名标识和地图基础图形显示。

协作分工：美术侧维护素材目录及其清单、审阅凭据、身份与批次；程序侧维护规则、视图和资源契约。武将清单继续按稳定武将 ID 与十一场景 ID 映射，不根据显示姓名找文件。生产记录中的 `assets/...` 是素材工作目录的虚拟路径，真实位置通过 `asset-workspace.mjs` 解析；不能在接入时拼接为程序目录路径。

```powershell
npm run art:check          # 检查登记文件、路径、武将场景及已登记 SHA
npm run art:bundle         # 单独生成可交付的运行时素材包
npm run test:asset-pack    # 检查外部挂载、缺图回退和模拟依赖边界
```

素材缓存独立于代码缓存，安装时从资源清单读取城镇图像列表。生产目录中的候选、队列与参考图不预缓存；外部试玩素材仍沿用 `/local-art/` 的隔离机制。

### 普通模式全国地图

普通模式的“天下大势”默认使用重新绘制的二维山河舆图，详见文末。支持全国/中原视野、四季换色、拖动和缩放。原项目 `BaseMap0–3.png` 的导入能力仍保留在本地资源清单中（秋 0、春 1、夏 2、冬 3），当前地图不再使用这些底图。

`art-strategic-map.mjs` 统一投影城池、军团行军、道路、粮道和遭遇标记；`strategic-map-art.mjs` 集中定义绘制内容与显示坐标。规则坐标、道路长度、行军天数和存档保持不变，地图不受本地资源开关影响。


```text
规则模块：武将 ID、兵种 ID、坐标、伤亡、战斗事件
                       ↓ 只读快照
art-battle.mjs：动画时钟、插值、逐帧图片和事件特效
art-models.mjs：OBJ / GLB 网格、材质、摆放及释放
                       ↓
art-assets.mjs：资源清单、ID 映射、加载与回退
                       ↓
local-art-server.mjs：仅向本机提供清单登记过的文件
```

规则层不导入这些模块，不读取模型大小、动画时长、图片路径或加载完成时间。新动画不推进模拟步，不回调伤害，不消耗规则随机数。已有程序战法演出与结算流程继续使用原机制。已有规则数据中的 `icon` / `visual` 提示字段仍保留以兼容当前显示，它们不绑定文件路径或资源包。

暂停、弹窗、后台状态冻结表现时钟；倍速改变播放速度；减少动态效果偏好显示静态帧。单步及读档不补播上一批事件。切换战场会释放 WebGL、几何、材质、纹理、观察器和动画循环。清单按稳定武将 ID / 兵种 ID / 地形类型映射，换素材只改资源包，不改规则和存档。

替换包的公开清单使用 `version: 1`，包含 `portraits`、`troops`、`models`、`effects`、`backgrounds` 和 `animations`。图集条目为 `{url, columns, rows, frames, duration, loop}`；模型条目为 `{format: "obj"|"glb", url, texture?}`。当前本地服务使用 SHA-256 前缀生成不含本机路径的资源 URL；私有文件表与来源哈希只留在 `.local/art/manifest.json`。美术包不能覆盖属性、技能、碰撞、占格或地形规则。

## 本地资源隔离与发布

原始资源留在外部目录。本机配置、清单、工具依赖及包含素材的验收截图被 Git 忽略；Service Worker 不缓存 `/local-art/`。本地美术需要本机服务在线，离线模式回退为默认图形。

`npm run build:release` 在 `dist/release-时间戳/` 生成独立的 `code/` 与 `art/`。代码包包含运行时代码、规则数据、Three.js 和应用图标；素材包包含公开资源清单引用的城镇及已审阅武将图像。生成的 `code/.local/assets.json` 仅以 `../art` 连接两个包，不包含开发机路径。进入 `code/` 执行 `npm start` 即可。

`npm run build:release -- --code-only` 只生成代码包；可用 `SANGO_ASSET_ROOT` 连接另行交付的素材包。`npm run art:bundle -- <输出目录>` 单独更新素材包。两个包可以分别交付、替换及版本管理。打包不复制开发机 `.local`、本机配置、生产提示词、队列、候选、身份参考、截图和外部试玩素材。不要将整个工作目录直接作为发行包。

这个打包步骤负责隔离本地美术，不替代对已有武将数据、列传等内容的来源审核，也不把这些试玩素材标记为可商用。

## 二维山河舆图（当前默认大地图）

`strategic-map-art.mjs` 提供独立绘制的 SVG 山脉、河流、海岸、林地、农田、城楼和港口；参考原地图的表现方向，未嵌入原地图贴图。`art-strategic-map.mjs` 负责城市、军团、粮道与战斗标记交互。四季换色、全国/中原视野、拖动和缩放只影响 UI。

显示坐标集中在 `MAP_CITIES`，行军插值仍使用规则层的 `roadLength`；显示坐标与绘图不进入存档。此图是适配当前九城玩法的示意图，不是精确地理复原。外部美术关闭、丢失或发布包没有本地资源时，二维地图仍可用。原四季贴图导入接口保留，默认地图不使用它。

`npm run art:verify-map` 验证城池/军团操作、视野与季节切换不改存档、移动端无横向溢出以及缺失外部素材时的地图显示。


## 战斗动画更新

普通部队采用六人步兵／三人骑兵队列，增加阵营旗帜、脚下投影、四方向图集选择、平滑移动、扬尘、攻击前摇、突刺和受击后仰。普通攻击增加弧线箭矢、刀光、命中火花和延后出现的伤害数字；清晰模式保留简化后的动作反馈。

战法演出分为人物切入、战法名称展开、退场和战场效果四段。同次施放的多个命中仍合并一次演出，所有切入均使用发动武将本人头像，暴击通过文字与金色强调表示；头像缺失时显示姓名标识。

暂停、隐藏页面及战法演出期间的表现时钟分别处理，动画不会写回战斗状态。规则、暴击率、结算和存档结构不变。现有 OBJ／GLB 展示继续保留；当前是 2.5D 图集与静态模型混合表现，未新增三维骨骼动画。



### 战法演出分级

100 战意的大战法（八百破阵、赤壁业火、火烧连营、无双乱舞）和真实连携保留人物插画演出。专属战法、大战法及专属特性增加双方独立的头像发动提示；普通特性、小战法只保留正常命中特效、数值和发动记录，不弹卡片或突出名称，不暂停模拟，小战法暴击也不升级为切屏。大战法名单由当前战法配置的战意门槛读取。

连携标记与原战法全部命中合并到一次演出，保留真实结算与记录，避免战法和连携各打断一次。清晰／完整模式均遵守此分级。


### 军略与持续状态（2026-09-19）

军略拥有独立的军令旗帜、横扫光幕与受影响部队的六角阵纹：进攻使用金色、援护使用青绿、扰敌使用紫色。敌我军令分别标明阵营，不进入战法人物演出队列，也不暂停战斗。暂停下令会立即显示静止的军令提示，继续战斗后播放并淡出；刷新存档不重播历史军令。

部队的持续状态从真实个人状态和军略状态读取。混乱显示旋涡，封技显示锁印；灼烧显示火焰，护盾／减伤显示蓝色罩体，治疗显示上升十字，增益显示光环和上升箭头，减益显示虚线环与向下箭头。部队侧面保留高对比状态字标，优先控制与持续伤害；过多状态用数量标记，完整名称、来源、剩余时间仍在部队详情里。图标跟随移动，到期、净化和离场后随真实状态清除。减少动态效果设置改用静止标识。
