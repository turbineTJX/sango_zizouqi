# 当前设计是否实现预期：判读

本轮 36000 场；规则保持不变；194 项机制回归测试通过。机制通过仅代表技能能运行，定位价值仍以对照数据判断。

## 结论与建议

**结论：部分实现，尚未完全达到“同一兵种、同一武将可以稳定切换多种职责”的目标。**

1. 张飞在四种对手下均有独立复核支持的换装收益；关羽和诸葛亮各有一种明确收益场景。黄忠虽然筛选出四组不同答案，独立复核没有超过本轮实用收益门槛，不能据此认定换装价值成立。
2. 关羽可以通过换枪兵形成更明确的承伤职责。10级、黄忠与诸葛亮在场、贴身掩护、对密集枪阵：骑兵输出5/24胜、骑兵护卫13/24胜、枪兵护卫23/24胜；枪兵护卫相对骑兵输出，后排平均多保留2241兵。对分散弩阵，枪兵护卫反而平均少保留1343兵，具有场景取舍。
3. 同一骑兵下的“护卫”缺乏可靠的后排保护机制。双翼骑兵场景里，关羽在前60步仍存活，但两队后排最终全部损失；换枪兵也未扭转这个结果。对分散弩阵的贴身掩护布阵中，骑兵护卫的策应受益队次为0。说明目标引导、接敌位置和支援距离都是实际限制。
4. 筛选前五组合中，黄忠的火矢和诸葛亮的烟幕均出现20/20次，仍有近乎必带风险；黄忠振旅、诸葛亮封喉仅1/20次。这是有限场景的风险信号，不等于全局无用或必带证明。
5. 布阵确实影响职责收益。例如关羽骑兵护卫对密集枪阵，相对输出在贴身掩护下平均增加1449兵力差，前后脱节时则为−321且区间跨0。但部分变化来自自动追敌，不能把初始“站在后排前面”等同于整场持续保护后排。

建议下一轮优先测试**短距离挑衅/拦截与守位行为**，解决敌人绕过前排的问题；再分别测试物理防御和军纪/谋略抗性，解决不同伤害类型下的承伤。应替换现有六件工具中的一件，保持六选三，而不是新增第七个必带槽位。挑衅不应同时捆绑高伤害、全体减伤与长控制。

本轮只测试现有规则和换兵种，没有加入嘲讽、没有修改技能数值。

## 能解释结果的当前规则

- 骑兵护卫没有守位、嘲讽或替友军承伤机制，仍按通用AI自动追敌；疾驰还会提高接敌速度。策应依赖实际距离，选择辅助战法不会自动让部队停在后排旁。
- 枪阵减伤30%并停止移动，镇军保护1格内友军；二者叠加时按乘法叠减伤，不是直接相加。关羽改枪兵后，骑术不再提高移速。
- 防御抵抗普攻与武技，军纪抵抗谋略伤害并缩短控制；额外减伤又是一层机制。防御提高不能替代谋略抗性，更不能决定敌人攻击谁。
- 若要在同一兵种内稳定扮演坦克，需要分别解决接敌/目标控制与承伤持续性。嘲讽是可测试的方向，不能从当前无嘲讽规则的结果直接断言其收益。
