# 城市钱粮与预算

实际金、粮、预备兵、现役和伤兵人数、运输物资均使用非负整数。每日口粮合计后向上取整一次，补给、分粮、购粮和轻装容量按实际可用量向下取整，余量留在来源。预算与实际扣粮共用同一取整规则；库存含小数的存档拒绝读取，不在读档时悄悄取整。比率、速度、评分及事务进度可使用小数。

金、粮和预备兵均保存于城市。城市设施基础产出及有效周期加成每旬末入本城，直接运营成果在事务完成时入本城；建设、内政、部队编制、装备和整补从执行城市扣金。全势力金粮仅显示各城合计，不提供跨城直接付款。武力占领只接收城仓50%的金、50%的粮和20%的预备兵，逐项向下取整，其余按散失扣除；和平移交仍按外交契约转交库存。

势力所属城市开局按规模配置发展余量：大城10000金、18000粮、18000预备兵；小城5000金、10000粮、9000预备兵。各势力的初始合计由实际城池数量和规模决定，城多不会稀释每城的资金。现有驻军保留，初始携粮回城沿共同粮仓容量处理。中立大城仅有1000金、3000粮、1000预备兵，小城500金、1500粮、500预备兵；中立期间没有周期产出，归属势力后恢复正常生产。玩家、AI及七个剧本使用同一套设计源 `data/design/economy-rules.mjs` 的 `opening`、`neutralOpening` 和 `occupation`。

接收中立城时先按其中立规模库存封顶，再计算占领保留量，因此中立大城最多接收500金、1500粮、200预备兵，小城最多250金、750粮、100预备兵。只接收实际存在的库存，空仓不补齐。空城抵达占领、放弃守城和真实攻城获胜共用一次交接处理；守方获胜、双方收兵和同方驻军进城不扣占领损失。占领记录保存原库存、接收量与散失量，查看和读档不重复扣减。行军军团自带粮与实际在途运输物资独立核算，不算入被攻占的城仓。AI只按新鲜合法情报估算可接收库存，不把预测接收量用于出发预算。

普通跨城调金与粮兵共用人员运输：装运扣来源城，途中保存于运输人，实际到达入目的城；遇敌沿既有运输损失和人员去向处理。携金的无兵武将也属于地图可见运输队。

## 官员俸禄

所有在仕武将按实际武将等级领取旬俸，1至10级每旬依次为5、10、15、22、30、40、52、66、82、100金。太守、内政人员、待命、已编制、出征、运输与外交外派人员均计薪，未编制或没有兵力不免薪；在野、被俘与战死者不在当前在仕名册中，不继续计新俸。名册按人物身份去重，军团、城内部队与归队交接不重复计薪。

驻城人员归实际所属城市；外派归派出城，随军及在途归本人原城，原城失守时改由本势力尚存城市承担。每旬末先计本城实际周期收入，再支付俸禄，不提前用未来收入开办事务。围城没有收入，仍支付实际应发俸禄。不足部分记为本城欠俸，下旬与新俸一并补发；账目与城池一并保留。重复查看、读档与同旬重复结算不会再累计一份新俸。城市预算单列计薪人数、每旬俸禄及欠俸，并计入预计支出，旬报记录实际发放与欠俸。

玩家与AI共用计薪及扣款。提案、自动征补、装备、出征和运输的预算判断保留应付俸禄及欠俸。钱不足时可继续真实免费赚钱事务；人员越多、等级越高，长期府库压力越大。俸禄不按士兵人数征收，未编制储备兵仍没有维持费。

出售余粮为本城市场交易，不要求拥有第二座相邻城市；围城时不能成交。成交前不扣金或粮，提案和在办事务保留实际待售粮，完成时复核口粮、运输与出征预留，再扣实际售粮并从货款中扣除至多30金手续费，未成交不收费。购粮继续要求实际畅通的己城道路。现金不足不妨碍出售未预留的真实余粮。

商业安排按预计完成的旬预估在办集市占用的共享额度；已经排满时选择其它实际有用事务，剩余额度少时降低重复集市的优先级。预估只影响安排，不改变库存、已产出数或随机结果，也不允许提前花未来收入。资金不足以维持人员工资或工资储备低于六旬时，提高市场发展的优先级；满仓且正常部队目标口粮已由持续产出覆盖时，暂不重复扩农田或灌溉。

外交资源报价及履约使用双方确认君主城的库存，行资由出发城市付款。报价锁定、契约预留、延期付款、交付与退款均保存原城市，不因君主迁城自动动用其它城市的金库。金货款按契约约定交付比例从预留入接收城；普通城际资金运输仍走实际道路。赎金从实际选定的己方付款城市扣除并入关押城市，无城或单城金不足时不从多城拼凑付款。

延期付款到期时最多扣入“总额－已实际交付－已托管”的余额，仍保留付款城市设置的金储备。对方实物还在路上、尚不能按约付款时，已收取资金停留在托管；同日两次处理和跨日等待均不得重复收取。托管与城库、实际交付及公开行资共同保持资金守恒。回归使用正常出使、批准、签约及真实粮车运输，验证等待和读档续行；不通过修订坏存档消除多扣款。

## 预算

城市详情的“收支预算”显示本城实际结算、产出明细，以及未来10天的现存、预计收入、支出、预留和预计结余。势力详情的同名分页显示各城预算合计、逐城缺口，可直接进入对应城市明细；各城钱粮继续独立核算，富城盈余不能掩盖另一城的用度缺口。实际结算使用既有旬末入库、运营与纪事入库、实发俸禄和旬末收支记录；势力另显示已有的真实城仓净变化，不用预测反推实际支出。保留金粮在本城详情设置，仅己方详情提供私有预算；内政页不再混合预算、人才和外交分页，人才接洽与重要报告移至本势力“人才”页面。收入只计周期产出，不计未完成事务和未到货运输；已开始事务已经付款，不再次扣预算。支出计驻军口粮、连接本城的军团粮道用度、待开始事务、外交接洽及行资、未来一旬内到期的未清债务和待执行运输等真实承诺。军团用度按当前粮道的实际供粮城市归账；按每日先补携粮、后消耗的顺序估算，各军团共享粮仓发送能力和每条道路的运力，不分别重复领取全额运力。规划保持当前兵力、位置和粮道不变，不能预知未来战损、转向和新封锁。

周期收入在旬末到达，因此另检查下一次收入到账前的钱粮用度，即使旬末预计结余为正也可能出现提前缺粮。围城时不预测周期产出。玩家可在筹划阶段分别设置本城保留金、保留粮；默认保留500金、0粮。内政自动选事尊重本城金预留和相关外交占用，自动售粮尊重保留粮及既有口粮预留。玩家明确下令仍可使用库存，预算给出不足提醒。

未开始事务按真实执行槽与实际可用钱粮估算下一轮：全城仅一项建设或修复、一项研究，同类经营加成不重复预留；其它等待负责人估算可负担的合法替代事务，并逐项扣减同一笔可用金。不会提出的付费愿望不计作必付费用。已有待批提案保留原案费用，已付款事务不再收取。预算查看只计算，不选工地、不抽成败、不更改委任。

武将拟案前检查本城可用金、粮及预备兵，扣除预留、真实口粮、已有提案和军令、外交承诺。预算不足的对应付费事项不呈案，免费且确有需求的事务仍可办理。提案与最终开办都使用同一可用资源校验；批准时仍保护其它待批提案占用的资源，不借用势力合计、不提前计入未来收入。

预算区分用度缺口与预留目标未满。用度缺口检查现存钱粮能否覆盖预计支出和实际承诺，仍扣除待发运输、外交报价等已占用资源；保留金粮及外交政策中的储备目标不作为实际支出。预留目标未满在城市预算中显示“预留金／粮尚差”，不弹奏报，也不列入顶部缺钱粮警报；预算查看不改库存或预留设置。

用度不足写入同一城市每日记录，现有奏报可查看并确认，顶部同时显示不足城市并可定位。持续同类不足不每天重复弹出；恢复后再次不足或可用于真实口粮的粮草下降至3天以内时重新提醒。警报状态与已读记录随当前版本存档保存；查看预算不推进日期或修改任何库存。只因预留未满且没有金支出的预算记录不列入重要奏报。

## AI预算与救急

AI按各城预算安排内政、征补、装备、出征和城际运输。军事可用金保留本城设置、明确提案、未清债务、外交行资、待发物资和必要运营，尚未开办的可选工程或常规整补可让位于主攻准备，不把所有等待岗位的建设愿望当成不可让步的支出。已选主攻的逐城资金需求约束随后办理的可选内政及征补，真实农业、商业运营继续；正在办理的事务按既有打断规则处理。粮草预留包含本城驻军及通过本城粮道供给的外军。持续供养判断按供粮来源分配耗粮，兵源及战损补充仍按真实归属和驻扎资格办理。

钱粮紧张时优先安排实际产粮、赚钱的人手，先选空闲人员；没有空闲人员时可调整尚未开始付费事务的等待岗位，不中断已付费的正在办理事务。可选出征、外交和运输保留最后一名必要且实际在城的农业、商业负责人。免费集市、督耕仍是需要真实人员、时间、成功判定和本城产能额度的内政行动。

运输先救有预算缺口或口粮即将耗尽的城市，再补其它库存；来源城也保留自身预算。已在途和等待中的货物用于避免重复派车，抵达前不入城仓。军团另外按真实城仓、旬末到账时间、携粮和共用运力预测断供，能回到可达粮仓时提前沿路收兵；回撤不补粮、不瞬移。当前预测保持现有粮道，后续移动或封锁发生后再重算。

安静且未被围城的城市若口粮不足三天、撑不到旬末，也没有能及时到达的安全粮车，会在保留实际守备需求后把多余驻军转回本城预备兵。武将和内政任职保留，兵员完整转回，已花编制金不退。这是最后的救急措施；正常运营先发展农业、商业和真实运输，不能用裁光部队证明经济可持续。

这些处理没有资源补助或缺粮豁免。围城、夺仓、切断粮道、拦截运输和堵住退路仍使用双方共用的真实规则，可能造成缺粮、减员和军团解散。验证位于 `tests/ai-city-budget.test.mjs`，包括共享运力与实际结算对照、供外军时控制征补、债务预留、真实调运、提前回撤、裁兵守恒及封路后的断粮损失；单城安静运行120天测试保留现役兵力并通过真实建设、运营及旬结算维持钱粮，不代表七剧本全年战争承载已经重测。
