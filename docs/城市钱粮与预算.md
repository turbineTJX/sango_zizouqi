# 城市钱粮与预算

金、粮和预备兵均保存于城市。城市设施基础产出及有效周期加成每旬末入本城，直接运营成果在事务完成时入本城；建设、内政、部队编制、装备和整补从执行城市扣金。全势力金粮仅显示各城合计，不提供跨城直接付款。城池占领或和平移交保留并转交本城库存。

开局保留原有各势力金总量，按大城2、小城1的权重分配，尾差归最后一城。普通跨城调金与粮兵共用人员运输：装运扣来源城，途中保存于运输人，实际到达入目的城；遇敌沿既有运输损失和人员去向处理。携金的无兵武将也属于地图可见运输队。

外交资源报价及履约使用双方确认君主城的库存，行资由出发城市付款。报价锁定、契约预留、延期付款、交付与退款均保存原城市，不因君主迁城自动动用其它城市的金库。金货款按契约约定交付比例从预留入接收城；普通城际资金运输仍走实际道路。赎金从实际选定的己方付款城市扣除并入关押城市，无城或单城金不足时不从多城拼凑付款。

## 预算

城市页、城市内政和势力事务中的预算显示未来10天的现存、预计收入、支出、预留及预计结余。收入只计周期产出，不计未完成事务和未到货运输；已开始事务已经付款，不再次扣预算。支出计驻军口粮、连接本城的军团粮道用度、待开始事务、外交接洽及行资、未来一旬内到期的未清债务和待执行运输等真实承诺。军团用度按当前粮道的实际供粮城市归账；按每日先补携粮、后消耗的顺序估算，各军团共享粮仓发送能力和每条道路的运力，不分别重复领取全额运力。规划保持当前兵力、位置和粮道不变，不能预知未来战损、转向和新封锁。

周期收入在旬末到达，因此另检查下一次收入到账前的钱粮用度，即使旬末预计结余为正也可能出现提前缺粮。围城时不预测周期产出。玩家可在筹划阶段分别设置本城保留金、保留粮；默认保留500金、0粮。内政自动选事尊重本城金预留和相关外交占用，自动售粮尊重保留粮及既有口粮预留。玩家明确下令仍可使用库存，预算给出不足提醒。

不足写入同一城市每日记录，现有奏报可查看并确认，顶部同时显示不足城市并可定位。持续同类不足不每天重复弹出；恢复后再次不足或粮草下降至3天以内时重新提醒。警报状态与已读记录随当前版本存档保存；查看预算不推进日期或修改任何库存。

## AI预算与救急

AI按各城预算安排内政、征补、装备、出征和城际运输。征兵至少保留本城一旬待用金与原有军事支出限制，未清债务、外交行资和待发物资不能被可选事务挪用；粮草预留包含本城驻军及通过本城粮道供给的外军。持续供养判断按供粮来源分配耗粮，兵源及战损补充仍按真实归属和驻扎资格办理。

钱粮紧张时优先安排实际产粮、赚钱的人手，先选空闲人员；没有空闲人员时可调整尚未开始付费事务的等待岗位，不中断已付费的正在办理事务。可选出征、外交和运输保留最后一名必要且实际在城的农业、商业负责人。免费集市、督耕仍是需要真实人员、时间、成功判定和本城产能额度的内政行动。

运输先救有预算缺口或口粮即将耗尽的城市，再补其它库存；来源城也保留自身预算。已在途和等待中的货物用于避免重复派车，抵达前不入城仓。军团另外按真实城仓、旬末到账时间、携粮和共用运力预测断供，能回到可达粮仓时提前沿路收兵；回撤不补粮、不瞬移。当前预测保持现有粮道，后续移动或封锁发生后再重算。

安静且未被围城的城市若口粮不足三天、撑不到旬末，也没有能及时到达的安全粮车，会在保留实际守备需求后把多余驻军转回本城预备兵。武将和内政任职保留，兵员完整转回，已花编制金不退。这是最后的救急措施；正常运营先发展农业、商业和真实运输，不能用裁光部队证明经济可持续。

这些处理没有资源补助或缺粮豁免。围城、夺仓、切断粮道、拦截运输和堵住退路仍使用双方共用的真实规则，可能造成缺粮、减员和军团解散。验证位于 `tests/ai-city-budget.test.mjs`，包括共享运力与实际结算对照、供外军时控制征补、债务预留、真实调运、提前回撤、裁兵守恒及封路后的断粮损失；单城安静运行120天测试保留现役兵力并通过真实建设、运营及旬结算维持钱粮，不代表七剧本全年战争承载已经重测。
