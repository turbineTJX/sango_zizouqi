# 技能、战法与军略分层（规则 29）

三层分别解决部队长期特性、局部交锋和全局决策。规则 29 不改变五技能成长、三个战法槽、战意自动施法与军略手动施放结构。

| 层次 | 核心用途 | 作用范围与触发 |
| --- | --- | --- |
| 技能 | 强化所率部队、兵种专精、条件被动 | 随等级解锁；常驻或满足条件生效，无需施放 |
| 战法 | 爆发、控制、局部援护 | 单体或附近少量目标，受距离、战意、独立冷却限制 |
| 军略 | 全军增益、敌军整体压制、战场调度 | 军略条蓄满后施放；全军、敌军全体或援军序列 |

## 被动调整

26 位扩展名将的终阶技能从条件式战法伤害／支援倍率，改为本队属性加成，统一接入面板和实际战斗。即使卸下专属战法，技能仍按条件生效。未重新设计原有 15 人已经有独立用途的被动；通用武技、谋略和支援专精仍允许与战法配合。

- 关羽：骑兵攻击 +18%、攻速 +12%。赵云：骑兵防御 +20%、军纪 +25%。
- 马超：骑兵移速 +25%、攻击 +15%。太史慈：弓兵攻速 +25%。
- 黄忠：弓兵连续 3 步未移动，攻击 +22%；移动立即重置。
- 诸葛亮：本队军纪 +30%、攻速 +12%。周瑜：弓兵／舰船攻速 +18%、军纪 +15%。
- 魏延、吕布：本队相邻无友军时获得攻势与机动加成；不再检查受击目标是否孤立。
- 刘备、黄盖、张角、董卓：低于一半兵力时强化自身对应面板。

其余名将的完整条目由运行数据生成，见 [技能设计](名将技能与专属战法设计.md)。兵种不符时加成立即失效，技能面板显示原因。攻速同时改变真实普攻间隔。

普通成长路线新增四项兵种专精：戟卫（戟兵防御与攻速）、辎护（后勤防御与军纪）、机巧（兵器攻击与攻城）、操舟（舰船防御与移速）。换兵种不重置成长路线。

## 辅助专属战法

| 武将 | 专属战法用途 | 局部范围 |
| --- | --- | --- |
| 曹操 | 护盾 + 战意，综合援护 | 3 格内最多 2 队 |
| 荀攸 | 净化 + 小护盾 | 3 格内最多 2 队 |
| 于禁 | 25% 基础减伤 | 2 格内最多 2 队 |
| 袁绍 | 25% 基础增攻 | 2 格内最多 2 队 |
| 沮授 | 单队厚盾 | 3 格内 1 队 |
| 刘备 | 救治本场伤兵，基础上限为兵力上限的 12% | 3 格内 1 队，无伤兵不发动 |
| 孙权 | 解控 + 冷却缩短 4 步 | 3 格内 1 队；自身不享受缩冷却 |
| 鲁肃 | 战意 +32 | 3 格内 1 队其他友军 |

表中数值仍遵守现有威力、被动、连携与伤兵上限规则。治疗不复活，不把永久阵亡转换成伤兵。其余伤害类专属继续使用单体或目标周围小范围结算。

军略已实现全局范围，本次保留其数值与触发方式。局部主动效果与全局军略可以共享增攻、治疗等效果类别，但覆盖范围、启动资源与使用时机不同。
