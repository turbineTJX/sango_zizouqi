# 战略地图性能

2026-10-27：普通模式地图缩放、每日推进和本机存档的表现层优化。

地图上的旬初开始与每日结算通过 `campaign-runner.mjs`、`campaign-worker.mjs` 调用原有 `beginExecution`、`advanceCampaignDay`，在独立线程中计算当前状态的副本。完成后一次提交结果；暂停、存档、读取、新命令和离开页面取消尚未提交的计算，旧线程的迟到消息不能覆盖新状态。取消不消耗日期、钱粮或随机状态。亲自指挥的战场仍沿用原有逐步时钟；不支持 Worker 的运行环境保留同步入口。

`strategic-dom.mjs` 按实际城市、节点、军团和建筑 ID 更新已有地图节点，保留 SVG、地形及已解码图像。地图控制器在重绑前释放事件、观察器、动画帧、计时器和临时图像 URL。城内施工、损毁、情报、实际部队及进入战场继续取自本轮的合法视角投影。

相同输入的子树按实际 DOM 节点记录并跳过，不把临时插入的指引、声音按钮或美术节点误认为原始控件。表单属性仍按当前草稿同步；城市模型数据变化时清除旧城内画面。关闭没有改动游戏状态的只读窗口只更新遮罩、暂停和推进控件，保留当前地图与镜头纹理；从侦察等全屏命令返回只绘制一次。每日地图生成在同步只读情报查询作用域内执行，隐藏的管理面板延后到打开时生成。

`map-camera-preview.mjs` 只从当前已投影的画面生成临时纹理。拖动及缩放期间变换这一缓存层，不逐帧改动根 SVG 的 viewBox 和全部文字、建筑；操作结束或进入建筑近景时恢复完整矢量和交互。新一天或切换视角丢弃旧纹理；缓存不写入存档。预览尚未生成、资源不可用时可继续使用原地图。美术文件及规则不改动。

发行构建单独封装后台入口，先传入已经校验的数据包，再加载同步引擎图；源码与发行版的离线清单均包含后台代码。没有在战斗循环依赖中添加网络等待。

战斗界面按变化更新名册、标签和部队 DOM；标签只在位置、文字或尺寸变化后重新避让。原生部队把几何与材质完全相同的刚性部件合并绘制，保留逐兵关节、位置、碰撞与身体锚点；闪白、变色、透明和倒下仍使用原有材质路径。暂停后仅在状态变化、模型载入、尺寸或焦点变化时绘制，恢复时重置帧时钟，暂停时间不计入演出。

`archive-reader.mjs` 通过独立队列在后台完成原有的完整存档校验。列表只返回通过校验的摘要，读取才返回完整状态；默认同步 API 仍保留自定义验证器的原语义。缓存仍绑定持久化事务的提交标记，不改 IndexedDB 结构、存档格式或损坏数据判定。搜索输入合并为 100ms 一次，中文输入组合期间不重建结果，提交后保留最终文本、光标和焦点。

日结算计算中，内政候选的单次评估共用只读预算、人员和粮道查询；同一武将的各内政方向在一份不变的预览中比较，结束后才办理真实任命或军令。城市预警先在只读作用域中测量全部本方预算，退出作用域后再保存提示与报告。缓存不跨任命、付款、下令、移动或日期保留，AI每旬完整评审、逐日执行和实际补给规则不变。

粮道评估使用 `supplyRoutingWorld` 的窄投影，只准备同一势力合法可见的城市、军团、战场及通行条约。它与完整情报共用城市和战场投影函数，不重新生成武将名册、内政、活动和人事记录；不得把该路由输入用于执行或完整游戏决策。已经传入的同势力投影保留其原值，包括只读的无库存连通性对照；不把未知状态变成实时敌情，不给真实仓库补粮。

验证入口：

- `npm run test:campaign-runner`：取消与迟到消息、失败后重试，以及原始全国全 AI 连续 12 天、跨旬和两次读档后的完整存档逐字一致。
- `npm run verify:campaign-responsiveness`：真实推演期间的帧间隔、立即暂停、取消不改存档、共同开始与每日结算、地图节点身份保留及实体增删。
- `npm run verify:map-performance`：缩放输入不丢步、缓存层运动、停止后细节恢复、拖动、桌面与短横屏，以及不改存档。桌面地图帧时间 P95 上限为 50ms；通过功能断言不能代替帧时间检查。
- `npm run verify:ui-performance`：只读关闭保留地图、城市外观失效、表单重置、临时按钮、中文组合输入、后台存档完整校验与精确读取、暂停休眠与恢复，以及合并前后的像素和几何量对照。
- `npm run test:battle-readability`、`node --test tests/native-model-batches.test.mjs tests/archive-reader.test.mjs tests/save-archives.test.mjs tests/save-storage.test.mjs`：演出时钟、实际关节变换、闪白与透明回退、取消及存档事务回归。
- `npm run verify:release`：真实封包、后台与源码一致、导入导出、离线重载后新建后台线程、在线／离线存档摘要与完整读取及损坏档拒绝、移动端及损坏数据拒绝。
- `node scripts/audit-ui-latency.mjs --out=<输出目录> --save=<当前自然存档>`：保留源码指纹的同机耗时复测；不能把已失效版本的自然存档改字段后用于测量。
- `npm run verify:campaign-performance -- --save=<当前自然全AI存档> --days=10 --out=<输出目录>`：记录纯引擎逐日耗时、验证与序列化开销。加 `--profile` 额外生成 `settlement.cpuprofile` 和函数自身／累计CPU采样摘要；采样会增加开销，速度对照须关闭采样。不提高原有8秒桌面日结算门槛。
