# 武将字段核对与修正

已修正漏读来源剧本人物资料的问题。关羽当前为 **刚胆、不会背叛**。本次依据本地来源项目的实际数据与读取代码，未凭人物印象重填字段。

## 原因

来源项目为 `C:/Users/tao50/Documents/New project/sango_infinity-main`。

此前仅导入 `Build/Content/Data/Common/PersonLibrary.json`。它与原始 `Data/Export/Common/PersonLibrary_武将库.xlsx` 完全一致，但并不是来源项目实际开局时的完整人物资料：

1. `Project/Assets/Sango/Scripts/Game/Scenario/Scenario.cs` 的 `LoadBaseContent` 先读取公共库，调用 `Person.FormLib` 创建人物，再用 `JsonConvert.PopulateObject` 读取剧本。
2. `Person.FormLib` 仅初始化编号和美术路径，人物设定由 `Build/Content/Scenario/Scenario.json` 的 `personSet` 提供。
3. 关羽（99）在公共库中为 `personality=4、argumentation=1`，剧本中为 `personality=3、argumentation=5`。导入漏掉剧本层，导致游戏采用了公共库旧值。
4. 性格和义理名称表没有读反。性格编号依次为胆小、冷静、刚胆、莽撞；义理编号依次为容易背叛、无情义、普通、情理坚定、不会背叛。源武将 Excel 辅助文本中的“小心／猪突”与运行名称表“胆小／莽撞”也有用词差异，游戏统一采用运行名称表。

## 修正范围

按来源编号连接，不按姓名匹配。832 条公共库记录读取剧本人物资料；3 条自建记录保持独立，避免同号串人。以下数量按字段分别计数，同一人物可能涉及多个字段。

| 字段 | 公共库与剧本差异 | 处理 |
| --- | ---: | --- |
| 性格 | 604 | 使用剧本编号 |
| 义理 | 620 | 使用剧本编号 |
| 姓名 | 23 | 使用剧本写法，旧名保留为检索别名 |
| 字 | 17 | 使用剧本写法；空字符串与原库未填不算差异 |
| 姓／名分字段 | 8／47 | 使用剧本写法 |
| 父亲 | 116 | 24 处已有父亲编号修正；另外 92 处为未收录父系引用，仅保留来源值 |
| 母亲 | 1 | 曹叡的母亲编号由 31 修正为 301 |
| 配偶 | 3 | 黄月英 29→290；曹丕 31→301；孙氏 63→603 |
| 亲爱 | 30 | 采用剧本列表，保留方向 |
| 厌恶 | 6 | 采用剧本列表，保留方向 |
| 性别 | 67 | 来源占位记录为 -1，正式字段转 null，不再显示为男 |
| 统率、武力、智力、政治、魅力 | 0 | 两份来源的基础数值一致 |
| 六类兵种适性、相性、生卒年 | 0 | 两份来源一致 |
| 登场年 | 0 | 公共库 yearAvailable 与剧本 appearance 一致 |

剧本能力数组的第一个元素才是基础数值，后续元素不是另一项人物能力。本项目不导入剧本的势力、城池、身份、官职、忠诚、等级或运行状态，这些由本项目机制确定。来源剧本额外的 18 条古代占位记录不加入现有名录。

保留公共库原文 `data/officers.mjs`，新增由导入脚本生成的 `data/officer-profile-overrides.mjs`。目录的 `source` 为原始公共库／自建库，`profileSource` 为应用剧本人物资料后的有效来源。来源文件校验值统一记录在 `data/officers-source.json`，重新导入会重建覆盖文件。

## 复核命令

在本游戏目录执行，Python 需安装 openpyxl。核对脚本只读来源文件，结果写入本项目 outputs。

```powershell
python scripts/audit-officer-workbooks.py "C:/Users/tao50/Documents/New project/sango_infinity-main" outputs/officer-source-workbooks.json
node scripts/audit-officer-source.mjs "C:/Users/tao50/Documents/New project/sango_infinity-main" outputs/officer-source-workbooks.json
```

完整字段差异、排除引用及检查结果写入 `outputs/officer-source-audit.json`。修改来源后应先运行 `npm run import:officers -- <来源项目目录>`，再执行 `npm run docs:famous` 和以上复核。
