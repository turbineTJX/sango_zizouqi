# 发行封包与试玩发布

开发目录保留可读程序和设计表。发行构建生成合并程序、版本化二进制数据包和可独立替换的美术资源包；Windows EXE 与 Android APK 共用这份运行时内容。封包用于整理发行文件、减少散装数据和检查文件损坏，不提供客户端内容无法提取的保证。

## 代码与数据

`npm run build:release -- --code-only` 在新的 `dist/release-时间戳/code/` 生成：

- `app.js`、`app.css`：合并压缩后的游戏程序与界面，不附带源码映射。
- `game-data.bin`：MessagePack 编码、gzip 压缩的二进制数据包。
- `release.json`：程序版本、当前规则版本、内容修订号、文件长度及 SHA-256。
- `index.html`、`bootstrap.js`、`sw.js`：启动、文件错误提示和网页版离线缓存。
- `server.mjs`、`start-game.cmd`：独立代码包的本机启动入口，需要 Node.js 20 以上，不需要安装 npm 依赖。
- `licenses/`：随运行时交付的第三方许可。

第一版编译七组大型纯数据表：原始武将资料、性格名称、人物补充资料、全国地图、固定能力分配、剧本来源快照及道路距离。完整名单见 `packaging/data-tables.mjs`。含函数的规则模块随程序构建，开发端导入方式不变。

二进制头为 `SANGODAT`、格式版本、解码长度和负载长度；当前格式版本为 1。加载器先校验完整文件 SHA-256，再解码并核对程序版本、规则版本和数据修订号。构建时逐字段核对编码往返结果。程序和数据不匹配时显示重新安装提示，不清除已有存档，也不加入旧规则兼容分支。

代码包不包含 `data/` 源文件、开发机配置、工具、测试、源地图、独立美术及生产记录。代码内置的 `icon.svg` 和 `landscape-scroll.svg` 保留。

## 独立美术封包

美术侧可运行 `npm run art:pack -- <输出目录>/art.pack`。工具先执行现有公开清单校验，只收录清单声明的运行时文件，再生成 ZIP 格式的 `art.pack`。包内索引保存各文件长度和 SHA-256；图片保留原压缩格式，JSON 等文本压缩。

`art.pack` 放在独立 art 目录中。原有 `SANGO_ASSET_ROOT` 或 `.local/assets.json` 仍指向该目录，服务将包内文件提供为原有 `/assets/` 地址。桌面及 Android 容器共用公开资源地址和稳定 ID，渲染代码不依赖封包内部文件命名。每包最多 512 MiB 解码内容、20,000 个公开文件，超出需拆分设计，不能直接强行打包。

未声明条目、哈希不符和非法路径拒绝加载。候选、身份参考、批次、生产提示词、私有收据和外部试玩素材不进入封包。生产目录及已有散装资源加载继续保留，缺包时回退为姓名和内置图形。

Windows 本机交付默认使用 code-only；本次不生成或上传实际美术包。资源封包测试仅使用临时模拟素材。

## Windows 与 Android

开发构建需要 Node.js 22 以上；首次运行 `npm ci` 安装锁定的构建依赖。

```powershell
npm run build:desktop -- --code-only
npm run build:apk -- --code-only
npm run build:native -- --code-only
```

各次构建使用新的 `dist/native-时间戳/` 和被忽略的 `.local/native-build-时间戳/`，不会复用或清空美术目录。

Windows 使用 Electron，交付 x64 免安装 EXE，内置运行时、ASAR 程序包和二进制数据。朋友无需安装 Node.js；F11 切换全屏。固定应用数据目录为用户 AppData 下的 `SangoSovereign`，固定 `sango://game/` 来源，不随发行目录变化。更换 EXE 保留本机存档，运行时文件不使用旧版本页面缓存。导出通过仅暴露存档操作的隔离接口打开系统保存对话框；取消不会显示导出成功。初期 EXE 不包含商业代码签名证书。

Android 使用 Capacitor，交付带固定本机签名的 APK，最低 Android 8.0，要求系统 WebView 120 以上。游戏文件随 APK 安装，首次启动也不访问远端游戏服务。后台暂停保存，返回键沿用页面关闭规则，存档导出使用系统分享面板，导入使用文件选择器。允许横竖屏切换。

Android 构建需要 JDK 21、SDK platform 36、build-tools 36.0.0 和 platform-tools。可配置 `JAVA_HOME`、`ANDROID_HOME`；本机工具也可放在 `.local/native-tools/jdk/` 与 `.local/native-tools/sdk/`。Gradle 分发包使用官方校验值。

Android 的固定签名密钥及密码记录位于 `.local/signing/`，不进入 Git 或发行包。应单独备份整个目录，以便后续覆盖安装。构建不会替换已有密钥；密钥或密码记录缺失时要求恢复原件。卸载 Android 应用会删除其本机存档，替换应用包仍受当前存档版本校验。

`npm run prepare:android -- --code-only` 仅生成原生工程，方便在 Android Studio 中检查，仍需安装构建依赖。

## 验证

```powershell
npm run test:release
npm run verify:release
```

回归覆盖数据往返、可重复构建、头部及版本拒绝、内容哈希、源码及美术隔离、资源包路径和公开文件名单。浏览器验证使用真实发行目录，比较开发版与封包版的新局、战略推进及读档续战，检查导入导出、重新加载、离线启动、触屏尺寸与损坏包保留存档。

EXE 和 APK 还需分别执行实际容器启动验收。模拟触屏尺寸不能代替 Android 设备验收，构建成功及行为检查不能代替战斗平衡结论。

`verify:desktop-release -- <win-unpacked/SangoSovereign.exe>` 检查应用来源、渲染隔离、原生导出导入和进程重启后的存档。`verify:portable-release -- <便携EXE>` 检查实际便携启动器。`verify:native-contents -- <发行目录>` 核对两端程序和数据相同，检查外层哈希以及无散装数据、开发美术或签名密钥。

本轮已完成发行、桌面容器和 Android 编译／签名检查。Android 模拟器镜像下载未完成，尚未进行 Android 设备运行验收；APK 属于待设备验证的试玩候选。
