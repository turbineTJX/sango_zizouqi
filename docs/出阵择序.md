# 敌方首发与补位择序

当前实现入口为 `engine.mjs` 的 `fillSlots` 与 `battle-ai.mjs` 的 `rankEnemyReserves`。

- 每方同时上场至多六队；敌方在首发及产生空位时，从已到达、存活且可合法落位的预备队中择序，玩家按既定队列。
- 每补入一队重新评估当前分工；考虑现役兵力、属性、已学战法、前排与支援需求、可见敌军构成及攻城条件。
- 不提前到达，不换下在场部队，不改变持久部队数组和行动顺序，不提供额外行动。断援、撤退、水陆通行及占位限制继续生效。
- 不选择、替换、重抽或重排战法。择序与初始格位规划是不同步骤，均遵守共同引擎。
- 评分细节以当前函数为准，不保留旧兵种与旧战法的评分副本。军略独立使用[固定条件触发](军略AI固定条件触发.md)。

行为验证检查合法到达、六队上限、缺前排补位、非均分兵力、支援条件、存读档和玩家队列不变。平衡对照遵守[当前验收目标](战斗平衡优化目标.md)。
