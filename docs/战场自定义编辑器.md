# 战场自定义编辑器

入口：主菜单 → 自定义战役 → 地图编辑器。编辑战场属于战役初始规则配置，双方在开战后共用真实地形、部署、移动、AI与战斗结算。

## 分类与模板

地图按用途分为野战、攻城、关卡、港口、水战，可新增自己的分类，并指定沿用哪种用途。分类与格子地形分别设置，不按平原、树林或山地分组。21张内置模板包含15张普通地图和6张历史地图；历史战场放在对应的用途分类下。

每张地图固定使用共享引擎的14×8六角网格，每格可独立设置平地、树林、高地、湿地、水面、桥梁、山壁。山壁对所有部队不可通行；水面需要真实携船，桥梁供陆军通过。道路绘制只是图纹，不增加移动速度。

正式分类与模板归属见 `data/design/battle-map-categories.mjs`，内置格子布局见 `data/design/battle-maps.mjs`。当前为野战14张、攻城2张、关卡1张、港口1张、水战3张。

## 编辑与校验

可从模板载入副本，或新建空白图；内置模板不会被覆盖。支持点击与拖刷、连片填充、取样、道路绘制、撤销重做、左右翻转及实际战场预览。键盘方向键移动格子焦点，回车或空格绘制。

地图保存、导出和用于战役前，校验双方各至少14个合法部署格，并逐格检查到对方部署区及本方撤离边界的连通性。攻城用途还要求两侧城门位置为可通行岸地。尚未连通的布局可以作为草稿保留，修好后再保存为正式地图。

港口、水战用途可设置“陆军与舰船”或“仅舰船”部署。仅舰船地图允许水面贯通；用于战役时，双方及全部援军每一队都须实际携船。不会因选择地图而免费获得舰船。攻城用途自动选择攻城场景，玩家仍可切换攻守方向，共用现有城门与胜负处理器。

## 保存与扩展

自建分类、地图与最近草稿保存在独立的 IndexedDB 地图库 `sango-battle-maps`，不占游戏存档槽；写入事务完成后才报告保存成功。可导出单张JSON地图或完整地图包，并从JSON导入。每包最多128张地图、32个自建分类；整包校验成功才写入，重复地图编号保留为副本，冲突分类另建编号。版本只支持当前结构。

“用于战役”保存地图并返回自定义战役配置。战役草稿、开战状态与游戏存档携带完整地图快照，开战后锁定；之后编辑、改名或删除地图库原图均不改变已有战役，重试、读档和回放沿用原图。绘制结果直接驱动真实通行与AI寻路。

当前自建地图用于独立自定义战役。全国模式仍按真实道路、交战地点和固定内置地图选图，自建地图不会自动加入全国轮换。

## 验证

`npm run test:map-editor` 验证用途与逐格地形独立、通路与城门校验、编辑历史、导入原子性、存储失败保护、实际水陆战斗及确定性续战。

`npm run verify:map-editor` 验证真实页面的绘制、拖刷、键盘、道路、预览、自建分类、持久化重载、地图导入导出、无效导入保留原库、手机布局、实际开战，以及删除原图后的战役读档。截图和结果在 `outputs/battle-map-editor/`。
