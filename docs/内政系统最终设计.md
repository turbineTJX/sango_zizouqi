# 内政规则

本页是当前内政设计入口，与[六方向规则](内政六方向-规则56.md)共同使用。具体数值以正式设计表为准。

## 委任和执行

| 方向 | 唯一主属性 |
| --- | --- |
| 商业、农业（两个独立方向） | 政治 |
| 军务 | 统率 |
| 武备 | 武力 |
| 技术 | 智力 |
| 人才 | 魅力 |

玩家选择方向和负责人，武将自动拟定具体事务，付费事项由玩家裁示后开办；同方向全部事务使用对应单属性与适用特技。玩家推荐、成功率、协作和战略AI选人共用规则，不混入其他属性。

同城同方向可多人委任，每人一个方向、独立记录正在办理的事务及进度。同方向可自动协作；资源、建设队列、研究槽和目标占用仍须实际满足。具体事务见[动作一览表](design-tables/内政动作一览表.md)，自动选择见[选事规则](design-tables/内政自动选事规则一览表.md)，协作见[协作机制](内政协作实现与验证.md)。

## 提案与成败

默认逐案裁示。需要支用金、粮或预备兵的事务先呈案，显示执行武将、实际地点、事务与目标、预计用度、时间及成事把握；用“颇有把握”“有望奏效”“尚可一试”“成事不易”“恐难奏功”表达判断，不显示概率。玩家可准奏或暂缓，亦可在城市内政或统一内政开启全势力自动准奏。免费集市、督耕及常规兵源征集自行开办，已付费工程和研究接续无需重新呈案。

待批原案占用相应工地、研究槽及目标的拟办资格，尚未扣款、创建工程或推进研究。世界在待裁时暂停，关闭窗口仍保留提案。准奏复核真实驻城、等待军令、围城、地点、目标、费用和库存；变化时不能以另一事项、地点或更高费用代替原案。暂缓保留原任职、本旬不再呈案；人员改令或城池失守撤案。多项提案的预计金费进入本城预算，开办后不再次计入未开始支出。提案、准奏方式及每日裁示记录随当前存档保存。

所有事务按各方向唯一主属性、适用命令特性及事务风险计算成败，仍有不成功的可能；成功、部分成果和失败按真实成果结算。普通失败不退回已消耗费用，无成果不发功绩；购粮未成交及未使用整补费按原规则退还。工程受阻保留实际耐久，按工期延期且不追加费用。研究在每轮开始保存随机结果，失败轮次无研究进展，不解锁技术，已有进度及费用保留，下轮免费接续；查看或读档不重抽。本轮成败参数由 `data/design/domestic-actions.mjs` 的 `DOMESTIC_OUTCOME_RULES` 统一提供。

聘请名匠、仿制改良等研究机会须在实际工作日仍有效。机会失效后立即结束本轮，不再增加研究进度或发放进度功绩；报告保留此前真实完成的进度与已付费用，后续研究免费接续。机会到期当天仍可办理，实际达到所需进度时正常解锁并清空研究项目，不留下满进度但未解锁的状态。

运行 `npm run test:domestic-proposals` 与 `npm run verify:domestic-proposals-ui` 检查裁示、预算、成败、接续、读档及桌面和手机布局。

## 建设与运营

办事过程中可触发内政纪事。亲密武将同城同岗办理同一事务时，可有「同心协力」提高双方本轮成事把握与成果；厌恶者也可能「相互掣肘」。跨领域意外不受报事人的方向限制，商业负责人也可发现农事或军营问题，事件有好有坏，以具体同城人物故事呈现，可能改变真实金粮兵库存和当事人交情，或影响实际在办项目。正面故事以大额私资、私仓馈赠或整批乡勇投效增进友好度，负面故事导致损失与嫌隙。每势力每旬仅一次3%总判定，城市和委任数不增加机会，成功后最多一项纪事；馈赠不占日常运营额度，但至少能接收基准奖励75%时才抽取，仓储和兵源上限正常生效。资源和交情一次结算，结果、来源和前后凭据保存，纪事先进入每日记录再以重要奏报汇报，确认不改变结果。内政页可查看本轮事务效果与已发生的故事；详见[协作与随机纪事](内政协作实现与验证.md)。

城市已完工设施形成基础产出，武将的太守任职、阶段经营及直接事务形成额外运营成果，两者分别显示和验收。建设比较完成同等工程量的实际人员时间；市场、农田、兵营另比较新增永久产值与净建设费用。普通施工受阻按原工期50%延期，命令特性可改变延期，接续不重复收费。运营比较同设施、同能力和需求下扣费后的日历净收益，排除城市基础；直接成果完成时已入库，旬末不再次支付。当地设施提高的潜在运营额度不视作已经获得收益。具体数值、城市圈承载与独立实测见[经济平衡规则](单城资源与经济调整-2026-09-22.md)。

## 中断、驻城和人员移动

- 城内预编与内政任职独立。太守、负责人可以编制部队，预编不取消任职、不打断事务。
- 改任、解除、调任或出征影响事务时，选择立即执行或完成当前事务后执行。等待命令保存，等待者不开始下一项事务；实际执行时重新校验。
- 实际参战守城者中断当前事务、取消相关等待军令并保留任职；其他人员遵守围城暂停规则。
- 内政资格按实际驻城、出征和移动状态判断。赴访、返程、调任、招募赴任均实际移动，不能瞬移。
- 详见[中断与命令](内政中断与后续命令.md)、[守城与内政](守城预编与内政兼任.md)、[人员移动](人员移动与战后去向.md)。

## 成果与特技

成果必须经过真实结算；救治受真实伤兵约束，仓储受容量约束，征募受资源与额度约束。失败、无成果和重复结算不凭空提供资源或功绩。事务特技按本人执行的动作生效；太守效果须明确太守职责，同名不叠加。

日常集市、督耕和常规兵源征集可在府库见底时继续办理，按共用能力倍率折算近似资源价值；设施建设和实际装备仍收费。军务在缺兵源时征集库存，兵源充足时按真实费用补充部队；全体医疗目标共用一次办理的救治额度。编制、补兵消耗金和储备兵，不扣粮；现役部队随后实际耗粮，战损减少现役士兵。未编制兵源不耗口粮、不轮换、不自行减少，当前无定期军费。详见[经济平衡](单城资源与经济调整-2026-09-22.md)。

设计增产、节粮、征募、运输能力时同时核对金、粮、预备兵、持续损兵补充、留守和运输成本，不能把开局库存当成长期产出。详见[经济规则表](design-tables/经济规则一览表.md)和[单城资源目标](单城资源与经济调整-2026-09-22.md)。

## 都市圈与建设地点

全国地图的小城、关卡、港口按实际道路行程距离归入最近的大城，等距按城市ID固定排序，野外路口只用于通行。成员列表在内政和设施面板显示并可直接定位。小城保留独立人员、资源与内政；关卡和港口只承接大城建设，不另设太守、独立资源账本或人才驻城。

大城负责人在主城及圈内同势力、道路可通行的地点自动建设。选址权重由 `data/design/metropolitan-areas.mjs` 维护；城墙固定在被防守的主城。每城仍只办理一个工程，每个实际地点同时只承接一个工程；每次新增设施等级保存实际地点，城市设施总等级和经济收益仍按共用规则结算。同类设施可分布在多个成员地点。

敌方小城、围城、交战或敌军封路均阻止开工并暂停已有施工；已付费用与进度保留，恢复通行后在原地继续，不自动迁移、不重复收费。小城失守时，已建成的当地设施移交该城，原大城不继续获得这些等级；小城本地及圈内外建设施共占该地点上限。未完工工程保留原址，待条件恢复。主城失守沿用取消事务与工程的规则。初始设施位于本城，新建和扩建可分布到圈内地点。当前战略存档版本53、内政版本19，旧档重新开局。经济设施按小城2、普通大城本地3、富城本地6、圈内单类总量最多12限级；外部地点另按类型限级，具体见[单城资源与经济平衡](单城资源与经济调整-2026-09-22.md)。

## 空闲人才定位

右上「自辖城市」显示己方城市总数及有空闲武将的城市数。城市列表按真实可用人员状态区分：有空闲武将用金色高亮并优先排列，无空闲武将用灰色显示，灰色城市仍可选择。可筛选「有空闲」，按城市或空闲武将姓名查找；点击立即定位实际城市，列表继续保留，桌面与移动端均可逐城切换。所选城市显示完整空闲姓名，可直接进入「安排事务」，或查看详情与管理。内政委任、解除任职、调任、随军、外出、等待命令及城池归属变化后，从实际状态重新计算人数与颜色；浏览、定位和筛选不推进日期、不修改任职或军令。详细据点列表沿用同样的高亮与灰色。

空闲判定复用城市内政统计：实际在城、没有内政任职、太守职责、军团任务、外出任务、在途任务或等待命令；已编制为城内部队不会被排除。在野人才不算己方待安排人员。

## 城市外观与城内查看

战略地图的城市、关卡、港口外观从本地点的真实设施等级生成。施工动画、脚手架、进度和完工外观在实际地点更新，不在主城重复绘制。建筑详情显示地点、都市圈和建设城市。城内使用平原、山地、江南水岸与西北四类原创地形，以及大城、小城、关卡、港口四类独立建造空间模型：大城有城墙、街巷与住宅街区，小城为紧凑民居与低矮围墙，关卡沿隘道和关墙布置，港口沿码头和岸线布置。住宅和道路构成聚落底层，十二类真实设施作为独立模型叠加，表现木梁、瓦顶、石阶、庭院与日常器具；地点ID固定建筑位置、朝向和间距，规模决定占地，所属势力与设施升级不改变地点布局。市场、农田、粮仓、工坊、兵营、医馆、校场、城防工事、招贤馆、箭塔、军乐台和救护营随实际等级扩大，三级、五级增加对应附属建筑；粮仓存粮、城门耐久、当前事务及有效增产措施也反映到模型。未建设施显示空地，正在建设或扩建显示独立施工模型和办理进度，中断或暂停保留工地，只有真实完工才提升外观等级。建筑名称在悬停或键盘聚焦时显示。

主图按都市圈、圈内据点、城内三级连续细化：缩远显示都市圈范围示意、名称与成员概况；放大时都市圈与据点在交叠区间逐步显隐，展开主城、小城、关卡、港口及真实道路；继续放大时保留原地图地形、道路与相邻聚落，在原坐标展开建筑，当前地点才开放建筑交互。远景和近景共用建造空间及设施位置、尺寸，不能在层级边界替换为独立矩形城内画面；缩小按相反顺序连续收拢。工具栏「都市圈」「据点」「城内」可定位对应层级；都市圈标记支持点选和键盘 Enter 展开。竖屏与横屏共用层级判定，都市圈展开按真实成员坐标适配视野。城市菜单「查看城内」仍直接定位。点击建筑或用键盘聚焦后按 Enter 查看等级、效果、工程状态、库存、耐久和对应事务；缩远或按 Esc 关闭详情。全国雷达、主图平移、操作中心和选路使用同一地图坐标与层级；展开都市圈只改变视野，不选择行军目标或改变待下达路线。模型仅从当前数据绘制，无额外建设操作；存档读取后按保存地点重建相同设施外观、工程和动画状态。

城内建筑显示在实际地点办事的武将头像，包括施工人员；外出或随军人员不在原城重复出现。点击头像直接打开武将每日行动记录，多人办事时建筑详情提供完整名单。头像与记录共用实际状态，查看不修改历史或推进日期。

## 每日记录与战略奏报

战略重要奏报从每日记录的真实事项节点选取，包括建筑完工、技术突破、人才发现和签约、离职预警、灾情、工程中断或受阻、战果、城池得失和人员伤亡被俘；普通开工、日常收支与待命不弹奏报。结果先按发生顺序写入每日记录，奏报直接引用同一节点，不从状态消失猜测完工，也不依赖会截断的内政事件队列。推进时自动暂停，查看当日记录保持暂停并返回奏报；确认或关闭奏报后继续推进。确认仅持久标记节点已读，原始记录不删除，读档不重报；无对应武将的灾情或城池事项保存在据点每日记录，不虚构汇报人。

武将行动记录同时展示实际位置、办理状态与当日结果，关键事项有独立标识；据点详情的「行动记录」提供当地事项，每页30天。节点保存稳定标识、顺序、日期、势力、相关武将及实际地点，随当前战略存档保存；每日记录结构版本2。

签约、设施完工与技术突破在原奏报中展示成果卡。新武将使用签约时的五项能力和特性快照，明确签约时所在地及赴任状态；异地赴任按实际道路进行。设施使用完成时的实际地点、本地等级变化和新增城市基础产出，沿用既有设施图像；技术展示按实际工作日完成研究并生效的城市科技成果。原始办理文字收在「办理经过」，查看武将、当日记录或地图上的实际设施均只读并可返回来源；从设施返回奏报时恢复进入前的地图视野。

普通接洽进度、未达预期和恢复接洽留在每日记录，不单独暂停世界。搜索成功由真实人才发现节点汇报，搜索完成记录不再重复弹出；真实签约、签约暂停、离职警告、工程受阻及研究中断继续提示。城市研究达到完成条件时直接进入技术成果奏报，不依赖武将升级或试制；未完成的一轮研究进度留在每日记录，不单独弹报。

每旬收获使用既有每日记录保存旬首库存和旬末实际结算凭据。汇总金、粮、预备兵时，旬末收入按实际入库计算，直接运营引用此前真实完成入库记录，满仓截掉的部分不计收获，城市易手前已经入库的运营也保留。执行期间各城金合计和己方城仓净变化单独显示，包含实际支出、消耗和城池归属变化。主界面汇总无需领取或确认，成果回看与读取记录不再发放资源。

## 设计来源

动作、建筑、建筑效果、经济和选事规则分别维护于 `data/design/` 对应文件。查看[设计表目录](design-tables/README.md)。表中标为待接入的项目不等于已经改变游戏行为；新机制必须实现处理器并做回归。

箭塔、军乐台和救护营通过守备技术解锁，研究后仍需真实建设。战场按原址已建等级和当前耐久提供射击、鼓舞及真实伤兵救治。详见[内政战场建筑](内政战场建筑.md)。
