# 名将历史协作与战斗定位

规则128以玩家设计的吕布、貂蝉为参照：貂蝉利用倾国降低敌军战意，吕布通过勇武利用战意差。配合范围包含名将之间、名将与辅助武将、名将与美女武将；“副将”指辅助搭档，军团职位仍只有军团长、军师。阵容、兵种、兵力分配、站位和实际施放时机决定收益。队伍不按姓名获得额外倍率；其他合法人物也能利用同样的公共条件。

规则132的阵法试验在保留这些公共协作链的基础上新增开场阵法羁绊。虎翼强化物理主核与护翼、疾翼阵位，龙飞强化谋略主核、镇军和翔翼阵位，三阵互斥。冻结规则132的54局合法布阵对照和18局明确标注的机制消融见[战斗体验试调记录](战斗平衡优化目标.md)，不沿用此前参数下的胜率或回归数量。

## 当前协作链

| 班底 | 战斗分工 | 当前机制 |
| --- | --- | --- |
| 吕布、貂蝉 | 单队主核、削战意辅助 | 倾国削战意，勇武利用战意差增伤及免伤；保留用户原设计 |
| 刘备、关羽、张飞 | 续战支援、乘隙爆发、先手控制 | 张飞65战意施放，混乱基础6回合；关羽利用已有混乱、迟滞或破甲增伤；刘备救伤、桃园共同维持阵线并响应实际溃败 |
| 司马懿、张郃、郭淮 | 压制与铺垫、物理收割、前排承伤 | 鹰视狼顾降低战意并附加疲弱与破甲5回合；张郃锐锋利用受损敌军，郭淮护卫与抗骑承担前排任务。郭淮不持有济军，张郃不持有远击 |
| 孙策、周瑜、太史慈 | 突击启动、谋略爆发、远程跟进 | 孙策自身速攻，所属军团在场的最多两隊其他友军各获基础20战意；优先补足接近且尚未用尽的战法门槛，没有待补门槛时不授予鼓舞；后备与其他军团不能受益。收益按真实门槛、次数及出场状态计算 |
| 庞统、刘备、黄忠、魏延 | 建立连环、续战、重点狙击、前排输出 | 连环奇计50战意启动，早于黄忠55战意门槛；命中后把至少两队合法存活敌军连接12回合。后续伤害的35%作为总额传导给同组其他敌军，不需火源，不递归。时序仍受真实交战、战意与站位影响，不强制谁先发动 |
| 陆逊、朱然、韩当 | 利用火势爆发、火源与连环、跟进收割 | 朱然火谋普攻先施加灼烧，陆逊对施放前已有灼烧的目标额外增加0.65伤害倍率；韩当可利用远击与锐锋跟进 |
| 曹操、郭嘉及魏军将领 | 全军鼓舞与编制、压战意、前排输出 | 沿用曹操全军支援、合法第七名额与郭嘉压制剩余战法威胁，已有明确分工，不统一提高个人倍率 |
| 周瑜、黄盖 | 火源与利用火势 | 黄盖火谋铺火，周瑜已有灼烧条件加成与火谋组合；保持现有强度 |
| 诸葛亮、赵云等蜀军 | 控制与军略、突入与续战 | 沿用八阵的控制窗口及合法军略支持，赵云利用失阵空隙与相邻实伤吸血；定位为统筹配合，未统一加攻击 |
| 孙权、周泰等吴军 | 全军保护与任职、前排护卫 | 沿用碧眼随真实军略提供保护、周泰护卫。孙权主要收益属于团战 |
| 张辽、李典 | 骑兵主核、入场强化与牵制 | 李典天覆1点、克骑1点；通过实际阵位入场和克骑牵制保留原有分工 |
| 周瑜、小乔；孙策、大乔 | 主核输出、远程启动辅助 | 小乔、大乔各倾国1点、战歌2点；单人战歌可激活第一档，倾国仍需实际合计2点，不因配偶姓名生效。二乔同时在场可激活倾国第一档 |
| 曹操、甄氏 | 全军支援、启动辅助 | 甄氏倾国1点、战歌2点，可支援2格内合法主核或其他队友；这是同阵营战术搭配，不声称两人有史实协战 |

郭淮正式羁绊为护卫1点、克骑3点；护卫保护相邻其他残血友军，不治疗或增加兵力。典韦、许褚、周泰等既有护卫搭档继续使用同一机制。战歌正式档位为2／6／12点，最高档继续至少六人在场；每次有效普攻只支援一次，无需补足战法门槛时按最低战意选择，后备、离场及避战人员不受益。其目标优先只改变支援接收者，不改变战法携带、施放顺序或AI组合规划。

## 历史依据与改编边界

规则128先核对光荣系列机制，再区分史实与演义。正式研究目录 `data/design/historical-cooperation.mjs` 保存26组合作、证据类型、来源、游戏参照和实际公共机制；不会因为出现在目录中就增加姓名同队倍率。本轮新增两种通用战法连携、三名辅助羁绊和四对初始关系，其余班底沿用已有机制。

优先的史实合作包括曹操—郭嘉、曹操—典韦／许褚、曹仁—徐晃—满宠、赵云—邓芝、刘备—法正—黄忠、孙策—周瑜、周瑜—黄盖—程普、孙权—周泰、鲁肃—吕蒙、董袭—凌统及陆逊—朱然—韩当—徐盛。主簿、器重传承、夫妻与同次征战分别注明，不统一解释为共同冲锋。

- 诸葛亮、姜维按历史器重及系列羁绊参照补入亲爱70；曹仁、徐晃和董袭、凌统按共同任务补入友好65。“友好”是游戏设计取值，不声称史书明确写私人亲爱。默认记录只补原本普通的关系，不覆盖原有夫妻、义兄弟、亲爱或厌恶；玩家保存的当前关系优先。来源见[卷44](https://zh.wikisource.org/wiki/三國志/卷44)、[卷17](https://zh.wikisource.org/wiki/三國志/卷17)、[卷55](https://zh.wikisource.org/wiki/三國志/卷55)。

战法连携可由实际支援接续与接应掩护触发，仍须2格范围、短窗口和关系判定。只放大后续已经合法施放的战法，不复制战法、退还次数或替队友施放；完整边界见[战法规则](战法规则.md)。

孙策、周瑜共同征战江东有[《三国志》卷54](https://zh.wikisource.org/wiki/三國志/卷54)的记载；陆逊统领朱然、韩当等抵御刘备见[卷58](https://zh.wikisource.org/wiki/三國志/卷58)。郭淮与张郃合作，以及接受司马懿部署意见的记载见[卷26](https://zh.wikisource.org/wiki/三國志/卷26)。庞统随刘备入蜀见[卷37](https://zh.wikisource.org/wiki/三國志/卷37)，黄忠随军入蜀见[卷36](https://zh.wikisource.org/wiki/三國志/卷36)；“入蜀班底”表示同属该次征战，不声称史书记载了游戏中的两人连环技。

公共状态、战意、羁绊和专属名称均属游戏化表达。史实合作用于选择班底及分工，不用于强制结算、锁定阵容或声称史实兵力比例。

## 边界与验证

- 规则135的局部方向同时覆盖普通将组合和一名名将带普通辅助。虎翼、龙飞按开场占位数逐步发放首发护盾，保留满阵盾量和36回合时长；小队溃败冲击按其相对首发平均兵力折算，给辅助与主核留出发挥已有配合的机会。双方共用，不加指定姓名倍率。具体规则与局部验证见[战斗平衡优化目标](战斗平衡优化目标.md)，不外推为任意普通名单必胜或全局验收要求。

- AI策略与评估继续忽略羁绊，战法顺序、目标与军略固定触发规则照旧；双方实际战斗结算相同，不新增组合搜索。
- 保留战法浪费在免疫或无敌目标上的既有设计。新增连环不能把死者、免疫者和不可选中目标接入，也不覆盖已有连环组；这是效果结算边界，不是新增施放避让策略。
- 机制测试通过真实持有者的当前战法与公共战斗流程制造铺垫，核对另一人的实际后续事件；包括双方交换、控制保护、连环非递归及确定性续战。入口为 `tests/historical-synergy.test.mjs`，相关名将、羁绊、特性与引擎回归一并运行。
- 平衡脚本 `scripts/audit-support-synergy.mjs` 以 `scripts/historical-cooperation-recipes.json` 的12组为输入，在冻结源码上比较双方均使用公开AI军议的完整战斗。各用四组合法名单：普通参照、仅A、仅B、A+B；均为10级、同兵种与18000兵力预算，同组训练费用一致。分别覆盖每队3000兵及主核5000兵、每队辅助1000兵的分配，双方换边，不授予未学战法或免费资源。曹操三名辅助实际占三个名额，对照同样占三个。
- 组合交互量为“A+B−仅A−仅B＋普通参照”的剩余军力差百分点；这是整套人物、羁绊档位及任命共同作用的条件测量，不是通用强度排名、胜率或某项技能的独立因果增益。普通AI布阵也不代表玩家最佳协作操作。
