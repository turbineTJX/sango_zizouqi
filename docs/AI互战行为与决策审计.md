# AI互战行为与决策审计

核对日期2026-10-12。当前势力AI结构14、战略目标结构10、战略存档61；战斗规则版本由 combat-rules.mjs 定义。

## 回合节奏与出兵评估

用户确认第1–20回合为前期，第21–60回合为中期，第61回合起为后期。一回合10天，60天只完成6回合。strategic-tempo.mjs 直接使用 s.turn；行旅、工资、口粮与征补仍逐日执行。前、中、后期集结上限为1／2／3回合，真实容量不足时缩回一回合。前中期最多一项进攻；后期至少四城、两座可负担城市、十队合法可用编组，支持每军团最多六队共同出征，以及主攻出发后使用独立兵源城的第二战线，最多两项。第二路也经过当前注册的目标评价器和选择器。

出征综合评估逐城真实库存、工资与承诺、留守稳定产出、已开始运营、安全在途物资、真实后续征补额度及预计回城后两旬整补。武将属性、适性、固定已学战法、装备和实际任命使用 static-v2-no-bonds；敌方只来自可见军团及带日期的合法城市情报。未知与陈旧情报不能获得整补余力优惠。新鲜城市报告中的金粮仅作有界目标收益，不提前加入己方预算或军粮。实际兵数、粮耗、战损和补兵仍由双方共同执行器结算。

## 战斗偏少的瓶颈与修正

自然第44回合的诊断中，各势力已有22–55队可用编组及可负担城市，仍频繁选择发展。原因包括大编组每队固定900粮，7000–9000人部队只够约10–13天；时间评分每一天计4分，实际应每战略回合4分；粮耗每100粮扣一分，显著高于共同经济参考价值；已经集结后的补兵仍按原始来源城检查，以及短计划期限挡住实际行程。

新编军团由玩家与AI共用 armySupplyCapacity，逐队取 max(900,ceil(现役/100＋伤兵/200)×30)，9000人一队容量2700粮。装载从实际来源仓库扣粮，容量不会产生粮；现有军团保存容量与携粮，途中不免费扩容，拆分合并守恒。路线预测逐日检查真实道路、仓库吞吐、去程停留返程及有限断供段，排除出征部队在来源城的重复口粮。

时间评分改为每回合4分，粮耗按每粮0.13金、每50金一分折算；真实耗粮与工期不折减。按军团实际返城据点评估整补，未来旬额度不重复扣本旬保留额度，可留存补兵金与固定收支缺口受可选内政预算保护。持续优势比当日出征门槛低0.2、最低1.1；实际供给、胜算或整补失败仍回撤。完整公式见 [AI架构与决策评价方法](AI架构与决策评价方法.md)，执行结构见 [势力AI与跨旬作战计划](势力AI与跨旬作战计划.md)。
