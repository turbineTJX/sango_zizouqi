# AI互战行为与决策审计

本页维护当前执行规则、复核入口与尚待验证的范围。实际版本见[当前版本验收与体验目标](当前版本验收与体验目标.md)。旧版对局、通过数量、战争节奏和统一成绩不并入当前源码的验收。

## 当前执行

- 2026-11-04：内政任职与跨城调任改为规则匹配。先按真实需求确定方向，再按资质和来源顺序检查，共同资格通过的首个人选即执行；不再对全部人员与全部岗位交叉模拟后取最高分。实际在办工作、前线守备、粮食和调任旅程继续复核。行为修复层及独立自然短窗保护与长期战略表现分别记录。
- 只读人员预览复用不变的全国都市圈和道路几何，城市对象按各自预览重新绑定。供给搜索用最远可胜出的供给率界限排除无用遍历，保留真实仓库选择、并列道路、封锁、共享吞吐和实际扣粮。该部分以新策略下逐日完整存档一致性及独立距离对照验证，不以减少交战或供给需求制造性能收益。
- 玩家与AI在每旬初筹划。出兵、撤军、侦察、人员与运输、整补、外交批准、宝物及内政任命使用各自合法情报和共同执行入口；旬内只执行已保存的军令及共同结算。
- AI按当前人员、真实兵粮、道路、守备及战损后整补能力准备进攻。预备兵当下为空不等于无法补兵，须核对实际返程前的有限生产；未来资源只用于评估，未实际入库不能花用。
- 分步集结按实际缺口、到达日期、来源守备与驻留成本逐旬复核。真实人员沿道路调任，各军团保留实际基地与补给账，抵达后才能进入援军流程。
- 前线人员、实际运输与必要经济人手受共同资格保护；安全后方无任务、无实际威胁时目标为一队，每队补至1000，不强制裁减既有军队。
- 攻城器械须用可见目标的真实城门收益抵偿往返行军损失。无城门或不划算时不为满足旧测试而配备器械。
- 未交战军团可在旬初沿实际路线改令或回撤。交战军团继续由共同战场规则处理，战略评审不直接改写战场撤退标记。
- 战略评估和战斗AI不规划羁绊；军略按固定条件与顺序触发。双方偶然形成的羁绊正常共用结算。

## 复核入口

1. `npm run test:ai-decisions`：21类具名决策行为，失败、跳过与未通过的必需用例分别记录。
2. `npm run audit:player-ai-decisions`：页面声明与共同入口覆盖；不代替行为或信息隔离检查。
3. `npm run audit:all-ai-decisions`：原始全国剧本、普通迷雾与内政意外，记录真实出征、交战、空城接收、缺粮及完整存档确定性续行。
4. `npm run audit:ai-local-loop`：四城与六城的登记诊断输入，观察出兵、占城、新城再利用与连续进攻；不充当全国自然统一。
5. `npm run verify:natural-completion -- <运行目录1> <运行目录2>`：至少两个剧本、两个种子的当前输入、真实统一、完整存档与长局性能。

机制测试按当前合法前置条件固定接触，保留费用、资源守恒、情报隔离和存读档检查。自然审计不注资、不指定战争或战果；只认绑定其冻结源码的实际记录。测试夹具失效与机制失败分别定位。

道路迎击与护路复核共同承认实际出击军团及已保存出征命令所保护的原城可见威胁；任务自身不构成威胁，也不依赖另有运输队。已有承诺足够迎击时不重复派出守军。威胁消失后等下一旬沿实际道路收兵，旬内不改令。检查见 [macro-defense-lifecycle.test.mjs](../tests/macro-defense-lifecycle.test.mjs)、[macro-defense.test.mjs](../tests/macro-defense.test.mjs) 和 [macro-defense-boundaries.test.mjs](../tests/macro-defense-boundaries.test.mjs)。

## 同旬决策衔接

- 调任人员到任后，普通农商优先分配、太守选任和额外岗位不占用尚未完成首项真实事务的承诺人员。已有合法岗位与事务继续通过共同入口办理；当前方向无合法工作时仍可释放。
- 真实口粮救急与未来满编产能预测分开判断，使用实际驻军口粮、本城存粮及能在断粮前到达的真实安全运输。确需改任农业时，先完成共同任命校验，再解除原调任承诺并记录告急城市、原方向及实际钱粮依据；失败不解除承诺。
- 某城缺粮只解除实际占用该城现有人员、预留粮或待执行出征命令的进攻计划。单纯的历史来源城不代表当前仍有资源占用，其他独立战线继续执行；原有站岗、回撤、补给和旬初决策边界保持。

策略选人位于 [domestic-staffing.mjs](../ai-policy/domestic-staffing.mjs)，共用口粮判定与依赖核对位于 [food-relief.mjs](../ai-policy/food-relief.mjs)。回归见 [same-turn-coherence.test.mjs](../tests/same-turn-coherence.test.mjs)，覆盖首项真实工作、实际工期、救急解除及原因、及时运粮、无合法工作释放、独立战线与存档续行。

## 当前待验证范围

持续进攻、长途返程供给、新城再利用、真实多军团同侧参战、中后期节奏及统一收尾，仍需在当前组合上分别留证。短窗无缺粮、局部闭环成功或回归通过，均不足以证明全国长期表现。

近均势战损、攻城、临时动员与援军的预测需按实际对战独立校准；不能以降低预测损失或强制开战制造活跃。胜负、战损、费用和玩家空间分别评价。

战略修复采用与回退按[AI自主迭代与验证规则](AI自主迭代与验证规则.md)执行；战斗候选按[战斗AI循环验证设计](战斗AI循环验证设计.md)复核当前组合。已验证但未接入的候选不算正式游戏行为。
