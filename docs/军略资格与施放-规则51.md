# 军略资格与施放（规则51）

## 资格

仅基础智力≥70的武将拥有军略。门槛对军团长和军师一致，低于70者即使任军团长也没有基础保底军略。副将仍不提供军略。

基础智力读取固定武将资料，不随升级、兵种或读档改变。合资格者沿用原有名额：通常2项，诸葛亮3项；专属占名额，同名军略不叠加，选择合资格来源中较强者。强度仍由统率和智力计算。

资格根据正式武将基础智力实时校验，具体持有者见[武将表](design-tables/武将一览表.md)。

## 施放

点击战斗底部军略入口，暂停战斗并打开“选择军略”弹窗。全部可用军略直接列出，不分分类页签。每项显示名称、实际提供者、按其能力折算的效果与持续时间。

选择一项即沿用引擎验证并施放，成功后关闭弹窗；取消不消耗进度、不改变战斗状态，保持暂停供玩家继续观察。进度不足、布阵中、冷却中或本场次数用尽时不能施放。没有合资格提供者时明确显示无可用军略；全军撤退仍作为免费基础军令提供。

施放界面不分类，不改变引擎内部的效果类别、强度权重或AI判断。双方使用相同资格与结算规则，在场智力积累军略进度的规则保持不变。
