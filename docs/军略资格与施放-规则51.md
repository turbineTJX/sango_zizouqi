# 军略资格与施放

全游戏统一15种军略，不再区分基础与专属。资格以明确人物名单为准，取消统一智力门槛；仅分配给有统军、谋划、军队组织或宗教领袖表现者。当前832人中49人持有，通常每人1项，诸葛亮2项。孙策可凭统军表现入选；张飞、甘宁、王平无军略。名单与实际分配共同校验，升级、兵种、转投与读档不重抽。

军团长和军师提供本人军略，其余武将不提供。部队须存活、已经实际抵达、在场或后备且未撤离；未到援军、零兵、离场者不提供。同名军略只取当前合资格来源较强效果，不按人数叠加。已有状态不因提供者离场取消。名单与势力分布见[军略与任职](军略池与任职-规则45.md)。防护和雷火均为玩法抽象，不声称人物具有超自然能力。

## 三种强机制

奇兵天降一次额外投入1～4支已经抵达的真实后备部队，使用共同入场、合法地形与空位、首次入场能力和羁绊处理；不改变单军团十队上限，不令未来援军提前抵达。玩家按既定队列投入，AI按共同后备排序。额外名额绑定这次实际投入的部队；该部队溃败或离场后名额随之消失，不能继续替补额外名额。可突破十面埋伏的补位封锁，正常补位仍受封锁影响。

重整旗鼓刷新己方已经抵达且仍在场或后备的存活部队全部主动战法次数，包括专属及整备类战法，恢复至当前合法上限；按施放者系数缩短20%～80%的剩余战法冷却。保留既有施放次数、贡献、战意、调息和正在施放的战法；增加独立军略补次记录，不把历史施放次数清零。不刷新军略、常驻光环、未到或已离场部队。此军略是[普通补次边界](战法次数与整备-规则48.md)之外的明确例外，每场只能施放一次。

天雷地火全战场随机8道雷火，每道影响半径2格，敌我皆受影响；相同部队可被多道命中。伤害基准为被击部队初始兵力25%×施放者系数×75%～125%浮动。先抽完整落点与伤害浮动，再按共同伤害流程结算，整批结束后处理溃败冲击。护盾、无敌、魔免、勇武和桃园分担正常生效；不命中后备、离场、避战部队或建筑，不给友军伤害计杀伤功绩。潜行部队可能被随机区域命中，实际受伤才显形。

## 玩家操作与保存

点击入口暂停并直接展示完整可用列表，显示实际提供者、统智、效果、冷却及限次；雷火明确提示不分敌我。满条可保存等待时机，成功施放清空进度，不能储存多次。范围军略选择落点、预览有效部队、确认施放；取消、Esc、查看和无合法目标均不扣进度、不推进战斗。八阵允许空地布置。全军与随机全战场效果选择后直接施放。

圆形半径2格，火烧连营为4×3矩形可旋转。几何、预览、AI及结算共用。救治仅恢复在场部队本场伤兵，不复活、不凭空补兵；缺粮不被驱散，无敌及魔免不免除缺粮和主动代价。常规状态不追补后到部队；重整旗鼓明确包含已到后备。

独立冷却32～128回合，均长于对应状态的最强时长。施放来源统智、强度、时长、选区、军纪快照、八阵、强军略限次、额外出场名单、战法补次及雷火实际落点与浮动均随当前存档保存；暂停和读档不重算、不延长、不重抽。只支持当前规则存档，不迁移旧档。双方、普通模式与独立战役共用。AI保持[固定触发](军略AI固定条件触发.md)。
