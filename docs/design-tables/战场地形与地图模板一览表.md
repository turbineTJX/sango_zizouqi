# 战场地形与地图模板一览表

正式来源：data/design/battle-maps.mjs、data/design/battle-map-categories.mjs、data/design/battle-terrain.mjs，已接入共享引擎。21张内置模板（15张普通地图与6张历史地图）按野战、攻城、关卡、港口、水战用途分类；历史战场放在相应用途下。分类不限制逐格地形，每张图使用14×8六角网格。战场编辑器支持自建分类、逐格绘制、撤销重做、通路校验、独立本机地图库及JSON地图包导入导出；自建图用于独立自定义战役，开战保存完整快照。详见[战场自定义编辑器](../战场自定义编辑器.md)。

普通模式按实际路段或节点固定选图；港口间水路遭遇为河战，接岸陆路仍为陆战，山道为高地战；抵达港口节点才固定采用湾岸港口，关卡节点采用狭口雄关。携船不改变陆路遭遇类型。山壁不可通行，水面须携船；图上小路仅标示通路，没有额外移动加成。
