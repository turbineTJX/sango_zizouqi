# 人员战后去向与俘虏

数据源：`data/design/officer-fate-rules.mjs`。本页由 `npm run design:export` 生成，请修改数据源后重新生成。内部分类与设计备注不进入游戏界面。

已接入普通模式共同战后结算，玩家与AI共用。野战、攻城、攻下最后一座主城分别采用对应俘虏概率；成功撤走者不重判，外地人员不因势力灭亡被远程俘获。脱身人才独立返回所属城，城失守则返回君主所在城，全势力无主城且未被俘则下野；人才路线允许穿过敌城。

| 参数 | 值 |
| --- | --- |
| deathChance | 0.02 |
| captureChance.field | 0.01 |
| captureChance.siege | 0.05 |
| captureChance.elimination | 0.3 |
| captureChance.transport | 0.33 |
| woundedCaptureRate | 0.25 |
| noHomeWaitDays | 31 |
| ransom.base | 300 |
| ransom.perHighestStat | 5 |

胜方接收未撤离敌军本场遗留伤兵，逐队向下取整，受幸存部队带兵余量限制；同数从原军扣除，仍为伤兵、正常耗粮并待休养。城池金粮兵继续按实际库存与占领保留比例接收。
