## 施放者属性折算

正式参数源为 data/design/stratagem-attributes.mjs；各项权重与主要缩放轴取 weights、scaling。系数为2^((统智综合值−reference)÷doublingPoints)，按min／max截断。强度类改变效果量，状态类改变时长，奇兵改变额外投入队数，范围、限次和冷却保持设计值。详见[军略强度](../军略强度与持有者-规则46.md)。

| 参数 | 值 |
| --- | --- |
| reference | 80 |
| doublingPoints | 20 |
| min | 0.5 |
| max | 2 |
