## 战争迷雾与侦察

| 参数 | 值 |
| --- | --- |
| city | 22 |
| army | 20 |
| scout | 36 |
| unknownDefense | 6000 |
| unknownGateHp | 15000 |

全国地形默认已探索；视野半径以地图坐标计，未侦察防守和城门参数仅用于AI估计。负责人在城工作，模拟斥候按独立的每日行程沿路移动，玩家与AI共用；每日行程=105。遇到据点和军团立即获取情报。

## 侦察视野持续时间

| 参数 | 值 |
| --- | --- |
| minimumDays | 1 |
| baseMaximumDays | 2 |
| intellectExtension | 4 |
| randomSpread | 2 |

随机范围：上限=ceil(基础上限+智力/100×智力延长天数)，下限=max(最低天数，上限−随机跨度)。斥候经过的区域立即点亮，智力越高持续越久，到期恢复灰雾。
