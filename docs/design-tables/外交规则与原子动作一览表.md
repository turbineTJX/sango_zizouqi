# 外交规则与原子动作

数据源：`data/design/diplomacy-rules.mjs`。本页由 `npm run design:export` 生成，请修改数据源后重新生成。内部分类与设计备注不进入游戏界面。

玩家只定方向和负责人；后台组合完整方案，玩家最终批准后才签署与实际履约。AI共用资格、预算、出使、签署与交付，仅用君主评分替代其自身批准。
