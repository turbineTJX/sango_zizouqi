# 宝物系统

更新日期：2026年10月31日。当前战斗规则138、战略存档71、宝物登记4。本文记载当前已实现规则，目录及参数以正式设计源为准。

宝物提供两种互斥的作用：提高持有者已有的一种羁绊等级，或在持有者部队首次实际上场时给予一种限时增益。当前共70件（武器30、坐骑10、其它30），19件羁绊宝物、51件入场宝物。每名武将按武器、坐骑、其它各装备1件，最多三件同时生效；每件宝物在一个游戏世界中只有一个实体。宝物帮助补足组合或建立短暂优势，名将特色、多人羁绊和军略仍承担主要战斗强度。

## 持有、分类与国库

每名武将最多持有并装备三件宝物，武器、坐骑、其它各一件，三件同时生效。武器包括目录中的名剑、刀、矛、戟、弓、锤和白羽扇；坐骑包括九匹马与四轮车；兵书、医书、地图、铠甲、羽衣和玉玺等归其它。宝物自身的效果类型（羁绊／入场增益）与装备类别独立，分类由 treasure-equipment.mjs 按正式目录类别统一确定。

未授予、主动收回、被同类替换的宝物统一放入所属势力国库，国库按势力登记，不依附君主或某座城市。发现和战后缴获取得的原物先进入国库，再在筹划阶段授予。开局按既定人物归属逐件处理，只有同类冲突的余件进入所属势力国库，不能形成额外实际装备。

同一件宝物只保留原来的一种作用，不提高五维、兵种适性、带兵上限、首发名额或战法次数。两个不同羁绊宝物可以同时贡献，但仍共享个人总六点和单项三点上限，人数门槛照旧。同名增益按实际来源独立保存和到期，不叠加幅度。

## 授予与同类替换

地图“宝物”与武将“授予与国库”使用同一管理界面，可按武器、坐骑、其它和国库、已授予、随军锁定、随俘封存筛选。先选宝物，再从本势力合法武将表选择接收人。该类空闲时确认后直接授予并装备；该类已有宝物时，明确显示将替换的名称及“原宝物归还国库”，由“确认替换并授予”提交。取消、查看和重新选人不更改原物。

替换只影响同一类别，另外两类的原物和装备不变。确认时共同处理器重新校验实际归属、双方人员和军事占用；非界面调用同样必须明确指定 replace，不能默默替换。同势力未出征武将可跨城立即授予；内政、侦察和非军事外出人员仍可接收，不创建运输队或移动人员。

随军、参战、撤离和军事返程期间，三类装备均锁定，不可远程授予、收回或换装；城内预编不锁定，军团暂驻己方城市须实际交接回城后才解锁。合法收回直接进入势力国库，不再存在单独卸下后继续收藏的状态。

## 势力灭亡

普通城池易主不转移势力国库。失去最后一城时，国库、该势力武将装备和随俘封存的已知原物统一移交攻灭该势力的一方国库，解除原持有者的装备引用，只结算一次。尚未发现及不投放的宝物没有势力所有权，不作为战利品凭空发放。

若该势力还有另一场进行中的战斗，原物归属及该战场装备同步更新，仅清理相应宝物入场状态，不影响其他来源增益。已结束战斗与已记录的历史画面保留原时点装备，回放按实际步骤记录之后的变化。人员去向仍沿既有共用流程结算，不额外俘虏或招募。

47件装备提供原生陆战模型外观：30件武器、九匹马、四轮车、六件铠甲及凤凰羽衣。武器改变代表主将的持械造型，包含白羽扇、双铁戟、流星锤；不同铠甲使用明镜、札甲、锁子或鳞甲装饰，羽衣增加披风；名马改变代表骑兵的马色及造型，步兵显示随队名马；四轮车显示随队四轮指挥车。三类外观可同时组合，其他士兵保留兵科辨识。登船或展开攻城器械继续使用真实船只、兵器形态。外观只读装备ID，不改变兵种、通行、属性、随机数或结算。

## 羁绊宝物规则

每件固定提高一种低级羁绊1点。仅当武将当前已经获得该羁绊至少1级时生效；预设拥有但本级尚未获得，或根本不在本人预设名单中，均不生效。宝物不授予新标签、不改成长轨迹，不用来提前获得高级资格。

个人战斗贡献点数为“当前原生等级＋宝物1点”，单项最多3点，装备后的个人总贡献最多6点。允许临时超过本人该项预设成长上限，但原生等级、个人成长上限和升级记录保持原值；卸下、丢失或失去在场资格就移除这1点。原生3级持有者已经到达单项上限，装备对应宝物不会再加点。

为保留当前组合的人数成本，接入宝物时须明确增加档位人数复核：第一档至少1名、第二档至少3名、最高档至少6名当前已获得该羁绊的真实在场持有者；点数和人数同时达标才激活该档。现有最低人数主要由正式分配和点数门槛保证，宝物引入后不能继续只靠点数间接保证。该复核由双方共用的羁绊计算执行，不虚构“宝物提供一个额外人头”。

同方同名羁绊的宝物额外贡献最多1点。当前19种羁绊各对应一件宝物，扩充目录仍保留此限制。后备、未抵达援军、疑兵、零兵、溃败和已离场部队不贡献。换兵种、展开器械或登船不改变点数；军阵等入场效果仍按首次实际入场的合法档位保存，不因后续凑回档位重发。

六种高级羁绊——勇武、倾国、桃园、深谋、蓄锐、背水——均不接受宝物加点。当前目录覆盖下表19种已有低级羁绊，仍不新增控制、战意或高级组合来源。

### 点数示例

曹操本级已获得智略1时，装备孙子兵法可贡献智略2点，达到第一档；若本级智略仍为0，宝物不能使其提前解锁。吕布满级有锐锋1，装备泰阿剑后贡献锐锋2，单人仍不够锐锋第一档3点；不能因此增加勇武。

三名强攻持有者原生合计5点，其中一人装备赤霄剑可达到6点第二档。两名持有者即使原生合计5点、加宝物后6点，也只能按人数条件停在第一档。五名持有者原生合计11点、加宝物后12点，仍不能激活最高档；六人原生合计11点时，宝物才可补到最高档。

宝物提升的是共享组合的一个点，而非令本队直接拥有对应最高档。对同方其他持有者的增益，仍由已有羁绊的受益资格、范围和档位处理。

## 入场宝物规则

只对装备者本队生效。首发在布阵确认并实际开战时触发，后备和援军在首次合法补入战场时触发；编组预览、战前拖动、未到援军、未上场后备不提前授予。

每件宝物、每支部队每场各只触发一次。持续时间从真实入场时刻起计，即使暂时没有交战、没有伤兵、被控制或进入避战，也不延期或重新发放。入场后撤离、被击溃或离场即失去宝物增益，不在后备继续治疗；本场重新出现也不刷新。新战斗重新取得一次入场资格。

沿用状态库的正式名称与公共处理器。奋战、速攻、疾行、穿阵、坚定、远射、阵枢、营垒、坚阵采用现有幅度，靠短时长限制预算；护盾与休整采用下表固定上限。无敌、魔免、神速、伏兵、重击、法球和持续燃击第一版不作为宝物奖励，避免覆盖高级组合、军略或限次入场装备的职责。

同名状态不叠加幅度。与战法、军略或其他来源同时存在时，按各来源保存自身强度和到期时间，当前取仍有效的较强同名效果；弱效果不能覆盖强效果或延长强效果的期限。宝物先到期后仍有效的其他来源照常继续。不同名称的状态沿用既有共同规则，例如速攻与神速的攻速部分取较强者，远射与架设、抛锚的射程部分取最高者。

护盾继续使用独立来源层，优先消耗最早到期层；明光铠来源不能触发护卫满档的破盾免伤。休整按来源计算救治量，不叠加重复治疗份数，不把未用额度存到下一回合或转送友军。青囊书在入场时无伤兵也会启动并计时，不把“有伤兵才开始倒计时”变成延迟发动机制。

入场装备快照按当前实际部队携带的宝物保存，形态变化不重触发。养由基弓的期限继续计时，若期限内切到非远程形态则无射程收益，切回合法远程形态只使用剩余期限。

## 内政事件获取

沿用六方向正常委任和真实事务，不新增“寻宝”命令，不为了宝物抢占农业、商业、人才或外交人员。正常完成且具有成功或部分成果的事务，才可成为发现机会；失败、取消、围城暂停、单纯浏览、免费接续中的重复结果不重复获得机会。

每势力每旬最多进行一次内政宝物判定，在旬末从本旬尚未用于宝物判定、发生地点确有相应类别未发现宝物的合法成果中选择一个来源。候选按完成日期、城市稳定ID、事务稳定ID固定排序，以游戏种子抽选一次；城市或武将多只扩大可能的事件背景，不增加判定次数。无合法候选则本旬不判定，不累计机会；藏点资格仅由事件处理器复核，不向玩家或战略AI提前公布。候选事务及随机结果写入实际记录。

基础发现概率为2%；仅本次合法来源满足下文“眼力”条件时提高到4%，仍只抽一次。内政与战后发现共享“同势力30个战略日最多发现一件未发现宝物”的间隔；间隔内不补抽，期满也不累计次数。此间隔同样适用于找回已经遗失的原物，不阻挡真实缴获、占领移交或随人员转移。概率不随武将五维、君主难度或其他内政特性放大，只有本文明确的两项宝物特技可修正其对应判定。

| 内政方向 | 宝物事件例子 | 倾向候选 |
| --- | --- | --- |
| 商业 | 商旅献器、旧藏售予官府 | 名剑、名甲、名马、兵书 |
| 农业 | 乡民耕地得古器、旧宅修整发现藏本 | 古剑、兵书 |
| 军务 | 清点军库得旧藏、归伍者献兵书 | 兵书、名甲 |
| 武备 | 修缮器具辨出古刃、匠人献器 | 兵器、名甲 |
| 技术 | 整理古籍得兵书、医方传本 | 兵书、医书 |
| 人才 | 隐士赠书、人才到任献藏 | 兵书、医书、名器 |

事件只引用实际完成事务的地点和执行人；人才外出与返程沿用现有流程，不能因为献宝让人瞬间到任。发现的实物留在事件实际城市；外出人员受赠时由本人收藏，未出征者仍可按当前共同授予规则立即分配。

未发现宝物可配置若干地域候选，并在新局生成时固定一个实际藏点城市。例如古剑倾向关中、中原，兵书倾向中原、荆襄、江淮，墨子可放入关中或巴蜀候选。实际发现仅从事件所在城市的合法、当前未发现目录抽取；不读取敌方实时仓库，也不搬走另一城市的藏物。具体藏点须在七个剧本中逐件落到现有城市ID后成为正式数据，不以地区文字作为运行时地点。无合法宝物时不强行补出，不发等价金或保底复制品。

“商旅献器”等均为当前事务成果附带的无额外收费事件，不弹未批准的买宝付款。第一版不设置独立宝物商店、拍卖、买卖或外交宝物条款。

## 战胜后随机获取

只在普通模式真实战斗结束且产生明确胜方后结算一次。须有敌我真实部队实际参战；空城直接占领、运输队遇敌、疑兵、城门单独被毁、平局和独立战役重复游玩不提供随机新宝物。后备未入场或援军未抵达不能制造携宝参战或缴获资格。

### 缴获敌方已有宝物

败方真正参战且本场被击溃的武将，其随身携带的既有宝物可进入缴获候选，包括三类实际装备，不包含势力国库。安全主动撤离并成功离场者不进入候选。

每场基础概率为5%，最多缴获1件；无候选不判定。先从合法候选按种子固定选定一件，再复核胜方是否有符合下文“夺宝”条件的来源；有则本次概率为10%，否则仍为5%。不为寻找加成重新换候选，不增加第二次抽取。先按共同人员规则结算战死、被俘、脱身，再原子地提交宝物归属，人员命运与宝物抽取互不重抽。脱身者失去被缴获的一件，其余随人走；俘虏未被缴获的宝物随人封存、不能装备，赎回后随实际返程带回；战死者未被缴获的宝物变成原战场城市附近的未发现实体，未来可再次被发现，但不复制。

缴获要求胜方有实际幸存且参战的合法来源，来源按战后兵力、稳定ID固定择序；取得的原物直接进入胜方国库，不自动占用来源武将的三类装备栏，不产生人员或运输队。

### 发现战场旧藏

本场未缴获已有宝物，且胜方满足宝物发现间隔时，基础概率为2%；有合法“眼力”来源时本次提高到4%。只从交战实际地点对应城市的未发现宝物中取得1件。来源写为战场旧藏，不写成敌将持有；不能抽取敌方仓库、别处未发现或已经有主的宝物。野外道路交战按现有道路归属的最近城市规则固定查找藏点，不把宝物复制到每个相邻城市。

一次真实战斗的两种随机奖励合计最多1件。缴获不受发现间隔限制；战场旧藏发现与内政发现共用间隔。宝物取得本身不发功绩，使用后产生的真实杀伤、救治与支援继续走现有战斗贡献结算。参与实际结算的每个武将、每件宝物和战斗结果均保留稳定记录，回看战报、导出导入或中途续战不再判定。

单座城池易主不移交势力国库；失去最后一城时按势力灭亡流程统一移交已拥有的原物，不增加随机奖励次数。

## 宝物获取特技

新增两项普通独立特技，名称均为两个字，按人物固定，不占宝物装备栏，不由宝物授予。眼力作用于实际办事及战后发现事件，夺宝作用于真实战后缴获；均不提供战中攻击、防御、选敌或行动优势，不作为新的战斗羁绊。

| 特技 | 作用 | 本次概率 | 固定持有者 |
| --- | --- | --- | --- |
| 眼力 | 本人办理指定既有事务取得合法发现机会，或有真实战斗贡献并存活时辨识战场旧藏 | 发现2%提高到4% | 钟繇、王朗、张华、虞翻 |
| 夺宝 | 本人对本次候选宝物原持有者造成足够真实战损，且对方溃败、本方获胜、本人存活 | 缴获5%提高到10% | 胡车儿、潘璋、韩当、周仓 |

持有者均为现有公共人物库的玩法分配，按稳定ID固定，保留已有特性，不声称存在相应史实特技；不在运行时按五维扩发，转仕不改变资格。

### 眼力

内政仅加强本人主办下表命令时，该次真实成果附带的宝物发现判定，不提高原事务成败率、资源成果或施工进度。各命令仍按原方向唯一主属性、费用、工期和审批处理；协作者、太守或君主拥有眼力不能替主办者提供加成。

| 方向 | 已有命令绑定 | 生效来源 |
| --- | --- | --- |
| 商业 | 举办集市 fair、招徕商旅 merchants | 本人办理完成的商旅、古器发现事件 |
| 农业 | 农田建设 build_farm、整理仓储 store | 本人办理完成的土地、仓藏发现事件 |
| 军务 | 检查整固 inspect、常规修缮 repair | 本人办理完成的库藏、旧器发现事件 |
| 武备 | 城防巡查 patrol、练兵场建设 build_drill | 本人办理完成的营地发现事件 |
| 技术 | 探索未知人才 explore、寻访工匠 craftsmen | 本人办理完成的古籍、器物发现事件 |
| 人才 | 登用在野人才 hire、劝说周边人才 persuade | 本人办理完成的赠书、献藏发现事件 |

成功或部分成果、真实地点存在适配未发现实体、被选为本旬唯一发现来源、发现间隔已经满足，四项条件均须成立。未绑定命令仍按基础2%处理。按事务实际完工时的执行人与特技保存快照，旬末才改变任职或出征不改变既成来源；不能在事后补派眼力持有者重抽。探索未知人才按现有命令属于技术，不改作人才方向。

战场旧藏要求眼力持有者本人实际上场、有真实杀伤、承伤、救治、保护或控制贡献之一，并在战后存活且未被俘；未到援军、未上场后备、零兵及单纯指挥挂名不提供加成。多名符合者只择一保存来源，按真实贡献评分、稳定ID固定择序。此项只改变本场原有发现判定，不新建搜宝任务、不读隐藏持有者或藏点。

### 夺宝

本次候选宝物必须原本随败方某名真实参战、被击溃的武将携带。持有夺宝的胜方武将须实际在场，其部队对该原持有者部队造成的累计真实士兵伤害，至少达到该敌队本场初始现役兵力的10%；战后本人仍存活且未被俘。伤害只计共同处理器归属本人的实际士兵损失，不计护盾吸收、友军伤害、无来源环境伤害、城门或疑兵。

不要求抢到最后一击，但必须有上述真实贡献，不能让未入场者、零兵军师或只挂名的军团长提供缴获加成。多名夺宝持有者符合时只取一名，按对该敌队的实际伤害、稳定ID固定择序；最终仍最多缴获1件，不因人数增加概率或数量。没有可缴获原物时，即使有夺宝也不能生成宝物。

夺宝不提高战场旧藏或内政发现概率，眼力不提高敌方原物缴获概率。两个特技均不缩短发现间隔、不突破全局唯一性、不影响人员战死被俘概率、不自动分配已经出征人员的随身宝物，也不改变军略与战法AI。

### 获取概率与频率

| 来源 | 基础概率 | 对应特技生效时 | 频率与数量上限 |
| --- | --- | --- | --- |
| 内政发现 | 2% | 眼力4% | 每势力每旬最多一次；发现间隔30个战略日 |
| 战场旧藏发现 | 2% | 眼力4% | 每场一次；与内政共享30日发现间隔 |
| 缴获敌方原物 | 5% | 夺宝10% | 每场一次；须有可缴获实体 |

概率修正以单次阈值完成，不失败后重抽，不累计保底。先判缴获，未取得才可进行合法战场旧藏判定，两种战后奖励合计最多1件。各环节均具备候选且不受间隔阻挡时，普通战后的合计取得概率为5%＋95%×2%＝6.9%；两项特技各自同时满足条件时最多10%＋90%×4%＝13.6%。这些是条件齐全时的上限，实际还受携宝敌军、藏点、真实贡献及发现间隔限制。

## 唯一性与人员去向

唯一性的范围是同一新局的整个世界，包含所有势力、在野人员、俘虏、运输、城市和进行中战场。不同新局各自拥有一套目录；不用跨用户、跨存档占用某件宝物。

世界为70件宝物各保存唯一登记记录，状态只能择一：不投放、未发现、势力国库、武将装备或随俘封存。装备字段只引用本人携带的宝物ID；战斗保存同一原物的入场快照，不创建副本。

发现必须先锁定同一实体的未发现状态，再提交地点、持有人及成果；同日多个势力、不同城市事务或两场战斗争到同一件时，按已保存的日期和事件顺序由第一个合法结果取得，后续结果取消，不另抽替代品。改令、围城、夺城、移动拦截及俘虏赎回也只能原子地改变这一条登记记录。

武将同势力调任、随军和出使时，三类装备随其真实位置走；国库按势力保管，不跟君主迁城。投降或正常转仕时，武将仍携带未被依法收缴的原物，不向原势力仓库复制。战死、被俘、全军覆灭及运输拦截均以共用人员和运输结果处理原物去向。运输队遇敌失去宝物时，把原ID标成拦截实际地点对应城市的未发现状态，不额外开启一轮战后抽取，不进入军团战斗。

发现地点、随机结果、转移、装备和缴获历史持久保存；停止使用或丢失不会把当前已拥有的宝物重新放进出世池。变成未发现的原物属于有记录的真实遗失，不能由灭亡势力一键把所有随军、在途和俘虏宝物重置。

## 玩家界面与AI

大地图左侧提供“宝物”入口，显示名称、效果、位置、携带者及装备状态，可按可分配、随军锁定、势力国库和封存筛选。接收人列表列出全势力未出征武将，核阅说明确认后立即授予，不再选择运送人。取消、换人及重载不改变宝物。

羁绊装备显示“智略1＋宝物1”，组合预览分别标明原生点数与宝物点数，仍只按预计首发计算；本级未获得、已达3点或个人总点数上限时说明不生效的原因。档位详情补充最低持有者人数，避免显示点数已经够但档位暗着却没有解释。武将原生羁绊等级不被宝物改写。

入场状态显示“奋战 · 方天画戟”等来源；护盾、休整显示真实剩余额度，不显示内部模拟步。取得宝物进入现有重要奏报及每日记录，读取奏报只标已读，不重新领取或推进日期。未侦察敌军的宝物携带、调配和藏点不显示；已见部队沿用部队情报的公开范围，失去视野保留带日期的旧情报。

AI取得宝物后，优先保留合法原配装。需安排新宝物时只根据单将原生资格、通常兵种和当前是否有空栏按固定排序授予，在全势力未出征人员中选择，执行与玩家相同的授予资格和随军锁定；没有有效收益的人不硬装备。AI不为凑羁绊门槛调整首发、补位或反复交换宝物，不预测替补入场后的羁绊变化，不为眼力改办无实际需求的事务，也不为夺宝改变战斗目标或偷读敌方装备。阵容及配装锁定后，出阵、普攻、战法、军略继续使用当前固定规则；宝物不成为军略优先序或战法施放顺序的新优化变量。

## 独立战役与自定义编辑器

独立战役复用同一宝物目录、装备规则、在场点数和入场状态处理，不连接普通模式国库，不累计随机取得的宝物。新建自定义战役默认双方无宝物，可为武将指定装备；预设历史战役是否加入宝物须另做双方预算与历史方向验证，本版保持六张历史阵容。

自定义编辑器必须跨双方、所有军团、后备及未到援军统一校验唯一性。一件宝物不能由首发和援军同时使用；未上场持有者不提前生效。续战保留首次入场记录，不重新授予BUFF；不能靠重新打开编辑器改变进行中的战斗配装。

## 宝物编辑器

首页和战役页面的“宝物编辑器”提供70件宝物的查找、分类、插画预览和效果编辑。可改名称、低级羁绊、11种入场增益及持续回合，保留稳定编号、装备类别、唯一性、羁绊点数和护盾／休整额度上限。支持撤销、重做、恢复本件或全部默认，以及完整配置的JSON导入导出。修改保留在当前编辑草稿中，点击“保存配置”持久化至独立IndexedDB；导入先校验完整文件，不部分写入，保存失败保留原配置。

保存的配置用于之后的普通模式及独立战役开局，双方共用。世界与战场保存完整配置，武将仅保存当前装备的效果；读档、后台日结、同类替换和实际首次上场继续使用该局快照，不随编辑器改动。未保存的修改在返回后保留，刷新页面恢复上次保存配置。默认配置不增加存档快照。

实现：[配置校验与快照](../treasure-catalog.mjs)、[编辑器与本机存储](../treasure-editor.mjs)。回归包含 tests/treasure-editor.test.mjs，浏览器操作验证运行 `npm run verify:treasure-editor-ui`，截图保存在 outputs/treasure-editor。

## 强度验收与接入顺序

以上参数受机制回归验证；完整胜率与强度对照仍是后续平衡工作的依据。不以一份胜率表宣布所有宝物平衡，也不为宝物调整现有技能倍率来维持旧胜率。

| 验收项目 | 必须覆盖的实际结果 |
| --- | --- |
| 全局唯一 | 同日两个发现、双方阵容重复、援军重复、导入重复ID均不能获得第二件 |
| 羁绊资格 | 当前0级不生效；1级变2点；原生3级不再加；个人总点数≤6；高级不加点 |
| 人数成本 | 点数够但2名／5名持有者不能到第二档／最高档；宝物持有者离场即时降点 |
| 入场时序 | 首发确认前无状态；后备与未到援军不提前领取；同批补位只领一次 |
| 状态预算 | 同名强弱期限分开；速攻与神速不叠加；射程不穿越最小射程规则；护盾来源不能冒充护卫 |
| 真实伤兵 | 无伤兵不加兵；休整不超单次、累计及真实伤兵预算；疫伤正常减疗 |
| 人员与库存 | 调任、缴获、被俘、战死、运输拦截、夺城和赎回只转移原物 |
| 授予与锁定 | 在城预编可授予；随军三类宝物均不可分配；暂驻己城不解锁；回城交接后解锁；跨城授予立即生效；确认前任一方出征则拒绝 |
| 两项特技 | 眼力只修正合法发现来源；夺宝须对候选原持有者造成至少10%初始兵力的真实伤害；存活、未被俘、实际在场均复核 |
| 概率上限 | 基础2%／2%／5%；特技4%／4%／10%；多持有者不叠加、不增加抽取或数量、不缩短发现间隔 |
| 随机与存档 | 保存判定及结果；读档、战报回看、导入导出、降级升级不重抽或重发 |
| 获取节奏 | 七剧本一年记录各势力事件机会、发现、缴获及总持有量；多城不会多次内政判定 |
| 共同规则 | 玩家与AI、双方换边、普通与独立战役使用同一效果与唯一性校验 |

强度对照使用相同武将、兵种、等级、总兵力、装备、布阵和固定战法，仅改变是否装备宝物或换同类宝物；包含非均分兵力、低强度武将辅助、名将主核和真实后备。用固定开发种子选择参数，再用独立验证种子和完整换边记录伤害、承伤、控制抵挡、救治、实际有效时长、获益人数及胜败。

羁绊宝物单独比较“没有跨档”“补到下一档”“受到人数限制仍未跨档”，重点检查省下的原生点数是否让大量组合同时满档。BUFF宝物检查接敌前已经耗尽、短时接敌、后备切入、围城和水陆变形；不能强行把每件增益都放在最适合的接敌位置才宣称强度可用。若出现场均增益过大，先减少持续时间或收紧可提升羁绊名单；保留名将本体和公共状态语义。

正式数据源：[宝物目录与概率](../data/design/treasures.mjs)、[历史归属](../data/design/national-scenarios.mjs)、[特技](../data/design/traits.mjs)、[人物固定分配](../data/design/assignments.mjs)。运行时使用 [唯一登记与获取](../treasures.mjs)、[首次入场](../treasure-battle.mjs)、[状态来源与额度](../treasure-statuses.mjs)，界面为地图“宝物”、武将详情和自定义编辑器配装。

机制回归：`npm run test:treasures`；界面验收：`npm run verify:treasures-ui` 和 `npm run verify:treasure-art-ui`。覆盖唯一登记、出征锁定、同城授予、跨城立即授予、非军事外出资格及确认时出征复核、个人及人数上限、51件宝物的真实首次入场状态、同名来源期限、真实伤兵与累计额度、固定特技、单次结算及确定性读档。界面同时检查桌面与390像素宽移动布局、装备替换核阅、取消与存档恢复。生成一览表使用 `npm run design:export`，设计约束使用 `npm run design:check` 和 `npm run design:verify`。

宝物实体、位置、授予、装备、内政来源、战后候选及伤害贡献、随机阈值与结果、已结算标记均存入当前结构；旧版本提示重新开始，不增加迁移或旧结算分支。机制通过不等于所有宝物已经完成胜率平衡，未改变名将技能倍率或六张历史战役预算。
