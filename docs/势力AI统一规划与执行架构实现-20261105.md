2026-11-05 实施登记。采用领域约束的 Chronicle 分层时序任务和任务契约；不宣称本游戏达到研究系统的 SOTA 指标。

## 本轮重做：目的评分与统一执行（协议6）

用户最新方向为“对动作目的评分”，以及“多军团协作时每个军团都能独立作战”。本轮不再把战争净利润作为默认战略排序标准，也不将凑齐总战力后按来源城拆出的零散人员算成进攻军团。下文原协议3记录保留为历史证据。

已采用的 `faction-runtime-v1` 建立了旬初统一草案、共同动作授权、人员与资源任务投影、原子提交、过期草案拒绝和幂等执行；AI结构23。其21类696项回归、687项正式登记检查以及官渡/赤壁各30天保护通过，仅说明执行架构接入，未证明持续进攻改善。

本轮候选的决策链为：当前合法局势 → 领域方法与动作目的 → 完整实际军团 → 共同资格及资源准入 → 一份旬初任务草案 → 旬内按保存军令执行 → 下一旬按真实结果交接或重评。没有另建会自行增产、征兵、治疗或招降的假想世界，不调用战斗试打或读取未来随机。

### 目的评分

默认评价器为 `action-purpose-v1`，代码位于 `ai-policy/action-purpose.mjs`。评分是有限的动作目的权重，收益达到目的后饱和；不是金币价格、胜率或精算净利润。实际战力、库存、粮道、来源城守备及人员资格有独立否决权，分数再高也不能花未来战利品出发。

| 动作目的 | 初始最高分 |
| --- | ---: |
| 扩张领土 | 50 |
| 消除敌方势力威胁 | 30 |
| 巩固区域、连接领土与道路 | 各20 |
| 减轻边境压力 | 12 |
| 继续当前主攻方向 | 10 |
| 取得前线粮源、补充兵源与伤兵 | 各12 |
| 补充军费、取得人才接洽机会 | 各8 |

风险负项分别为战损比例（最多40）、行动占用时间（15）、出动兵员占当前城内兵力比例（有实际驻军或援军时最多2，空城占领最多10）及多来源基地协调（8）、中断真实工作（20）及旧情报不确定性（10）。钱粮兵源目的按本势力同一旬的实际维持需求归一，不能因多派一队、把预计损失降小，就把同一份缴获反复抬价。人数、工期和负责人能力共同反映真实工作中断。这些是本轮实现初值，非用户指定。诊断轨迹保存分项分数和共同准入理由。既有具名算法仍可替换，不覆盖用户选择的评价器。

占城前估计沿用合法城市报告和真实缴获规则，包含钱粮、预备兵、城市旧伤兵池、战后可接收伤兵、实际治疗吞吐和当前可见人才机会。伤兵要进城、治疗后才能成为预备兵；俘虏不等于招降。没有视野时不读取隐藏人才，旧报告不自动刷新。

### 军团与准备

联合行动先形成完整军团，再计算各自实际道路、统军任命、携粮和接敌时机。常规编成按六队首发、共同十队上限分组；紧凑备选允许四至五队，但须拥有至少六支常规准备部队的真实兵力（当前27000）。这些是实现选择，不是用户规定的固定军团规模。相同来源城可均衡分组，例如13队分成7队与6队；不能拆成6、6、1。7队加异地1人不会组成两支独立进攻军团，零散人员先走真实集结。零散来源不污染其他来源已完整成军的方案；协同能力不强迫同城七至十队拆编，一支军团已能执行时可独立行动。

后方余员经实际调任到达，交接前线任务后再编制、付费整补；各模块不能争用。前线长期留守的忠诚需求由实际人才负责人办理，不靠虚职或免费忠诚。失守后正在转移或已退至另一城市的待命外交任职先经共同入口解除，再从真实位置重新匹配，避免旧出发地和实际人员位置不一致。驻城军团中部分人员进入新计划时，任务投影按实际个人分别继承，留守者仍保留其军团归属；不能把同一人重复登记为两份占用，也不隐去不相容任务。

已有前线职责可交接到同一目标的更近作战基地：比较合法视野下的真实道路距离，新基地必须缩短接敌路线，且仍通过来源守备、在办工作、运输及接收预算校验。交接与真实调任同步，失败或异常恢复原归属；已完成任务保留历史名单。无需等到完整攻城已获准才允许这类有明确目的的集结，也不以固定禁止折返或冷却代替任务协调。

前沿调运不以固定20天作为距离否决；按真实道路、在办工作及目的地实际钱粮核对更长旅程，预计准备日期不代表已抵达。小势力若有真实人员与预算，也可准备两支军团，不以四城数量解锁。

多路行动共用真实粮路吞吐与装粮预留。同一协同计划已经整体审查过的待出发列继承其共同供给判断，不重复当作新的独立往返远征；其他计划继续竞争真实运力。只有已知目标仓库可能支持驻留时，才允许条件占领供给：己方现有库存必须撑过完整去程、估计攻城和额外执行缓冲，敌城粮食不能提前装袋。这是带失败风险的占领行动，不保证任何敌情变化下都能撤回。

侦察优先服务当前战略主攻及备选前线（最多两个观察方向），在判定攻守优势、安排发展或集结之前提出，不以军力增长、已有可行攻城方案或开战为解锁条件。未知边境继续探索，这些决策方向失去当前视野时优先实际侦察，已有当前视野与在途斥候复用；普通非目标旧报告不因年龄自动重派。替代方向另有决策价值检查，已结算城战或领地变化可重开一次核实机会，但这些不是主攻侦察的前提。侦察假设不写入报告，也不授权出兵。

撤回补给判断覆盖下一旬等待期、当前道路实际折返及返城时间；护路任务回撤由原任务授权。被俘、死亡或接收城失守会在共同军令执行阶段使旧调任承诺失效，不在旬内发新战略命令。定时出征回执只更新有效且整列名单、来源和目标完全对应的计划，不复活历史取消计划。

## 已接入的决策链

- Chronicle内核检查时间区间、依赖顺序、因果支持与威胁，以及人员、库存、工位和道路等可累加资源约束；按已给定领域方法顺序寻找首个完整可行方法，预算耗尽不会提交半份分配。内核不模拟战斗、不读取未来随机。
- 集结完成的实际位置作为事实，建立前线准备父任务。普通任职、调任、运输、外交、侦察和讨贼所用的共同人员承诺查询可见该归属，军团整编也保护该人员。共同军令入口拒绝绕过归属的直接调令。
- 新进攻方法在既有战力、费用、守备、恢复与粮道评估后，再检查整份人员与出发装粮约束；通过后一次性交接选中的前线人员，剩余人员继续原准备。未通过不释放父任务。现有进攻、支援、外交和调任记录作为执行事实投影，不复制成另一套库存或人员。
- 真实威胁、失去城市、停战、断路、实际口粮危局或没有可实施的后继准备方法，会在旬初取消前线任务并记录原因。救援/护路只有在释放具体任务后能形成足够的真实部队时才抢占，不把释放人数算作援军。
- 前线缺口先于额外后方发展。安全后方的成熟判据采用本城真实持续收入能覆盖实际支出、预算无缺口、无在建/研究项目；不是固定年份、势力规模或统一留守人数。保留太守、必要钱粮与治理负责人、已付事务、明确提案及真实研究班底。额外后方工作人员允许沿真实道路调任，正在办理的可接续工作使用原有“办完后调任”，不取消已付款。
- 地理候选按每旬32项的确定性批次接续，已承诺的前线方向优先复核。候选集合不变时保存批次顺序，局部评分变化不会反复重置到前32项；全部失败后后续方向仍能被检查。现有批内目标评估接口保留，不宣称所有战略选择均已改为首个匹配。

## 方法与实现范围

这是领域规则驱动的受限Chronicle实现，不是完整FAPE或Aries求解器。时间区间/资源内核已用于集结交接与进攻方法准入；长期准备仍以共同守卫与旬初修复处理，预测日期不授予执行许可。现有内政工作、外交谈判、逐日行军和战斗执行器继续使用原公共规则。

当前并未把所有业务模块重写成纯提案生成器，也未把全部现有库存、工位与粮路承诺迁移为单一持久化时间线：其实际执行记录仍是事实来源，通过统一人员查询与原共同资源校验衔接。不能把本次首个接入版本称为全部势力AI已完成研究架构迁移；完整统一授权迁移与长期策略收益仍需后续实现和验证。
