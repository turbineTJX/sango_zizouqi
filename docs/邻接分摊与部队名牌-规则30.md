# 邻接分摊与部队名牌（规则 30）

## 普攻

- 一支部队同时邻接 N 支存活敌军时，一次普攻的输出按 1/N 分配给每支敌军。分别结算兵种克制、防御／军纪、减伤与护盾，因而实际掉兵不一定相等。
- 多面接敌优先于普攻的合围／挑衅单目标选择；远程部队在贴身接敌时同样分摊。兵器的最小射程继续生效，盲区内不攻击。只有一个邻接敌军时沿用原有选敌行为；非接触远射、战法和攻城门保留原有目标规则。
- 每轮只计算一次攻击间隔、进攻战意、士气与连射计数。各受击部队正常结算自己的受击战意。稳定排序与一次伤害随机数保证续战确定性。
- 强化普攻的直接伤害、附加威力与新增灼烧伤害一起分摊；整轮只消耗一次强化次数。非伤害状态的幅度和持续时间保留原规则。
- 所有分摊先结算，再逐队判定反击；反击不会让排序靠后的敌军漏掉本轮分摊。护盾吸收或目标溃败后的剩余份额不转移给其他敌军。
- 伤害按累计份额取整，不会为每个目标额外生成一份最低伤害。

## 地图与查看

- 士兵阵形与头像分离：桌面头像按敌我固定排列在战场左右；手机竖屏在战场上方显示两排可滑动名册。名册显示头像、姓名、兵种、兵力与战意条。
- 地图仅保留短队名和兵力条，移除散布名牌与连线。鼠标悬停或键盘聚焦名册时对应部队高亮；缺失头像时保留文字头像。
- 默认清晰模式只在地图显示眩晕、混乱、封技、灼烧等关键状态中的一项。完整状态、数值与来源仍在情报面板查看；完整特效模式保留丰富的战场状态表现。
- 布阵时点士兵选择／交换阵位，点名牌查看情报；战斗时点士兵或名牌均可查看。合围选目标期间点名牌仍用于下达合围。
- 查看时暂停，桌面在右侧显示部队属性，手机从底部展开，可切换部队、查看状态／战法、进入武将资料。手机名牌点击区域高 44 px；战场可滑动，关闭情报后保留查看位置。
- 规则版本升级到 30，旧规则存档提示重新开始；保留当前版本保存、加载和确定性续战。
