# 邻接分摊与部队名牌（规则 30）

## 普攻

- 一支部队同时邻接 N 支存活敌军时，一次普攻的输出按 1/N 分配给每支敌军。分别结算兵种克制、防御／军纪、减伤与护盾，因而实际掉兵不一定相等。
- 多面接敌优先于普攻的合围／挑衅单目标选择；远程部队在贴身接敌时同样分摊。兵器的最小射程继续生效，盲区内不攻击。只有一个邻接敌军时沿用原有选敌行为；非接触远射、战法和攻城门保留原有目标规则。
- 每轮只计算一次攻击间隔、进攻战意、士气与连射计数。各受击部队正常结算自己的受击战意。稳定排序与一次伤害随机数保证续战确定性。
- 强化普攻的直接伤害、附加威力与新增灼烧伤害一起分摊；整轮只消耗一次强化次数。非伤害状态的幅度和持续时间保留原规则。
- 所有分摊先结算，再逐队判定反击；反击不会让排序靠后的敌军漏掉本轮分摊。护盾吸收或目标溃败后的剩余份额不转移给其他敌军。
- 伤害按累计份额取整，不会为每个目标额外生成一份最低伤害。

## 地图与查看

- 桌面和手机横屏均取消两侧重复武将名册及羁绊专栏，战场延伸至顶部信息条下方。羁绊以一列紧凑图标浮在场内，可收起、切换敌我，点选或拖动布阵时保持显示，不占用战场布局宽度。每队只常驻小头像、血条和战意条；不显示姓名、兵力或战意数字，不使用厚底框。桌面头像面孔40×40像素，横屏手机36×36像素，血条与战意条在头像旁，头像避开顶部信息条；姓名与完整数值通过悬停或详情查看。血条随实际命中演出更新，不提前显示结算后的损兵。手机竖屏暂停并提示旋转。
- 战前及援军军议的底部后备席常驻，使用44像素头像卡片显示血条与战意条，按位置排列后备顺序，不显示姓名、兵力数字及队列编号；全部真实后备均列出，队伍较多时横向滚动，未到援军明确标为待援。点击整张卡片查看该部队属性，桌面和手机均可直接拖动排序、交换上场部队或放入阵位，也可将上场部队拖回后备席空位。姓名、兵种、实际兵力、战意及入场位置在详情查看。
- 血条采用伤势式三段显示：整条表示本场原始兵力上限，实色为当前兵，浅金色为可救治的本场伤兵，深色为不能救回的损失。可恢复上限等于当前兵加公共规则算出的可救治伤兵，排除逃散并计入已治疗量；治疗只把浅色伤兵转为实色现役，不将上限补回。双方上场及后备共用，受伤与治疗均在实际命中时更新，不提前泄露结算结果。血条悬停和详情按“当前兵 / 可恢复上限 / 原上限”显示具体数值，战场仍不常驻数字。
- 小头像和双条紧贴部队模型上沿，跟随模型移动、加载及画面缩放；拥挤时只在附近轻微避让，不绘制名牌牵引线。悬停或键盘聚焦部队及其名牌时突出实际对象，缺失素材时保留文字头像；透明的外围点击区域不遮挡相邻部队小头像。
- 默认清晰模式只在地图显示混乱、封技、灼烧等关键状态中的一项。完整状态、数值与来源仍在情报面板查看；完整特效模式保留丰富的战场状态表现。
- 布阵和战斗时，点击士兵、头像或名牌均打开同一部队详情，包括敌军；桌面和手机布阵均可直接拖动我军士兵、头像或名牌至合法格子或我军部队，松手立即换位并保存。详情中的“调整站位”点选入口继续保留；拖动不误开详情，取消或手势中断不改阵型与存档。军略选目标期间点名牌仍用于选择军略目标。
- 查看时暂停，桌面与手机横屏均在右侧展开紧凑简报；手机面板约占44%宽度，保留大部分战场。先显示三段兵力、战意、护盾、当前行动及战法剩余次数；状态区显示增益、减益的效果、来源与剩余时间，完整属性、计算来源和个人羁绊默认折叠。点头像可查看武将资料。返回战场、关闭或 Esc 均保持暂停，普通战斗中明确点击“继续战斗”才关闭并恢复；战前及援军军议不提供该按钮，继续沿用部署与军议确认。手机使用部队本体或整张名牌点按，后备席卡片点击区域高44像素；关闭后保留查看位置。
- 详情打开时可直接点击另一支上场或后备部队，当前面板立即切换，不必先关闭；此时点击士兵也用于切换详情，不改变布阵或合围目标。武将、据点、军团与能力说明采用同样的切换逻辑，来源名单保持可点，返回保留筛选、滚动位置和编制草稿。
- 部队属性仅展示所选部队的战况、个人羁绊、特性、战法、状态及实际战斗属性；双方全军在场羁绊通过场内羁绊浮层切换查看。
- 旧规则存档提示重新开始；保留当前版本保存、加载和确定性续战。
