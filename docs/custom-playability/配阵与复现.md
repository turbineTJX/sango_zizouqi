# 配阵与复现

游戏进入自由对战，按以下武将、兵种、等级5、兵力配置；双方与种子在存档内。坐标为从0开始的格位，开战前选择相同战斗意图并按表中顺序装备战法。也可使用游戏的导入存档功能载入 presets 里的 JSON，从布阵阶段开始。导入替换当前进度，应先自行导出现有进度。
玩家战中军略按 scripts/custom-playability-lib.mjs 中 playerOrder 执行；只导入存档不会自动替你下军略。电脑始终由固定规则引擎控制。全部存档均通过当前 validateSave 检查。没有进行浏览器手动导入验收。
