# 目标选择、避战与功绩（规则61）

## 目标选择

普攻在合法目标内先遵守嘲讽、集火与近战拦截。没有集火时，距离不超过两格、兵力不超过上限10%的可攻击目标优先于普通远程偏好。目标仍须满足射程和最小射程；多面接敌沿用分摊攻击预算。双方共用规则。

## 短暂无敌

疑兵、雾隐在施放时目标兵力不超过10%，额外获得2日／1日避战。疑兵使用实体假目标，已取消原幻卫次数减伤；实体疑兵本身不赋予免伤，见[规则62](部队状态与特殊机制-规则62.md)。避战免疫直接伤害和持续伤害、不能被敌方选中，停止移动、普攻、战法和协阵光环，暂时不产生ZOC，但仍占据格子。不能复活，已有负面状态时间正常流逝，到期后继续生效。友方仍可治疗。

同一目标12日内不能再次避战，限制跨来源连续保护；原战意、冷却与每场次数不变。持续时间不受连携或能力倍率延长。状态及间隔随当前存档保存。非当前版本存档需重新开始。

设计参考：云顶之弈的低血量短暂不可选中与短暂无敌机制，采用停止自身行动和共用保护间隔控制连续保护。这里明确同时免疫范围与持续伤害，区别于仅不可选中。
参考：https://teamfighttactics.leagueoflegends.com/en-au/news/game-updates/teamfight-tactics-patch-12-4-notes/

## 功绩

正式参数：`data/design/progression.mjs`。战斗贡献评分不变，兑换除数为60，胜方仍乘1.25，无贡献为0。内政单次奖励暂不变。

1至9级每次升级分别需100、300、600、1000、1500、2100、2800、3600、4500功绩；1升10累计16500。等级越高，新增成本越大；双方和两种模式使用同一算法，升级不再增加或更换战法。这是节奏初值，不能视为长期战役平衡结论。

机制回归覆盖残血收割、双方转火、真实合法战法施放、持续伤害免疫、行动暂停、到期恢复、连续保护限制和确定性续战。
