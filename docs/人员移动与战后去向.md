# 人员移动、战后去向与快速运输

## 统一考虑的移动

| 人员 / 情境 | 动向 | 大地图 | 每日行动力 |
| --- | --- | --- | --- |
| 模拟侦察斥候 | 沿道路前往终点并驻察，负责人留城工作；经过即获取情报，区域视野按智力随机期限保留 | 显示斥候，不移动负责人 | 70 |
| 在势力中、轻装调任 | 从当前城沿实际道路赴任，到达前不能在目的地任职 | 不显示 | 70 |
| 招揽、劝说负责人 | 赴访 → 当地接洽 → 返回原城；在途不推进接洽天数 | 不显示 | 70 |
| 在野人才 | 沿真实相邻道路迁移，旧位置情报失效；招募成功后实际赴任 | 不显示 | 70 |
| 战败脱身、赎回、获释 | 从实际位置返回所属城；所属城失守则前往君主所在城 | 不显示 | 70 |
| 俘虏 | 从被俘处押送至俘获方关押城，到达后才能办理赎回或释放 | 不显示 | 50 |
| 运输队 | 运兵、预备兵、伤兵、金粮及混载同速，按军团方式逐段移动，每天至多完成一段 | 显示并可选取 | 常行步兵军团的1.5倍 |
| 正常军团与有生力量撤退 | 沿用兵种、统率、士气及缺粮决定的行军速度 | 显示 | 陆路常规相邻城约3–5旬；水路按实际船速 |

移动逐段消耗道路成本，不以直线距离倒计时或瞬移。保存人员所在节点、当前路段进度、剩余路线、任务阶段；所有阶段可存读档并确定性续行。

人才与军团采用不同通行规则。轻装调任、招揽赴访、招募赴任与脱身返城允许沿实际道路穿过敌方城市，不要求连续己方领地或军事通行权，不因经过敌城而直接被俘。调任预览、军令校验与实际执行共用这一规则。携带实际作战部队、金粮和预备兵的运输仍按运输规则办理。

## 外出办理任务

人才负责人到达目标所在地后，次日才开始当地接洽。任务完成后保留返程状态，到原城后才能执行后续改任、调任或出征。目标移动或身份改变会使原接洽失效，不产生远程接洽进度。

外出的武将不能同时在原城带队出征、守城或办理另一项事务。其已有驻城部队保留编制和士兵，但主将外出期间不能抽为出征或守城部队；不得因此重新抽取战法或注销正常保留的内政职务。太守外出期间保留名义任职，不提供在城加成。

玩家改任、调任仍可选择立即执行或完成事务后执行；指定出征、侦察时提示后立即中止可解除事务。立即执行对外出人员的含义是立即中止当前任务、实际返城后执行新令；不会把外出人员瞬移回城。等待原事务时，包含办事完成后的返程。等待期间不开始下一项内政。

## 战后与被俘去向

- 单队按[战前撤离条件](部队撤离与战前设置-规则65.md)成功离场后，仍随原军团结算、整队或败退，不进行灭队抽签；途中实际灭队仍按下列去向规则处理。
- **成功撤退且仍有兵员**：武将随幸存部队沿实际道路位置撤离，不进行被俘或战死抽签。军团保持原有撤退与休整规则。
- **部队全歼、本人脱身**：移出原军团并释放军团任职，从实际位置独立返回所属城；所属城失守则转往君主所在城。军团最终获胜也不把已经溃败的武将留在军团内。零现役人员不能参战或提供军略。
- **返程人员**：沿用同一武将记录保存身份、零现役兵力、未被接收的本方伤兵、功绩及学习记录。返程属于人才移动，可穿过敌城，按70行动力逐日推进，不生成可携现役和物资的运输命令，也不领取运输功绩。抵城后保留真实伤兵并按既有休养和整补恢复；学习记录不重抽。
- **途中失城**：保留实际路段进度，从当前位置改道前往君主所在城；君主在外时按其所属城或已记录驻城处理，均失效时临时安置于本方现存城市。有城但道路不通只等待，不误判为在野；到达后才更新所属城。
- **军团失去全部作战部队**：本场被歼灭者照常判定去向；未再次参战的零兵人员不重抽战死或被俘，从实际位置沿路返城。无兵军团移除，不留下无法移动的地图军团。
- **重新参战**：返回所属城或君主驻城后，按城内独立部队规则休养、征募整补并重新编组；实际补兵消耗本城资源。城内不保留持久军团任命，后续出征照常重新编组。
- **运输队遇敌**：随队现役、伤兵、预备兵和未卸载物资全部损失，不建立战斗；带队武将独立判定去向。
- **战后俘虏率**：野战1%、攻城5%、攻下最后一城灭势力30%，均按每名符合条件人员的无条件概率计算。战死仍占2%，其余脱身；俘获方没有关押城则脱身。最后一城失守的30%仅用于真实留城人员和本场被歼守军，外地部队、在途与已撤离人员不被远程俘获。运输遇敌保持独立的2%战死、33%被俘、65%脱身规则。
- **己方控制战场**：不被己方俘虏，除战死外脱身并按所属城／君主驻城规则返程。军团缺职按实际存活有兵者补任。
- **全部城池失守**：未被俘的在城、在途及非交战军团人员转为在野，残余部队解散，不等待残军自行耗尽。仍在另一真实战场者结算当场去向后下野，不远程增加俘虏抽签。保留原人物及能力记录，并进入既有整理期；已被俘者保持俘虏状态。
- **概率确定性**：用本局种子、事件和武将标识决定结果，不通过反复读档重抽。

战死、被俘人物保留唯一身份、能力和学习记录。战死者不再参与任职、战斗或招募；被俘者不能任职或出征。不会把同一人物同时放在军团、驻城、待命及人物池中。

## 战胜收益与伤兵接收

普通模式攻城沿用真实库存交接：接收城内50%金、50%粮、20%预备兵，向下取整，其余散失；空城同规则，中立城先按其小额库存上限计算，不补空仓。当地技术和设施保留，战损按实际耐久接续。和平换城仍按外交契约办理。

有明确胜方时，可接收败方尚未成功撤离部队本场新增遗留伤兵的25%，逐队向下取整；25%是偏低收益方向的可调初值。接收在普通模式真实兵损回写后、人员去向与军团清理前处理，同数从败方伤兵扣除，加入胜方已抵达、未撤离且仍有现役的真实部队伤兵，受现役加伤兵的带兵上限约束。接收数不足上限时按实际接收记录，不把未收容者当成收益。原有旧伤、逃散、已治疗者、已撤离者、未到援军、疑兵及匿名守备兵不参与；平局、停战和独立战役不生成战略接收。

接收者保持伤兵身份、正常耗粮，随军返城并按现有休养或救治规则恢复，不能在结算时直接变成现役或预备兵。原战报伤兵栏保留本场历史伤亡，另外显示“胜方接收敌方伤兵”实际人数；原军扣除与胜军增加保持守恒，结果及逐队凭据保存，回看和读档不再次发奖。

参数正式源：[战后去向与接收规则](../data/design/officer-fate-rules.mjs)、[城仓交接](../city-resources.mjs)。普通模式玩家与AI共用，战略存档结构67。回归 `node --test tests/battle-aftermath.test.mjs tests/officer-mobility.test.mjs tests/follow-army.test.mjs tests/city-occupation-resources.test.mjs`。

参考[《三国志14》官方说明书的部队溃灭、俘虏与伤兵](https://www.gamecity.ne.jp/manual/sangokushi14-pk/ce/cht/5110.html)及[势力失去全部城市即灭亡](https://www.koeitecmoamerica.com/manual/rtk14/en/3100.html)的机制方向；本项目的1%／5%／30%由用户指定，伤兵接收比例为本项目初值，不声称是原作概率。

## 押送、赎回与释放

俘虏从被俘道路位置押送至俘获方城池，押送途中不可办理赎回。抵达后通过大地图“人员动向 · 被俘与赎回”或“天下情报”的人物详情操作。

- 己方武将：支付 `300 + 5 × max(统率, 武力, 智力)` 金赎回，赎金计入俘获方府库。重复点击不能重复扣费或复制人物。
- 己方关押的敌将：可释放；敌方有友城、府库足够且被俘至少3天后，也可按同价自动赎回其武将。
- 关押城或押送目的地失守：获释后从实际位置返城。
- 赎回与释放均从关押处出发，抵达后才重新成为可任用的在城武将。原势力无城时不能付款赎回；释放后转为在野。

## 每日行动记录

每名武将从开局开始保存每日实际位置及行动。内政使用当前事务与实际建设地点；赴访、返程、调任、运输、在野游历和押送记录当前路段及进度；军团使用真实行军路段与战场状态，待命、休整、被俘、战死和未登场分别记录。未登场者不显示虚构地点。

武将详情的「当前动态」只显示当前所在、任职、行军、参战、休整及实际进度，每人仅保存一份当前快照，不保留内政与人员的历史回放和日期翻页。待执行命令、本旬功绩额度和未读奏报保留必要结算凭据，完成依赖后清理；累计功绩用分类计数保存。当前动态结构3，旧档重新开局。战场每日快照与回放继续保留。查看不改变模拟。

城内建筑头像与记录共用实际状态投影，显示在当地办理对应事务的武将，包括施工、研究、训练、招募及外地接洽；外出和随军人员不重复显示在原城。头像点击直接进入当前动态，超出三人显示人数提示，建筑详情提供完整名单。复用现有头像资源，缺图时显示姓名标识。

## 快速运输队

从“调任武将”选择在城武将，携带已编制部队、粮草或预备兵时组成运输队；不任命作战军团职务。出发时扣除原城资源，到达时交接，粮仓不足则分批卸载，未卸载部分仍有被袭损失风险。

所有运输队采用统一常行步兵军团基准：统率80、士气80、无缺粮，陆上为枪兵，水上为走舸。共用军团移动公式，速度乘1.5；不因载荷种类、随队兵种或器械、武将或运粮特性改变速度。每个战略日最多完成一个实际路段，抵达路口后的剩余行动力不结转；水陆分段计算速度，预览、AI集结及救急估时、在途资源预算与实际行进一致。转漕保留接力，漕运保留最多5批往返及空车回程，全部使用同一速度。运输队与军团一样沿地图道路曲线显示实时位置，可点选查看人员、物资和剩余时间。运输途中与敌军道路移动按同一日内时间检查，包含迎面相遇、追及、中途驻军、途经敌方据点和终点驻敌；主路与支路仅在共有节点相遇时拦截。抵达路口后停留期间也检查敌军到达，不能跳过拦截。遭敌直接损失，不暂停等待安全，也不进入部队自动战斗。

## 战场撤离

主动撤离部队离场当步开始按运输队规则移动，统一前往战前选定的合法己方军团编制据点；兵力、伤兵、携粮仅移交一次，功绩在原战斗结束时按实际贡献结算。返城后不得再次加入原战场。目的地失去资格须从实际位置改道，途中遇敌按运输损失处理。具体设置、脱战与补位见 [部队脱战与撤离](部队撤离与战前设置-规则65.md)。

战略奏报从这些每日记录中的实际结果节点选取，人员遇敌、战死、被俘、脱身、赎回和获释均在实际处理时写入，保留原所属势力和事件地点。战役结算按实际参战人员关联战果，城池得失按真实归属变化写入；读取或查看记录不能重复结算。
