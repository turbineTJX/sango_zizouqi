# 任务推荐与 AI 选人

选人默认按「任务推荐」排序，先列可选武将。候选区只显示当前任务需要比较的能力和适用特性，不显示内部推荐分数，也不展示全套五维和通用名册字段。点选姓名在侧栏查看任用参考、适用特性效果和当前职务；完整人物资料作为可返回的详情页。可切换本任务相关能力排序。改变内政方向时恢复对应任务推荐。

界面、敌方内政委任和战略整军使用 `officer-recommendation.mjs` 的同一评分入口。评分是当前条件下的确定性启发式比较，不是成功率，也不宣称全局最优。

## 内政六方向

读取实际事务候选规则，包括本城资源、设施、冷却、兵员、伤兵、研究和人才条件。按武将自动办事的相同候选区间与选择权重，综合当前事务优先级、实际成功率、工期、执行者的数量加成和费用节省，计算方向推荐。

规则56按六方向固定主属性：商业、农业均用政治，军务用统率，武备用武力，技术用智力，人才用魅力。推荐在后台评估可办事务，玩家只选方向和人，不需要分析需求或逐项选事。每个方向全部事务使用同一主属性。特性按执行范围列出：善商用于商业、农政用于农业、巧匠用于技术，医术、征募、练兵、筑城按相应军事事务生效；人才显示眼力、说客等。能吏标注建设作用，调和标注协作作用。富豪、米道、名声不作为普通事务执行人的收益加成，只在太守选择中计算。

同城同方向的协作关系纳入参考。已有事务改任或出征会计入等待时间；预编部队不打断内政，也不会因此扣分。当前无合法事务时标为候补，避免把无事可办误判为能力不足。排序、筛选与查看详情不抽随机数，不修改存档。

## 其它选人

- 太守：政治与实际太守特性。
- 调任与运输：实际轻装或运输行进速度，区分健行与运输。
- 预编、守城补编与出征：统率、兵种适性、现役兵力、武智与已学战法，展示本队战斗特性。
- 军团长、军师：对应统率、智力，并说明当前任职可提供的军略；保留玩家已选任职。
- 整补：按可补兵员排序，明确伤兵不属于可直接征补的缺额。

## 战略 AI

敌方先用同源太守评分补任空缺太守，再为六个方向的空缺岗位比较候选人和任务评分，优先安排高分组合，每人只担任一个内政方向；不打断已有任务，不重复分配，不征用外出或已有等待命令的武将。围城期间不改派。

战略预编、出征选队及整补也调用共用推荐；出征保留军团长、军师随军的合法限制。建设通过真实武将内政事务完成，移除不经武将的直接建设捷径。战斗行动、战法学习与自动施放规则不变。

验证命令：`npm run test:recommendations`、`npm run verify:recommendations`。专项覆盖商业／农业推荐反转、太守专属作用范围、同源 AI 选人、只读与确定性、运输速度、预编不打断内政，以及手机选将界面。


## 任务专用选择界面

查阅《三国志14》官方出阵流程和《三国志8 Remake》内政说明后，选将改为全宽比较表与选定摘要：政治等属性直接分列，能吏、调和、农政等适用特性分别成列，圆点表示持有。点击特性表头或持有标记查看效果，关闭后保留勾选。取消右侧说明栏，点击姓名查看完整武将资料。查看武将与勾选任用分开，点选和切换不直接执行。保留当前工程的自动内政和自动战法规则，不照搬参考作品的数值或战法配置。

参考：https://www.gamecity.ne.jp/manual/PaSjK1n4/jp/5100.html 、https://www.gamecity.ne.jp/manual/sangokushi8-re/jp/4200.html 。

## 军团编制比较分页

出征编组、现有军团调整、部队预编、守城整备和确认预览共用战斗比较组件，按任职、部队、战法、特性、军略、连携分页。任职内再切换军团长、军师；特性每页最多四项，连携按双方组合列出并按概率降序排列。切页仅改变界面，不提交军令，不重抽学习记录。

军略直接使用引擎的资格、持有者强度和同名取强函数，显示实际提供者及效果。连携读取当前关系值，说明同方在场、同一目标及时间窗口条件；关系概率不是实战触发率。战法只展示当前兵种已学内容。征补和拆分选队改为兵员比较表。

验证包括实际军略来源和可变关系值与引擎一致、只读存档、分页列数和任职保留，以及出征、整军、围城预编浏览器流程。
