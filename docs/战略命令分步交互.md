# 战略命令分步交互

城市以「城中议事」作为命令入口，展示内政委任、调任武将、预编部队、军团出征。内政办理列表与太守、军费信息折叠查看；当前会话内返回城市时保留展开状态。

## 操作流程

| 命令 | 流程 |
| --- | --- |
| 内政委任 | 选择事务 → 选择武将 → 确认下令 |
| 太守任命 | 选择武将 → 确认下令 |
| 调任 | 选择武将 → 地图选择目的地 → 确认下令 |
| 预编 | 选择武将 → 安排兵种与整补 → 确认下令 |
| 出征 | 逐支编制部队 → 选择已编部队 → 任命军团长、军师 → 大地图逐点选路 → 确认出征 |

从已有明确上下文的入口发令时直接沿用：内政方向中的委任跳过选事务，军团面板中的下令跳过选军团。步骤栏支持返回已经过的步骤；选将中查看武将、部队和战法详情后可返回原操作。筛选、勾选和配置保留，变更内政方向或更换出征部队时清除不再适用的选择。

## 查看界面的复用

- 选将复用势力武将名册，增加选择控件、资格说明和对应排序。编制时补充现兵种适性、现役兵力、带兵上限和携带战法。
- 目的地复用战略舆图及缩放功能，点击据点选择，也可从据点下拉框查找。出征预览所选道路的路线和消耗；调任仅可选择己方且道路相通的其它据点。
- 兵种配置使用城市已解锁技术与武将已有学习记录，不重抽战法。预编沿用现有兵员；可勾选按现有征募规则整补本次选择的部队，并在下令前展示兵员与金粮消耗。

## 提交与取消

步骤只保留本次操作草稿，不自动存档，不修改实际游戏状态。编制与整补在状态副本上进行完整预演，最终重新校验后一次应用；失败不部分扣费或编军。关闭或取消丢弃草稿，刷新后回到实际已保存进度。

委任、调任与出征继续调用现有军令接口；有正在办理的内政事务时，最终下令后选择立即执行或完成后执行。返回会恢复待下达命令，等待命令仍持久保存，按原规则自动执行。等待出征期间不创建军团，实际执行时才从城市转出所选部队。战略存档版本升至 10，旧档提示重新开始；战斗规则不变。
