# 战略命令分步交互

完整行动清单、返回规则和生效边界见[玩家行动交互流程](玩家行动交互流程.md)。本页说明战略命令的共用草稿与提交方式。

点击己方城市打开内政、军事、人事、侦察、城内和详情；军事展开编制、出征，人事展开武将、调任、太守。管理、预算和完整人员表须主动打开，不在选城后自动铺开。

## 操作流程

| 命令 | 流程 |
| --- | --- |
| 内政委任 | 本城内政 → 方向 → 岗位 → 选择本城武将 → 直接确认 |
| 太守任命 | 选择武将 → 确认下令 |
| 调任与运输 | 来源城 → 选择本城武将 → 地图友城终点 → 物资及可用运输选项 → 核阅下令 |
| 预编 | 部队列表 → 新增或编辑单队 → 表单内选择主将、兵种、兵力和装备 → 回列表 → 核阅下令 |
| 出征 | 选择已编部队 → 任命军团长、军师 → 地图终点与路线 → 核阅下令；需要时从选队页进入编制 |
| 军团调动 | 明确己方军团 → 地图终点与路线 → 核阅下令 |
| 侦察 | 派出城市 → 本城执行人 → 周边终点 → 路线预览与调整 → 派遣 |

从已有明确上下文的入口发令时直接沿用：内政方向中的委任跳过选方向，军团面板中的下令跳过选军团。使用返回、上一步及明确业务入口往返，不显示顶部数字步骤条。查看武将、部队和战法详情后保留筛选、勾选、配置与滚动位置。更换上游对象清理失效依赖，同值重选不清路线。

出征已有可用驻城部队时直接进入选队；没有时先进入部队管理。已选条可直接移除部队，不解散真实编制。侦察更换城市清空人选与终点，更换人选清空终点；城市入口预选本城但不自动选人。

## 查看界面的复用

- 选将复用势力武将名册，增加选择控件、资格说明和对应排序。编制时补充现兵种适性、现役兵力、带兵上限和携带战法。
- 目的地复用战略舆图：出征、调动、调任与运输在地图选择，搜索只定位；侦察同时提供城市和终点选择框。出征、调动与侦察可拖动中转点改线；运输目标是其它可达友城，接力选项按实际特性提供。
- 兵种配置使用城市已解锁技术与武将已有学习记录，不重抽战法。预编沿用现有兵员；可勾选按现有征募规则整补本次选择的部队，并在下令前展示兵员与金粮消耗。

## 提交与取消

命令步骤只保留本次操作草稿，不修改实际游戏状态。编制与整补在状态副本上完整预演，最终重新校验后一次应用；失败不部分扣费或编军。返回详情、上一步及取消子选点保留来源草稿；取消整个命令不提交，重新进入或刷新不保证恢复临时草稿。

运输输入即时校验整数、非负值与库存，只更新摘要和资格，不替换正在输入的控件。抵达预估共用实际人员速度，计入运输特性与接力停驻；分批运输明确标注首批。路线拖动时按 Esc 只取消本次拖动；主动重置路线才清除中转点。

委任、调任与出征调用共同军令接口；涉及在办事务时，完整提交后选择立即执行或完成后执行。返回恢复待下达草稿；已提交的等待令持久保存，实际执行时重新复核。等待出征保存选定道路但不创建军团，实际执行时才从城市转出部队。只支持当前存档结构，版本以运行时为准。
