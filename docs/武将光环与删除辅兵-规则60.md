# 武将光环与删除辅兵（规则60）

本规则取代规则59中“辅兵属于戟兵”的处理：辅兵已删除，不再作为独立兵种或戟兵子类型存在。

- 正式兵种、适性、科技、编制费用、普通战法学习池及当前战役配置均不再包含辅兵。当前战役原辅兵位置改用戟兵，原武将与兵力保持。
- 协阵从战法表与固定配置池移除，改为两个字的固定武将特性。不占战法名额、不需学习、不计施放次数；换兵种、升级和读档不改变归属。政治高不会自动获得协阵。
- 协阵每6日救治相邻其他友军已有伤兵并恢复战意；来源和目标均不限兵种。自身不受自己的光环，同名只取当前最强的一个来源。离开相邻范围、来源混乱／撤退／溃败时中断；封技只限制战法，不禁止此固定特性。仍遵守伤兵额度、减疗、满兵与战意上限。
- 协阵强度采用政治与现役兵力：`P=(80+政治×2)×现役兵力/3000×补给修正`，倍率沿用统一 `clamp(0.6+P/700,0.7,1.6)`。每次救治上限为目标兵力上限的0.5%×倍率，恢复战意为四舍五入的2×倍率。智力、武力不提高此特性倍率。实际效果在武将特性和受益部队状态详情中展示。
- 营务由原兵种强化定义改为固定武将特性：防御提高政治×0.2%，军纪提高政治×0.1%，政治按0～100计算。不限制兵种，不直接提高攻击。
- 普通战法按[固定战法规则](固定战法与稀缺专属-规则64.md)配置，协阵光环不占战法名额。
- AI通过持有的协阵特性识别支援职责、优先安排邻接主力的位置，不再判断辅兵类型。双方共用同一光环结算。

固定持有者与效果参数统一维护于[特技一览表](design-tables/特技一览表.md)及[能力分配表](design-tables/能力分配一览表.md)。验证应覆盖政治与兵力缩放、相邻范围、同名最强来源、受控与避战中断、真实伤兵及确定性续战。
