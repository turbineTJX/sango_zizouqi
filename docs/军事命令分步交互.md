# 军事命令分步交互

完整入口、取消边界与各项生效时点见[玩家行动交互流程](玩家行动交互流程.md)。整军操作以选择、安排、核阅和确认组成草稿流程，最终重新校验资格；详情返回保留草稿，取消不扣费、不改编。战场军议的部分设置即时保存，不能把关闭军议当成撤销整页。

## 军团调度

- 调整编制：整军 → 调整编制 → 修改合法兵种和装备 → 军团长、军师 → 比较前后与费用 → 确认。
- 拆分：选择另立军团的部队 → 配置部队 → 安排新军任职 → 核阅新军和原军剩余部队 → 确认；双方均须保留有兵部队。
- 合并：选择同地合法军团 → 核阅合并结果 → 确认，合并后不得超过十队。
- 征募整补：选择本军部队 → 核阅实际补充后的兵力和金粮消耗 → 确认，只补充所选部队。

沿用友城、筹划阶段、行军与交战限制，以及当前征募额度、兵源、兵种技术和资源规则。

详细属性在配置或核阅页面按需展开，不增加独立重复属性核阅页。路口、港口和关卡可按合法条件调整任职、拆分与合并，但不能征募或换兵种。

## 战前军议与多战线

遭遇入口进入「查看敌情 → 整备部队 → 确认指挥」。敌我部队复用现有详情页面，守城可进入临时编制，完成后回到军议。多个待处理战线可切换，确认仅影响所选战线。

亲自指挥进入实际战场，开战前保持暂停；先核对本军任命，再安排首发顺序、站位、后备入场位置、战斗意图与撤离。拖动站位先预览再确认；顺序、意图和撤离设置按各控件生效，开战按钮锁定部署。委托作战使用同一引擎，不增加额外行动或兵力。其它待处理遭遇仍会阻止世界继续。

援军实际抵达才进入军议，可调整合法任命、后备顺序、入场位置和撤离条件，不能移动在场部队或重选意图。战后缺失军团长、军师时，先结算真实人员去向，再由该军现役人选补任；确认前暂停，关闭不能代替确认。

遭遇页当前仍有数字步骤条，其展示差异列入[交互待统一项](玩家行动交互流程.md#待统一项)，不作为新增流程要求。

## 自动事务与只读情报

内政事务和建设由武将自动选择，城市设施只展示等级、效果及已有建设进度，不提供逐项建设向导或直接建设按钮。委任方向与人事安排继续保留。

战法自动携带当前兵种已学内容并按固定规则施放。战法页面仅展示学习记录、次数、门槛及效果，不提供配置或顺序调整控件。
