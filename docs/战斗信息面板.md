# 战斗信息面板

武将页和部队页顶部复用 `battleUnitSummaryMarkup`，展示当前战斗步、阵营、在场状态、战场行列与地形、当前行动、实时兵力、伤兵、战意、普攻间隔与调息。预备队显示援军到达、援路受阻或等待补位；溃败、撤离不显示旧坐标为当前位置。

本步实际作用对象来自当前步战斗效果记录，只说明本步已经发生的行动。战法目标则调用共用 `readyTactic` 读取当前局面下的候选结果，并明确标注为预览。查看不修改行动、随机数、战法顺序或目标。

战法详情同时列出当前的在场、受控、撤退、次数、战意、独立冷却、共享调息限制。常驻光环不显示主动战法次数。未携带战法明确标注。条件满足时仍说明下一次自动行动会重新检查目标和优先级。

部队页按实时战况、状态效果、携带战法、属性来源组织。状态效果保留来源、剩余时间、实际属性变化的展开详情；属性注明已计入当前兵力、地形与生效加成。
