# 战斗信息面板

战场即时表现使用共同的只读演出队列：普攻和小战法在同一节拍内按实际记录顺序错峰，保留起手、释放、命中和收势；大战法、真实连携与军略保留独立窗口。一次多目标战法与其真实连携共用一个窗口。施法者包含无伤害的治疗、控制和支援，连携参与者在各自位置响应。清晰模式以短尾飞行弹体、局部箭雨、冲锋尘土、火焰、控制印记、治疗上升光点及护盾区分作用，不绘制部队之间的关系线或身份旗牵引线；持续效果不重复施法。名将头像和能力名称集中在战场上方，完整模式保留额外特写与粒子。

战斗节奏与视觉反馈集中在部队本身：普攻和小招连续错峰，前冲在实际命中点达到峰值并短暂保持，随后收势；连携参与者错开起手并在共同命中点接续。命中力度按真实损兵比例、暴击及真实击溃分级，在士兵护甲位置表现短促亮点、沿受力方向飞散的火星与扬尘，并同步后仰。真实溃败先完成倒伏及旗帜落下，再淡出；正常离场不倒伏，隐藏敌军不留下虚构的死亡演出。清晰、完整与减少动态效果模式共用实际命中时序，暂停冻结；不新增结果摘要或解释性文字。

清晰模式同样显示持续罩体和状态动画：真实护盾包裹部队，吸收伤害时闪亮，实际耗尽时碎裂，期限结束时消散；免伤罩使用金色，不混作护盾数值。控制、灼烧、疫伤、减益和增益各有局部持续表现，附加、刷新、解除及自然结束按真实状态变化播放，不为免疫或失败判定虚构状态。飞行体强化亮芯和短尾，弹道抵达、兵力变化、受击闪白与后仰均以同一命中点对齐。普通伤害、暴击、谋略伤害、持续伤害、护盾吸收和恢复使用独立样式的跳字；多段同源合并，不同攻击者分行，全额吸收不产生掉血跳字或身体受击动作。二维精灵与原生模型共用反馈时序，暂停冻结，减少动态效果设置保留静态形状及数值。

部队模型上方常驻小头像、血条和战意条，不显示姓名及数字，不设置两侧武将名册。血条以本场原始上限为基准，实色为现役、浅金色为可救治伤兵、深色为不可恢复损失；数值在详情按“当前兵 / 可恢复上限 / 原上限”显示。标记在模型上沿有限避让并跟随移动，密集处聚焦会抬高当前对象；即使移出部队原点击范围仍可查看，换位时优先命中真实部队。

手机以横屏游玩：Android 容器支持左右横屏，安装式网页声明横屏；普通网页战斗遇到手机竖屏会暂停并显示旋转提示，转回横屏后由玩家继续。战场占据主要区域，羁绊以场内浮层收起或切换敌我，布阵时自动让开；底部保留暂停／继续、速度和军略。安全区域仍由容器和页面边距处理。

战前及援军军议的底部后备席常驻，桌面及手机可直接拖动上场、交换、拖回或排序，松手预览后确认；军议按钮展开任命、撤离等设置。援军仍须实际抵达，战中不能重布在场部队；提示显示本次抵达者。战后必填任命先呈现实际胜负与伤亡，仍须共同处理器确认后继续。以上不改变战斗数值、成本、随机数或存档结构。

兵力标记随命中阶段更新，阵亡目标保留到最后一击表现完成；暂停冻结当前播放阶段，切速作用于后续行动。状态变化和跳字队列位于 `battle-feedback.mjs`，只保存演出副本，载入或暂停步进不补播旧效果。持续伤害事件保留实际伤害包的 `shieldAbsorbed`，演出据此区分吸收与掉血，不让原施法者重复出手。真实兵力、随机数、状态、战法顺序及胜负仍由共同战斗引擎一次结算，演出不写入或迁移存档。播放中的真实状态查看、军略资格及下令继续按共同处理器校验。运行 `npm run test:battle-readability` 检查边界；`npm run verify:battle-feedback` 使用合法守城开场护盾和真实六对六对战，采集吸收、破盾、伤害及状态截图和动图，并核对暂停、四倍速、手机布局及原生模型闪白恢复。

部队页采用右侧紧凑简报，手机横屏约占44%宽，先看三段兵力、战意、护盾和战法次数，完整属性与个人羁绊默认收起。切换器只列姓名，敌我在下拉分组处显示，兵种用独立小标记；点另一支部队可直接切换。武将页保留完整战况，预备队说明抵达及补位条件，离场者不将旧坐标显示为当前位置。查看时暂停，关闭或“返回战场”保持暂停，“继续战斗”才关闭并恢复；战前及援军军议仍须原有确认。

本步实际作用对象来自当前步战斗效果记录，只说明本步已经发生的行动。战法目标则调用共用 `readyTactic` 读取当前局面下的候选结果，并明确标注为预览。查看不修改行动、随机数、战法顺序或目标。

战法详情同时列出当前的在场、受控、撤退、次数、战意、独立冷却、共享调息限制。常驻光环不显示主动战法次数。未携带战法明确标注。条件满足时仍说明下一次自动行动会重新检查目标和优先级。

状态区统一称“状态”，效果只列“混乱”“奋战”等名称，不重复拼接“控制减益”等分类，空状态只显示“无”。实际效果、来源、剩余时间及可展开的属性变化保留；属性已计入当前兵力、地形与生效加成。

2026-11-04 用户确认的战场状态交互：状态名本身就是详情入口，不增加独立的“状态详情”按钮。桌面悬停或键盘聚焦状态名即可查看效果，点击状态名固定展开，再次点击或按 Esc 收起；手机轻点同一状态名查看。来源、剩余时间、数值与属性变化沿用当前状态数据，查看不改变战斗状态、军令、随机数或暂停规则。战法与军略仍从各自名称进入能力说明，状态名不冒充战法按钮。

窗口标题不再重复所选姓名，折叠区称“详细情报”，状态数值比较称“属性变化”。状态来源以“曹操「鼓舞」”说明施加者及能力。军议任命保留人选的统率、智力，取消视觉上重复列出已选姓名；尚未上场或抵达的部队显示“后备待命”或“援军尚未抵达”。战场指引分为“入门、操作、用兵、状态”，说明优先列出操作、结果与必要限制。

两种模式共用具体能力详情入口。点击战法只显示该战法的效果、威力、次数与当前限制，不附带全部战法一览或重复分类页签；部队战法按钮只显示名称及战中剩余次数。特性和军略同样只显示所选能力，详情表格按窗口宽度换行。
