# 兵科与据点编制（规则59）

> 规则60已删除辅兵及其费用、科技和学习池；战斗特性使用共享羁绊。本文其余据点与兵器规则继续有效，详见《武将光环与删除辅兵-规则60》。

正式来源：`data/design/troops.mjs`、`data/design/technologies.mjs`、`data/design/officers.mjs`。本文记录当前实现及费用初值，费用不是已完成平衡验收的结论。

- 弩兵归入弓兵适性；832名武将的设计记录与运行时查询一致。各具体兵种仍分别保存既有学习记录，不因换兵种重抽。
- 原通用兵器明确为投石，新增冲车、井栏，三者共享兵器适性与当前兵器战法池。冲车射程1、攻城系数4；投石射程5、最小射程2、攻城系数2；井栏射程4、攻城系数1.5。属性进入普通攻击、城门伤害、部署、地形、行军与战法学习。兵器特性对三者生效。
- 科技按据点独立研究、试制，枪兵与弓兵为初始基础技术；开局已编部队所在据点保留对应已掌握技术。每种兵器独立解锁，舰船另需水域。研究目标和解锁规则读取科技设计表。
- 战略编制、改编与整补只能在实际驻扎的己方据点办理。城内预编、出征前编制、守城战前临时编制共用校验；野外军团不能改编。武将实际外出时不能通过城内记录改编。
- 编制表单列出本据点当前可编兵种，兵种选项显示所属兵科、适性及每千人费用。未掌握的兵种不进入可选列表。核阅页显示实际总金粮与兵员消耗；失败不留下部分改编或扣款。

编制单价以[兵种表](design-tables/兵种一览表.md)为准；已删除辅兵费用。

新编已有兵员按当前人数收取编制费；新增兵员按所选兵种收取费用，并扣除对应预备兵、征募额度及每人1粮。换兵种按现役与伤兵总人数收取新兵种费用，保持原兵种不收费；减少兵力退回预备兵，不返还已投入编制费。玩家直接整补与战略AI整补共用单价；自动内政征募也使用兵种单价，保留原有事务固定费用、紧急征募倍率和特性折扣，并按实际完成数量退还未使用费用。事务保存目标兵种，目标改编后不会按旧价补入新兵种。

独立战役继续使用共用编制界面，但按原模式约定不扣战略资源、不要求战略据点科技；历史战役仍固定剧本人员与兵力。兵器三种当前共用兵器美术资源，名称及战斗参数独立。
