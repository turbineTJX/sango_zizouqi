# 四大兵科 城市技术与携带装备

当前战斗规则版本以 `combat-rules.mjs` 为准，战略存档版本以 `strategic-campaign.mjs` 为准。普通模式与独立战役共用兵种、属性、适性、固定战法、装备和形态切换处理器；独立战役编制不扣战略资源、不要求城市技术。旧档重新开始，不迁移。

正式数据源为 `data/design/troops.mjs`、`technologies.mjs`、`assignments.mjs` 与 `tactics.mjs`。以下属性和费用是当前机制的初始参数，尚未完成新兵种及装备的平衡验收。

## 基础兵科与升级兵种

枪、戟、骑、弓四大基础兵科均可直接编制。每个升级兵种继承本兵科适性、克制关系和两个小战法，仅替换高级战法。S携带两个小战法和一个高级战法，A携带一个小战法和一个高级战法，B/C携带一个小战法但享受升级属性。名将专属、羁绊和军略继续按人物规则生效。

| 兵科 | 升级兵种 | 定位 |
| --- | --- | --- |
| 枪 | 青州兵、白毦兵 | 持续进攻、护卫友军 |
| 戟 | 藤甲兵、大戟士 | 高防御与减伤、击退敌军拆阵 |
| 骑 | 虎豹骑、白马骑 | 突击后排、3格普通骑射与机动追射 |
| 弓 | 连弩兵、长弓兵 | 提高普通攻速及连续射击、5格普通射程与远距狙射 |

藤甲兵防御基础140，戟兵100；大戟士以大戟推阵攻击相邻敌军，再按威力与防御判定击退，最多沿空闲格推退两格。定身、方阵、控制保护、魔免和勇武来源免疫可阻止位移。占位、建筑和水陆通行继续校验，不能越过阻挡。

## 城市独立技术与资源

城市科技树共23项、四条分支、最多两层。每城固定开放10～13项，有1～2种地方资质与1～2种特色兵种；建筑升级不会改变资质。同势力其它城市不会自动获得技术。城市技术与未完成研究进度随城保存，失守不清除；已编制部队进入无对应技术的城市保持原兵种和装备。正式范围见 `data/design/city-technologies.mjs`。

| 分支 | 基础科技 | 本地进阶科技 |
| --- | --- | --- |
| 民生 | 商税法、农垦法 | 商贸资质的通商法、农耕资质的灌溉法 |
| 军务 | 军籍法 | 军镇资质的营户法、军需法，以及本城特色兵种 |
| 工造 | 省工法 | 工造资质的攻城器械、水乡资质的战船营造 |
| 守备 | 烽堠法 | 边塞资质的连烽法，以及守备箭术、军乐鼓吹、战地救护 |

技术负责人自动选择满足条件的科技，同城同时只有一个研究项目，其它负责人可协作。新研究从本城支付一次费用，资源冲突按共同内政审批处理；免费接续不重复审批。研究逐个实际工作日推进百分比；负责人智力、工坊等级、本轮成果判定及适用命令特性影响每日进度。基础项目200金、基准10个工作日；进阶项目600金、基准20个工作日；烽堠法400金、基准10个工作日。研究失败或部分推进后保留进度，下一轮及更换负责人不重复收取项目费用。达到100%直接掌握。围城暂停进度；读档、查看界面不推进、不重抽结果。

进阶科技开办要求同城至少两名实际驻城的技术负责人，并同时满足多种设施、治安、前置技术和地方资质。出征、在途、外出事务、侦察、待执行调令及已被战略计划占用的人员不计入人数；人物去重，外城或同势力其它城市的人手不计。人员门槛表示本城技术岗位规模，不凭人数增加研究进度；协作收益仍按真实协作结算。新项目在实际开办及提案批准时复核，已支付项目接续不再检查这些开办门槛。科技树详情显示所需人数、当前人数及缺少的设施。

人手充足、设施发展较快的势力更容易建立研究条件；小势力可以集中建设、调入和委任真实人员达成相同条件，没有按势力身份或领城数直接放宽门槛。AI在旬初保护原有任职、工作、计划及预算，从空闲人员中补齐实际技术岗位；人员不足或资源不够时等待，不在旬内增派。这些门槛及收益为2026-11-03按用户方向接入的试玩初值，尚未完成大小势力长期平衡验收。

军务和兵种科技完全不使用兵营等级前置。军籍法需要治安60；营户法需要军籍法、农田2级、粮仓2级、校场2级及治安75；军需法需要军籍法、市场2级、工坊3级、粮仓2级及治安75。特色兵种需要军籍法、两名技术负责人和多种2～3级设施，普通门槛为治安75，虎豹骑及白马骑为80。白毦另需医馆，白马另需城防。治安等动态条件只在开始新项目时检查，下降不取消已付费研究或已掌握科技。

民生科技基础收入加20%，对应进阶再加30%，同资源合计50%，不复利。加成作用于本城永久产出、实际直接运营及共享旬运营额度；运输、买卖、外交付款和退费不放大。军籍法、营户法同样提高预备兵产出。军需法降低本城编制、改编、补兵与装备费用25%；省工法降低本城负责的建设费用20%，与既有建设优惠相加后仍遵守50%上限。预算、草稿预览、最终扣款与AI共用函数。

通商法需要市场3级、粮仓2级、工坊2级；灌溉法需要农田3级、粮仓3级、工坊2级，两者均需治安70。小城的市场、农田、粮仓前置按本城上限取2级。攻城器械需要省工法、工坊4级、校场3级、城防2级、治安75；战船营造需要省工法、工坊3级、粮仓2级、校场2级、治安70及真实水域。这些进阶项目均需本城两名技术负责人。完整前置和效果由 `technologies.mjs` 读取并导出。

烽堠法完成后自动建成区域瞭望塔，研究费包含工程；从塔的实际地点提供32视野。连烽法需要烽堠法、城防工事3级、工坊2级、校场2级、治安75、两名技术负责人及边塞资质，原址视野扩大到38。视野双方同规则，失去城池立即失去该视野来源；新城主取得原址瞭望塔及其实际耐久；被摧毁后停止额外视野，修复后恢复。瞭望塔不能查看范围外隐藏部队和实时情报，斥候仍负责远处探查。

战略编制、改编、整补和配备装备只能在实际驻扎的己方城市办理。新编或改编升级兵种要求本城技术；补兵要求本兵种及携带装备的当地生产条件。伤兵恢复不要求对应技术。现有部队可以正常从无技术城市出征，不能在野外改编或添置装备。

编制、改编和装备按正式表的每千人金价收费。新兵从本城预备兵转为现役，不扣粮；现役继续正常耗粮。补兵费用包含本兵种和携带装备的材料。更换兵种只收新兵种费用，保留原装备；更换装备只收新装备费用，不退还旧投入。取消草稿或校验失败不留下扣款、改编、装备或部分兵数变更。

普通模式AI使用相同城市条件、费用和实际预算，保留内政及补兵资源。无对应技术不能获得升级兵种或升级装备。

## 兵器与船

每支部队分别携带至多一种兵器和一种船，仍保留原兵种、主将和同一份兵力。装备不占独立部队及上场名额，也不增加兵科适性。

| 栏位 | 基础型 | 技术解锁型 |
| --- | --- | --- |
| 兵器 | 冲车 | 重型冲车、井栏、投石车 |
| 船 | 走舸 | 艨艟、楼船、斗舰 |

冲车无需升级技术。走舸无需升级技术，但只能在具备水域的城市配备；升级船也要求水域。攻城器械统一解锁三种升级兵器，战船营造统一解锁三种升级船。兵器与船各有独立属性、射程、攻城系数和费用。携带兵器在陆上按兵器运输速度限制移速；水面使用实际携带船的速度和战斗属性，不叠加陆军与装备的两套基础值。

## 作战形态与次数

部队进入水面自动使用船形态，没有船不能进入水面；登岸或进入桥面恢复原兵种。攻城方以城门为目标并进入所携兵器的有效距离后展开兵器，需要一个原兵种行动周期；已展开兵器在有效攻城位置保持形态，离开位置、城门被破坏或撤离时收起。水面船形态优先。

陆军、船与兵器使用各自固定战法，但普通战法按武技小战法、谋略小战法、高级战法三个名额共享次数、增次、恢复和冷却。切换不改变兵力、伤兵、战意、状态、护盾、调息、羁绊触发记录和专属次数，不重复领取入场效果。切换后按新形态重新检查目标和射程。

实际形态、展开准备时间和全部形态的次数冷却账本随当前版本保存，读档继续确定性战斗。战役双方、各援军以及普通模式守城临时编组使用同一处理器。六张历史战役中的船和兵器已改为陆军携带装备；兵力、武将、到达条件继续由统一战役生成器保存。

## 验证

`tests/technology-upgrades.test.mjs`覆盖城市科技、失败原子性、射程和骑射、藤甲防御、大戟实际位移、形态切换共享次数及确定性续战，以及普通模式真实遭遇战与独立战役的属性和战法一致性。全部枪、戟、骑、弓固定战法另由`tests/current-fixed-actions.test.mjs`验证双方实际施放与读档；八种装备形态的48个双方固定战法场景由`tests/equipment-fixed-actions.test.mjs`验证。`scripts/verify-technology-upgrades-ui.mjs`覆盖战役与城市实际提交、装备扣款、草稿隔离、键盘焦点和桌面/手机布局。

`tests/city-technology.test.mjs`覆盖全部城市固定范围、无兵营前置、逐日进度、真实本城扣费、协作、接续、确定性存读档、收入与费用、装备总科技和瞭望塔视野；`scripts/verify-city-technology-ui.mjs`验证桌面、手机和实际保存的研究进度。

运行 `npm run test:city-technology` 或 `npm run test:technology-upgrades` 可重跑科技及兵种装备回归；浏览器验收入口为 `npm run verify:city-technology-ui` 与 `npm run verify:technology-upgrades-ui`。设计表仍按项目统一的 `design:check / design:export / design:verify / test:design` 与 `docs:check` 验证。

守备分支增加守备箭术、军乐鼓吹和战地救护，以烽堠法为前置；分别解锁箭塔、军乐台和救护营建设。完成研究后仍须本城支付施工费用，实际战场效果及耐久见[内政战场建筑](内政战场建筑.md)。
