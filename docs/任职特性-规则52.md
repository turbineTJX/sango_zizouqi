# 任职特性（规则52引入，规则54修订）

军团长、军师任职特技按指定武将身份固定分配，只影响所属军团全部部队，包括后备和待援部队。任职判定不依赖持有者本人部队是否在场、退场或兵力归零；后备和待援部队仍按正常规则入场。非对应任职不生效，同名不叠加，不影响其它军团。

名称、效果、持有者及内部设计分类单独维护于 [军团特技设计表](军团特技设计表.md)。不按基础能力阈值批量发放，升级、换兵种、读档不会重抽。

普通模式与战役模式共用任命界面，显示名称、任职条件和完整效果；选军团长只显示军团长特技，选军师只显示军师特技。界面不显示“高级”“稀有”等设计分类。任务推荐共用评分计入适用效果，每个百分点记1分。战斗属性明细展示实际加成来源。

任职效果使用实际战斗指挥官记录判定，当前版本保留确定性续战，旧档不迁移。
