# 历史战役试玩

默认入口提供四场历史战役，另有五场[演义推演](带兵上限与演义推演.md)，战略原型与演武试炼位于首页底部。玩家先读简报、选择战役，再布阵、配置战法、开战、暂停下令，最后查看战报或重试。

| 战役 | 玩家阵营 | 核心体验 | 预设兵力（我 / 敌） |
| --- | --- | --- | --- |
| 官渡，200 年 | 曹操军 | 步骑配合，入门 | 16,800 / 10,500 |
| 赤壁，208 年 | 孙刘联军中的周瑜部 | 舰船、水陆协同与火攻军略 | 16,800 / 14,400 |
| 合肥，215 年 | 张辽、乐进、李典 | 三将保护城门，主动运用军略 | 9,000 / 8,400 |
| 夷陵，222 年 | 陆逊军 | 林地火攻与远程配合 | 16,200 / 15,600 |

兵力、等级、兵种和地形均为现有战斗规则下的缩编改编。对战不预定胜负，没有额外的历史必胜倍率。赤壁沿用双水道与桥面规则，水面火攻仍受现有削弱；合肥以守门战表达守城压力。乌巢奇袭、风向变化、连环船及追击事件尚未做成独立机制。

战役数据位于 `historical-campaigns.mjs`，共用 `createScenario` 和现行引擎；历史场地在试玩界面固定。周瑜、陆逊、李典、孙权、刘备、吕蒙、黄权获得符合定位的现有军略，主将/军师任命和积累规则与其余武将一致。夷陵使用蜀将张南（person-430），与袁军同名张南区分。

历史背景参考《三国志》[张辽传](https://zh.wikisource.org/zh-hant/三國志_(四庫全書本)/卷17)；夷陵火攻亦见《十一家注孙子》[火攻篇](https://zh.wikisource.org/wiki/十一家注孫子/火攻篇)引述。文案只作简要背景，具体阵容是玩法预设。

## 保存与导航

- 历史战役：`sango-historical-battle-v1`，战场路由 `#historical-battle`。
- 演武试炼：`sango-battle-lab-v1`，战场路由 `#battle-lab`。
- 战略原型：`sango-sovereign-v2`，路由 `#strategy`。

无路由的默认页面始终显示战役首页。战场刷新时暂停恢复；返回首页同样暂停并保存。历史战役首页显示继续战役或查看战报。新开另一历史战役替换历史槽位，页面提前说明。所有模式保留当前结构的导入导出；不做旧存档迁移。

## 验证

`tests/scenarios.test.mjs` 自动覆盖新增四战的完整模拟、伤亡守恒、布阵合法性、保存读取与战报校验。`tests/historical-campaigns.test.mjs` 额外验证历史阵容、正确的张南、军略从零积累、正常下令可胜、确定性续战，以及官渡无需军略也能完成的入门预设。测试不注入战意、伤害或军略进度。

`scripts/verify-historical-ui.mjs` 使用 Playwright，在隔离浏览器上下文验证默认首页、四战入口、战法配置、暂停刷新、战报关闭重试、三个存档隔离、导入导出、战略恢复与手机布局。通过 `PLAYWRIGHT_MODULE` 指向已安装的 Playwright；默认使用本机 Edge 和 `http://127.0.0.1:4173`。结果与截图写入 `outputs/historical-ui`。

这些结果验证预设可玩性与流程，不代表对所有布阵、配装及随机种子的全面平衡结论。
