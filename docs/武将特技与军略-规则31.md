# 武将特技、专属战法与军略（规则31）

最新优先级已调整为先确定[三类共享基础技能池](基础技能池-设计草案.md)。本文记录当前已试配的机制与人物方案，不作为基础池定稿或最终分配依据；不继续扩写逐人专属设计。

本轮按用户补充要求重新分配技能用途：参考《三国志11》的特技，把战斗、内政与外交能力放进武将五技能成长；参考《三国志12》《14》的特色战法，改编为个人专属自动战法；军略继续负责全军指挥。下列数值全部是本项目的改编值，不是原作数据。

参考资料：[三国志11特技资料](https://w.atwiki.jp/sangokushi11/pages/13.html)、[三国志12战法资料](https://w.atwiki.jp/sangokushi12/pages/25.html)、[三国志14官方战法介绍](https://www.gamecity.com.tw/sangokushi14/system-battle.html)。前两项用于核对条目名称与原作用途方向；夏侯惇“豪气冲天”的鼓舞和压制方向可见官方介绍。

## 武将技能：五个节点，可以跨领域

仍在 2／3／5／8／10 级解锁，不增加额外技能槽。换兵种保留人物成长路线；技能根据自身条件生效。当前共有 77 项技能定义：70 项战斗、5 项内政、2 项外交预留。

| 技能 | 已实现的本项目效果 | 使用条件 |
| --- | --- | --- |
| 枪将／戟将／骑将／弓将 | 对武力低于自己的部队，武技战法伤害 +20% | 使用对应兵种，不强化普攻、谋略伤害或攻城；不照搬必定暴击 |
| 飞将 | 攻击 +30%、移速 +15% | 保留吕布现有技能：骑兵、相邻无友军；不无视占格和地形 |
| 富豪 | 本城每旬金收入 +25% | 任本城太守，不增殖府库已有资金 |
| 米道 | 本城每旬粮收入 +25% | 任本城太守，仍受粮仓上限约束 |
| 能吏 | 本城新开工建设费用 −20% | 任太守，在开工时计算；没有追溯退款 |
| 名声 | 本城每旬兵源恢复 +20% | 任太守；不是直接增兵，不提高征募额度 |
| 仁政 | 赈济民心额外 +5 | 任太守；上限100，每旬一次，金粮费用不变 |
| 论客／亲善 | 外交交涉／改善关系的预留技能 | 当前没有外交流程，明确显示“外交预留 · 未开放”，不产生任何加成 |

城池收入先按设施、民心与太守政治计算，再乘相应特技加成，最后取整。太守必须属于本城势力、在城且不在调任途中。未任太守的待命武将、军团中的武将、其他城池的武将不提供内政加成。同城只有一个太守，不叠加多个“富豪”或“米道”。围城仍停止旬生产与治政经验，库容和兵源上限不变。

正常完成一旬结算后，太守获得100治政经验；先结算本旬收入，再处理升级，避免新解锁技能倒算本旬收益。建设优惠、赈济增益在后续下达指令时立即按当前等级计算。文官无需通过参战才能成长。

人物配置包括：张鲁以米道起步，糜竺与鲁肃拥有富豪，荀彧、张昭、顾雍侧重能吏，陈群侧重名声，满宠侧重仁政；简雍保留护持、辅军并加入仁政与论客，维持前线援护职责。邓芝、诸葛瑾拥有混合内政外交路线。政治突出而无固定路线的普通武将使用治政路线。完整人物分配从运行数据生成到[技能设计表](../技能设计表.md)。

## 个人专属战法：局部强项与取舍

| 武将 | 战法 | 基础效果 | 战意／冷却 |
| --- | --- | --- | --- |
| 曹操 | 魏武之强 | 3格内最多2队，攻击、防御各 +15% 持续6步；另给较小护盾，沿用护盾威力公式 | 75／34步 |
| 夏侯惇 | 豪气冲天 | 相邻单体1.35倍武技伤害、攻击 −20% 5步；自身减伤12% 5步；自身2格内最多2队其他友军战意 +12 | 65／28步 |
| 刘备 | 义勇兵 | 3格内最多2队，每队最多救治兵力上限8%的本场伤兵，攻防各 +10% 5步；无可救伤兵不发动 | 65／34步 |
| 周瑜 | 神火计 | 4格内、目标周围1格最多2队，0.8倍谋略伤害、灼烧基础每步24、防御 −20%，持续5步 | 100／34步 |
| 吕布 | 人中吕布 | 近处最多3队，各1倍武技伤害；震军4步，使普攻间隔 +25%、谋略威力 −15% | 100／36步 |

其余专属保留已有设计。全部战法仍占三个战法槽之一，自动按优先级、战意、独立冷却与合法目标发动。战意不扣除，范围采用六边形距离。伤兵预算、护盾上限、军纪、控制保护、兵力衰减、威力系数与连携继续约束实际结果。义勇兵不复活；神火计可净化；人中吕布的震军不阻止移动和施法。

魏武之强与义勇兵使用现有增攻／防御状态，并按各自较低的幅度结算。较弱增益不能覆盖仍有效的更强同类增益，不叠加成多个同类百分比。原有存档校验同步支持这些合法幅度。

## 军略：改变全军节奏

| 军略 | 当前效果 | 与局部战法的区别 |
| --- | --- | --- |
| 坚壁之策 | 全军防御、军纪 +20%，18步 | 同时应对武技与谋攻，后续入场者也受益 |
| 虚实之策 | 敌军攻击、防御、军纪 −15%，16步 | 为物理与谋略队同时创造窗口，后续入场者同样受压制 |
| 连环之策 | 全军战意 +15，正在冷却的战法缩短4步 | 含预备队；仍需达到战法门槛，不保证立即连携或清空全部冷却 |

其余11项军略保留当前分工。司马懿补入虚实、断援、连环；鲁肃补入救疗、鼓舞、后军固阵；张鲁补入持续救疗、即时救疗与鼓舞。完整14项及提供武将见生成表。

军略每次仍需12000进度，使用后清空，同项冷却8步；双方AI使用相同规则，连环评分同时考虑战意缺口和可缩短冷却。此处“军略”是战场全军指挥；内政特技不会增加军略条收入。

## 版本与验证边界

战斗规则升至31，离线缓存同步更新；按项目规定旧规则存档需新开局，不增加迁移分支。战略存档中的武将等级与经验、战斗状态及随机序列继续确定性保存和续战。

战斗与治理专项测试覆盖任命位置和势力、跨城不串加成、真实旬收入、建设扣费、赈济限制、治政成长、外交预留不生效、兵种和武力条件、专属战法自动发动、较小增益快照续战和军略军纪效果。

2026-09-19：`npm test` 全部410项通过，`npm run check`通过。武将总表已增加技能领域和实现状态，覆盖835人、133字段。此后工作顺序按用户补充要求调整为先确定共享基础技能池，人物试配不继续扩展。

坚守测试仍要求真实存活到240步。规则31下旧种子3会在226步失败；调整救援配套后使用种子5验证坚守成功，未降低胜利条件或修改关卡兵力。此次属于机制与功能抽查，不证明所有场景已经充分平衡；默认局仍可能失败。
