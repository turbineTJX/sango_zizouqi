# 武将编辑器

首页和战役配置页均可进入“武将编辑器”。左侧按姓名、字或编号查找人物，可筛选全部、已修改和自建武将，点击表头排序；右侧编辑资料。

支持姓名、字、性别，统率、武力、智力、政治、魅力，枪、戟、骑、弓四项适性，常用兵种、性格、义理、相性、生卒年和人物生平。能力为0～100，适性为C／B／A／S；空白年份表示未载。死亡年须晚于出生年。

“新建武将”产生独立人物；“复制新建”复制当前资料并生成新编号，同名人物不会合并。自建武将最多256名。内置832名人物的来源、编号、关系和固定专属能力保留；恢复默认只移除本机对该人物的修改，内置人物不能删除。自建人物使用现有通用战法与羁绊成长，不因复制名将资料取得该名将专属战法、军略或独立特性。

点击“保存”后，资料写入独立的本机武将库。切换人物或返回时，未保存修改须选择保存、舍弃或取消。存储不可用、容量不足或其它窗口已改变武将库时不会报告保存成功，草稿保留并可单独导出。浏览器刷新前也会提示未保存修改。

“导出此将”可备份当前草稿，“导出武将包”备份所有已保存的修改和自建人物。导入先整包校验，再显示人数和同编号覆盖提示，确认后一次写入；取消或无效输入不改变武将库。导入导出采用 `sango-officer-library` 第1版 JSON。

保存的修改用于之后的新局：战役模式沿用现有主将选择、编制与战斗流程；普通模式把自建人物放入在野人才池，由现有发现、招揽和赴任流程入仕。历史剧本遵守生卒年和16岁登场条件，架空剧本不限制年代；自建人物初始活动城市由地图顺序分配，不表示历史籍贯。编辑已有君主的生卒年可能使部分历史剧本无法开局。

每局保存开局时的武将库快照。后续修改、恢复默认、删除本机人物或在另一台设备读取存档，都继续使用该局原来的资料。武将库不会自动覆盖当前游戏的能力、战法、功绩或人物去向。删除了战役草稿所引用的人物后，返回配置会提示并恢复默认编制；已经开战的存档保留人物。

实现：`officer-library-data.mjs` 定义资料及导入校验，`officer-library.mjs` 提供独立 IndexedDB 事务，`officer-editor.mjs` 和 `officer-editor.css` 负责编辑界面，`officer-catalog.mjs` 明确安装新局或存档的资料。模拟引擎不读取浏览器存储；后台日结按同一存档快照安装资料。

验证入口：`npm run test:officer-editor`、`npm run verify:officer-editor`。界面检查覆盖桌面、手机横屏与竖屏、主将选择、开战、刷新读取、删除库记录后的续战，以及后台日结与前台处理的一致性。
