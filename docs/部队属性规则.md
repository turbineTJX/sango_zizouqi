# 部队属性规则

面板与战斗共用 `unit-stats.mjs` 的 `unitAttributes`，不另存最终属性。武将为统率、武力、智力、政治、魅力五维；内政分工见[六方向](内政六方向-规则56.md)。

以下为未叠加特技、军略、地形、缺粮及状态修正的基础公式，现役兵力不含伤兵。

| 属性 | 基础计算 |
| --- | --- |
| 攻击 | 现役兵力÷3000 ×（兵种攻击＋统率×1.6） |
| 防御 | 兵种防御＋统率×0.65 |
| 军纪 | 兵种军纪＋政治×0.8 |
| 武技威力 | 现役兵力÷3000 ×（80＋武力×2） |
| 谋略威力 | 现役兵力÷3000 ×（80＋智力×2） |
| 营务威力 | 现役兵力÷3000 ×（80＋政治×1.4＋智力×0.6） |
| 攻城 | 当前攻击×兵种攻城系数，再应用攻城专属修正 |
| 移速、射程、普攻间隔 | 读取兵种属性及实际修正 |
| 控制抗性 | min(0.6，军纪÷（军纪＋150）) |

不同修正的叠加方式遵守共享处理器；射程同类增益取最高、最小射程仍有效，攻速改变普攻间隔而非战法冷却。具体状态见[规则62](部队状态与特殊机制-规则62.md)。

兵种数值见[兵种表](design-tables/兵种一览表.md)，能力数值见[特技表](design-tables/特技一览表.md)与[军略表](design-tables/军略一览表.md)。战法使用何种威力、是否可暴击和需概率判定，见[威力与概率](战法威力与概率规则.md)。
