# 固定战法与稀缺专属（规则64）

所有等级使用相同战法配置，取消随机学习、升级获取和等级保底。正式兵种配置与专属归属维护于 `data/design/assignments.mjs`，效果维护于 `data/design/tactics.mjs`。

## 专属可用强度（规则87）

- 郭嘉「十胜奇谋」以群体压制为职责：战意门槛35、冷却22回合、每场2次；4格内选仍有战法次数、非魔免且有战意的目标，覆盖其周围1格最多3队。按目标尚余战法的门槛、冷却及覆盖收益选敌，不再浪费于已耗尽战法的高战意敌军。基础夺气40，高战意额外20，随谋略威力变化；抑气与疲弱持续10回合，攻击和受击战意收入降低50%，疲弱幅度按共享谋略威力缩放。
- 曹操「魏武之强」支援4格内最多3队其他友军，奋战和营垒持续12回合，并恢复基础20战意；门槛55、冷却24回合、每场2次。幅度仍走共享威力公式，不凭空恢复战法次数。
- 黄忠「百步穿杨」保留5格后排优先及残兵追击，基础伤害系数2.6，门槛55、冷却22回合、每场2次；仍遵守嘲讽、拦截和合法目标限制。
- 其余13名专属保留当前效果。此轮先修正目标浪费并建立可观察的职责收益，不要求名将必胜，也不把全体专属拉到同一收益。后续再调整精确数值。
- 双方、两模式共用。规则87旧档重新开始，不进行迁移。

## 普通战法

陆战兵种与舰船各有3种小战法、3种大战法，分别覆盖武技、谋略、营务三条威力通道；冲车、重型冲车、投石车和井栏各有3种小战法、1种大战法；这是战法池，不是单将的携带数量。每队最多2小＋1大，指定名将另有1项本人专属。

| 适性 | 实际携带 |
| --- | --- |
| S | 主属性对应小战法1项＋按人物角色选择另一项小战法＋1项大战法 |
| A | 1项小战法＋1项大战法 |
| B、C | 1项小战法 |

具体招式按人物库基础能力、性格与各招式职责固定分配。武力、智力、政治分别决定武技、谋略、营务偏好，统率、魅力和性格进一步区分强攻、守御、控制与支援；它们只决定初始取招，实际效果使用当前对应威力。S首先取得主属性对应的小招，再从另外两类中按角色偏好选一项；A／B／C选一项。常规与舰船大战法从三类中按特点选一项，兵器只选唯一合成大战法。平分按正式池顺序，不随机、不自由配装。

读取该局人物库快照；临时状态、兵力、等级和随机种子不重抽。技术兵种继承兵科适性。形态切换共用“主属性小招／第二小招／大招”三个名额的次数、恢复、增次与冷却；第二小招从谋略变为营务，也不会产生第三份次数。

## 营务战法的实际分工

政治通过营务威力参与战斗，营务不是旧谋略战法的文字别名。

| 小战法铺垫 | 大战法的扩大用途 | 布阵与代价 |
| --- | --- | --- |
| 急救、救护、镇静、整军 | 救援：两队救治、护盾、镇静与坚定；固阵：两队营垒与护盾 | 接近前排或同列友军，不造成直接伤害；治疗受真实伤兵与疫伤限制 |
| 策应 | 整备：两队救治、缩短冷却与疾行 | 同列与侧翼队友优先；不恢复已用尽次数或取消施法间隔 |
| 振旅、救护 | 休整：持续救治；备射：两队远程友军速攻、远射 | 后排在主力附近；备射只影响普攻，不扩大战法范围 |
| 扑火、接舷 | 修船：两队舰船扑火、救治与护盾 | 限当前舰船形态，陆军不能领取 |

刘备义勇援军也使用营务威力，仍保留专属次数与伤兵资格；其他谋略支援可保留谋略来源，例如阵枢与疑兵。营务不包揽所有支援，大小也不等于伤害类别。数值与分配权重属于本轮试玩初值。

## 基础效果与专属强度

兵种战法让玩家先认识常见状态和行为，再理解专属如何组合、扩大或利用它们。基础描述突出主用途，专属仍逐项遵守共同抗性、免疫、伤兵、路径和范围规则，不以专属身份绕过限制。

| 认识的机制 | 当前兵种来源示例 |
| --- | --- |
| 眩晕、混乱、封技、缴械、定身的区别 | 扰阵、惑敌／扰乱、扰策、卸兵、缚足 |
| 嘲讽、失阵与突破 | 挑衅、挫敌、奔袭／冲阵／牵引 |
| 破甲、疲弱、迟滞、缓攻与短射 | 破甲、挫敌、阻射、震军、短射 |
| 灼烧、疫伤与减疗 | 火矢／火计、枯竭／毒矢／疫矢 |
| 战意给予、直接削减与持续损失 | 振旅／接舷、挫敌、挫志 |
| 护盾、减伤、护卫、反击 | 镇静／救护、方阵／藤甲坚壁、援护、反击 |
| 魔免、坚定及解除／驱散 | 御术、镇静、整军／扑火／破阵 |
| 射程、移速与站定的取舍 | 远射／短射／备射、奔袭／策应／整备、架设／抛锚 |
| 疑兵、识破、连环传导 | 疑兵、洞察、连锁 |
| 单体／直线／扇形／范围与后排优先 | 连弩齐射、贯阵／长弓狙射、横扫、乱射／火计 |

例如先通过火矢认识灼烧，再比较普通火计与神火燎原、火烧连营的覆盖、附加状态及乘隙收益；先通过护卫、镇静认识分担与护盾，再理解群体保护的价值。来源表代表可获得且可结算，不代表任一武将或每场战斗都能使用全部状态。军略／羁绊专有免伤和内部间隔不必复制成基础技能。

## 属性与实际效果

武技、谋略、营务战法分别通过部队当前对应威力结算；先计入现役兵力、状态、羁绊、军师及支援修正，不直接使用武将裸武力、智力代替。兵器大战法使用“（当前武技威力＋当前谋略威力）÷2”的合成威力；两者均为280时合成仍为280，不重复计入兵力。冲车、重型冲车使用冲车，投石车使用投石，井栏使用攒射；井栏与普通连弩的战法定义分开，普通连弩仍使用武技威力。兵器大战法伤害仍为物理伤害、受防御抵御，攻击城门仍计入真实攻城威力；暴击率、说明及战略静态评估共用同一合成公式。

护盾、救治、战意量及减益幅度按对应当前威力增长，控制成功率和时长按威力与抗性结算。射程、目标数、位移格数、固定解除列表及强化普攻次数保持各自规则。营务威力保留政治为主、智力为辅的基础来源，继续用于救治、休整和修缮。详见[威力与概率](战法威力与概率规则.md)。

御术为藤甲兵池中的自保选择：门槛35、每场2次、冷却36，基础魔免3回合，持续时间随谋略威力增长；解除并免疫战斗异常，仅承受物理普攻，不免除缺粮或主动代价。御术的来源、施放时威力与时限保存校验，不冒用军略来源。

战法与羁绊名称不得重复。羁绊名称保留；相关战法使用惑敌、牵引、奔袭、援护、连锁、挫敌。状态名称仍使用原有混乱、护卫、连环等公共名称，不因战法改名而改变效果。

## 稀缺专属

仅以下16人持有专属：曹操、刘备、孙策、关羽、张飞、赵云、马超、黄忠、吕布、张辽、诸葛亮、庞统、郭嘉、司马懿、周瑜、陆逊。

专属所有等级可用，任何兵种均可携带和施放，不占普通名额。其他武将保留各自固定特技、合资格军略与普通战法。具体名称与效果见[武将表](design-tables/武将一览表.md)。

不限兵种不等于无条件施放：仍检查实际合法目标、射程、路径、控制、战意、冷却、调息及每场次数。需要伤兵、队友或特定敌情的能力仍须有真实作用对象。

## 保存、成长与验收

配置不受开局随机种子影响；换兵种使用对应固定配置，升级不增加或更换战法。普通模式、独立战役、玩家和AI共用同一算法；界面只查看，不提供自由换装或顺序优化。

当前版本保存全兵种配置和专属资格，并按当前人物属性、适性与正式分配校验；不兼容旧随机学习存档，不做迁移。新战斗重置次数，当前战斗读档保留次数、冷却与确定性随机状态。

验收覆盖832名武将、四兵科及八种升级兵种和八种装备形态、各适性、属性相等及魅力49/50边界、等级和种子独立、非均分兵力真实战斗、专属跨兵种施放与确定性续战。强度须另做同预算及独立种子对照，不沿用旧随机战法胜率。

## 后排打击与近战续战（规则65）

- 连弩齐射（连弩兵大战法）与攒射（井栏大战法）在2～5格内优先选择后排，连续射击两次；投石与黄忠百步穿杨同样优先后排。后排按当前兵种判定；无合法后排时攻击其他合法目标。嘲讽、最小射程、不可选中状态和近战拦截先于后排偏好，不能提前攻击预备队。
- 远射是长弓兵池中仅增加普攻射程的状态，不承担后排选敌。
- 戟兵大战法横扫、赵云七进七出：仅相邻直接攻击实际削减的敌军兵力计入吸血，30%救治自身已有伤兵、25%转为自身护盾。每次施放救治和护盾分别封顶本队兵力上限8%；减疗影响救治。护盾持续6日，同来源替换不叠加，仍受全队护盾总上限约束。
- 不计算护盾吸收、疑兵、城门、灼烧、反击、连环传导或护卫分担伤害。自身在反击中溃败后不能救治或生成护盾；没有伤兵仍可获得护盾。两格施放七进七出仍有原有效果，但不触发吸血护盾。
- 普通固定名额及16人专属名单不变；新增效果随现有次数、护盾、伤兵和贡献字段保存。当前版本存档保存此机制，规则版本更新时旧档需重新开始。

## 状态分工（规则75）

- 冲车池中的枯竭：近程谋略伤害与疫伤6回合，每场2次；井栏池中的短射：在4格内压制远程普攻射程，与井栏基础交战距离一致，仍受目标类型、嘲讽、免疫、战意、调息及次数限制。连弩兵的小战法池为破甲、救护、扰策，大战法池为连弩齐射、疫矢。
- 抛锚改为停止移动、普攻最大射程增加1，持续8回合；不提供减伤，不扩大战法范围，同类增程取最高。
- 西凉铁骑以定身2回合替换破甲，仍需控制概率与坚定判定；定身保留目标ZOC。霸王讨逆提供自身速攻6回合，并鼓舞所属军团在场的最多两队其他友军，各增加基础20战意；优先补足接近且尚未用尽的战法门槛，没有待补门槛时不授予鼓舞；后备与其他军团不能受益。
- 义勇援军以休整6回合、护盾替换即时救治、防御和战意；仅支援有真实伤兵者，休整每回合基础1.2%，护盾系数4%，均受战法威力影响。休整不凭空增兵，遵守疫伤减疗。
- 本轮为机制接入及初始参数，不作为同预算、独立种子的平衡结论。

## 名将协作（规则126）

- 长坂怒喝门槛65战意，混乱基础6回合，保持每场一次；关羽青龙偃月可利用命中前已有任意生效中的战斗异常追击。
- 鹰视狼顾保留削战意与疲弱，并施加破甲基础5回合，支持张郃等物理队友进攻；破甲不反过来提高本次开场伤害。
- 连环奇计50战意锁定目标周围1格，蓄势2回合；以0.6倍率攻击实际落点最多3队，不附加迟滞。至少两队合法存活目标连接3回合，后续直接兵力伤害的20%总额由同组其他敌军平分，传导不递归。无需灼烧；已有连环取较强效果，同强度保留原组，新组不继承较弱旧组的时限；死者、魔免与无敌目标不加入新组。
- 火烧连营对施放前已经灼烧的目标额外增加0.65伤害倍率；新施加的灼烧不能为同次施放铺垫。孙策鼓舞、陆逊铺火追击及庞统传导均通过当前公共处理器结算。
- 不绑定搭档姓名或阵营。阵容、站位及交战时机决定队友能否利用窗口；AI继续忽略羁绊组合的策略收益。定位及检验方法见[名将历史协作与战斗定位](名将历史协作与战斗定位.md)。
