# 固定战法与稀缺专属（规则64）

所有等级使用相同战法配置，取消随机学习、升级获取和等级保底。正式兵种配置与专属归属维护于 `data/design/assignments.mjs`，效果维护于 `data/design/tactics.mjs`。

## 普通战法

每种兵种固定提供一个武技威力小战法、一个谋略威力小战法、一个大战法。

| 适性 | 实际携带 |
| --- | --- |
| S | 两个小战法＋一个大战法 |
| A | 一个小战法＋一个大战法 |
| B、C | 一个小战法 |

只有一个小战法时，先比较武力与智力：武力高选武技，智力高选谋略。相同则比较统率与政治：统率高选武技，政治高选谋略。再次相同则看魅力，魅力≥50选谋略，否则选武技。比较主将属性，不使用部队人数或临时战斗增益。

| 兵种 | 武技小战法 | 谋略小战法 | 大战法 |
| --- | --- | --- | --- |
| 枪兵 | 方阵 | 挑衅 | 贯阵 |
| 戟兵 | 坚阵 | 挫志 | 浴血横扫 |
| 骑兵 | 疾驰 | 挫锐 | 冲阵 |
| 弓兵 | 火矢 | 振旅 | 乱射 |
| 弩兵 | 破甲 | 疑兵 | 穿阵狙射 |
| 投石 | 架设 | 震军 | 投石 |
| 冲车 | 坚阵 | 枯竭 | 冲车 |
| 井栏 | 架设 | 短射 | 穿阵狙射 |
| 舰船 | 抛锚 | 接舷 | 舷射 |

当前复用已有战法效果，不因改成固定配置而统一增加伤害或改变兵种属性。此表是当前组合，名称、数值及后续调整以[能力分配表](design-tables/能力分配一览表.md)和[战法表](design-tables/战法一览表.md)为准。

## 稀缺专属

仅以下16人持有专属：曹操、刘备、孙策、关羽、张飞、赵云、马超、黄忠、吕布、张辽、诸葛亮、庞统、郭嘉、司马懿、周瑜、陆逊。

专属所有等级可用，任何兵种均可携带和施放，不占普通名额。其他武将保留各自固定特技、合资格军略与普通战法。具体名称与效果见[武将表](design-tables/武将一览表.md)。

不限兵种不等于无条件施放：仍检查实际合法目标、射程、路径、控制、战意、冷却、调息及每场次数。需要伤兵、队友或特定敌情的能力仍须有真实作用对象。

## 保存、成长与验收

配置不受开局随机种子影响；换兵种使用对应固定配置，升级不增加或更换战法。普通模式、独立战役、玩家和AI共用同一算法；界面只查看，不提供自由换装或顺序优化。

当前版本保存全兵种配置和专属资格，并按当前人物属性、适性与正式分配校验；不兼容旧随机学习存档，不做迁移。新战斗重置次数，当前战斗读档保留次数、冷却与确定性随机状态。

验收覆盖832名武将、九种兵种、各适性、属性相等及魅力49/50边界、等级和种子独立、非均分兵力真实战斗、专属跨兵种施放与确定性续战。强度须另做同预算及独立种子对照，不沿用旧随机战法胜率。

## 后排打击与近战续战（规则65）

- 穿阵狙射（弩兵、井栏大战法）在2～5格内优先选择后排，连续射击两次；投石与黄忠百步穿杨同样优先后排。后排按当前兵种判定；无合法后排时攻击其他合法目标。嘲讽、最小射程、不可选中状态和近战拦截先于后排偏好，不能提前攻击预备队。
- 远射仍是仅增加普攻射程的效果库状态，不承担后排选敌。
- 戟兵大战法浴血横扫、赵云七进七出：仅相邻直接攻击实际削减的敌军兵力计入吸血，30%救治自身已有伤兵、25%转为自身护盾。每次施放救治和护盾分别封顶本队兵力上限8%；减疗影响救治。护盾持续6日，同来源替换不叠加，仍受全队护盾总上限约束。
- 不计算护盾吸收、疑兵、城门、灼烧、反击、连环传导或护卫分担伤害。自身在反击中溃败后不能救治或生成护盾；没有伤兵仍可获得护盾。两格施放七进七出仍有原有效果，但不触发吸血护盾。
- 普通固定名额及16人专属名单不变；新增效果随现有次数、护盾、伤兵和贡献字段保存。当前版本存档保存此机制，规则版本更新时旧档需重新开始。

## 状态分工（规则75）

- 冲车谋略小战法为枯竭：近程谋略伤害与疫伤6回合，每场2次；井栏为短射：压制远程普攻射程；弩兵为疑兵：转火救援，残血附带避战和避战间隔。
- 抛锚改为停止移动、普攻最大射程增加1，持续8回合；不提供减伤，不扩大战法范围，同类增程取最高。
- 西凉铁骑以定身2回合替换破甲，仍需控制概率与坚定判定；定身保留目标ZOC。霸王讨逆以自身速攻6回合替换破甲及自身减伤，保留邻近单队鼓舞。
- 义勇援军以休整6回合、护盾替换即时救治、防御和战意；仅支援有真实伤兵者，休整每回合基础1.2%，护盾系数4%，均受战法威力影响。休整不凭空增兵，遵守疫伤减疗。
- 本轮为机制接入及初始参数，不作为同预算、独立种子的平衡结论。
